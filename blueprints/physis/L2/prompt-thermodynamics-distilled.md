# Thermodynamics Distilled 레포지토리 제작 프롬프트

나는 "Thermodynamics Distilled" 레포지토리를 만들려고 해.
열역학 공식을 외워서 문제를 푸는 것과, **온도가 입자가 아니라 *분포*의 성질**임을 — 그리고 열역학이 미시 세부에 무관하게 작동하는 이유를 — 이해하는 것은 다르다.
"카르노 효율은 $1-T_c/T_h$"라고 외우는 것과, *왜 어떤 열기관도 이 한계를 넘을 수 없고* 작동물질과 무관한지를 제2법칙에서 유도하는 것은 다르다.
"엔트로피는 증가한다"고 말하는 것과, 엔트로피가 *상태함수*임을 증명하고 그것이 시간의 화살임을 아는 것은 다르다.
영구기관이 *왜* 불가능한지를 — 그리고 열역학이 어떻게 미시(통계역학)와 블랙홀·우주의 운명으로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "온도는 분포의 성질, 엔트로피는 시간의 화살 — 미시 세부에 무관하게 작동하는 거시 법칙"

**핵심 차별화**:
1. **온도·엔트로피를 거시에서 정확히** — 온도가 *분포의 성질*임을, 엔트로피가 상태함수임을 클라우지우스에서 유도(미시 의미는 통계역학으로 넘김)
2. **카르노 한계의 필연** — 제2법칙에서 최대 효율이 *작동물질 무관*하게 따라 나옴, 절대온도의 정의
3. **자유에너지와 변분** — 평형 = 자유에너지 최소, 르장드르 변환의 열역학판(→ L0 variational)
4. **영구기관의 불가능을 원리로** — 제1·2종 영구기관이 왜 불가능한지, 열역학의 금지 목록

**타겟 독자**:
- 열역학 공식은 쓰지만 온도가 *왜* 분포의 성질인지 설명 못 하는 사람
- 카르노 효율을 외우지만 *왜 넘을 수 없는지* 유도 못 하는 사람
- 엔트로피를 "무질서"로만 알고 상태함수·시간의 화살임을 모르는 사람
- 자유에너지가 *왜* "자유"이고 변분 원리와 어떻게 연결되는지 모르는 사람
- 열역학이 통계역학·블랙홀·우주론으로 어떻게 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — 에너지·일의 역학적 토대

### Chapter 1: 열역학이라는 수수께끼 (5개 문서)
- **열역학의 위상** — 미시 무지 위에서 작동하는 거시 법칙, 왜 이렇게 강력한가(물질의 세부에 무관)
- **온도란 무엇인가** — 온도는 입자가 아니라 *분포*의 성질, 열평형과 제0법칙
- **상태와 상태함수** — 평형 상태, 상태변수 vs 경로변수, 완전미분의 의미
- **일과 열** — 두 가지 에너지 전달, 둘 다 경로 의존, 내부에너지는 상태함수
- **준정적·가역·비가역** — 과정의 종류, 이상화의 의미와 한계(→ arrow-of-time 예고)

### Chapter 2: 제1법칙 — 에너지 보존 (5개 문서)
- **제1법칙** — $dU=\delta Q-\delta W$, 내부에너지의 존재와 에너지 보존(→ L1 보존법칙)
- **열용량과 비열** — $C_V$, $C_P$, 왜 둘이 다른가, 마이어 관계
- **이상기체** — 상태방정식, 내부에너지가 온도만의 함수인 이유
- **단열·등온 과정** — 각 과정의 일·열, $PV$ 도표와 폴리트로픽 과정
- **엔탈피와 열화학** — $H=U+PV$, 정압 과정, 반응열과 헤스 법칙

### Chapter 3: 제2법칙과 엔트로피 (6개 문서)
- **제2법칙의 두 진술** — 클라우지우스 vs 켈빈, 둘의 동치성 증명
- **카르노 정리** — 최대 효율, 가역 기관이 가장 효율적인 이유, 작동물질 무관
- **카르노 사이클** — 효율 $\eta=1-T_c/T_h$의 유도, 절대온도의 정의
- **엔트로피의 정의(거시)** — 클라우지우스 $dS=\delta Q_{\rm rev}/T$, 상태함수임의 증명
- **엔트로피 증가 법칙** — 고립계에서 $dS\ge0$, 비가역성의 척도(→ arrow-of-time)
- **영구기관의 불가능** — 제1종·제2종 영구기관, 왜 불가능한가(열역학의 금지 목록)

### Chapter 4: 열역학 퍼텐셜 (5개 문서)
- **자유에너지** — 헬름홀츠 $F$, 깁스 $G$, 왜 "자유"인가(추출 가능한 일)
- **르장드르 변환(열역학)** — $U\to F\to G\to H$, 자연변수의 선택(→ L0 variational 르장드르)
- **평형과 최소화** — 자유에너지 최소가 평형, 변분 원리의 열역학판(→ L0 variational)
- **맥스웰 관계** — 2계 미분의 대칭에서 나오는 관계식, 측정 가능량으로의 환원
- **화학 퍼텐셜과 깁스-듀헴** — 입자 수 변화, 다성분계, 상평형의 조건

### Chapter 5: 상과 상전이(거시) (5개 문서)
- **상과 상평형** — 고체·액체·기체, 클라우지우스-클라페롱 방정식
- **상도표** — $PT$ 도표, 삼중점·임계점, 1차 vs 연속 전이 예고(→ phase-transitions)
- **반데르발스 기체** — 실제 기체의 상태방정식, 임계점, 맥스웰 작도
- **잠열과 1차 전이** — 엔트로피 점프, 끓음·녹음의 열역학
- **제3법칙** — $T\to0$에서 엔트로피, 절대영도 도달 불가, 양자 효과 예고(→ L3)

### Chapter 6: 비평형·응용 (4개 문서)
- **열기관과 냉동기** — 효율·성능계수(COP), 실제 사이클(오토·디젤·랭킨)
- **비평형 열역학 맛보기** — 엔트로피 생성률, 온사거 상반관계(→ fluctuations)
- **열전달** — 전도·대류·복사, 흑체복사의 예고(→ L3, → L4)
- **열역학의 한계** — 작은 계·요동·정보가 끼어드는 곳(→ statistical-mechanics, fluctuations)

### Chapter 7: 종합·계산 (5개 문서)
- **카르노 효율 시뮬레이션** — 사이클 수치 계산, 효율 한계 확인(Python)
- **이상기체 과정 시각화** — $PV$·$TS$ 도표, 일·열 계산(Python)
- **반데르발스 임계점** — 상도표·맥스웰 작도 수치(Python)
- **거시→미시 다리** — 온도·엔트로피의 미시 의미 예고($S=k\ln W$)(→ statistical-mechanics)
- **종합** — "온도는 분포의 성질, 엔트로피는 화살"의 통합과 미시로의 다리(→ statistical-mechanics, L6)

## 🎨 스타일 가이드

1. **온도·엔트로피의 진짜 의미** — 온도는 분포의 성질, 엔트로피는 상태함수·시간의 화살. "무질서"는 통계역학에서 정밀화(→ statistical-mechanics)
2. **카르노 한계를 유도로** — 효율 상한이 *작동물질 무관*하게 제2법칙에서 따라 나옴을 보인다
3. **자유에너지 = 변분** — 평형이 자유에너지 최소임을, 르장드르가 L0 변분과 같은 구조임을 명시
4. **금지 목록을 분명히** — 영구기관·100% 효율·절대영도 도달이 *왜* 금지인지
5. **수치로 부순다** — 카르노 효율·반데르발스 임계점·$PV/TS$ 도표를 직접 계산
6. $PV$·$TS$ 도표·카르노 사이클·상도표는 다이어그램으로

## 🔬 검증 프로토콜

> 카르노 효율 한계 + 이상기체 사이클 + 반데르발스 임계점·맥스웰 작도.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 카르노 효율 한계
#    임의 사이클(오토/디젤)을 수치 적분해 효율을 구하고
#    같은 온도 범위의 카르노 효율 1−Tc/Th 와 대조 → 항상 ≤ 카르노 확인
import numpy as np
def carnot_eff(Tc, Th): return 1 - Tc/Th
# 임의 사이클 효율 < carnot_eff(Tc,Th) 임을 여러 사이클로 검증

# 2) 이상기체 과정 (PV·TS 도표)
#    등온·단열·등압·등적 과정의 일 W=∮P dV, 열 Q를 수치 계산
#    → PV 도표의 닫힌 면적 = 순일, TS 도표의 면적 = 순열 확인
def isothermal_work(n,R,T,V1,V2): return n*R*T*np.log(V2/V1)

# 3) 반데르발스 임계점 + 맥스웰 작도
#    (P + a/v²)(v − b) = RT 의 등온선; 임계점 ∂P/∂v=∂²P/∂v²=0 풀이
#    → 임계 상수 Pc, vc, Tc 와 보편비 Pc vc/(R Tc)=3/8 확인
#    → 불안정 구간을 맥스웰 등면적 작도로 평탄화(상공존)

# 4) 엔트로피 상태함수성 검증
#    두 경로(등온→단열 vs 단열→등온)로 같은 두 상태를 잇고
#    ∮ δQ_rev/T 를 계산 → 경로 무관(ΔS 동일) 확인 (상태함수)

# 5) 클라우지우스-클라페롱
#    상경계 dP/dT = L/(TΔv) 를 수치로, 물의 상도표 기울기와 대조

# 6) 거시→미시 예고
#    2상태계의 미시상태 수 W(E)에서 S=k ln W, T=(∂S/∂E)⁻¹ 계산
#    → 거시 온도가 미시 분포에서 나옴을 시연 (→ statistical-mechanics)
```

  미시: 1/T = ∂S/∂E  → 온도는 에너지 분포의 기울기 (→ statistical-mechanics)

카르노 한계 (작동물질 무관):
       Th ─── Q_h ──▶ [기관] ──▶ W
                         │
                      Q_c ▼
       Tc ◀───────────────
  η = W/Q_h = 1 − Q_c/Q_h
  제2법칙(가역) ⇒ Q_c/Q_h = Tc/Th
  ⇒ η_max = 1 − Tc/Th   (어떤 기관도 못 넘음, 물질 무관)
  ⇒ 절대온도가 이렇게 정의된다

엔트로피 — 상태함수, 시간의 화살:
  dS = δQ_rev/T   (가역 경로로 정의, 경로 무관 = 상태함수)
  고립계:  dS ≥ 0   (등호는 가역)
        ↓
  비가역성의 척도 — 깨진 컵은 안 합쳐진다 (→ arrow-of-time)

열역학 퍼텐셜 (르장드르 변환, → L0 variational):
  U(S,V)  ──−TS──▶  F(T,V)   헬름홀츠 (등온서 추출 가능 일)
       │              │+PV
      +PV             ▼
  H(S,P)  ──−TS──▶  G(T,P)   깁스 (등온등압 평형)
  평형 = 해당 퍼텐셜 최소  ⇐ 변분 원리의 열역학판

금지 목록 (영구기관 불가능):
  제1종 영구기관: 무에서 일 (제1법칙 위반)         ✗
  제2종 영구기관: 한 열원에서만 100% 일 (제2법칙)   ✗
  절대영도 도달 (제3법칙)                          ✗
