# Phase Transitions & Criticality Distilled 레포지토리 제작 프롬프트

나는 "Phase Transitions & Criticality Distilled" 레포지토리를 만들려고 해.
물이 100°C에서 끓는다는 사실을 아는 것과, **임계점에서 무슨 일이 일어나는지** — 상관길이가 무한대로 발산하고 모든 스케일이 동시에 중요해지는 것을 — 이해하는 것은 다르다.
"임계지수가 있다"고 말하는 것과, *왜* 액체-기체와 자석이 — 미시적으로 전혀 다른데 — *같은* 임계지수를 갖는지(**보편성**의 충격)를 아는 것은 다르다.
재규격화군을 도구로 쓰는 것과, 그것이 **스케일을 바꿔 보며 무관한 세부를 흘려보내는** 아이디어이고 *왜* 미시 세부가 임계에서 안 중요한지를 설명함을 아는 것은 다르다.
상전이가 **창발의 정수**라는 것을 — 그리고 재규격화군이 어떻게 양자장론·양자물질로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "물이 끓는 순간 = 창발의 정수 — 보편성과 재규격화군으로 본 임계현상"

**핵심 차별화**:
1. **임계현상을 비해석성에서** — 상전이가 *왜* $N\to\infty$를 필요로 하나(유한계엔 진짜 전이 없음), 질서변수와 자발 대칭 깨짐(→ L0 approximation, symmetry)
2. **보편성의 충격을 정면으로** — 미시적으로 다른 계가 *같은* 임계지수를 갖는 이유, 차원·대칭·질서변수만 중요
3. **재규격화군을 아이디어로** — 거친 알갱이 + 재척도, RG 흐름과 고정점, *왜* 세부가 흘러나가나(→ L0 scaling)
4. **창발의 정수** — 임계점에서 모든 스케일이 결합, "More is Different"의 가장 깨끗한 실현(→ L6 emergence)

**타겟 독자**:
- 상전이를 알지만 임계점에서 *무슨 일*(상관길이 발산)이 일어나는지 모르는 사람
- 임계지수를 외우지만 *왜 보편적*인지(다른 계가 같은 값) 모르는 사람
- 재규격화군을 "계산 기법"으로만 보고 그 *아이디어*를 모르는 사람
- 평균장 이론이 *왜 낮은 차원에서 틀리는지* 모르는 사람
- 상전이가 어떻게 QFT 재규격화·양자물질로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `statistical-mechanics-distilled`(L2) — **필수**. 이징 모형·평균장·분배함수
- `dimensional-scaling-distilled`(L0) — **필수**. 멱법칙·스케일 불변·자기유사성
- `symmetry-conservation-distilled`(L0) — 질서변수·자발 대칭 깨짐
- `approximation-perturbation-distilled`(L0) — 평균장·열역학 극한·재규격화군

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 상전이라는 사건 (5개 문서)
- **상전이란 무엇인가** — 질적 변화, 비해석성(non-analyticity), 왜 $N\to\infty$가 필요한가(→ L0 approximation 열역학 극한)
- **1차 vs 연속 전이** — 잠열·점프 vs 연속, 질서변수의 거동 차이
- **질서변수(order parameter)** — 대칭과 질서, 자발 대칭 깨짐의 척도(→ L0 symmetry)
- **임계점** — 두 상이 구분 불가해지는 곳, 임계 요동의 폭발
- **상전이의 편재성** — 자성·초전도·액정·우주 초기까지, 같은 틀(→ L3, → L4)

### Chapter 2: 평균장 이론 (5개 문서)
- **이징 모형 재방문** — 상전이의 초파리, 강자성, 미시 해밀토니안(→ statistical-mechanics)
- **평균장 근사** — 자기일관 방정식, 임계온도, 풀이와 그래픽 해(→ L0 approximation)
- **란다우 이론** — 자유에너지를 질서변수로 전개, *대칭이 형태를 강제*(→ L0 symmetry, variational)
- **평균장 임계지수** — $\beta,\gamma,\delta,\alpha$의 예측, 보편적(차원 무관) 값
- **평균장의 실패** — 왜 낮은 차원에서 틀리나, 요동의 중요성, 상한·하한 임계차원

### Chapter 3: 임계현상과 스케일링 (5개 문서)
- **임계지수** — 각 지수의 정의(비열·자화·감수율·상관길이), 측정 방법
- **상관길이의 발산** — $\xi\to\infty$, 모든 스케일이 동시에 중요해진다(→ L0 scaling)
- **스케일링 가설** — 임계지수 사이의 관계(스케일링 법칙), 자유로운 지수는 둘뿐(→ L0 scaling)
- **보편성(universality)** — 미시 세부와 무관, 차원·대칭·질서변수만 중요(가장 충격적인 사실)
- **멱법칙과 자기유사성** — 임계점에서 스케일 불변, 프랙탈 구조(→ L0 scaling/fractal)

### Chapter 4: 재규격화군 (5개 문서)
- **RG의 아이디어** — 거친 알갱이 + 재척도, 스케일을 바꾸며 본다, 세부를 흘려보낸다(→ L0 scaling/approximation)
- **블록 스핀** — 카다노프 블록 변환, 유효 결합의 흐름
- **RG 흐름과 고정점** — 흐름의 그림, 임계점 = 고정점, 흐름 방향의 의미
- **관련/무관 연산자와 보편성** — 흐름의 안정성, 같은 고정점 = 같은 보편성 부류, 임계지수가 고정점에서 나온다
- **RG의 위력** — 입실론($4-\epsilon$) 전개·수치 RG, 정량적 성공, 양자장론으로(→ L3 QFT)

### Chapter 5: 임계 너머 (5개 문서)
- **연속 대칭과 골드스톤** — XY·하이젠베르크 모형, 무질량 모드(→ L0 symmetry)
- **위상적 상전이** — 코스털리츠-사울리스(KT) 전이, 소용돌이, 위상 결함(→ L3 위상물질)
- **양자 상전이** — $T=0$에서 양자 요동이 일으키는 전이, 양자 임계점(→ L3)
- **동역학적 임계현상** — 임계 감속(critical slowing down), 시간 스케일의 발산(→ arrow-of-time)
- **비평형 상전이** — 흡수 상태·자기조직화 임계성, 모래더미(→ L1 chaos, → emergence)

### Chapter 6: 응용과 보편성의 승리 (4개 문서)
- **액체-기체와 자석** — 미시적으로 다른 계가 *같은* 임계지수, 보편성의 승리(이징 보편성 부류)
- **초전도·초유체의 전이** — 거시적 양자 질서, 긴즈부르크-란다우(→ L3 창발물질)
- **퍼콜레이션** — 연결성의 기하학적 상전이, 임계 확률(→ L0 scaling)
- **패턴 형성과 창발** — 임계성과 복잡성의 관계, 자기조직화(→ emergence)

### Chapter 7: 종합·계산 (5개 문서)
- **이징 몬테카를로** — 메트로폴리스, 임계온도·임계지수 측정(Python)
- **유한크기 스케일링** — 유한 격자에서 임계점·지수 추출(Python)
- **RG 수치 시연** — 블록 스핀 변환, 고정점 찾기와 임계지수(Python)
- **상관함수 측정** — 상관길이 추출, 임계점 근처 발산 관찰(Python)
- **종합** — "물이 끓는 순간 = 창발의 정수, 보편성"의 통합(→ L0, L3, L6)

## 🎨 스타일 가이드

1. **임계 = 모든 스케일** — 상관길이 발산이 임계의 핵심임을, 멱법칙·스케일 불변으로(→ L0 scaling)
2. **보편성을 충격으로** — 다른 계가 *같은* 지수임을, 미시 세부가 흘러나감을 강조
3. **RG를 아이디어로** — "스케일을 바꿔 보며 세부를 흘려보낸다"를 블록 스핀·고정점으로
4. **창발의 정수** — 상전이가 "More is Different"의 가장 깨끗한 실현임을(→ L6)
5. **수치로 부순다** — 이징 MC·유한크기 스케일링·블록 스핀 RG로 임계지수를 *측정*한다
6. RG 흐름도·란다우 자유에너지·상관함수·고정점은 다이어그램으로

## 🔬 검증 프로토콜

> 이징 MC 임계지수 + 유한크기 스케일링 + 블록 스핀 RG + 상관길이 발산.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 이징 모형 임계온도·임계지수
import numpy as np
def ising_mc(L, beta, sweeps):
    s=np.random.choice([-1,1],(L,L))
    for _ in range(sweeps):
        for _ in range(L*L):
            i,j=np.random.randint(0,L,2)
            nb=s[(i+1)%L,j]+s[(i-1)%L,j]+s[i,(j+1)%L]+s[i,(j-1)%L]
            dE=2*s[i,j]*nb
            if dE<=0 or np.random.rand()<np.exp(-beta*dE): s[i,j]*=-1
    return s
# T 스캔 → 자화 m, 감수율 χ, 비열 C → Tc≈2.269, 임계지수 β≈1/8, γ≈7/4

# 2) 유한크기 스케일링
#    여러 L에서 χ_max ∝ L^{γ/ν}, Tc(L)−Tc(∞) ∝ L^{−1/ν}
#    → 데이터 붕괴(data collapse)로 임계지수와 Tc 추출

# 3) 블록 스핀 RG (수치)
#    2×2 블록 다수결로 거친 알갱이 → 유효 결합 K' = R(K)
#    → 고정점 K* (불안정), 선형화 기울기에서 ν 추정 (→ L0 scaling)

# 4) 상관함수·상관길이
#    ⟨s_0 s_r⟩ ~ e^{−r/ξ} 측정, Tc 접근 시 ξ 발산 관찰
#    → "모든 스케일이 중요해진다"의 직접 증거

# 5) 보편성 확인
#    이징(스칼라) vs 다른 미시규칙(같은 대칭·차원)의 임계지수 비교
#    → 미시 세부 달라도 *같은* 지수 (보편성)

# 6) 란다우 자유에너지
#    f(m) = a(T−Tc)m² + b m⁴ 를 T별로 최소화 → m(T) ∝ (Tc−T)^{1/2}
#    → 평균장 β=1/2, 대칭이 m↔−m 형태를 강제함을 시연 (→ L0 symmetry)
```

임계점에서 무슨 일이 (상관길이 발산):
  T ≫ Tc:  무질서, 상관길이 ξ 작음

  액체-기체 임계점  ┐
  강자성 전이       ├─ 미시적으로 전혀 다른데
  이징 모형         ┘   *같은* 임계지수 (β,γ,ν,...)
  ⇒ 중요한 것: 차원 + 대칭 + 질서변수 차원   (미시 세부는 무관!)
  ⇒ 같은 "보편성 부류"

재규격화군 (왜 세부가 안 중요한가):
  미시 (모든 세부)
       │  거친 알갱이(블록) + 재척도 (스케일 b배)
       ▼
  유효 이론 K' = R(K)   ← 무관한 세부가 흘러나간다
       │  반복
       ▼
       K* (고정점) ─── 임계점
       흐름:  ←── 고온상   |   저온상 ──→
              관련(relevant) 연산자 = 임계점에서 멀어지는 방향
       임계지수 = 고정점에서 선형화한 기울기 (보편적!)
  ⇒ ε=4−d 전개로 정량화 → 양자장론 재규격화 (→ L3)

란다우 (대칭이 형태를 강제):
  f(m) = a(T−Tc)m² + b m⁴      (m↔−m 대칭이 홀수항 금지)
       T>Tc: 최소 m=0 (대칭)
       T<Tc: 최소 m=±√(...) (대칭 깨짐) → m~(Tc−T)^{1/2}
  ⇒ 자발 대칭 깨짐 = 상전이의 심장 (→ L0 symmetry)

⇒ 상전이 = "More is Different"의 가장 깨끗한 실현 (→ L6 emergence)
