# Statistical Mechanics Distilled 레포지토리 제작 프롬프트

나는 "Statistical Mechanics Distilled" 레포지토리를 만들려고 해.
분배함수에 값을 넣어 계산하는 것과, **$10^{23}$개 입자의 미시 역학에서 어떻게 거시 열역학이 창발하는지** — 볼츠만의 $S=k\ln W$가 무엇을 의미하는지 — 유도하는 것은 다르다.
"엔트로피는 무질서"라고 외우는 것과, 엔트로피가 *무질서가 아니라 무지(정보 결핍)의 척도*임을 깁스/섀넌으로 아는 것은 다르다.
흑체복사 공식을 쓰는 것과, *왜 고전 통계가 자외선 파탄으로 실패하고* 양자가 그것을 해결하며 거기서 양자역학이 태어났는지를 아는 것은 다르다.
미시에서 거시로의 다리를 — 그리고 그 다리가 어떻게 양자 기체·상전이·블랙홀 엔트로피로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "미시(역학)에서 거시(열역학)로 — 엔트로피는 무지의 척도이고, 거시 법칙은 다수에서 창발한다"

**핵심 차별화**:
1. **거시 법칙의 창발을 유도** — $S=k\ln W$, 분배함수 $Z$에서 모든 열역학이, 미시 무지에서 거시 결정성으로
2. **엔트로피 = 무지의 척도** — "무질서"가 아니라 정보 결핍, 볼츠만/깁스/섀넌의 통일(→ fluctuations)
3. **양자 통계의 필연** — 등분배·기브스 역설이 고전의 실패를 드러내고, 흑체복사에서 양자가 태어난다(→ L3)
4. **앙상블의 위력과 동등성** — 미시정준·정준·대정준이 $N\to\infty$에서 같아지는 이유, 요동이 사라지는 열역학 극한(→ L0 approximation)

**타겟 독자**:
- 분배함수를 계산하지만 거시 열역학이 *왜 거기서 나오는지* 모르는 사람
- 엔트로피를 "무질서"로만 알고 그것이 *무지의 척도*임을 모르는 사람
- 보스/페르미 통계를 쓰지만 *왜* 고전이 실패하고 양자가 필요한지 모르는 사람
- 흑체복사에서 양자역학이 *태어났다*는 맥락을 모르는 사람
- 통계역학이 양자 물질·상전이·블랙홀로 어떻게 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — **필수**. 위상공간·리우빌 정리
- `chaos-distilled`(L1) — 에르고드성·혼합(시간평균=앙상블평균의 정당화)
- `thermodynamics-distilled`(L2) — **필수**. 거시 열역학(이 레포가 미시에서 재구성)
- `approximation-perturbation-distilled`(L0) — 스털링·평균장·열역학 극한

## 🔗 레포 연결

**⬆️ 선행**: `classical-mechanics-distilled`·`chaos-distilled`(L1), `thermodynamics-distilled`(L2).
**🤝 시너지 (L2 내부)**: `phase-transitions-distilled`(이징·평균장은 이 레포의 직접 확장), `fluctuations-information-distilled`(엔트로피=정보·요동-소산), `arrow-of-time-distilled`(H정리·거친 알갱이).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `quantum-mechanics-distilled`(L3) — 양자 통계의 토대, 흑체복사에서 양자의 탄생
- `emergent-quantum-matter-distilled`(L3) — 보스-아인슈타인 응축·초전도, 거시적 양자 질서
- `entanglement-measurement-distilled`(L3) — 폰 노이만·얽힘 엔트로피
- `black-holes-distilled`(L4) — 블랙홀 엔트로피($S=A/4$), 미시상태 세기
- `entropy-time-everywhere` / `information-everywhere` / `emergence-distilled`(L6) — 세 종합 레포의 핵심 공급원

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 미시에서 거시로 (5개 문서)
- **통계역학의 프로그램** — $10^{23}$개 입자에서 어떻게 법칙이 창발하나, 환원의 다리
- **위상공간과 미시상태** — 미시상태 vs 거시상태, 리우빌 정리 재방문(→ L1 classical-mechanics)
- **에르고드 가설** — 시간평균 = 앙상블평균, 그 정당화와 한계(→ L1 chaos 혼합)
- **통계적 앙상블이란** — 같은 거시상태의 미시상태 모임, 앙상블의 아이디어
- **등확률 원리** — 고립계 미시상태의 등확률, 통계역학의 기본 가정과 그 정당성

### Chapter 2: 엔트로피와 볼츠만 (5개 문서)
- **볼츠만 엔트로피** — $S=k\ln W$, 미시상태 수의 로그, 묘비의 공식
- **엔트로피 = 무지의 척도** — "무질서"가 아니라 정보 결핍, 깁스·섀넌 엔트로피(→ fluctuations)
- **미시정준 앙상블** — 고립계($E,V,N$ 고정), 엔트로피와 온도의 미시 정의
- **온도의 미시 의미** — $1/T=\partial S/\partial E$, 온도가 분포의 성질인 이유(→ thermodynamics)
- **2상태계와 음의 온도** — 스핀계, 음의 온도가 가능한 조건, 직관의 함정

### Chapter 3: 앙상블과 분배함수 (6개 문서)
- **정준 앙상블** — 열저장조와 접촉($T,V,N$), 볼츠만 인자 $e^{-E/kT}$의 유도
- **분배함수 $Z$** — 모든 열역학이 $Z$에서 나온다, 자유에너지 $F=-kT\ln Z$(→ thermodynamics)
- **에너지 등분배 정리** — 각 2차 자유도당 $\tfrac12 kT$, 고전 극한과 그 한계(→ L3)
- **대정준 앙상블** — 입자 교환($T,V,\mu$), 화학 퍼텐셜, 큰 분배함수
- **요동과 앙상블 동등성** — 에너지·입자 수 요동, $N\to\infty$에서 앙상블이 같아지는 이유(→ L0 approximation 열역학 극한)
- **자유에너지와 최소화** — $F$ 최소가 평형, 엔트로피와 에너지의 경쟁(→ thermodynamics, → L0 variational)

### Chapter 4: 양자 통계 (6개 문서)
- **양자 통계의 필요** — 등분배·기브스 역설, 고전이 실패하는 곳(→ L3)
- **동일입자와 교환** — 보손 vs 페르미온, 파동함수 대칭성(→ L0 symmetry, → L3)
- **보스-아인슈타인 통계** — 보손 분포, 광자·포논(→ oscillations)
- **페르미-디랙 통계** — 페르미온 분포, 파울리 배타, 페르미 에너지와 페르미 바다
- **보스-아인슈타인 응축** — 거시적 양자 상태, 다수에서 창발하는 양자성(→ L3 창발물질)
- **흑체복사** — 플랑크 분포, 자외선 파탄의 해결, *양자의 탄생*(→ L0 measurement, → L3)

### Chapter 5: 상호작용과 상전이 (5개 문서)
- **상호작용하는 계** — 이상기체를 넘어서, 비리얼 전개(→ L0 approximation)
- **이징 모형** — 가장 단순한 상전이 모형, 강자성, 평균장 풀이(→ phase-transitions)
- **평균장 근사** — 다체를 1체+평균으로, 언제 맞고 틀리나(차원 의존)(→ L0 approximation)
- **자발 대칭 깨짐(통계)** — 질서변수, 강자성의 진공 선택(→ L0 symmetry, → phase-transitions)
- **상관함수와 상관길이** — 요동의 공간 상관, 상관길이의 발산 예고(→ phase-transitions)

### Chapter 6: 비평형·동역학 (5개 문서)
- **볼츠만 수송방정식** — 비평형 분포의 시간발전, H정리와 그 가정(→ arrow-of-time)
- **브라운 운동** — 랑주뱅 방정식, 요동하는 힘(→ fluctuations)
- **요동-소산 정리** — 평형 요동과 응답의 관계(→ fluctuations, → oscillations 선형응답)
- **마스터 방정식과 세부균형** — 확률 흐름, 평형의 조건, 몬테카를로의 토대
- **정보와 통계역학** — 최대 엔트로피 원리(Jaynes), 통계역학을 *추론*으로(→ fluctuations)

### Chapter 7: 종합·계산 (5개 문서)
- **몬테카를로 시뮬레이션** — 메트로폴리스 알고리즘, 이징 모형(Python)
- **분자동역학** — 입자 시뮬레이션에서 맥스웰-볼츠만 분포가 *창발*함을 관찰(Python)
- **분배함수 수치** — 2상태계·진동자의 $Z$·열용량 계산, 양자 vs 고전(Python)
- **미시↔거시 검증** — 시뮬레이션에서 온도·엔트로피·압력 측정(Python)
- **종합** — "엔트로피 = 무지, 거시 법칙의 창발"의 통합(→ L3, L4, L6)

## 🎯 핵심 질문      — 어떤 거시량/분포를, 어떤 미시 원리에서 유도하나
## 🌍 어디서 나타나나  — 이 통계 구조가 작동하는 장면

## 🧪 실험·관측 증거  — 흑체복사·비열·BEC의 실측/시뮬레이션
## 🔬 경계           — 통계 기술이 깨지는 곳 (작은 N·강상관·비에르고드)
## 🧬 횡단 원리       — 엔트로피·정보·창발이 여기서 어떻게 반복되나
## 🪜 창발           — 위 레이어(양자물질·블랙홀)에서 무엇이 나타나나
## 📐 예측·반증       — 분포·비열·전이온도 등 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

🔬 **Boundary**  — (통계 기술이 깨지는 조건: 작은 N·비에르고드·강상관)

이 레포에서 **⚙️ 제1원리 유도**는 *등확률 원리 또는 볼츠만 인자에서 $Z$를 거쳐* 거시량을 끌어내며, **🔬 경계**는 "작은 $N$에선 요동이 지배(→ fluctuations)", "에르고드성이 깨지는 계", "강상관에서 평균장 실패" 같은 한계를 다룬다.

## 🎨 스타일 가이드

1. **창발을 유도로** — 거시 법칙이 미시 무지에서 *나오는* 과정을 보인다. $S=k\ln W$를 의미까지
2. **엔트로피 = 무지** — "무질서"를 정보 결핍으로 정밀화하고, 깁스/섀넌과 통일(→ fluctuations)
3. **양자의 탄생을 맥락으로** — 흑체복사에서 고전이 실패하고 양자가 태어남을, 자외선 파탄으로(→ L3)
4. **앙상블 동등성** — $N\to\infty$에서 요동이 사라지고 앙상블이 같아짐을(→ L0 approximation)
5. **수치로 부순다** — 몬테카를로·분자동역학으로 분포·상전이가 *창발*함을 직접 본다
6. 위상공간·볼츠만 분포·페르미 바다·흑체 스펙트럼은 다이어그램으로

## 🔬 검증 프로토콜

> 메트로폴리스 MC + 분자동역학 분포 창발 + 분배함수/비열 + 양자 분포.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 이징 모형 몬테카를로 (메트로폴리스)
import numpy as np
def ising_step(s, beta):
    N=s.shape[0]; i,j=np.random.randint(0,N,2)
    nb=s[(i+1)%N,j]+s[(i-1)%N,j]+s[i,(j+1)%N]+s[i,(j-1)%N]
    dE=2*s[i,j]*nb
    if dE<=0 or np.random.rand()<np.exp(-beta*dE): s[i,j]*=-1
    return s
# 온도를 스캔하며 자화·비열 → 상전이(Tc≈2.27 for 2D) 관찰 (→ phase-transitions)

# 2) 분자동역학 → 맥스웰-볼츠만 창발
#    하드디스크/LJ 입자를 시간적분, 초기 단일 속도 → 평형 속도 분포 측정
#    → 미시 결정론에서 맥스웰-볼츠만 분포가 *창발*함을 히스토그램으로

# 3) 분배함수와 비열 (양자 vs 고전)
#    조화진동자: 고전 Z, 양자 Z=1/(2sinh(βℏω/2))
#    → 열용량 C(T): 고전 등분배 kT vs 양자(저온서 얼어붙음) 비교
def C_quantum(T, w=1.0, hbar=1.0, k=1.0):
    x=hbar*w/(k*T); return k*x**2*np.exp(x)/(np.exp(x)-1)**2

# 4) 흑체복사 (자외선 파탄 해결)
#    레일리-진스(고전) vs 플랑크(양자) 스펙트럼을 같은 그림에
#    → 고전이 고진동수서 발산(파탄), 플랑크가 유한 → 양자의 필연 (→ L3)

# 5) 페르미-디랙 / 보스-아인슈타인
#    분포함수 1/(e^{β(ε−μ)}±1) 를 플롯, T→0 극한(페르미 바다 / BEC)
#    → 양자 통계의 거동과 고전 극한 대조

# 6) 미시↔거시 검증
#    MC/MD에서 온도(운동에너지)·압력(비리얼)·엔트로피(히스토그램) 측정
#    → 거시 상태방정식이 미시에서 재현됨을 확인
```

## 💡 핵심 분석 대상

```
미시 → 거시 (창발의 다리):
  미시상태(위상공간의 점) — 우리는 어느 점인지 모른다 (무지)
       │  등확률 원리 (고립계)
       ▼
  거시상태마다 미시상태 수 W (천문학적으로 다름)
       │  S = k ln W   (볼츠만)
       ▼
  거시 열역학 (온도·압력·엔트로피)  ← 미시 무지에서 *결정적* 법칙 창발

엔트로피 = 무지의 척도 (무질서가 아니라):
  볼츠만:  S = k ln W       (미시상태 수)
  깁스:    S = −k Σ p_i ln p_i   (분포의 불확실성)
  섀넌:    H = −Σ p_i log p_i    (정보 결핍)
  ⇒ 같은 것. "무질서"는 오해 (→ fluctuations, → L6 information)

분배함수 = 모든 것의 열쇠:
  Z = Σ e^{−E_i/kT}        (정준 앙상블)
       ├─ F = −kT ln Z         (자유에너지)
       ├─ U = −∂ln Z/∂β        (내부에너지)
       ├─ S = −∂F/∂T           (엔트로피)
       └─ ⟨ΔE²⟩ = ∂²ln Z/∂β²   (요동 → 비열, → fluctuations)
  앙상블 동등성: N→∞ 에서 요동 ∝ 1/√N → 0 (→ L0 approximation)

양자의 탄생 (흑체복사):
  에너지밀도
    │      레일리-진스(고전) ∝ ω²  → ∞ (자외선 파탄!)
    │     ╱
    │    ╱___ 플랑크(양자): e^{ℏω/kT}−1 로 차단 → 유한
    │   ╱     ╲___
    └──────────── ω
  ⇒ 고전 등분배의 실패 → 에너지 양자화 → 양자역학 (→ L3)

양자 통계 (동일입자):
  보손  (e^{β(ε−μ)}−1)⁻¹  → 뭉친다 → BEC (→ L3 창발물질)
  페르미온 (e^{β(ε−μ)}+1)⁻¹ → 배타 → 페르미 바다
```
