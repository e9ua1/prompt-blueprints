# Fluctuations & Information Distilled 레포지토리 제작 프롬프트

나는 "Fluctuations & Information Distilled" 레포지토리를 만들려고 해.
"평형은 정적이다"라고 생각하는 것과, **평형에서도 거시량이 끊임없이 떤다**는 것 — 그리고 그 요동이 *마찰(소산)과 깊이 연결*되어 있다는 요동-소산 정리를 — 이해하는 것은 다르다.
맥스웰의 도깨비가 제2법칙을 위반하는 것처럼 *보이는* 것과, **왜 도깨비가 결국 졌는지**(정보를 지우면 열이 난다는 란다우어 원리)를 아는 것은 다르다.
"정보는 추상적"이라고 여기는 것과, **정보가 물리량**임을 — 1비트를 지우면 최소 $kT\ln2$의 열이 나고, 정보가 일을 뽑아낼 수 있음을 — 아는 것은 다르다.
정보와 열역학이 하나라는 깊은 사실을 — 그리고 그것이 양자정보·블랙홀·홀로그래피의 "it-from-bit"로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "맥스웰의 도깨비는 왜 졌나 — 요동과 소산은 하나이고, 정보는 물리다"

**핵심 차별화**:
1. **요동-소산 정리** — 평형 요동과 외부 자극에 대한 응답(마찰)이 *같은 뿌리*임을, 브라운 운동·아인슈타인 관계에서(→ oscillations 선형응답)
2. **엔트로피 = 정보** — 볼츠만/깁스/섀넌의 통일, 최대 엔트로피 원리(추론으로서의 통계역학)(→ statistical-mechanics)
3. **맥스웰 도깨비의 진짜 해결** — 측정이 아니라 *기억 소거*가 비용, 란다우어 원리($kT\ln2$/비트)
4. **정보는 물리적이다** — 정보가 일을 뽑고 열을 내는 물리량, 계산의 열역학, it-from-bit로의 다리(→ L4, L5, L6)

**타겟 독자**:
- 평형을 "정적"으로 보고 요동의 존재와 의미를 모르는 사람
- 마찰(소산)과 요동이 *같은 뿌리*임(요동-소산)을 모르는 사람
- 맥스웰 도깨비가 *왜* 제2법칙을 안 깨는지 정확히 모르는 사람
- 정보를 추상으로만 보고 그것이 *물리량*(란다우어)임을 모르는 사람
- 정보 열역학이 양자정보·블랙홀·홀로그래피로 어떻게 *이어지는지* 보고 싶은 사람

**선행 학습**:

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 요동이라는 창문 (4개 문서)
- **요동의 의미** — 평형은 정적이 아니다, 거시량이 끊임없이 떤다, 요동이 미시를 드러낸다
- **브라운 운동** — 꽃가루의 춤, 아인슈타인의 설명, 원자 실재의 증거(페랭)
- **랑주뱅 방정식** — 요동하는 힘 + 마찰, 확률적 동역학의 골격
- **요동의 스케일** — 상대 요동 $\propto 1/\sqrt N$, 큰 계에서 사라지는 이유(→ statistical-mechanics)

### Chapter 2: 요동-소산 정리 (5개 문서)
- **요동과 응답** — 평형 요동이 외부 자극에 대한 응답을 결정(→ oscillations 선형응답)
- **요동-소산 정리** — 마찰(소산)과 요동의 깊은 관계, 같은 뿌리, 아인슈타인 관계
- **확산과 이동도** — $D=\mu kT$, 브라운 운동에서 확산계수, 미시-거시 연결
- **존슨-나이퀴스트 잡음** — 저항의 열잡음, 회로의 근본 요동(→ L0 measurement)
- **그린-쿠보 관계** — 수송계수를 요동의 시간 상관으로, 비평형을 평형 요동으로

### Chapter 3: 정보와 엔트로피 (5개 문서)
- **섀넌 엔트로피** — 정보의 척도, 불확실성의 정량화, 비트
- **엔트로피 = 무지** — 볼츠만/깁스/섀넌의 통일, "무질서"가 아니다(→ statistical-mechanics)
- **최대 엔트로피 원리** — Jaynes, 통계역학을 *추론*으로, 편향 없는 분포
- **상호정보와 상관** — 두 계가 공유하는 정보, 상관의 정보이론적 척도
- **정보는 물리적이다** — 정보가 추상이 아니라 물리량인 이유의 예고(→ 란다우어, → L6)

### Chapter 4: 맥스웰의 도깨비 (5개 문서)
- **맥스웰의 도깨비** — 제2법칙을 위반하는 사고실험, 150년의 수수께끼
- **실라드 엔진** — 1비트 정보로 $kT\ln2$의 일을 뽑는다, 정보=일의 등가
- **측정의 비용?** — 측정이 비용이라는 초기 해결(브릴루앙)과 그 한계
- **란다우어 원리** — *정보를 지우면* $kT\ln2$의 열이 난다, 진짜 해결
- **도깨비가 진 이유** — 기억 소거의 불가피한 비용, 정보와 열역학의 통합

### Chapter 5: 정보 열역학 (5개 문서)
- **계산의 열역학** — 가역 계산, 비트 연산의 에너지 하한, 비가역 게이트의 비용
- **란다우어 한계와 실제** — 현대 컴퓨터의 에너지, 한계까지의 거리(→ IQ AI Lab 교차)
- **되먹임과 정보 엔진** — 측정+되먹임으로 일 추출, 정보를 포함한 일반화 제2법칙
- **요동 정리와 정보** — 정보를 포함한 야르진스키·사가와-우에다(→ arrow-of-time)
- **정보의 물리적 한계** — 베켄슈타인 한계 예고, 정보 밀도의 상한(→ L4 black holes)

### Chapter 6: 양자 요동과 정보 (5개 문서)
- **양자 요동** — 영점 운동, 진공 요동, 불확정성과 요동(→ L1 field-theory, → L3)
- **카시미르 효과** — 진공 요동의 힘, "빈 공간"의 압력, 측정된 진공(→ L3)
- **양자 정보 맛보기** — 큐비트, 폰 노이만 엔트로피 $S=-\text{Tr}\rho\ln\rho$(→ L3 quantum information)
- **얽힘 엔트로피** — 양자 상관의 정보, 면적 법칙 예고(→ L3, → L5 holography)
- **양자 측정과 정보** — 측정이 정보를 얻고 엔트로피를 바꾼다(→ L3, → arrow-of-time)

### Chapter 7: 종합·계산 (4개 문서)
- **브라운 운동 시뮬레이션** — 랑주뱅 방정식, 확산계수 측정, 아인슈타인 관계 검증(Python)
- **실라드 엔진·란다우어** — 정보-일 변환과 소거 비용의 수치 시연(Python)
- **요동-소산 검증** — 평형 요동의 상관함수와 응답함수를 대조(Python)
- **종합** — "맥스웰 도깨비가 진 이유 = 정보는 물리"의 통합과 it-from-bit로의 다리(→ L4, L5, L6)

## 🎨 스타일 가이드

1. **요동 = 소산** — 평형 요동과 마찰이 *같은 뿌리*임을 요동-소산 정리로(→ oscillations)
2. **정보는 물리** — 정보가 일을 뽑고 열을 내는 물리량임을, 란다우어·실라드로 구체적으로
3. **도깨비의 진짜 패인** — 측정이 아니라 *기억 소거*가 비용임을 정확히(흔한 오답 교정)
4. **it-from-bit로 다리** — 정보 열역학이 블랙홀·홀로그래피로 이어짐을 예고(→ L4, L5, L6)
5. **수치로 부순다** — 브라운 운동·실라드 엔진·요동-소산을 직접 시뮬레이션
6. 랑주뱅 궤적·요동-소산·실라드 사이클·란다우어 소거는 다이어그램으로

## 🔬 검증 프로토콜

> 랑주뱅 브라운 운동 + 아인슈타인 관계 + 실라드/란다우어 + 요동-소산 대조.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 브라운 운동 (랑주뱅) + 확산계수
import numpy as np
def langevin(N=100000, dt=0.01, gamma=1.0, kT=1.0, m=1.0):
    v=0.0; x=0.0; xs=[]
    c=np.sqrt(2*gamma*kT/dt)
    for _ in range(N):
        v += (-gamma*v/m + c*np.random.randn()/m)*dt
        x += v*dt; xs.append(x)
    return np.array(xs)
# MSD ⟨x²⟩ = 2Dt 에서 D 측정 → 아인슈타인 D=kT/γ 와 대조

# 2) 아인슈타인 관계 검증
#    여러 온도/마찰에서 D를 측정 → D·γ/kT = 1 (요동-소산의 가장 단순한 형태)

# 3) 실라드 엔진 (정보 → 일)
#    1분자 상자: 측정으로 어느 쪽인지 1비트 획득 → 등온 팽창으로 kT ln2 일 추출
#    → 정보 1비트 = kT ln2 일의 등가를 수치로

# 4) 란다우어 소거 비용
#    이중우물에서 비트 소거(두 상태 → 한 상태)를 준정적으로 수행
#    → 방출 열 ≥ kT ln2 확인 (소거가 비용, 측정이 아님)

# 5) 요동-소산 정리 직접 검증
#    평형 시계열의 자기상관 C(t)=⟨v(0)v(t)⟩ 와
#    작은 힘에 대한 응답함수 χ(t) 를 각각 측정 → FDT 관계 대조

# 6) 존슨-나이퀴스트 잡음
#    RC 회로의 열잡음 전압 분산 ⟨V²⟩=kT/C 를 시뮬레이션으로 확인
#    → 회로의 근본 요동(→ L0 measurement)
```

  ⇒ 마찰(소산)과 요동은 분리 불가 (→ oscillations 선형응답)

엔트로피 = 정보 (세 얼굴, 한 본질):
  볼츠만 S=k ln W  =  깁스 −kΣp ln p  =  섀넌 H=−Σp log p
  최대 엔트로피 원리(Jaynes): 아는 것만 제약, 나머진 편향 없이
  ⇒ 통계역학 = 추론 (→ statistical-mechanics)

맥스웰의 도깨비가 진 이유:
  도깨비: 빠른/느린 분자 분류 → 온도차 생성 → 제2법칙 위반?!
       ↓ 실라드 엔진
  1비트 정보 → kT ln2 일 추출 (정보 = 일)
       ↓ 측정이 비용? (브릴루앙) — 틀린 해결
       ↓ 란다우어 (진짜 해결)
  *기억을 지울 때* kT ln2 열 방출 (소거가 비용!)
  ⇒ 한 사이클 닫으려면 기억 소거 필수 → 제2법칙 회복
  ⇒ 정보는 물리적이다

정보 열역학 → it-from-bit:
  비트 소거 ≥ kT ln2          (란다우어, → AI Lab 계산의 열역학)
       │
  베켄슈타인 한계: 정보 ≤ 면적/4 (→ L4 black holes)
       │
  얽힘 엔트로피 ~ 경계 면적     (→ L5 holography)
       ▼
  "It from Bit" — 정보가 물리의 새 바닥인가? (→ L6 information-everywhere)
