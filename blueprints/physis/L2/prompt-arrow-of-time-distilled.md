# Arrow of Time Distilled 레포지토리 제작 프롬프트

나는 "Arrow of Time Distilled" 레포지토리를 만들려고 해.
"엔트로피가 증가하니까 시간이 흐른다"고 말하는 것과, **미시 법칙은 시간 대칭인데 거시 세계는 왜 한 방향인지** — 그 비대칭이 법칙이 아니라 *초기조건*에서 온다는 것을 — 이해하는 것은 다르다.
"깨진 컵은 안 합쳐진다"고 관찰하는 것과, 로슈미트 역설(모든 속도를 뒤집으면?)과 푸앵카레 재귀(유한계는 결국 돌아온다)에 *어떻게 답하는지* 아는 것은 다르다.
볼츠만의 H정리를 외우는 것과, *어디서 시간 비대칭이 몰래 들어왔는지*(분자 카오스 가정)를 짚어내는 것은 다르다.
시간의 화살이 법칙이 아니라 초기조건(과거 가설)이라는 깊은 사실을 — 그리고 그것이 빅뱅·블랙홀·양자 측정과 어떻게 얽히는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "시간의 화살은 법칙이 아니라 초기조건이다 — 미시 대칭에서 거시 비가역성이 어떻게 나오는가"

**핵심 차별화**:
1. **법칙 대칭 vs 거시 비대칭의 정면 대결** — 미시 가역성과 거시 비가역성의 모순을 회피하지 않고, 로슈미트·푸앵카레의 도전에 답한다
2. **비가역성의 통계적 기원** — 미시상태 수의 천문학적 비대칭, 거친 알갱이(coarse-graining), 혼합(mixing)이 만드는 *실효적* 비가역성(→ L1 chaos)
3. **과거 가설(Past Hypothesis)** — 화살의 진짜 뿌리가 우주의 낮은 초기 엔트로피임을, 중력과 빅뱅에서(→ L4)
4. **양자·정보와 시간** — 결잃음·CP 위반·기록의 비대칭, 정보가 화살과 얽히는 곳(→ L3, → fluctuations)

**타겟 독자**:
- "엔트로피 증가 = 시간"을 말하지만 *왜* 그런지, 비대칭이 어디서 오는지 모르는 사람
- 로슈미트 역설·푸앵카레 재귀를 모르거나 답하지 못하는 사람
- H정리를 외우지만 *분자 카오스 가정*에 비대칭이 숨었음을 모르는 사람
- 시간의 화살이 *초기조건*(과거 가설)의 문제임을 모르는 사람
- 화살이 어떻게 우주론·블랙홀·양자 측정과 *얽히는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — **필수**. 시간 가역적 미시 법칙
- `chaos-distilled`(L1) — **필수**. 혼합(mixing)·민감성
- `statistical-mechanics-distilled`(L2) — **필수**. 엔트로피·H정리·거친 알갱이
- `symmetry-conservation-distilled`(L0) — T·CP 대칭

## 🔗 레포 연결

**⬆️ 선행**: `classical-mechanics-distilled`·`chaos-distilled`(L1), `statistical-mechanics-distilled`(L2).
**🤝 시너지 (L2 내부)**: `thermodynamics-distilled`(제2법칙·엔트로피 증가), `fluctuations-information-distilled`(맥스웰 도깨비·요동 정리·란다우어).

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 시간의 화살이라는 역설 (4개 문서)
- **화살의 수수께끼** — 미시 법칙은 시간 대칭인데 거시는 한 방향, 다섯 개의 화살(열역학·우주론·심리·복사·인과)의 정렬
- **시간 가역적 미시 법칙** — 뉴턴·맥스웰·슈뢰딩거는 $t\to-t$ 대칭(거의), 무엇이 깨지나(→ L1, L3)
- **비가역성의 관찰** — 깨진 컵·섞인 잉크·식는 커피, 왜 거꾸로는 안 보이나
- **화살의 핵심 질문** — 법칙이 대칭이면 비대칭은 *어디서* 오나(초기조건이라는 답의 예고)

### Chapter 2: 로슈미트와 푸앵카레의 도전 (4개 문서)
- **볼츠만의 H정리** — 비가역성을 미시에서 유도하려는 시도, $H$가 단조 감소
- **로슈미트 역설** — 모든 속도를 뒤집으면? 시간 대칭이 H정리의 비가역성과 모순
- **푸앵카레 재귀 정리** — 유한계는 결국 초기상태 근처로 돌아온다, 재귀 시간의 천문학적 크기
- **가정의 정체** — Stosszahlansatz(분자 카오스 가정), *어디서* 시간 비대칭이 몰래 들어왔나

### Chapter 3: 통계적 비가역성 (5개 문서)
- **미시상태 수의 비대칭** — 거시상태마다 미시상태 수가 천문학적으로 다르다(→ statistical-mechanics)
- **왜 엔트로피는 증가하나** — 확률적 논증, 압도적으로 많은 쪽으로 흘러간다(법칙이 아니라 셈)
- **거친 알갱이(coarse-graining)** — 거시 기술이 정보를 버린다, 실효적 비가역성의 기원
- **혼합(mixing)과 카오스** — 위상공간 혼합이 만드는 실효적 비가역성(→ L1 chaos)
- **원리적 가역 vs 실용적 불가역** — 정보 추적의 불가능, "되돌릴 수 있다"의 공허함

### Chapter 4: 초기조건과 과거 가설 (4개 문서)
- **과거 가설(Past Hypothesis)** — 우주의 초기 엔트로피가 낮았다는 가정, 화살의 진짜 뿌리
- **왜 초기 엔트로피가 낮았나** — 빅뱅·중력의 역할, 균질했던 초기 우주(→ L4 cosmology)
- **중력과 엔트로피의 역설** — 중력계에선 *뭉칠수록* 엔트로피 증가, 균질=저엔트로피(→ L4 black holes)
- **화살의 우주론적 기원** — 열역학 화살이 우주론 화살에서 나온다(→ L4)

### Chapter 5: 양자와 시간 (5개 문서)
- **양자 측정과 비가역성** — 결잃음(decoherence)이 만드는 화살, 측정의 비가역성(→ L3 entanglement)
- **T 대칭과 CP 위반** — 약력의 시간 비대칭, CPT 정리(→ L0 symmetry, → L3 표준모형)
- **양자 엔트로피** — 폰 노이만 엔트로피, 얽힘 엔트로피의 증가(→ L3 quantum information)
- **결잃음과 고전성의 창발** — 왜 거시는 고전적이고 비가역적인가(→ L3)
- **정보와 시간** — 기록·기억이 한 방향인 이유, 인과의 화살(→ fluctuations 란다우어)

### Chapter 6: 비평형과 요동 정리 (5개 문서)
- **비평형 정상상태** — 흐름이 있는 평형 아닌 상태, 지속적 엔트로피 생성
- **요동 정리(Fluctuation Theorem)** — 작은 계에선 엔트로피 *감소*도 일어난다, 그 확률의 정량(Crooks)
- **야르진스키 등식** — 비평형 일과 자유에너지 차이, 정밀 검증(→ fluctuations)
- **맥스웰 도깨비와 시간** — 정보가 화살과 얽히는 곳(→ fluctuations)
- **생명과 엔트로피** — 국소 엔트로피 감소, 산일구조(dissipative structure)(→ emergence)

### Chapter 7: 종합·계산 (5개 문서)
- **확산 시뮬레이션** — 잉크 섞임의 비가역성, 거친 알갱이 엔트로피의 증가(Python)
- **로슈미트 수치 실험** — 속도 반전과 수치 오차, *실용적* 비가역성의 시연(Python)
- **요동 정리 검증** — 작은 계의 일 분포, Crooks 대칭 관계(Python)
- **푸앵카레 재귀 수치** — 작은 계의 재귀, 재귀 시간의 $N$ 의존 스케일링(Python)
- **종합** — "화살은 법칙이 아니라 초기조건"의 통합(→ L4, L3, L6)

→ **총 32개 문서** 목표.

## 🎨 스타일 가이드

1. **법칙 ≠ 비대칭** — 미시 가역성을 정직하게 인정하고, 비대칭이 *초기조건*에서 옴을 보인다. "법칙이 화살을 만든다" 금지
2. **로슈미트·푸앵카레에 답한다** — 두 도전을 회피하지 않고, 통계적·실용적 답을 제시
3. **가정을 짚는다** — H정리의 분자 카오스 가정처럼, *어디서 비대칭이 들어왔는지* 명시
4. **과거 가설을 정직하게** — 화살의 궁극 뿌리가 우주론(미해결의 영역)임을 표시(→ L4)
5. **수치로 부순다** — 로슈미트 반전·요동 정리·푸앵카레 재귀를 직접 시뮬레이션
6. 위상공간 혼합·미시상태 수 비대칭·요동 정리 분포는 다이어그램으로

```python
# 1) 확산의 비가역성 + 거친 알갱이 엔트로피

def diffuse(grid, steps):
    S=[]
    for _ in range(steps):
        # 입자 무작위 걷기(결정론적 가역 규칙도 가능); 거친 알갱이 격자로 분할
        # 각 셀 점유확률 p_i → S = −Σ p_i ln p_i (coarse-grained)
        S.append(coarse_entropy(grid))
    return S   # → 단조 증가(섞임), 거꾸로는 안 일어남

# 2) 로슈미트 수치 실험
#    역학계(하드디스크)를 T까지 적분 → 모든 속도 반전 → 다시 T까지 적분
#    완벽하면 초기로 복귀하나, 부동소수 오차가 카오스로 증폭 → 복귀 실패
#    → "원리적 가역, 실용적 불가역" 시연 (→ L1 chaos)

# 3) 요동 정리 (Crooks)
#    작은 계를 비평형으로 끌며 한 일 W를 여러 번 샘플 → 정/역 과정 분포
#    P_F(W)/P_R(−W) = e^{(W−ΔF)/kT}  검증, 야르진스키 ⟨e^{−W/kT}⟩=e^{−ΔF/kT}
#    → 작은 계에선 엔트로피 감소(드물게) 일어남 확인 (→ fluctuations)

# 4) 푸앵카레 재귀
#    작은 N(예: 칸-볼 모형, Ehrenfest 개미상자)에서 재귀까지 시간 측정
#    → 재귀 시간이 N에 지수적으로 폭발(거시계에선 우주 나이 초과) 확인

# 5) 미시상태 수 비대칭 (셈)
#    Ehrenfest 모형: 한쪽에 모인 거시상태 vs 반반 거시상태의 미시상태 수
#    → 반반 쪽이 압도적 → "왜 그쪽으로 가나"의 통계적 답

# 6) 엔트로피 생성 측정
#    비평형 정상상태(온도차 격자)에서 엔트로피 생성률 → 항상 ≥ 0 확인
```

## 💡 핵심 분석 대상

```
역설: 대칭 법칙, 비대칭 세계
  미시 법칙: t → −t 대칭 (뉴턴·맥스웰·슈뢰딩거)
  거시 세계: 한 방향 (컵 깨짐, 잉크 섞임, 커피 식음)
       ?  법칙이 대칭이면 비대칭은 어디서?

로슈미트 & 푸앵카레의 도전:
  H정리:  H(t) 단조 감소 (비가역성 유도 주장)
       │ 로슈미트: 모든 속도 반전하면 H 증가해야 (모순!)
       │ 푸앵카레: 유한계는 결국 초기로 복귀 (단조 감소 불가!)
       ▼ 해결의 열쇠
  H정리에 *분자 카오스 가정*(미래 상관 무시)이 시간 비대칭을 몰래 넣었다

통계적 답 (법칙이 아니라 셈):
  거시상태 A(질서) → 미시상태 수 W_A 작음
  거시상태 B(섞임) → 미시상태 수 W_B 천문학적으로 큼
       ⇒ A에서 시작하면 압도적으로 B로 (확률, 법칙 아님)
  거친 알갱이 + 혼합(→ L1 chaos) → *실효적* 비가역성
  ※ 원리적으로는 가역, 실용적으로 불가역 (정보 추적 불가)

진짜 뿌리: 과거 가설
  왜 *과거*가 저엔트로피였나?
       ↑
  빅뱅의 낮은 엔트로피 (중력계: 균질 = 저엔트로피!) (→ L4)
  ⇒ 열역학 화살 ← 우주론 화살 (미해결의 영역)

작은 계의 반전 (요동 정리):
  P_F(+W)/P_R(−W) = e^{(W−ΔF)/kT}
  ⇒ 작은 계·짧은 시간엔 엔트로피 *감소*도 (드물게) 일어난다 (→ fluctuations)
  ⇒ 제2법칙은 통계적 진술 (N→∞에서만 절대적)
```
