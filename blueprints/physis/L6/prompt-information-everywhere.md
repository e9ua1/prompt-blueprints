# Information Everywhere 레포지토리 제작 프롬프트

나는 "Information Everywhere" 레포지토리를 만들려고 해.
이건 *새로운 주제*가 아니다. **정보라는 하나의 척추가 L0부터 L5까지 전 레이어를 어떻게 꿰는지** — 그리고 정보가 *물리의 바닥*일 수도 있다는 가장 급진적 가설까지 — 종단하는 종합(Synthesis) 레포다.
개별 레포에서 정보는 거듭 나타났다: L2의 엔트로피=정보·란다우어(정보는 물리), L3의 얽힘=자원·복제 불가, L4의 블랙홀 정보 역설·베켄슈타인 한계, L5의 홀로그래피(정보가 면적에)·ER=EPR. 이 레포는 그 모두가 *하나의 실*임을 엮는다.
하나의 명제 — **"정보는 물리이고, 어쩌면 물리의 바닥이다(it-from-bit)"** — 가 열역학·양자·블랙홀·시공간을 어떻게 관통하는지를, 과대포장 없이 끝까지 꿰는 레포를 만들 거야. 이것은 이 연구소의 지적 중심축 중 하나다.

## 📋 프로젝트 목표

**컨셉**: "정보는 물리다 — 어쩌면 물리의 바닥이다. 열역학·양자·블랙홀·시공간을 잇는 하나의 실(it-from-bit)"

**핵심 차별화**:
1. **종단(横断) 구조** — 주제가 아니라 *정보라는 한 원리*를 L0~L5에 걸쳐 추적, 연구소의 지적 중심축
2. **"정보는 물리"의 단계적 심화** — 엔트로피=정보(L2)→란다우어(정보↔열)→얽힘=자원(L3)→블랙홀 정보(L4)→홀로그래피(정보=시공간, L5)
3. **얽힘이 기하를 만든다** — 류-타카야나기·ER=EPR을 정보의 렌즈로, it-from-qubit(→ L5)
4. **it-from-bit를 정직하게** — 가장 급진적 가설이되 검증 가능성을 정면으로(→ L0 measurement, → emergent-spacetime)

**타겟 독자**:
- 여러 레포에서 정보를 만났지만 *하나의 실*로 통합 못 한 사람
- 엔트로피=정보·란다우어·얽힘·블랙홀 정보가 *같은 원리*임을 모르는 사람
- "정보가 물리의 바닥인가"라는 급진적 질문을 전 레이어에서 보고 싶은 사람
- it-from-bit의 매력과 *검증 한계*를 함께 알고 싶은 사람
- **IQ AI Lab**의 정보이론·계산과의 교차에 관심 있는 사람

**선행 학습** (이 레포는 종합이므로 전 레이어를 가정):
- `fluctuations-information-distilled`(L2) — **필수, 본향 1**. 엔트로피=정보·란다우어
- `quantum-information-distilled`(L3) — **필수, 본향 2**. 얽힘=자원·복제 불가
- `holographic-principle-distilled`(L5) — **필수, 본향 3**. 정보가 시공간을 / `black-holes-distilled`(L4) — 정보 역설

## 🔗 레포 연결

**🌐 횡단 입력** (이 레포는 L0~L5 전체를 꿰며, 다음을 입력으로 삼는다):

- **L3**: `quantum-information`(본향 — 큐비트·얽힘=자원·홀레보), `entanglement-measurement`(얽힘·벨·결잃음), `quantum-mechanics`(측정·복제 불가), `emergent-quantum-matter`(위상 질서=긴 거리 얽힘)

다음 7개 챕터로 레포지토리를 설계해줘 (레이어를 *종단*하는 구조):

### Chapter 1: 정보라는 렌즈 (5개 문서)
- **정보란 무엇인가** — 섀넌, 불확실성의 척도(전체 관통 명제)(→ L0 measurement)
- **엔트로피 = 정보** — 볼츠만·깁스·섀넌의 통일(→ L2 statistical-mechanics, → entropy-time-everywhere)
- **정보는 물리적이다** — 추상이 아니라 물리량(→ L2 fluctuations)
- **비트와 큐비트** — 고전·양자 정보의 단위(→ L3 quantum-information)
- **정보의 다섯 무대** — 열역학·양자·블랙홀·시공간·it-from-bit(이 레포의 지도)

### Chapter 2: 정보와 열역학 (L2) (5개 문서)
- **최대 엔트로피** — 통계역학은 추론이다(→ L2 statistical-mechanics, fluctuations)
- **맥스웰의 도깨비** — 정보로 일을 뽑나(→ L2 fluctuations)
- **실라드 엔진** — 1비트 = $kT\ln2$ 일(→ L2 fluctuations)
- **란다우어 원리** — 정보 소거가 열을 낸다, 도깨비의 패인(→ L2 fluctuations)
- **계산의 열역학** — 비트 연산의 에너지 한계(→ L2 fluctuations, → IQ AI Lab)

### Chapter 3: 양자 정보 (L3) (5개 문서)
- **복제 불가** — 양자는 복사 안 된다(→ L3 quantum-information)
- **얽힘 = 자원** — 텔레포테이션·초고밀도 부호화(→ L3 quantum-information, entanglement-measurement)
- **벨 부등식** — 정보로 본 비국소성(→ L3 entanglement-measurement)
- **폰 노이만·홀레보** — 양자 엔트로피와 정보 한계(→ L3 quantum-information)
- **양자 우위** — 정보 처리의 경계(간섭, 특정 문제만)(→ L3 quantum-information, → IQ AI Lab)

### Chapter 4: 정보와 측정·물질 (L0·L3) (4개 문서)
- **측정과 정보** — 관측가능성, 정보 추출의 비용(→ L0 measurement, → L3)
- **불확정성과 정보** — 푸리에·상보성, 시간-진동수 거래(→ L1 oscillations, → L3)
- **얽힘과 물질의 상** — 위상 질서 = 긴 거리 얽힘(→ L3 emergent-quantum-matter)
- **결잃음** — 정보 누출이 고전성을 만든다(→ L3 entanglement-measurement, → entropy-time-everywhere)

### Chapter 5: 정보와 시공간 (L4·L5) (5개 문서)
- **블랙홀 정보 역설** — 정보가 파괴되나(→ L4 black-holes)
- **베켄슈타인 한계** — 정보 ≤ 면적(→ L4, → L2 fluctuations)
- **홀로그래피** — 정보가 경계에 산다(→ L5 holographic-principle)
- **류-타카야나기** — 얽힘 = 기하(→ L5 holographic-principle, → L3)
- **ER=EPR** — 얽힘이 시공간을 꿰맨다(→ L5 holographic-principle, → L3)

### Chapter 6: it-from-bit (L5) (4개 문서)
- **it-from-bit** — 휠러의 명제, 정보가 존재의 바닥(→ L5)
- **it-from-qubit** — 시공간이 양자정보에서 창발(→ L5 holographic, emergent-spacetime)
- **정보가 근본인가** — 가장 급진적 가설(→ L5 emergent-spacetime)
- **정보 우주의 검증** — 무엇을 말할 수 있나(정직)(→ L0 measurement, → L5)

### Chapter 7: 종합 — 정보가 우주를 꿰다 (5개 문서)

- **정보와 다른 척추** — 엔트로피·창발·대칭과의 관계(→ L6 자매 레포)
- **정보 계산 모음** — 란다우어·얽힘 엔트로피·RT·텔레포테이션을 한 노트북에(Python)
- **정보 환원주의의 한계** — it-from-bit는 검증 가능한가(정직)(→ L0 measurement)
- **종합** — "정보는 물리이고 어쩌면 물리의 바닥이다"의 전 레이어 통합 + IQ AI Lab 교차

## 📐 문서 구조 — Principle → Boundary → Emergence

## 🎯 핵심 질문      — 이 정보 개념이 무엇을 말하나

## 🔍 직관의 함정     — "정보는 추상"·"동시에 모든 입력" 같은 오해

## 📐 예측·반증       — 란다우어 한계·얽힘 엔트로피 등 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---

## 🔬 검증 프로토콜

> 종합 레포답게, 전 레이어의 정보 계산을 *한 노트북*에 모아 "같은 실"임을 보인다. ⚠️ it-from-bit 등 최전선은 검증 한계를 정직히 표시.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 엔트로피 = 정보 (L2): 볼츠만=깁스=섀넌
import numpy as np
def shannon(p): p=p[p>0]; return -np.sum(p*np.log2(p))
#    같은 분포에 세 엔트로피가 비례함을 확인 (→ L2)

# 2) 란다우어 (L2): 정보 소거 = 열
#    비트 소거 시 방출 열 ≥ kT ln2 시연 (정보↔열, → L2 fluctuations)

# 3) 얽힘 엔트로피 (L3): 폰 노이만
#    벨 상태 환원 밀도행렬 → S=−Tr(ρ ln ρ)=ln2 (최대 얽힘, → L3)
def von_neumann(rho):
    ev=np.linalg.eigvalsh(rho); ev=ev[ev>1e-12]; return -np.sum(ev*np.log(ev))

# 4) 양자 텔레포테이션 (L3): 얽힘 = 자원
#    얽힘 1ebit + 고전 2비트로 임의 상태 전송 (복제 아님, → L3)

# 5) 베켄슈타인 한계 (L4): 정보 ≤ 면적
#    S ≤ A/(4ℓ_P²) 계산, 블랙홀이 최대 정보 (→ L4, L2)

# 6) 류-타카야나기 (L5): 얽힘 = 기하
#    2D CFT 구간의 S=(c/3)ln(ℓ/ε) = 벌크 최소면적 (→ L5 holographic)

# 7) 정보의 사다리 요약표
#    열역학/양자/블랙홀/시공간의 정보 개념을 레이어별로 매핑한 표 출력
#    + 각 항목의 "검증 가능성" 라벨 (it-from-bit는 정직히 '추측')
```

     베켄슈타인 한계: 정보 ≤ 면적 (부피가 아니라!)
     페이지 곡선: 정보가 호킹 복사로 나온다
       │  가장 깊은 곳에서
       ▼
  ④ 시공간 (L5)
     홀로그래피: 정보가 경계 면적에
     류-타카야나기: 얽힘 엔트로피 = 최소면적 (얽힘=기하)
     ER=EPR: 얽힌 쌍 = 웜홀
       │  궁극의 가설
       ▼
  ⑤ it-from-bit (L5)
     정보가 *존재의 바닥*인가? (휠러)
     it-from-qubit: 시공간이 양자정보에서 창발 (→ emergent-spacetime)

  ─────────────────────────────────────────
  정직한 한계:
     it-from-bit는 *검증 가능한가*? (대부분 추측, → L0 measurement)
     ⇒ 가장 매혹적이되 가장 불확실한 가설

전 레이어 통합:
  L2 란다우어 → L3 얽힘=자원 → L4 베켄슈타인/정보 역설
       → L5 홀로그래피/RT/ER=EPR → it-from-bit
