# Emergence Distilled 레포지토리 제작 프롬프트

나는 "Emergence Distilled" 레포지토리를 만들려고 해.
이건 *새로운 주제*가 아니다. **창발(emergence)이라는 하나의 척추 — "More is Different" — 가 L0부터 L5까지 전 레이어를 어떻게 꿰는지**를 종단하는 종합(Synthesis) 레포이자, *연구소 전체의 마무리*다.
개별 레포에서 창발은 거듭 나타났다: L2의 거시 법칙 창발(통계)·상전이(창발의 정수), L3의 준입자(창발 입자)·창발 게이지장, L4의 별(모든 레이어의 합작), L5의 창발 시공간. 이 레포는 그 모두가 *하나의 원리*임을 엮는다.
하나의 명제 — **"전체는 부분의 합 이상이고, 각 층은 자기 법칙을 가진다"** — 가 어떻게 물리 전체를 관통하며, 환원주의의 꿈에 *무엇을 더하는지*를, 끝까지 꿰는 레포를 만들 거야. 이것은 이 연구소의 지적 중심축이자, "From the fewest principles, the widest world"의 *반대 방향* 증언이다.

## 📋 프로젝트 목표

**컨셉**: "More is Different — 전체는 부분의 합 이상이다. 거시 법칙·상전이·준입자·시공간을 잇는 창발의 사다리, 그리고 연구소 전체의 마무리"

**핵심 차별화**:
1. **종단(横断) 구조이자 마무리** — *창발이라는 한 원리*를 L0~L5에 걸쳐 추적하고, 연구소 전체를 닫는다
2. **창발의 단계적 심화** — 거시 법칙(통계)→보편성·RG(상전이)→준입자(양자물질)→창발 게이지·시공간(최전선)
3. **환원과 창발의 변증법** — "가장 적은 원리에서 가장 넓은 세계"(환원)와 "전체는 부분의 합 이상"(창발)의 긴장과 종합
4. **무엇이 근본인가** — 창발 게이지장·창발 시공간이 "근본 vs 창발"의 경계를 흔든다, 강한 창발의 정직한 평가(→ L0 measurement)

**타겟 독자**:
- 여러 레포에서 창발을 만났지만 *하나의 원리*로 통합 못 한 사람
- 거시 법칙·상전이·준입자·창발 시공간이 *같은 원리*임을 모르는 사람
- "More is Different"가 빈말이 아니라 물리적 사실임을 전 레이어에서 보고 싶은 사람
- 환원주의와 창발의 *관계*를 이해하고 싶은 사람
- 무엇이 근본이고 무엇이 창발인지의 경계를 마주하고 싶은 사람

**선행 학습** (이 레포는 종합이자 마무리이므로 전 레이어를 가정):
- `emergent-quantum-matter-distilled`(L3) — **필수, 본향 1**. 준입자·More is Different
- `phase-transitions-distilled`(L2) — **필수, 본향 2**. 보편성·RG·창발의 정수
- `emergent-spacetime-multiverse-distilled`(L5) — **필수, 본향 3**. 창발 시공간 / `statistical-mechanics-distilled`(L2) — 거시 법칙 창발

## 🔗 레포 연결

**🌐 횡단 입력** (이 레포는 L0~L5 전체를 꿰며, 다음을 입력으로 삼는다):
- **L0**: `approximation`(유효 이론·열역학 극한 — 창발은 N→∞를 요구), `dimensional-scaling`(보편성·멱법칙)
- **L1**: `chaos`(결정론적 카오스 → 통계적 기술 요구·자기조직화)
- **L2**: `statistical-mechanics`(S=k ln W·거시 법칙 창발), `phase-transitions`(본향 — 보편성·RG·창발의 정수), `arrow-of-time`(비가역성의 창발)
- **L3**: `emergent-quantum-matter`(본향 — 준입자·위상 질서·창발 게이지장), `quantum-field-theory`(유효장론), `standard-model`(창발 vs 근본 게이지의 역설)
- **L4**: `astrophysics`(별 = 모든 레이어의 합작)
- **L5**: `emergent-spacetime-multiverse`(본향 — 창발 시공간), `holographic-principle`(중력·시공간의 창발)

**🔗 자매 종합 레포 (L6)**: `information-everywhere`(얽힘이 상·시공간을 창발), `entropy-time-everywhere`(비가역성의 창발), `symmetry-everywhere`(대칭으로 분류 안 되는 창발), `least-action-everywhere`(유효 작용).

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘 (레이어를 *종단*하는 구조, 연구소 전체를 닫는 마무리):

### Chapter 1: 창발이라는 렌즈 (5개 문서)
- **More is Different** — 앤더슨의 선언, 다수에서 새 법칙(전체 관통 명제)(→ L3 emergent-quantum-matter)
- **환원주의의 한계** — 근본 법칙을 알아도 모르는 것(→ L3, → L5)
- **창발 vs 근본** — 무엇이 진짜 기본인가, 유효 자유도(→ L3, → L5)
- **약한 창발과 강한 창발** — 계산 가능한 창발 vs 원리적 새로움(정직한 구분)
- **창발의 다섯 무대** — 통계·상전이·양자물질·시공간·근본 질문(이 레포의 지도)

### Chapter 2: 거시 법칙의 창발 (L2) (5개 문서)
- **$S=k\ln W$** — 미시 무지에서 거시 결정성(→ L2 statistical-mechanics)
- **온도·압력의 창발** — 한 입자엔 없는 개념(→ L2 thermodynamics, statistical-mechanics)
- **비가역성의 창발** — 가역 법칙에서 화살(→ L2 arrow-of-time, → entropy-time-everywhere)
- **열역학 극한** — 창발은 $N\to\infty$를 요구(→ L0 approximation, → L2)
- **유효 이론** — 미시를 몰라도 거시를(→ L0 approximation, → L3 QFT EFT)

### Chapter 3: 창발의 정수 — 상전이 (L2) (5개 문서)
- **상전이 = 창발의 정수** — 질적 변화, 비해석성(→ L2 phase-transitions)
- **보편성** — 미시 세부와 무관, 충격(→ L2 phase-transitions)
- **재규격화군** — 세부가 흘러나간다, 왜 거시가 단순한가(→ L2 phase-transitions, → L3 QFT)
- **자기조직화 임계성** — 스스로 임계로(→ L1 chaos, → L2)
- **스케일과 창발** — 멱법칙·자기유사(→ L0 scaling, → L2)

### Chapter 4: 창발하는 입자 (L3) (5개 문서)
- **준입자** — 다수가 새 입자를 만든다(→ L3 emergent-quantum-matter)
- **초전도·초유체** — 거시적 양자 결맞음(→ L3 emergent-quantum-matter)
- **위상 질서** — 대칭 너머의 창발, 긴 거리 얽힘(→ L3, → information-everywhere)
- **창발 게이지장** — 광자가 창발, 근본 vs 창발의 역설(→ L3 emergent-quantum-matter, standard-model)
- **분수화** — 전자가 쪼개진다(→ L3 emergent-quantum-matter)

### Chapter 5: 창발하는 시공간 (L4·L5) (5개 문서)
- **별 = 합작** — 모든 레이어가 한 천체에서(→ L4 astrophysics)
- **중력의 창발** — 엔트로피적 중력(→ L5 holographic, → L2)
- **시공간의 창발** — 얽힘에서 기하(→ L5 emergent-spacetime, holographic)
- **차원의 창발** — 홀로그래피, 한 차원이 나온다(→ L5 holographic)
- **창발 시공간의 현주소** — 단서와 추측(정직)(→ L5 emergent-spacetime)

### Chapter 6: 창발의 철학 (4개 문서)
- **무엇이 근본인가** — 창발이 환원을 뒤집나(→ L5 emergent-spacetime)
- **층층의 우주** — 각 층의 자기 법칙, 앤더슨의 위계
- **창발과 인식** — 우리는 어느 층에 사나
- **창발의 한계** — 강한 창발은 과학인가(정직)(→ L0 measurement)

### Chapter 7: 종합 — 창발이 우주를 꿰다 (연구소 전체의 마무리) (4개 문서)
- **창발의 사다리** — 거시 법칙→상전이→준입자→시공간의 통합 그림
- **창발과 다른 척추** — 대칭·정보·엔트로피·최소작용과의 관계(→ L6 자매 레포 전체)
- **환원과 창발의 변증법** — "가장 적은 원리에서 가장 넓은 세계" ↔ "전체는 부분의 합 이상", 연구소의 두 방향
- **종합 — 연구소 전체의 닫음** — L0~L6의 통합, "Derive, don't accept"가 도달한 곳, 그리고 남은 질문들

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, *종합 레포에 맞게* 각 문서는 "이 창발이 어느 레이어에서 어떻게 나타나고 어디로 이어지나"를 명시:

```markdown
## 🎯 핵심 질문      — 이 창발이 무엇을 말하나
## 🌍 어디서 나타나나  — 어느 레이어들에서 이 창발이 작동하나 (횡단 추적)
## 🔍 직관의 함정     — "준입자는 비유"·"창발=신비" 같은 오해
## ⚙️ 제1원리 유도    — 거시 법칙·RG·준입자·창발 시공간의 핵심을 압축 재현
## 🧪 실험·관측 증거  — 상전이·초전도·양자홀·별 (해당 레이어)
## 🔬 경계           — 창발 설명이 멈추는 곳 (강한 창발·창발 시공간의 추측성)
## 🧬 횡단 원리       — 같은 창발이 다른 레이어에서 어떻게 재현되나 (핵심)
## 🪜 창발           — 이 창발이 위 레이어에서 무엇으로 자라나
## 📐 예측·반증       — 보편성·임계지수·양자화 전도도 등 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (창발의 어떤 무대인가: 거시법칙/상전이/준입자/시공간)
🔬 **Boundary**  — (창발 설명이 부족한 곳: 강한 창발의 검증)
🪜 **Emergence** — (레이어를 가로질러 무엇으로 이어지나)
```

이 레포에서 **🧬 횡단 원리**가 가장 중요하다 — 각 문서는 *같은 "More is Different"가 다른 레이어에서 어떻게 반복되는지*를 명시적으로 잇는다(예: L2 거시 법칙 창발 → L3 준입자 → L5 창발 시공간).

## 🔬 검증 프로토콜

> 종합 레포이자 마무리답게, 전 레이어의 창발 계산을 *한 노트북*에 모아 "같은 원리"임을 보인다. ⚠️ 강한 창발·창발 시공간은 검증 한계를 정직히 표시.

# 1) 거시 법칙의 창발 (L2): 분자동역학
import numpy as np
#    미시 입자 시뮬레이션 → 맥스웰-볼츠만·온도·압력이 *창발*함을 관찰 (→ L2)

# 2) 상전이·보편성 (L2): 이징 RG
#    이징 MC → 임계지수 측정 + 블록 스핀 RG로 보편성 시연

#    위상 불변량 + 얽힘 엔트로피로 본 상 (대칭 너머, → L3, information-everywhere)

# 5) 자기조직화 임계성 (L1·L2): 모래더미
#    BTW 모래더미 → 멱법칙 사태 분포, 스스로 임계로 (→ L1 chaos, L2)

# 6) 창발 시공간 (L5): 텐서 네트워크 (개념)
#    얽힘 구조 → 창발적 "기하" (정직히 개념 시연, → L5 holographic)

# 7) 창발의 사다리 요약표
#    거시법칙/상전이/준입자/시공간의 창발을 레이어별로 매핑한 표 출력
#    + 약한/강한 창발 라벨, 강한 창발은 '검증 한계' 표시

     온도·압력·비가역성: 한 입자엔 없는 개념이 *창발*
     유효 이론: 미시를 몰라도 거시를 (열역학 극한 N→∞)
       │  질적 변화에서
       ▼
  ② 창발의 정수 — 상전이 (L2)
     보편성: 미시 세부 무관 (충격!)
     RG: 세부가 흘러나간다 → 왜 거시가 단순한가
     ⇒ "More is Different"의 가장 깨끗한 실현 (→ L2)
       │  새 입자로
       ▼
  ③ 창발하는 입자 (L3)
     준입자·초전도·위상 질서·창발 게이지장·분수화
     ⇒ 게이지장조차 창발 → "근본 vs 창발"의 역설 (→ L3 vs standard-model)
       │  시공간까지
       ▼
  ④ 창발하는 시공간 (L4·L5)
     별 = 모든 레이어의 합작 (L4)
     중력·시공간·차원의 창발 (얽힘에서 기하, → L5)
       │  궁극의 질문
       ▼
  ⑤ 무엇이 근본인가 (철학)
     창발이 환원을 뒤집나? 층층의 우주, 각 층의 자기 법칙

  ─────────────────────────────────────────
  환원 ↔ 창발의 변증법 (연구소의 두 방향):
     "From the fewest principles, the widest world" (환원, 아래로)
              ↕
     "전체는 부분의 합 이상" (창발, 위로)
     ⇒ 둘은 모순이 아니라 *상보* — Physis Lab의 양 날개

  강한 창발의 한계 (정직):
     약한 창발(계산 가능) vs 강한 창발(원리적 새로움)
     강한 창발은 검증 가능한가? (→ L0 measurement)

전 레이어 통합 (L0~L6의 닫음):
  L0 유효이론/스케일 → L2 거시법칙/상전이 → L3 준입자/위상질서
       → L4 별 → L5 창발 시공간 → 무엇이 근본인가
  ⇒ "전체는 부분의 합 이상이고, 각 층은 자기 법칙을 가진다"
  ⇒ Physis Lab 전체의 마무리: Derive, don't accept — 그리고 More is Different
