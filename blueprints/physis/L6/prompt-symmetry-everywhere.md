# Symmetry Everywhere 레포지토리 제작 프롬프트

나는 "Symmetry Everywhere" 레포지토리를 만들려고 해.
이건 *새로운 주제*가 아니다. **대칭성이라는 하나의 척추 원리가 L0부터 L5까지 — 차원분석에서 양자중력까지 — 전 레이어를 어떻게 꿰는지**를 종단하는 종합(Synthesis) 레포다.
개별 레포에서 대칭은 조각조각 나타났다: L0의 뇌터 정리, L1의 케플러 숨은 대칭, L2의 자발 대칭 깨짐, L3의 게이지 원리와 힉스, L4의 로런츠·일반 공변성, L5의 쌍대성. 이 레포는 그 조각들을 *하나의 이야기*로 엮는다.
대칭의 한 사다리 — **보존(뇌터) → 힘(게이지) → 질량·상(깨짐) → 입자·기하(분류) → 근본의 상대성(쌍대성)** — 가 어떻게 물리 전체를 지정하는지를, 끝까지 꿰는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "법칙의 대칭이 물리를 지정한다 — 보존·힘·질량·분류·쌍대성을 잇는 하나의 사다리"

**핵심 차별화**:
1. **종단(横断) 구조** — 주제가 아니라 *대칭이라는 한 원리*를 L0~L5에 걸쳐 추적, 조각들을 하나로
2. **대칭의 다섯 얼굴을 사다리로** — 보존(뇌터)→힘(게이지)→깨짐(SSB/힉스)→분류(입자/위상/기하)→쌍대성, 단계적 심화
3. **각 레이어의 대칭을 회수** — L0 뇌터·L1 룽게-렌츠·L2 SSB·L3 게이지/힉스·L4 로런츠/공변성·L5 쌍대성을 명시적으로 연결
4. **대칭이 못 하는 것도 정직하게** — 위상 질서·창발처럼 대칭만으론 부족한 곳(→ emergence-distilled)

**타겟 독자**:
- 여러 레포에서 대칭을 만났지만 그것이 *하나의 원리*임을 통합 못 한 사람
- 보존·게이지·SSB·쌍대성이 *같은 대칭의 다른 얼굴*임을 모르는 사람
- "대칭이 물리를 지정한다"는 명제를 전 레이어에서 보고 싶은 사람
- 대칭의 위력과 *한계*(위상·창발)를 함께 알고 싶은 사람

**선행 학습** (이 레포는 종합이므로 전 레이어를 가정):
- `symmetry-conservation-distilled`(L0) — **필수, 출발점**. 뇌터 정리
- `standard-model-distilled`(L3) — **필수**. 게이지 원리·힉스
- `phase-transitions-distilled`(L2) — SSB / `general-relativity-distilled`(L4) — 일반 공변성 / `string-theory-distilled`(L5) — 쌍대성

## 🔗 레포 연결

**🌐 횡단 입력** (이 레포는 L0~L5 전체를 꿰며, 다음을 입력으로 삼는다):
- **L0**: `symmetry-conservation`(뇌터 — 척추의 뿌리), `dimensional-scaling`(스케일 대칭)
- **L1**: `classical-mechanics`(보존=대칭·룽게-렌츠), `electromagnetism`(게이지 U(1)), `classical-field-theory`(장의 뇌터)
- **L2**: `phase-transitions`(자발 대칭 깨짐·란다우·골드스톤), `statistical-mechanics`(SSB)
- **L3**: `standard-model`(게이지가 힘을 낳음·힉스·표현), `quantum-mechanics`(각운동량 SU(2)·보존=교환자), `emergent-quantum-matter`(창발 게이지·골드스톤)
- **L4**: `special-relativity`(로런츠/푸앵카레), `general-relativity`(일반 공변성·미분동형), `cosmology`(CP 위반과 바리온)
- **L5**: `string-theory`(T·S 쌍대성·M이론), `holographic-principle`(게이지/중력 이중성)

**🔗 자매 종합 레포 (L6)**: `least-action-everywhere`(작용의 대칭이 뇌터), `entropy-time-everywhere`(T·CP 대칭과 화살), `information-everywhere`(대칭과 보존 정보), `emergence-distilled`(대칭으로 분류 안 되는 창발).

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘 (레이어를 *종단*하는 구조):

### Chapter 1: 대칭이라는 렌즈 (5개 문서)
- **대칭이란 무엇인가** — 변환 불변성, "법칙의 대칭이 물리를 지정한다"(전체 관통 명제)
- **뇌터의 정리** — 연속 대칭 ↔ 보존량, 물리에서 가장 깊은 정리(→ L0 symmetry)
- **대칭의 언어** — 군(group)·표현(representation), 대칭을 수학으로
- **이산 대칭** — P·C·T, 거울·전하·시간(→ L3, L2)
- **대칭의 다섯 얼굴** — 보존·게이지·깨짐·분류·쌍대성(이 레포의 지도)

### Chapter 2: 대칭 → 보존 (뇌터, L0~L1) (5개 문서)
- **시공간 대칭과 보존** — 시간/공간/회전 → 에너지/운동량/각운동량(→ L0, → L1 classical-mechanics)
- **숨은 대칭** — 케플러의 룽게-렌츠 $SO(4)$, 왜 타원이 닫히나(→ L1)
- **갈릴레이에서 로런츠로** — 시공간 대칭의 확장(→ L4 special-relativity)
- **장(field)의 뇌터** — 보존류·에너지-운동량 텐서(→ L1 classical-field-theory)
- **양자의 뇌터** — 대칭 $=[\hat O,\hat H]=0$, 보존량의 양자판(→ L3 quantum-mechanics)

### Chapter 3: 대칭 → 힘 (게이지, L1·L3) (5개 문서)
- **게이지 원리** — 대칭 국소화 → 힘의 강제(→ L1 EM, → L3)
- **$U(1)$과 전자기** — 가장 단순한 게이지, 빛(→ L1 EM)
- **비가환 게이지** — 양-밀스, 약·강력(→ L3 standard-model)
- **게이지가 힘을 낳는다** — $SU(3)\times SU(2)\times U(1)$, 세 힘의 통일 논리(→ L3 standard-model)
- **게이지 = 측정 불가의 잉여** — 자유도와 실재(→ L0 measurement, → L1 EM)

### Chapter 4: 대칭 → 깨짐 (SSB, L2·L3) (5개 문서)
- **자발 대칭 깨짐** — 법칙은 대칭, 상태는 비대칭(→ L2 phase-transitions)
- **란다우와 질서변수** — 대칭이 상전이의 형태를 강제(→ L2)
- **골드스톤 정리** — 깨진 연속 대칭 → 무질량 모드(→ L3, → L2)
- **힉스 메커니즘** — 골드스톤이 먹혀 질량, 질량의 기원(→ L3 standard-model)
- **창발하는 대칭** — 응집물질의 창발 게이지장(→ L3 emergent-quantum-matter)

### Chapter 5: 대칭 → 분류 (입자·상·기하, L3·L4) (5개 문서)
- **대칭이 입자를 분류** — 표현으로서의 입자(→ L3 standard-model)
- **스핀과 통계** — 회전 대칭 → 스핀, 보손/페르미온(→ L3, → L2)
- **위상 질서** — 대칭 *너머*의 분류, 위상 불변량(→ L3 emergent-quantum-matter, → emergence-distilled)
- **일반 공변성** — GR의 대칭, 미분동형(→ L4 general-relativity)
- **CP 위반과 우주** — 깨진 대칭이 물질을 남겼다(→ L3, → L4 cosmology)

### Chapter 6: 대칭 → 쌍대성 (L5) (4개 문서)
- **쌍대성 = 대칭의 일반화** — 다른 기술, 같은 물리(→ L5 string-theory)
- **T·S 쌍대성** — 근본이 관점 의존(→ L5 string-theory)
- **게이지/중력 이중성** — AdS/CFT, 대칭의 홀로그래피(→ L5 holographic-principle)
- **대칭의 미래** — 일반화 대칭·범주론, 최전선(→ L5)

### Chapter 7: 종합 — 한 대칭이 우주를 꿰다 (5개 문서)
- **대칭의 사다리** — 보존→게이지→깨짐→분류→쌍대성의 통합 그림
- **대칭과 다른 척추** — 최소작용(뇌터)·정보·창발과의 관계(→ L6 자매 레포)
- **대칭 계산 모음** — 뇌터·게이지·SSB·표현을 한 노트북에(Python)
- **대칭이 못 하는 것** — 위상 질서·창발 등 대칭만으론 부족한 곳(정직)(→ emergence-distilled)
- **종합** — "법칙의 대칭이 물리를 지정한다"의 전 레이어 통합

→ **총 34개 문서** 목표.

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, 단 *종합 레포에 맞게* 각 문서는 "이 대칭이 어느 레이어에서 어떻게 나타나고 어디로 이어지나"를 명시:

```markdown
## 🎯 핵심 질문      — 이 대칭의 얼굴이 무엇을 지정하나
## 🌍 어디서 나타나나  — 어느 레이어들에서 이 대칭이 작동하나 (횡단 추적)
## 🔍 직관의 함정     — "대칭은 장식"·"게이지는 진짜 자유도" 같은 오해
## ⚙️ 제1원리 유도    — 뇌터·게이지·SSB의 핵심 유도를 압축 재현
## 🧪 실험·관측 증거  — 보존·힉스·CP 위반의 실측 (해당 레이어에서)
## 🔬 경계           — 이 대칭 기술이 멈추는 곳 (위상·창발)
## 🧬 횡단 원리       — 같은 대칭이 다른 레이어에서 어떻게 재현되나 (핵심)
## 🪜 창발           — 이 대칭이 위 레이어에서 무엇으로 자라나
## 📐 예측·반증       — 대칭이 내놓는 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (대칭의 어떤 얼굴인가: 보존/게이지/깨짐/분류/쌍대성)
🔬 **Boundary**  — (이 대칭 기술이 부족한 곳)
🪜 **Emergence** — (레이어를 가로질러 무엇으로 이어지나)
```

이 레포에서 **🧬 횡단 원리**가 가장 중요하다 — 각 문서는 *같은 대칭이 다른 레이어에서 어떻게 반복되는지*를 명시적으로 잇는다(예: U(1)이 L1 전자기와 L3 표준모형에서).

## 🎨 스타일 가이드

1. **종단이 핵심** — 주제를 새로 가르치지 않고, *대칭이라는 실로 레이어를 꿴다*. 매 문서가 횡단 연결을 명시
2. **사다리로 구성** — 보존→게이지→깨짐→분류→쌍대성의 단계적 심화를 일관되게
3. **개별 레포로 되돌려보낸다** — 깊은 유도는 원 레포(L0~L5)를 가리키고, 여기선 *통합*에 집중
4. **대칭의 한계를 정직하게** — 위상 질서·창발은 대칭으로 다 안 됨을(→ emergence-distilled)
5. **수치는 통합 노트북** — 여러 레이어의 대칭 계산을 한곳에 모아 비교
6. 대칭의 사다리·게이지 군·SSB·쌍대성 망은 다이어그램으로

## 🔬 검증 프로토콜

> 종합 레포답게, 전 레이어의 대칭 계산을 *한 노트북*에 모아 "같은 원리"임을 보인다.

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 뇌터 정리 (L0~L1): 작용 대칭 → 보존량
import sympy as sp
#    시간 병진 → 에너지, 회전 → 각운동량을 라그랑지안에서 직접 유도
#    + 케플러 룽게-렌츠 보존 확인 (숨은 SO(4) 대칭, → L1)

# 2) 게이지 대칭 (L1·L3): U(1) → 전자기, 비가환 → 양-밀스
#    공변미분 D=∂−igA 에서 게이지 불변 라그랑지안 구성
#    → U(1)(전자기)과 SU(2)(약력)의 같은 구조 비교 (→ L1 EM, L3)

# 3) 자발 대칭 깨짐 (L2·L3): 멕시칸 햇 → 골드스톤·힉스
#    V(φ)=−μ²|φ|²+λ|φ|⁴ 최소화 → 진공 선택, 골드스톤 모드
#    → 상전이(L2)와 힉스(L3)가 같은 메커니즘 (→ L2, L3)

# 4) 대칭과 표현 (L3): 각운동량 대수, 입자 분류
#    SU(2) 사다리 연산자 → 스핀 다중항; 표현이 입자를 분류 (→ L3)

# 5) 로런츠 대칭 (L4): 불변 간격, 장의 변환
#    부스트 하에서 s²=−(ct)²+x² 불변, 전기↔자기 (→ L4 special-relativity)

# 6) 쌍대성 (L5): T-쌍대성 스펙트럼 불변
#    R ↔ α'/R 에서 스펙트럼 불변 → "근본은 관점 의존" (→ L5 string-theory)

# 7) 대칭의 사다리 요약표
#    보존/게이지/깨짐/분류/쌍대성을 레이어별로 매핑한 표 출력
```

     ⇒ 상전이(L2)와 질량의 기원(L3)이 같은 메커니즘
          │  무엇이 같은가를 묻는
          ▼
  ④ 분류 (입자·상·기하, L3·L4)
     표현 = 입자 · 스핀/통계 · 위상 질서 · 일반 공변성(GR)
     CP 위반 → 물질이 남았다 (→ L4 cosmology)
          │  다른 기술이 같은 물리면
          ▼
  ⑤ 쌍대성 (L5)
     T·S 쌍대성, AdS/CFT(게이지/중력)
     ⇒ "근본이 관점 의존" — 시공간조차 창발? (→ L5)

  ─────────────────────────────────────────
  대칭의 한계 (정직):
     위상 질서·창발은 대칭으로 *다 분류 안 됨* (→ emergence-distilled)
     ⇒ 대칭은 강력하나 전부는 아니다

전 레이어 통합:
  L0 뇌터 → L1 게이지·룽게렌츠 → L2 SSB → L3 게이지/힉스/표현
       → L4 로런츠/공변성/CP → L5 쌍대성
  ⇒ "법칙의 대칭이 물리를 지정한다"
