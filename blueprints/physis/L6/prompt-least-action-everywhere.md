# Least Action Everywhere 레포지토리 제작 프롬프트

나는 "Least Action Everywhere" 레포지토리를 만들려고 해.
이건 *새로운 주제*가 아니다. **최소작용 원리($\delta S=0$)라는 하나의 척추가 L0부터 L5까지 전 레이어를 어떻게 꿰는지**를 종단하는 종합(Synthesis) 레포다.
개별 레포에서 작용은 거듭 나타났다: L0의 오일러-라그랑주, L1의 라그랑주·해밀턴·맥스웰 작용, L3의 경로적분, L4의 아인슈타인-힐베르트 작용(최소작용이 *가장 큰 스케일에서* 재등장!), L5의 끈 작용. 이 레포는 그 모두가 *하나의 변분 원리*임을 엮는다.
하나의 명제 — **"자연은 작용을 정류시킨다"** — 가 고전역학·장론·상대성·양자(경로적분)·끈을 어떻게 관통하는지를, 끝까지 꿰는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "자연은 작용을 정류시킨다 — 하나의 변분 원리가 고전·장·상대성·양자·끈을 관통한다"

**핵심 차별화**:
1. **종단(横断) 구조** — 주제가 아니라 *최소작용이라는 한 원리*를 L0~L5에 걸쳐 추적
2. **$\delta S=0$의 다섯 무대** — 고전역학→장(field)→상대성(휜 시공간)→양자(경로적분)→끈, 같은 원리의 심화
3. **경로적분이 정점** — 고전 $\delta S=0$이 양자에선 *모든 경로의 합*이고 $\hbar\to0$에서 회복됨을(→ L3)
4. **아인슈타인-힐베르트의 충격** — 최소작용이 *가장 큰 스케일*(중력)에서도 작동함을(→ L4)

**타겟 독자**:
- 여러 레포에서 작용을 만났지만 그것이 *하나의 원리*임을 통합 못 한 사람
- 라그랑주·맥스웰·아인슈타인·경로적분이 *같은 변분*임을 모르는 사람
- 경로적분이 고전 최소작용의 *양자판*임을 명확히 모르는 사람
- 작용 원리의 위력과 *한계*(산일계)를 함께 알고 싶은 사람

**선행 학습** (이 레포는 종합이므로 전 레이어를 가정):
- `variational-principles-distilled`(L0) — **필수, 출발점**. $\delta S=0$·오일러-라그랑주
- `quantum-field-theory-distilled`(L3) — **필수**. 경로적분
- `general-relativity-distilled`(L4) — 아인슈타인-힐베르트 / `classical-mechanics-distilled`(L1) — 라그랑주/해밀턴 / `string-theory-distilled`(L5) — 끈 작용

## 🔗 레포 연결

**🌐 횡단 입력** (이 레포는 L0~L5 전체를 꿰며, 다음을 입력으로 삼는다):
- **L0**: `variational-principles`(δS=0 — 척추의 뿌리), `dimensional-scaling`(작용의 차원)
- **L1**: `classical-mechanics`(라그랑주/해밀턴), `oscillations-waves`(파동방정식의 변분), `electromagnetism`(맥스웰 작용 −¼F²), `classical-field-theory`(장의 오일러-라그랑주)
- **L2**: `thermodynamics`(자유에너지 최소=변분), `fluctuations-information`(최대 엔트로피 원리)
- **L3**: `quantum-mechanics`(경로적분 맛보기·해밀턴-야코비), `quantum-field-theory`(경로적분 Z=∫Dφe^{iS}), `standard-model`(게이지 작용)
- **L4**: `special-relativity`(상대론적 작용), `general-relativity`(아인슈타인-힐베르트·측지선)
- **L5**: `string-theory`(남부-고토/폴랴코프 작용), `holographic-principle`(작용과 홀로그래피)

**🔗 자매 종합 레포 (L6)**: `symmetry-everywhere`(작용의 대칭이 뇌터), `entropy-time-everywhere`(자유에너지 변분), `information-everywhere`(최대 엔트로피=변분), `emergence-distilled`(유효 작용·창발).

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘 (레이어를 *종단*하는 구조):

### Chapter 1: 최소작용이라는 렌즈 (5개 문서)
- **최소작용 원리란** — $\delta S=0$, "자연은 작용을 정류시킨다"(전체 관통 명제)
- **오일러-라그랑주** — 변분에서 운동방정식(→ L0 variational)
- **페르마에서 모페르튀이로** — 빛·입자의 변분, 역사적 뿌리(→ L1 oscillations)
- **라그랑지안의 의미** — $T-V$, 작용의 차원과 단위(→ L0, → L1)
- **작용의 다섯 무대** — 고전·장·상대성·양자·끈(이 레포의 지도)

### Chapter 2: 작용 → 고전역학 (L1) (5개 문서)
- **뉴턴에서 라그랑주로** — $\delta S=0$ → 운동방정식(→ L1 classical-mechanics)
- **라그랑주에서 해밀턴으로** — 르장그르 변환, 위상공간(→ L1)
- **대칭과 작용** — 뇌터, 보존 = 작용의 대칭(→ L0 symmetry, → symmetry-everywhere)
- **해밀턴-야코비** — 작용이 생성함수, 양자로 가는 다리(→ L1, → L3)
- **진동과 작용** — 작은 진동·파동방정식의 변분(→ L1 oscillations)

### Chapter 3: 작용 → 장(field) (L1·L3) (5개 문서)
- **장(field)의 작용** — 라그랑지안 밀도, $S=\int\mathcal L\,d^4x$(→ L1 classical-field-theory)
- **맥스웰의 작용** — $S=-\tfrac14\int F_{\mu\nu}F^{\mu\nu}$, 변분으로 전자기(→ L1 EM)
- **게이지 작용** — 양-밀스, 표준모형의 작용(→ L3 standard-model)
- **클라인-고든·디랙 작용** — 입자장의 변분(→ L3 QFT)
- **장(field)의 뇌터** — 작용 대칭 → 보존류(→ L1, → symmetry-everywhere)

### Chapter 4: 작용 → 상대성 (L4) (5개 문서)
- **상대론적 작용** — 고유시간의 변분, 자유 입자(→ L4 special-relativity)
- **측지선 = 작용 정류** — 휜 공간의 직선(→ L4 general-relativity)
- **아인슈타인-힐베르트 작용** — $\delta S=0$ → 아인슈타인 방정식(→ L4 general-relativity)
- **최소작용이 가장 큰 스케일에서** — 우주의 작용, 척추의 재등장(→ L4)
- **중력 작용의 변분** — 물질이 기하를 휜다($T_{\mu\nu}$)(→ L4)

### Chapter 5: 작용 → 양자 (경로적분, L3) (5개 문서)
- **경로적분** — 모든 경로의 합, $Z=\int\mathcal D x\,e^{iS/\hbar}$(→ L3 quantum-mechanics)
- **고전극한** — $\hbar\to0$에서 $\delta S=0$ 회복, 정류위상(→ L3, → L0 variational)
- **장(field)의 경로적분** — $Z=\int\mathcal D\phi\,e^{iS/\hbar}$(→ L3 QFT)
- **파인만 도표** — 작용에서 진폭으로(→ L3 QFT)
- **유클리드 작용** — 윅 회전, 통계역학과의 통일(→ L2, → L3)

### Chapter 6: 작용 → 통계·끈 (L2·L5) (4개 문서)
- **자유에너지 = 변분** — 평형은 작용 최소의 열역학판(→ L2 thermodynamics)
- **최대 엔트로피 원리** — 변분으로서의 추론(→ L2 fluctuations, → information-everywhere)
- **끈의 작용** — 세계면의 넓이, 남부-고토/폴랴코프(→ L5 string-theory)
- **작용의 미래** — 홀로그래피·복잡도=작용(→ L5 holographic-principle)

### Chapter 7: 종합 — 한 변분이 우주를 꿰다 (5개 문서)
- **작용의 사다리** — 고전→장→상대성→양자→끈의 통합 그림
- **작용과 다른 척추** — 대칭(뇌터)·정보·창발과의 관계(→ L6 자매 레포)
- **작용 계산 모음** — 오일러-라그랑주·경로적분·측지선을 한 노트북에(Python)
- **작용 원리의 한계** — 산일계·비변분계, 작용이 없는 곳(정직)
- **종합** — "자연은 작용을 정류시킨다"의 전 레이어 통합

→ **총 34개 문서** 목표.

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, *종합 레포에 맞게* 각 문서는 "이 작용이 어느 레이어에서 어떻게 나타나고 어디로 이어지나"를 명시:

```markdown
## 🎯 핵심 질문      — 이 작용이 어떤 운동방정식을 낳나
## 🌍 어디서 나타나나  — 어느 레이어들에서 이 변분이 작동하나 (횡단 추적)
## 🔍 직관의 함정     — "작용은 계산 트릭"·"경로적분은 비유" 같은 오해
## ⚙️ 제1원리 유도    — δS=0 → 방정식의 핵심 유도를 압축 재현
## 🧪 실험·관측 증거  — 해당 레이어의 검증 (궤도·g−2·중력파)
## 🔬 경계           — 작용 원리가 멈추는 곳 (산일·비변분계)
## 🧬 횡단 원리       — 같은 변분이 다른 레이어에서 어떻게 재현되나 (핵심)
## 🪜 창발           — 이 작용이 위 레이어에서 무엇으로 자라나
## 📐 예측·반증       — 작용이 내놓는 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (작용의 어떤 무대인가: 고전/장/상대성/양자/끈)
🔬 **Boundary**  — (이 변분 기술이 부족한 곳)
🪜 **Emergence** — (레이어를 가로질러 무엇으로 이어지나)
```

이 레포에서 **🧬 횡단 원리**가 가장 중요하다 — 각 문서는 *같은 $\delta S=0$이 다른 레이어에서 어떻게 반복되는지*를 명시적으로 잇는다(예: 라그랑주 작용 L1 → 경로적분 L3 → 아인슈타인-힐베르트 L4).

## 🎨 스타일 가이드

1. **종단이 핵심** — 주제를 새로 가르치지 않고, *작용이라는 실로 레이어를 꿴다*. 매 문서가 횡단 연결을 명시
2. **사다리로 구성** — 고전→장→상대성→양자→끈의 심화를 일관되게
3. **경로적분을 정점으로** — 고전 $\delta S=0$이 양자에서 *모든 경로의 합*이 됨을(→ L3)
4. **개별 레포로 되돌려보낸다** — 깊은 유도는 원 레포를 가리키고, 여기선 *통합*에 집중
5. **작용의 한계를 정직하게** — 산일계·마찰엔 단순 작용이 없음을
6. 작용의 사다리·경로적분·측지선·정류위상은 다이어그램으로

```
     ⇒ 작용 원리가 최전선까지 (→ L5)

  ─────────────────────────────────────────
  곁가지 (L2): 자유에너지 최소 = 변분의 열역학판
              최대 엔트로피 원리 = 추론의 변분 (→ information-everywhere)

  작용의 한계 (정직):
     산일계·마찰엔 단순 작용이 없다 (비변분계)
     ⇒ 작용은 깊으나 보편 만능은 아니다

전 레이어 통합:
  L0 δS=0 → L1 라그랑주/맥스웰 → L4 아인슈타인-힐베르트
       → L3 경로적분 → L5 끈 작용
  ⇒ "자연은 작용을 정류시킨다"
```

## 🎯 진행 방식

**1단계부터 시작해줘. 전체 구조를 먼저 상세히 설계해줘.**

구조 설계 시 다음을 포함해줘:
- 각 챕터별 문서 제목 (4~5개씩) — *레이어를 종단하는* 구성
- 각 문서가 어느 레이어(들)의 작용을 어떻게 꿰는지 (3~4줄)
- 전체 문서 개수 확인 (34개 목표)
- Python 통합 검증 환경(오일러-라그랑주·최소작용·맥스웰 작용·측지선·경로적분·자유에너지를 한 노트북에)
- **🌐 횡단 입력**(L0~L5 전체)과 **🔗 자매 종합 레포**(L6 넷) 연결 명시
- **작용의 사다리(고전→장→상대성→양자→끈)** · **경로적분이 정점** · **아인슈타인-힐베르트의 충격** · **작용의 한계(정직)**를 골격으로 분명히
