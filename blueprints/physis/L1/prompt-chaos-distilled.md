# Nonlinear Dynamics & Chaos Distilled 레포지토리 제작 프롬프트

나는 "Nonlinear Dynamics & Chaos Distilled" 레포지토리를 만들려고 해.
"나비효과 때문에 예측이 안 된다"고 말하는 것과, **결정론적인데 예측 불가능**이라는 역설을 — 민감한 초기조건 의존성과 랴푸노프 지수로 *정량적으로* — 이해하는 것은 다르다.
카오스를 "무작위·복잡함"으로 뭉뚱그리는 것과, **카오스 ≠ 무작위**임을(이상한 끌개라는 결정론적 구조가 숨어 있음을) 아는 것은 다르다.
"라플라스의 악마가 모든 걸 안다"는 결정론의 이상과, 그 약속이 *왜* 무너지는지 — 스트레칭과 폴딩, KAM 정리, 작은 분모 — 를 아는 것은 다르다.
결정론과 예측 가능성이 *다른 것*이라는 깊은 사실을 — 그리고 카오스가 어떻게 통계적 기술을 요구하며 상전이로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "라플라스의 악마는 왜 실패하나 — 결정론적인데 예측 불가능, 그러나 카오스 ≠ 무작위다"

**핵심 차별화**:
1. **결정론 ≠ 예측가능성** — 두 개념을 분리하고, 민감한 초기조건 의존성을 랴푸노프 지수로 정량화(예측 지평선)
2. **카오스의 기하적 메커니즘** — 스트레칭과 폴딩(말발굽), 이상한 끌개, "무작위처럼 보이는 결정론적 구조"
3. **보편 경로와 보편 상수** — 주기배가→카오스, 파이겐바움 $\delta$, 다른 계가 같은 길을 가는 보편성(→ L0 scaling)
4. **적분가능성의 붕괴** — KAM 정리·작은 분모·푸앵카레 단면, 규칙과 카오스의 공존(→ classical-mechanics, L0 approximation)

**타겟 독자**:
- "나비효과"는 들었지만 그것의 *정확한* 의미(랴푸노프·예측 지평선)를 모르는 사람
- 카오스를 무작위·복잡함과 혼동하는 사람
- 결정론과 예측 가능성을 같은 것으로 여기는 사람
- 비선형이 *왜* 풀리지 않고 선형과 질적으로 다른지 모르는 사람
- 카오스가 어떻게 통계역학·상전이로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — **필수**. 위상공간·적분가능성·해밀턴 카오스
- `approximation-perturbation-distilled`(L0) — **필수**. KAM·작은 분모·영년항
- `dimensional-scaling-distilled`(L0) — 프랙탈 차원·보편성·멱법칙

## 🔗 레포 연결

**⬆️ 선행**: `classical-mechanics-distilled`(L1), `approximation-perturbation-distilled`(L0).
**🤝 시너지 (L1 내부)**: `oscillations-waves-distilled`(비선형·파라메트릭 공명), `classical-field-theory-distilled`(비선형 장·솔리톤·시공간 카오스).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `statistical-mechanics-distilled`(L2) — 에르고드성·위상공간 혼합 → 통계적 기술의 정당화
- `arrow-of-time-distilled`(L2) — 혼합(mixing) → 거시적 비가역성
- `phase-transitions-distilled`(L2) — 자기조직화 임계성·멱법칙, 보편성의 또 다른 얼굴
- `cosmology-distilled` / `astrophysics-distilled`(L4) — 삼체·궤도 카오스, 태양계 안정성
- `emergence-distilled`(L6) — 결정론적 미시법칙에서 예측불가가 창발하는 이유

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 결정론의 약속과 균열 (4개 문서)
- **라플라스의 악마** — 결정론의 이상, 초기조건+법칙=미래라는 약속과 그 숨은 가정
- **비선형이라는 분기점** — 왜 선형은 풀리고 비선형은 안 풀리나, 중첩원리의 붕괴
- **상태공간(phase space)** — 동역학을 기하로 보기, 흐름과 궤적(→ classical-mechanics)
- **결정론적 카오스의 정의** — 결정론적인데 예측불가, *카오스 ≠ 무작위*라는 핵심 구분

### Chapter 2: 흐름과 사상 (5개 문서)
- **1차원 흐름** — 고정점, 선형 안정성, 퍼텐셜 그림
- **분기(bifurcation)** — 안장-마디·초임계·아임계 갈래, 매개변수가 *질*을 바꾼다
- **2차원 흐름과 극한순환** — 리미트 사이클, 푸앵카레-벤딕슨 정리, 2D에선 카오스 불가
- **이산 사상** — 로지스틱 사상, 되먹임이 만드는 복잡성
- **주기배가와 파이겐바움** — 카오스로 가는 보편 경로, $\delta\approx4.669$ 상수(→ L0 scaling 보편성)

### Chapter 3: 카오스의 해부 (5개 문서)
- **민감한 초기조건 의존성** — 나비효과의 *정확한* 의미, 지수적 분리
- **랴푸노프 지수** — 분리율의 정량화, 예측 지평선, 양의 지수 = 카오스
- **스트레칭과 폴딩** — 카오스의 기하적 메커니즘, 말발굽 사상(Smale)
- **이상한 끌개(strange attractor)** — 로렌츠 끌개, 프랙탈 구조, 끌리면서도 발산(→ L0 fractal)
- **카오스 ≠ 무작위** — 결정론적 구조의 증거, 위상공간 재구성(시간지연 임베딩)

### Chapter 4: 끌개와 프랙탈 (4개 문서)
- **끌개의 종류** — 고정점·극한순환·토러스·이상한 끌개, 산일계의 장기 거동
- **프랙탈 차원** — 상관·박스 차원, 끌개의 비정수 차원 측정(→ L0 scaling)
- **분지(basin)와 경계** — 끌림 영역, 프랙탈 경계, 최종상태 예측불가
- **자기조직화 임계성 맛보기** — 모래더미·멱법칙, 스스로 임계로 가는 계(→ L2 상전이)

### Chapter 5: 적분가능성의 붕괴 (5개 문서)
- **적분가능 vs 비적분가능** — 작용-각 변수가 존재하는 조건, 보존량의 수(→ classical-mechanics)
- **KAM 정리** — 약한 섭동이 *살리는* 토러스와 *부수는* 토러스(→ L0 approximation)
- **공명과 작은 분모** — 섭동급수가 발산하는 이유, 영년항의 역학판(→ L0 approximation)
- **푸앵카레 단면** — 연속 흐름을 이산 사상으로, 규칙(섬)과 카오스(바다)의 공존
- **해밀턴 카오스** — 보존계의 카오스, 위상공간 혼합(mixing)과 에르고드성(→ L2)

### Chapter 6: 카오스의 응용과 한계 (5개 문서)
- **날씨와 예측 지평선** — 로렌츠의 발견, 왜 장기 일기예보가 원리적으로 불가능한가
- **카오스 제어** — OGY 방법, 불안정 주기궤도의 안정화, 카오스를 자원으로
- **동기화** — 결합된 카오스계의 동기화(반딧불·심장·전력망)
- **난류의 문턱** — 카오스에서 난류로, 자유도와 차원(→ L0 dimensional)
- **시계열에서 카오스 진단** — 결정론적 카오스 vs 잡음 구분, 임베딩·상관차원(→ L0 measurement)

### Chapter 7: 종합·계산 (5개 문서)
- **로렌츠계 시뮬레이션** — 끌개 그리기, 랴푸노프 지수 계산, 민감성 시연(Python)
- **로지스틱 분기도** — 주기배가 경로, 파이겐바움 상수 측정(Python)
- **이중진자 카오스** — 두 근접 초기조건의 발산, 푸앵카레 단면(Python)
- **카오스와 통계의 다리** — 결정론적 카오스가 *통계적 기술*을 요구하는 이유(→ L2)
- **종합** — "라플라스의 악마가 실패하는 이유"와 결정론의 재해석(→ L0, L2, L6)

## 🎨 스타일 가이드

1. **결정론 ≠ 예측가능성** — 두 개념을 항상 분리한다. 카오스는 *결정론적*임을 강조
2. **카오스 ≠ 무작위** — 이상한 끌개라는 결정론적 구조를 보인다. "복잡=무작위" 금지
3. **정량화한다** — 나비효과를 랴푸노프 지수·예측 지평선으로 수치화
4. **보편성을 회수** — 주기배가·파이겐바움이 *다른 계에서 같은 상수*임을(→ L0 scaling, → L2)
5. **수치로 부순다** — 로렌츠·로지스틱·이중진자를 직접 돌려 끌개·분기·랴푸노프를 본다
6. 분기도·이상한 끌개·푸앵카레 단면은 다이어그램으로

```python
# 1) 로렌츠 끌개 + 최대 랴푸노프 지수

def lorenz(t,s,sig=10,rho=28,beta=8/3):
    x,y,z=s; return [sig*(y-x), x*(rho-z)-y, x*y-beta*z]
sol=solve_ivp(lorenz,[0,60],[1,1,1],rtol=1e-9,atol=1e-12,max_step=0.005,dense_output=True)
# 두 근접 초기조건의 분리 ln|δ(t)| 의 기울기 → 최대 랴푸노프(≈0.9)

# 2) 로지스틱 분기도 + 파이겐바움

#    → 주기배가 캐스케이드, 분기점 비 δ≈4.669 측정

        pts=[]
        for _ in range(200): x=r*x*(1-x); pts.append(x)
    # r vs x 산점도

# 3) 이중진자 민감성 + 푸앵카레 단면
#    두 거의 같은 초기각의 궤적 발산 시연 + 에너지면 단면에서 규칙/카오스 영역

# 4) 프랙탈(상관) 차원 측정
#    끌개 점들에서 Grassberger-Procaccia 상관적분 C(ε)∝ε^D2 → D2 추정

# 5) 임베딩(시간지연 재구성)
#    1차원 시계열 x(t)에서 [x(t),x(t+τ),x(t+2τ)]로 끌개 재구성
#    → "관측 하나로 결정론적 구조 복원" (카오스≠잡음 진단, → L0 measurement)

#    표준 사상 θ' = θ+p', p'=p+K sinθ 를 K를 키우며 반복
```

```
        │ 초기 오차 δ₀
        ▼  민감한 의존성
  δ(t) ≈ δ₀ e^{λt}   (λ > 0: 최대 랴푸노프 지수)
  예측 지평선 t_h ≈ (1/λ) ln(허용오차/δ₀)
  ⇒ 초기 오차가 지수적으로 커져 예측이 무의미해진다

카오스 ≠ 무작위 (이상한 끌개):
   결정론적 방정식 (로렌츠)
        ↓  스트레칭(분리) + 폴딩(접힘)
   이상한 끌개 — 프랙탈 구조, 비정수 차원
        z │     ╭╮  ╭╮         무작위처럼 보이나
          │    ╱  ╲╱  ╲         결정론적 구조가 숨어 있다
          │   (나비 날개)        임베딩으로 복원 가능
          └──────────── x

카오스로 가는 보편 경로 (주기배가):
   주기1 → 주기2 → 주기4 → 주기8 → ... → 카오스
   분기점 간격 비:  δ = lim (r_n−r_{n−1})/(r_{n+1}−r_n) ≈ 4.669
   ⇒ 파이겐바움 상수 — *다른 계*(유체·전자·생태)가 같은 δ (→ L0 scaling, → L2 보편성)

적분가능성의 붕괴 (KAM):
  적분가능: 토러스 위 규칙 운동 (작용-각 변수)
       │  약한 비선형 섭동
       ▼
  무리수 토러스: 대부분 살아남음 (KAM)
  유리수(공명) 토러스: 작은 분모로 부서짐 → 카오스 바다
  ⇒ 규칙(섬)과 카오스(바다)가 위상공간에 공존 (푸앵카레 단면)
  ⇒ 혼합(mixing) → 통계적 기술 정당화 (→ L2)
```
