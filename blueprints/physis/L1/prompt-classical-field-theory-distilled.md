# Classical Field Theory Distilled 레포지토리 제작 프롬프트

나는 "Classical Field Theory Distilled" 레포지토리를 만들려고 해.
입자의 라그랑지안을 쓰는 것과, **입자에서 장(field)으로의 도약** — 무한 자유도를 가진 연속장의 라그랑지안 *밀도*에서 운동방정식이 나오는 과정을 — 유도하는 것은 다르다.
"장(field)이 있다"고 말하는 것과, 장이 *근본 존재*가 되는 순간(입자는 장의 들뜸이다)과 국소성(왜 라그랑지안은 한 점의 장과 그 미분만으로)을 아는 것은 다르다.
뇌터 정리를 입자에 적용하는 것과, **장(field)의 뇌터** — 시공간 대칭이 에너지-운동량 텐서를, 내부 대칭이 보존류를 낳는 과정을 — 아는 것은 다르다.
고전장론이 어떻게 **양자장론으로 가는 다리**인지를 — 장이 무한개 진동자이고, 그것을 양자화하면 입자가 나온다는 것을 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "입자에서 장(field)으로의 도약 — 장이 근본 존재가 되고, 그것을 양자화하면 입자가 나온다"

**핵심 차별화**:
1. **장(field)의 변분을 유도** — 라그랑지안 밀도 $\mathcal L$에서 $\delta S=0$으로 장의 오일러-라그랑주를(→ L0 variational), 이산에서 연속으로의 도약
2. **장(field)의 존재론과 국소성** — 장이 *실재*인 이유(→ electromagnetism), 왜 $\mathcal L$은 국소적인가(인과율)
3. **장(field)의 뇌터** — 시공간 대칭 → 에너지-운동량 텐서 $T^{\mu\nu}$, 내부 대칭 → 보존류, 게이지 대칭(고전)(→ L0 symmetry 완전판)
4. **양자장론으로 가는 다리** — 장(field) = 무한개 정규모드 진동자(→ oscillations), 양자화하면 입자, "입자는 장의 들뜸"(→ L3)

**타겟 독자**:
- 입자 라그랑지안은 알지만 *장(field)*의 라그랑지안 밀도·변분을 모르는 사람
- 장(field)을 "공간에 퍼진 양"으로만 보고 그것이 근본 존재가 되는 의미를 모르는 사람
- 뇌터 정리를 입자에만 적용하고 *장(field)의* 에너지-운동량 텐서·보존류를 모르는 사람
- "입자는 장의 들뜸"이라는 말을 듣지만 그 다리(정규모드 양자화)를 모르는 사람
- 고전장론이 어떻게 QFT·표준모형·일반상대성으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `variational-principles-distilled`(L0) — **필수**. 라그랑지안 밀도·장(field)의 오일러-라그랑주
- `symmetry-conservation-distilled`(L0) — **필수**. 뇌터(보존류·에너지-운동량 텐서)·게이지
- `oscillations-waves-distilled`(L1) — **필수**. 연속체 극한·정규모드 / `electromagnetism-distilled`(L1) — 장의 존재론·전자기장론

## 🔗 레포 연결

**⬆️ 선행**: `variational-principles-distilled`·`symmetry-conservation-distilled`(L0), `oscillations-waves-distilled`·`electromagnetism-distilled`(L1).
**🤝 시너지 (L1 내부)**: `electromagnetism-distilled`(전자기장 = 게이지장의 완전한 장론), `classical-mechanics-distilled`(이산 입자 역학과의 대비).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `quantum-field-theory-distilled`(L3) — 장의 양자화, 입자 = 장의 들뜸, 경로적분, 진공
- `standard-model-distilled`(L3) — 야-밀스 게이지장, 힉스장
- `emergent-quantum-matter-distilled`(L3) — 솔리톤·위상적 보존·자발 대칭 깨짐의 응집물질판
- `general-relativity-distilled`(L4) — 계량장 $g_{\mu\nu}$, 아인슈타인-힐베르트 작용, $T^{\mu\nu}$가 중력원
- `least-action-everywhere` / `symmetry-everywhere`(L6) — 장(field)의 변분·뇌터가 회수되는 곳

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 입자에서 장(field)으로 (5개 문서)
- **왜 장(field)인가** — 무한 자유도, 연속체, 원격작용의 해소(→ electromagnetism 존재론)
- **사슬에서 줄로** — 이산 진동자 → 연속장, 라그랑지안 밀도의 출현(→ oscillations 연속체 극한)
- **장(field)의 작용** — $S=\int\mathcal L\,d^4x$, 라그랑지안 밀도란 무엇인가(→ L0 variational)
- **국소성(locality)** — 왜 $\mathcal L$은 한 점의 장과 그 미분만으로, 인과율과의 관계
- **장(field)의 자유도 세기** — 스칼라·벡터·텐서·스피너장, 성분과 게이지 잉여

### Chapter 2: 장(field)의 변분과 운동방정식 (5개 문서)
- **장(field)의 오일러-라그랑주** — $\delta S=0\Rightarrow \partial_\mu(\partial\mathcal L/\partial(\partial_\mu\phi))-\partial\mathcal L/\partial\phi=0$ 제1원리 유도
- **스칼라장과 클라인-고든** — 가장 단순한 장, 질량항 $m^2\phi^2$의 의미와 분산관계
- **파동방정식 재방문** — 무질량 스칼라 = 파동, 장론적 시선(→ oscillations)
- **복소 스칼라장** — 내부 $U(1)$ 대칭, 전하의 등장(→ L0 symmetry)
- **벡터장** — 전자기장의 라그랑지안, 게이지장으로서의 $A_\mu$(→ electromagnetism)

### Chapter 3: 대칭과 보존류 — 장(field)의 뇌터 (5개 문서)
- **장(field)의 뇌터 정리** — 연속 대칭 → 보존류 $\partial_\mu j^\mu=0$의 완전 유도(→ L0 symmetry 완전판)
- **시공간 대칭과 에너지-운동량 텐서** — 병진 대칭 → $T^{\mu\nu}$, 정준 vs 대칭(벨린판테) 텐서
- **내부 대칭과 전하** — 위상 대칭 → 전하 보존, 보존 전하 $Q=\int j^0 d^3x$
- **게이지 대칭(고전)** — 국소 $U(1)$ → 게이지장 필연, 최소 결합(→ L0 symmetry, → L3)
- **응력-에너지와 중력원** — $T^{\mu\nu}$가 일반상대성의 원천이 되는 다리(→ L4 GR)

### Chapter 4: 고전장의 종류와 동역학 (5개 문서)
- **실/복소 스칼라장** — 동역학, 보존량, 솔리톤의 예고
- **전자기장의 완전한 장론** — $F_{\mu\nu}$, 맥스웰 라그랑지안, 게이지 불변(→ electromagnetism)
- **야-밀스장(고전)** — 비가환 게이지장, 자기상호작용, $SU(N)$(→ L3 표준모형)
- **중력장(고전, 맛보기)** — 계량장 $g_{\mu\nu}$, 아인슈타인-힐베르트 작용의 변분(→ L4)
- **스피너장 맛보기** — 디랙장의 고전적 측면, 반교환의 예고(→ L3)

### Chapter 5: 비선형 장과 솔리톤 (4개 문서)
- **비선형 장(field)** — $\phi^4$ 이론, 자기상호작용, 섭동의 한계(→ L0 approximation)
- **솔리톤** — 안정한 국소 파동, sine-Gordon·KdV, 입자처럼 행동하는 장의 덩어리
- **위상학적 보존** — 위상수(topological charge), 킹크·소용돌이, 동역학과 무관한 보존(→ L3 위상물질)
- **자발 대칭 깨짐(장론)** — 멕시칸 햇 퍼텐셜, 골드스톤장, 도메인 벽(→ L0 symmetry, → L3)

### Chapter 6: 장(field)에서 입자로 — 양자장론의 문턱 (5개 문서)
- **정규모드와 진동자** — 장(field) = 무한개 조화진동자의 모임(→ oscillations)
- **장(field)의 양자화 예고** — 각 모드를 양자화하면 입자가 나온다, 제2양자화의 직관(→ L3 QFT)
- **입자 = 장(field)의 들뜸** — 왜 이 관점이 근본인가, 동일입자성의 기원
- **경로적분 예고** — 장(field)의 경로적분 $Z=\int\mathcal D\phi\,e^{iS/\hbar}$(→ L0 variational, → L3)
- **진공과 영점 에너지** — 장(field)의 바닥상태, 카시미르 효과 예고, "진공은 비어있지 않다"(→ L3)

### Chapter 7: 종합·계산 (6개 문서)
- **스칼라장 수치해** — 클라인-고든/파동 방정식의 격자 시뮬레이션(Python)
- **솔리톤 시뮬레이션** — sine-Gordon 킹크 충돌, 안정성과 위상 보존(Python)
- **보존류 수치 검증** — 에너지-운동량·전하 보존을 격자에서 측정(Python)
- **SSB 장론 시뮬레이션** — $\phi^4$ 이론의 진공 선택, 도메인 벽 형성(Python)
- **고전장→QFT 다리** — 정규모드 양자화, 생성·소멸 연산자 예고(→ L3)
- **종합** — "장(field)이 근본 존재가 되는 순간"과 모든 상호작용의 장론적 통일(→ L0, L3, L4, L6)

→ **총 35개 문서** 목표.

## 🎨 스타일 가이드

1. **장(field)의 변분을 유도로** — 모든 장방정식은 라그랑지안 밀도에서 $\delta S=0$으로 끌어낸다
2. **장(field)은 근본 존재** — "입자는 장의 들뜸"임을, 장이 실재(에너지·운동량·보존류를 가짐)임을 보인다
3. **뇌터를 장(field)으로 완성** — 에너지-운동량 텐서·게이지 보존류를 명시적으로 유도(→ L0 symmetry 완전판)
4. **QFT로 가는 다리를 깐다** — 정규모드 양자화·경로적분·진공을 예고로 명확히(→ L3)
5. **수치로 부순다** — 클라인-고든·솔리톤·SSB를 격자에서 직접 돌려 보존·안정성을 본다
6. 라그랑지안 밀도·솔리톤·멕시칸 햇·정규모드는 다이어그램으로

## 🔬 검증 프로토콜

> 장(field) EL 기호 유도 + 격자 장 시뮬레이션 + 솔리톤·보존류 + SSB 도메인 벽.

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 장(field)의 오일러-라그랑주 (sympy)
#    ℒ(φ, ∂φ)를 주면 장방정식을 자동 도출 → 손유도와 대조
#    예: ℒ = ½(∂φ)² − ½m²φ²  →  (□ + m²)φ = 0  (클라인-고든)

# 2) 클라인-고든 격자 시뮬레이션
#    φ_tt = φ_xx − m²φ 를 유한차분; 분산관계 ω²=k²+m² 측정
import numpy as np
def klein_gordon(N=512, m=0.3, steps=2000, dt=0.02, dx=0.05):
    x=np.arange(N)*dx; phi=np.exp(-((x-x.mean())/1.0)**2); old=phi.copy()
    for _ in range(steps):
        lap=(np.roll(phi,1)-2*phi+np.roll(phi,-1))/dx**2
        new=2*phi-old+dt**2*(lap-m**2*phi); old,phi=phi,new
    return phi   # FFT로 ω(k) 추출 → ω²=k²+m² 확인

# 3) sine-Gordon 솔리톤
#    φ_tt − φ_xx + sin φ = 0 의 킹크 해를 초기조건으로, 두 킹크 충돌
#    → 충돌 후에도 모양 보존(솔리톤), 위상수 보존 확인

# 4) 보존류 수치 검증
#    복소 스칼라장의 U(1) 전류 j^μ, 에너지-운동량 T^{μν}를 격자에서 계산
#    → ∂_μ j^μ ≈ 0, 총에너지·운동량 보존(기계오차 수준)

# 5) φ⁴ 자발 대칭 깨짐 + 도메인 벽
#    V(φ)=−½φ²+¼φ⁴ 에서 장이 ±1 진공으로 정착, 경계에 도메인 벽(킹크)
#    → 진공 선택과 위상 결함 시각화 (→ L0 symmetry, → L3)

# 6) 정규모드 양자화 다리 (개념 시연)
#    자유장을 푸리에 모드로 분해 → 각 모드가 독립 조화진동자임을 수치로
#    → "장 = 무한개 진동자" → 양자화하면 입자 (→ L3 QFT 예고)
```

## 💡 핵심 분석 대상

```
입자 → 장(field)으로의 도약:
  N개 진동자 라그랑지안 (이산)
       │  N→∞, 간격 a→0 (연속체 극한, → oscillations)
       ▼
  장(field)의 작용:  S = ∫ ℒ(φ, ∂_μφ) d⁴x      (ℒ = 라그랑지안 밀도)
       │  δS = 0  (→ L0 variational)
       ▼
  장(field)의 오일러-라그랑주:
       ∂_μ (∂ℒ/∂(∂_μφ)) − ∂ℒ/∂φ = 0
  ─────────────────────────────────────
  ℒ = ½(∂φ)² − ½m²φ²  →  (□ + m²)φ = 0   (클라인-고든)
       m=0 →  □φ = 0   (파동방정식, → oscillations)

장(field)의 뇌터 (대칭 → 보존):
   시공간 병진  →  에너지-운동량 텐서 T^{μν} ,  ∂_μ T^{μν}=0
                  (T^{μν} 가 일반상대성의 중력원 → L4)
   내부 U(1)    →  전류 j^μ ,  ∂_μ j^μ=0 ,  전하 Q 보존
   국소 U(1)    →  게이지장 A_μ 필연 (최소 결합, → electromagnetism, → L3)

자발 대칭 깨짐 (장론):
            V(φ)
             │  ╲     ╱       멕시칸 햇:  진공이 φ=0 아님
        ─────┼───●───●───→ φ   골드스톤장(무질량) + 도메인 벽(킹크)
             │  대칭 법칙 + 비대칭 진공  (→ L0 symmetry, → L3)

장(field) → 입자 (양자장론의 문턱):
  자유장 = 무한개 정규모드 (→ oscillations)
       │  각 모드를 양자화 (제2양자화)
       ▼
  생성·소멸 연산자 → 들뜸 = 입자
  ⇒ "입자는 장(field)의 들뜸"
  경로적분  Z = ∫ Dφ e^{iS/ℏ}  (→ L0 variational, → L3 QFT)
  진공: 영점 에너지 → 카시미르 → "진공은 비어있지 않다" (→ L3)
```
