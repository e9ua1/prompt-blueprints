# Electromagnetism Distilled 레포지토리 제작 프롬프트

나는 "Electromagnetism Distilled" 레포지토리를 만들려고 해.
맥스웰 방정식을 외워서 문제를 푸는 것과, **네 개의 방정식이 어떻게 빛을 예언하는지** — 진공에서 그 방정식들이 파동방정식으로 합쳐지고 $c=1/\sqrt{\varepsilon_0\mu_0}$가 나오는 과정을 — 유도하는 것은 다르다.
"전기장·자기장이 있다"고 말하는 것과, 장(field)이 *비유가 아니라 존재*임을(에너지와 운동량을 나르고, 원천 없이 스스로 전파한다) 아는 것은 다르다.
벡터 퍼텐셜 $A$를 계산 편의로 쓰는 것과, **게이지 자유도**가 왜 "측정 불가능한 것은 물리가 아니다"의 교과서 사례이고, $U(1)$ 대칭이 어떻게 전자기를 *지정*하는지 아는 것은 다르다.
전기와 자기가 사실 *하나*이며(상대성), 게이지 원리가 표준모형으로 가는 문이라는 것을 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "네 방정식이 빛을 예언한다 — 장(field)은 실재이고, 게이지 대칭이 전자기를 지정한다"

**핵심 차별화**:
1. **빛의 필연을 유도** — 진공 맥스웰 → 파동방정식 → $c=1/\sqrt{\varepsilon_0\mu_0}$, "빛은 전자기파일 수밖에 없다"
2. **장(field)의 존재론** — 원격작용 대 장(field), 장이 에너지·운동량을 나르는 *실재*임(포인팅·응력텐서), 비유가 아님
3. **게이지를 진지하게** — 게이지 자유도 = "측정 불가는 물리 아님"(→ L0 measurement), $U(1)$ 게이지 원리가 전자기를 지정(→ L0 symmetry, → L3)
4. **전기·자기는 하나** — 한 관성계의 전기장이 다른 계에선 자기장, 상대론적 공변 형식($F_{\mu\nu}$)이 통합을 드러낸다(→ L4)

**타겟 독자**:
- 맥스웰 방정식을 풀지만 그것이 *빛을 예언*함을 유도 못 하는 사람
- 장(field)을 "계산 도구"로만 보고 그것이 실재(에너지·운동량을 나름)임을 모르는 사람
- 벡터 퍼텐셜·게이지를 편의로만 쓰고 게이지 자유도의 의미를 모르는 사람
- 전기와 자기가 *상대성으로 통합*된다는 것을 모르는 사람
- 전자기가 어떻게 QED·게이지 이론으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `variational-principles-distilled`(L0) — 전자기 라그랑지안 $-\tfrac14 F_{\mu\nu}F^{\mu\nu}$의 변분
- `symmetry-conservation-distilled`(L0) — **필수**. 게이지 대칭·$U(1)$·전하 보존
- `measurement-uncertainty-distilled`(L0) — 게이지 자유도 = 관측 불가 / `oscillations-waves-distilled`(L1) — 파동방정식

## 🔗 레포 연결

**⬆️ 선행**: `symmetry-conservation-distilled`(L0, 게이지), `oscillations-waves-distilled`(L1, 파동).
**🤝 시너지 (L1 내부)**: `classical-field-theory-distilled`(전자기장의 완전한 장론적 형식), `classical-mechanics-distilled`(하전입자 동역학).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `special-relativity-distilled`(L4) — 전기와 자기는 하나, 전자기가 상대성을 *강제*한다
- `general-relativity-distilled`(L4) — 전자기 에너지-운동량 텐서가 중력원
- `quantum-field-theory-distilled`(L3) — QED, 광자, 장의 양자화
- `standard-model-distilled`(L3) — 게이지 원리의 일반화($SU(2)\times U(1)\times SU(3)$)
- `emergent-quantum-matter-distilled`(L3) — 자성·초전도, 창발 게이지장
- `symmetry-everywhere`(L6) — $U(1)$ 게이지가 회수되는 곳

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 장(field)이라는 존재론 (5개 문서)
- **원격작용 vs 장(field)** — 뉴턴 중력의 불편함, 장이 왜 *실재*인가(에너지·운동량을 나르고 지연되어 전파)
- **전하와 쿨롱** — 역제곱의 의미, 중첩원리, 전하의 양자화 맛보기
- **전기장과 가우스 법칙** — 플럭스·발산, 역제곱 ↔ 가우스 법칙의 동치, 대칭 활용
- **전위와 보존성** — 스칼라 퍼텐셜, $\nabla\times E=0$(정전기), 에너지
- **자기장의 수수께끼** — 자기홀극(monopole)은 왜 없나, $\nabla\cdot B=0$의 의미

### Chapter 2: 맥스웰 방정식의 조립 (6개 문서)
- **앙페르 법칙과 그 결함** — 정상전류의 자기장, 연속성과의 모순
- **변위전류** — 맥스웰의 수정, 왜 $\partial E/\partial t$가 필요한가(전하 보존의 요구, → L0)
- **패러데이 법칙** — 전자기 유도, 운동기전력 vs 변환기전력, 렌츠 법칙
- **네 방정식의 완성** — 미분형·적분형, 각 방정식의 물리적 내용
- **전하 보존과 연속방정식** — $\partial_t\rho+\nabla\cdot J=0$이 맥스웰에 *내장*됨(→ L0 symmetry)
- **경계조건** — 매질 계면에서 장의 거동, 도체·유전체 경계

### Chapter 3: 빛의 필연 (5개 문서)
- **파동방정식의 출현** — 진공 맥스웰 → $\nabla^2 E=\tfrac{1}{c^2}\partial_t^2 E$ 제1원리 유도
- **$c$의 정체** — $c=1/\sqrt{\varepsilon_0\mu_0}$, 빛이 전자기파일 수밖에 없는 이유
- **전자기파의 구조** — 횡파, $E\perp B\perp k$, 편광과 그 상태
- **에너지·운동량** — 포인팅 벡터, 복사압, 맥스웰 응력텐서(장이 운동량을 나른다)
- **복사** — 가속하는 전하가 빛을 낸다, 쌍극자 복사, 라모 공식

### Chapter 4: 게이지와 퍼텐셜 (5개 문서)
- **벡터·스칼라 퍼텐셜** — $A$와 $\phi$, 장을 퍼텐셜로 표현(→ L0 symmetry)
- **게이지 자유도** — $A\to A+\nabla\chi$가 물리를 안 바꾼다, "측정 불가는 물리 아님"(→ L0 measurement)
- **게이지 고정** — 쿨롱 게이지·로런츠 게이지, 각각의 쓸모와 한계
- **게이지 원리 예고** — $U(1)$ 국소 대칭이 전자기를 *지정*한다(→ L0 symmetry, → L3 표준모형)
- **아로노프-봄 효과** — 퍼텐셜이 장보다 근본적인가, 게이지의 물리적 실재성(→ L3)

### Chapter 5: 상대론적 전자기 (6개 문서)
- **전기와 자기는 하나** — 한 관성계의 전기장이 다른 계에선 자기장(→ L4 special relativity)
- **4-퍼텐셜과 장텐서** — $A^\mu$, $F_{\mu\nu}$, 맥스웰의 공변 형식
- **로런츠 변환된 장** — 장의 변환 규칙, 운동하는 전하의 장(수축)
- **전자기 라그랑지안** — $S=-\tfrac14\int F_{\mu\nu}F^{\mu\nu}d^4x$, 변분으로 맥스웰(→ L0 variational)
- **에너지-운동량 텐서** — 장의 에너지·운동량·응력의 공변 형식(→ L4 GR 중력원)
- **복사의 상대론** — 체렌코프·싱크로트론 복사, 가속 전하의 상대론적 빛

### Chapter 6: 매질 속 전자기 (5개 문서)
- **유전체와 분극** — 속박전하, $D$장, 감수율과 유전율
- **자성체** — 상자성·반자성·강자성, $H$장, 자화(강자성 = 자발 대칭 깨짐, → L0 symmetry)
- **분산과 굴절률** — 주파수 의존 $\varepsilon(\omega)$, 매질에서 빛이 느려지는 기전
- **흡수와 인과율** — 크라머스-크로니히 관계, 인과율이 분산을 *구속*한다
- **도파관·플라스마** — 차단 진동수, 분산관계, 차원 논증(→ L0 dimensional)

### Chapter 7: 종합·계산 (5개 문서)
- **맥스웰 수치해 (FDTD)** — Yee 격자 시간영역 유한차분, 파동 전파 시뮬레이션(Python)
- **정전기·정자기 경계값** — 라플라스 방정식 완화법(relaxation), 분리변수(Python)
- **복사 패턴 계산** — 안테나·쌍극자 복사장 시각화(Python)
- **전자기→QED 다리** — 광자, 장의 양자화 예고, 진공의 비어있지 않음(→ L3 QFT)
- **종합** — "네 방정식이 빛·상대성·게이지를 낳는다"의 통합(→ L0, L4, L3, L6)

→ **총 37개 문서** 목표.

## 🎨 스타일 가이드

1. **빛의 필연을 유도로** — 진공 맥스웰에서 파동방정식과 $c$를 *끌어낸다*. 외워서 제시 금지
2. **장(field)은 실재** — 장이 에너지·운동량을 나르는 물리적 존재임을 포인팅·응력텐서로 보인다
3. **게이지 = 측정 불가의 교과서** — 게이지 자유도가 "관측 불가능한 것은 물리가 아니다"의 사례임을 명시(→ L0 measurement)
4. **전기·자기는 하나** — 상대성으로의 통합을 공변 형식($F_{\mu\nu}$)으로 드러낸다(→ L4)
5. **수치로 부순다** — FDTD로 파동을, 완화법으로 경계값을, 복사 패턴을 직접 그린다
6. 장선·플럭스·복사 패턴·게이지 변환은 다이어그램으로

## 🔬 검증 프로토콜

> 맥스웰 FDTD + 경계값 완화법 + 게이지 불변량 점검 + $c$ 복원 + 복사 패턴.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) c 복원
#    c = 1/sqrt(ε₀μ₀) 를 CODATA 상수로 계산 → 측정된 광속과 대조
import numpy as np
eps0=8.8541878128e-12; mu0=1.25663706212e-6
print("c =", 1/np.sqrt(eps0*mu0))      # → 2.998e8 m/s

# 2) 1D 맥스웰 FDTD (Yee 격자)
#    E_z, H_y 를 반격자에서 갱신; 진공에서 펄스가 c로 전파하는지 확인
#    → 수치 분산·안정성(Courant) 관찰
def fdtd1d(N=400, steps=600):
    Ez=np.zeros(N); Hy=np.zeros(N)
    for t in range(steps):
        Hy[:-1] += 0.5*(Ez[1:]-Ez[:-1])
        Ez[1:]  += 0.5*(Hy[1:]-Hy[:-1])
        Ez[N//2]+= np.exp(-((t-30)/10)**2)   # 소스
    return Ez

# 3) 정전기 경계값 (라플라스 완화법)
#    경계 전위 고정 → 자코비/가우스-자이델 반복으로 ∇²φ=0 풀기
#    → 등전위선·전기장 시각화 (분리변수 해와 대조)

# 4) 게이지 불변량 점검
#    A → A + ∇χ 변환 후 B=∇×A, E=−∇φ−∂A/∂t 가 불변임을 수치로 확인
#    → "게이지 자유도는 측정 불가, 장은 관측 가능" 시연 (→ L0 measurement)

# 5) 쌍극자 복사 패턴
#    진동 쌍극자의 원거리장 ∝ sin θ / r 를 극좌표로 플롯
#    → 복사 패턴(도넛 모양)과 라모 총복사 전력 확인

# 6) 분산관계와 굴절률
#    플라스마/유전체 모델 ε(ω)에서 차단 진동수·굴절률을 계산
#    → 크라머스-크로니히(인과율↔분산) 수치 확인
```

## 💡 핵심 분석 대상

```
네 방정식이 빛을 예언한다:
  ∇·E = ρ/ε₀          (가우스: 전하가 전기장의 원천)
  ∇·B = 0             (자기홀극 없음)
  ∇×E = −∂B/∂t        (패러데이: 변하는 B가 E를 만든다)
  ∇×B = μ₀J + μ₀ε₀∂E/∂t  (앙페르+변위전류: 변하는 E가 B를 만든다)
        │ 진공(ρ=0,J=0)에서 ∇× 취하고 대입
        ▼
  ∇²E = (1/c²)∂²E/∂t²  ,  c = 1/√(ε₀μ₀)
  ⇒ 빛은 전자기파일 수밖에 없다. 변위전류가 핵심 (→ L0 전하보존)

장(field)은 실재 (비유가 아님):
  포인팅 벡터 S = (1/μ₀)E×B   →  에너지 흐름
  운동량 밀도 g = ε₀ E×B       →  복사압 (장이 운동량을 나른다)
  맥스웰 응력텐서 T_ij          →  장이 힘을 전달
  ⇒ 원천이 사라져도 장은 스스로 전파 (지연·복사)

게이지 자유도 = 측정 불가는 물리 아님:
  E = −∇φ − ∂A/∂t ,  B = ∇×A
  변환:  A → A + ∇χ ,  φ → φ − ∂χ/∂t
        ⇒ E, B 불변 (물리 불변), A·φ는 임의
  ⇒ "측정 가능한 것만 물리" (→ L0 measurement)
  국소 U(1) 대칭이 전자기를 *지정* (→ L0 symmetry, → L3)

전기와 자기는 하나 (상대성):
  정지한 전하   →  전기장만
  운동하는 전하 →  전기장 + 자기장
  로런츠 변환: 한 계의 E가 다른 계에선 B로 섞인다
        ⇒ F_μν 하나로 통합  (→ L4 special relativity)
        S = −¼∫F_μν F^μν d⁴x  →  변분 →  맥스웰 (→ L0 variational)
```
