# Classical Mechanics Distilled 레포지토리 제작 프롬프트

나는 "Classical Mechanics Distilled" 레포지토리를 만들려고 해.
$F=ma$로 문제를 푸는 것과, **같은 운동을 Newton·Lagrange·Hamilton 세 가지 시선으로 보고** 각각이 무엇을 드러내는지 아는 것은 다르다.
"에너지·운동량·각운동량이 보존된다"고 외우는 것과, 그 셋이 *시간·공간·회전 대칭*에서 뇌터 정리로 따라 나온다는 것을 아는 것은 다르다.
케플러 궤도가 닫힌 타원이라는 사실을 아는 것과, 그것이 **숨은 대칭 $SO(4)$**(룽게-렌츠 벡터)의 귀결임을 아는 것은 다르다.
위상공간·포아송 괄호가 어떻게 *양자역학의 선조*가 되는지를 — 고전역학이 사실 더 깊은 구조의 그림자라는 것을 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "같은 운동, 세 시선 — Newton(힘)·Lagrange(작용)·Hamilton(위상공간), 그리고 그 뿌리인 최소작용과 대칭"

**핵심 차별화**:
1. **세 형식을 한 운동으로 통합** — 언제 Newton이 편하고 언제 Lagrange/Hamilton이 이기는지, 같은 물리를 보는 다른 창문
2. **보존 = 대칭을 역학에서 직접** — 뇌터 정리의 역학판, 케플러의 숨은 대칭($SO(4)$)까지(→ L0 symmetry)
3. **위상공간을 진지하게** — 포아송 괄호·정준변환·해밀턴-야코비·리우빌 정리가 통계역학과 양자역학으로 가는 다리(→ L2, L3)
4. **적분가능성의 붕괴까지** — 작용-각 변수·단열 불변량·KAM, 결정론이 카오스와 만나는 첫 균열(→ chaos)

**타겟 독자**:
- $F=ma$는 풀지만 라그랑지안·해밀토니안이 *같은 운동의 다른 언어*임을 모르는 사람
- 보존법칙을 외우지만 그것이 대칭에서 *유도*된다는 것을 모르는 사람
- 위상공간·포아송 괄호를 기호로만 보고 그 의미를 모르는 사람
- 케플러 궤도가 *왜* 닫히는지, 룽게-렌츠가 무엇인지 모르는 사람
- 고전역학이 어떻게 양자역학·통계역학으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `variational-principles-distilled`(L0) — **필수**. 최소작용·오일러-라그랑주·해밀턴 형식의 토대
- `symmetry-conservation-distilled`(L0) — **필수**. 뇌터 정리(보존=대칭)
- `dimensional-scaling-distilled`(L0) — 비리얼·스케일링 논증 / `approximation-perturbation-distilled`(L0) — 섭동·KAM·작은 진동

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 뉴턴의 세계와 그 한계 (5개 문서)
- **운동의 법칙 재검토** — 관성·$F=ma$·작용반작용의 진짜 내용, 무엇이 *정의*이고 무엇이 *물리*인가
- **관성계와 갈릴레이 상대성** — 절대공간 논쟁, 관성계의 동등성, 가속계의 관성력(→ L0 symmetry, → L4 예고)
- **힘과 퍼텐셜** — 보존력의 조건($\nabla\times F=0$), 퍼텐셜 에너지의 존재, 일-에너지 정리
- **구속과 좌표의 저주** — 뉴턴 형식이 구속 앞에서 번거로워지는 이유 — 라그랑주가 필요한 동기
- **결정론과 라플라스의 악마** — 초기조건+법칙=미래?, 카오스가 무너뜨릴 약속(→ chaos)

### Chapter 2: 라그랑주 역학 (6개 문서)
- **일반화 좌표와 자유도** — 구속을 좌표 선택으로 흡수, 배위공간(configuration space)
- **달랑베르 원리** — 가상일, 구속력 소거, 라그랑주 방정식으로 가는 또 다른 길
- **최소작용에서 라그랑주로** — $\delta S=0\Rightarrow$ 오일러-라그랑주(→ L0 variational 재등장), $L=T-V$의 회복
- **순환 좌표와 보존량** — $L$이 좌표를 명시적으로 모르면 켤레운동량 보존(→ L0 symmetry)
- **라그랑주 승수와 구속력** — 구속력을 *복원*하는 법, 장력·수직항력 계산
- **라그랑주 역학 실전** — 이중진자·구면진자·회전계의 운동방정식 유도

### Chapter 3: 대칭성과 보존 — 뇌터의 역학판 (5개 문서)
- **뇌터 정리(역학)** — 연속 대칭 → 보존량, 시간/공간/회전의 세 보존을 직접 유도(→ L0 symmetry)
- **에너지 보존의 조건** — $L$이 시간을 명시적으로 모를 때, 야코비 적분과 에너지의 구분
- **운동량·각운동량** — 병진·회전 대칭의 직접 귀결, 중심력에서 각운동량 보존
- **갈릴레이 군과 추가 보존량** — 질량중심의 등속 운동, 갈릴레이 부스트가 낳는 보존량
- **스케일링 대칭과 비리얼 정리** — 차원/스케일 논증(→ L0 dimensional), $\langle T\rangle$-$\langle V\rangle$ 관계

### Chapter 4: 해밀턴 역학과 위상공간 (6개 문서)
- **르장드르 변환** — $L(q,\dot q)\to H(q,p)$, 켤레운동량, 변환의 기하(→ L0 variational)
- **해밀턴 방정식과 위상공간 흐름** — 상태=점, 시간발전=벡터장, 흐름의 기하학
- **포아송 괄호** — 대수 구조, 보존량의 판정 $\{f,H\}=0$, 양자 교환자 $[\hat q,\hat p]=i\hbar$의 선조(→ L3)
- **정준변환** — 위상공간의 대칭, 생성함수, 좌표의 자유와 심플렉틱 구조
- **해밀턴-야코비 이론** — 작용이 생성함수, 파동과 입자의 다리, 슈뢰딩거의 예고(→ L3)
- **리우빌 정리** — 위상부피 보존, 비압축 흐름, 통계역학으로 가는 다리(→ L2)

### Chapter 5: 진동·강체·중심력 (6개 문서)
- **작은 진동과 정규모드** — 평형 근처 2차 전개, 연성 진동, 고유진동수 문제(→ oscillations-waves)
- **중심력 문제** — 유효퍼텐셜, 궤도 방정식, 케플러 문제의 완전 해
- **케플러와 룽게-렌츠** — 숨은 대칭 $SO(4)$, 왜 타원이 *닫히나*, 추가 보존 벡터(→ L0 symmetry 심화)
- **강체 운동학** — 오일러 각, 각속도, 관성텐서와 주축
- **강체 동역학** — 오일러 방정식, 팽이의 세차·장동, 자유 회전의 안정성(중간축 정리)
- **산란** — 충돌·러더퍼드 산란, 단면적, 미시 상호작용에서 거시 관측으로(→ L3, L4)

### Chapter 6: 적분가능성과 그 너머 (5개 문서)
- **적분가능계** — 작용-각 변수, 토러스 위의 운동, 왜 어떤 계는 풀리나
- **단열 불변량** — 천천히 변하는 계의 보존량(진자 길이 변화), 작용의 단열 보존
- **섭동과 KAM 정리** — 약한 비선형이 토러스를 부수기 시작(→ L0 approximation, → chaos)
- **카오스의 문턱** — 비적분가능계, 푸앵카레 단면, 결정론적 예측불가의 등장(→ chaos)
- **비선형 진동** — 영년항·다중 스케일의 역학적 사례, 진폭 의존 진동수(→ L0 approximation)

### Chapter 7: 종합·계산 (5개 문서)
- **세 형식의 비교** — Newton/Lagrange/Hamilton, 언제 무엇을 쓰나, 같은 물리 다른 창문의 총정리
- **심플렉틱 적분기** — 에너지·위상공간 구조를 지키는 수치적분, 단순 오일러와의 차이(Python)
- **N체 시뮬레이션** — 보존량 추적, 카오스 진단(랴푸노프), 안정성 분석(Python)
- **고전→양자 다리** — 포아송→교환자, 해밀턴-야코비→슈뢰딩거, 대응원리(→ L3)
- **종합** — "같은 운동, 세 시선"의 통합과 최소작용·대칭이라는 두 뿌리(→ L0, L6)

## 🎨 스타일 가이드

1. **유도할 수 없다면 이해한 게 아니다** — 운동방정식은 작용/대칭에서 끌어낸다. 세 형식을 *같은 물리*로 잇는다
2. **보존은 대칭의 그림자** — 모든 보존을 뇌터로 유도하고, 케플러의 숨은 대칭까지 보인다
3. **위상공간을 진지하게** — 포아송 괄호·심플렉틱 구조가 양자·통계로 가는 다리임을 명시
4. **결정론의 균열을 정직하게** — 적분가능성이 예외이고 카오스가 일반임을 표시(→ chaos)

6. 위상공간 흐름·정규모드·궤도·푸앵카레 단면은 다이어그램으로

## 🔬 검증 프로토콜

> 라그랑지안 기호 유도 + 심플렉틱 적분 + 보존량·리우빌 점검 + 카오스 진단.

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 라그랑지안 → 운동방정식 (sympy)
import sympy as sp
t = sp.symbols('t'); th = sp.Function('theta')
m,l,g = sp.symbols('m l g', positive=True)
L = sp.Rational(1,2)*m*l**2*sp.diff(th(t),t)**2 + m*g*l*sp.cos(th(t))  # 진자
EL = sp.diff(L, th(t)) - sp.diff(sp.diff(L, sp.diff(th(t),t)), t)
print(sp.simplify(EL))   # → m l² θ'' = -m g l sinθ

# 2) 심플렉틱 적분기 vs 단순 오일러
#    조화진동자/케플러를 leapfrog(velocity Verlet)와 Euler로 적분
#    → Euler는 에너지가 표류, symplectic은 장기적으로 보존됨을 비교
import numpy as np
def leapfrog(x,v,a,dt,N):
    xs=[]; 
    for _ in range(N):
        v=v+0.5*dt*a(x); x=x+dt*v; v=v+0.5*dt*a(x); xs.append(x)
    return np.array(xs)
# E(t)의 표준편차로 보존성 비교

# 3) 보존량(뇌터) 점검
#    중심력 N체에서 에너지·총운동량·각운동량의 시간 변화 측정
#    → 대칭에 대응하는 보존량이 기계오차 수준 유지됨을 확인

# 4) 리우빌 정리 수치 시연
#    위상공간의 작은 사각형(점 구름)을 시간발전 → 면적(부피) 보존 확인
#    (모양은 변해도 넓이는 불변 → 비압축 흐름)

# 5) 포아송 괄호 검증 (sympy)
#    {q,p}=1, {Lz, Lx}=Ly 등 각운동량 대수 직접 계산 → 교환자 구조 예고

# 6) 카오스 진단
#    이중진자/헤논-하일레스: 두 근접 초기조건의 분리율(최대 랴푸노프 지수)
#    + 푸앵카레 단면으로 규칙/카오스 영역 시각화 (→ chaos 레포)
```

## 💡 핵심 분석 대상

```
같은 운동, 세 시선:
  Newton:    F = ma          (힘, 벡터, 직관적이나 구속에 약함)
       │ 최소작용 δS=0 (→ L0 variational)
       ▼
  Lagrange:  d/dt(∂L/∂q̇) − ∂L/∂q = 0   (작용, 일반화 좌표, 구속에 강함)
       │ 르장드르 변환  p = ∂L/∂q̇
       ▼
  Hamilton:  q̇ = ∂H/∂p ,  ṗ = −∂H/∂q   (위상공간, 1계, 대칭적)
       포아송 {q,p}=1  ──양자화──▶  [q̂,p̂]=iℏ   (→ L3)
       리우빌: 위상부피 보존  ──────▶  앙상블·통계역학 (→ L2)

보존 = 대칭 (뇌터의 역학판):
   시간 병진 대칭  →  에너지 보존
   공간 병진 대칭  →  운동량 보존
   회전 대칭        →  각운동량 보존
   + 케플러 숨은 대칭 SO(4) (룽게-렌츠) → 타원이 닫힌다

적분가능성의 붕괴 (결정론의 첫 균열):
  적분가능: 작용-각 변수 존재 → 토러스 위 규칙 운동
       │  약한 비선형 섭동
       ▼  (KAM 정리)
  일부 토러스 살아남고 / 일부 부서진다 → 카오스의 씨앗 (→ chaos)
  공명·작은 분모 → 섭동급수 발산 (→ L0 approximation)

위상공간 흐름:
   p │   ╭───╮      에너지 등고선 = 궤도
     │  │  ·→ │     점 = 상태,  화살 = 시간발전
     │   ╰───╯      닫힌 곡선 = 주기운동
     └────────── q   리우빌: 면적 보존
```
