# Oscillations & Waves Distilled 레포지토리 제작 프롬프트

나는 "Oscillations & Waves Distilled" 레포지토리를 만들려고 해.
조화진동자 공식을 외우는 것과, **왜 단순조화진동이 우주의 거의 모든 곳에서 기본 모드인지** — 평형 근처에선 어떤 퍼텐셜이든 포물선이라는 사실에서 — 유도하는 것은 다르다.
"공명은 진동수가 맞을 때 일어난다"고 말하는 것과, 공명 폭·위상 지연·$Q$값이 *왜* 그렇게 되는지, 그리고 타코마 다리부터 분자 흡수선까지 같은 수학인 이유를 아는 것은 다르다.
푸리에 변환을 도구로 쓰는 것과, 그것이 **세계를 진동으로 분해**하는 것이고 $\Delta t\cdot\Delta\omega\ge 1/2$가 양자 불확정성의 고전적 선조임을 아는 것은 다르다.
진동이 왜 물리의 기본 언어인지를 — 정규모드·파동방정식·푸리에가 어떻게 양자역학과 장론으로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "평형 근처에선 모든 것이 진동한다 — 정규모드·공명·푸리에가 세계를 진동으로 분해하는 보편 언어다"

**핵심 차별화**:
1. **SHM의 보편성을 유도** — "왜 어디에나 조화진동인가"를 *평형 근처 2차 전개*에서(→ L0 approximation), 우연이 아니라 필연
2. **공명을 메커니즘으로** — 정상상태 응답·위상 지연·$Q$값을 식에서, 그리고 진자·LC회로·분자·다리가 *같은 방정식*임을
3. **푸리에 = 세계의 분해** — 정규모드의 직교성에서 푸리에로, 시간↔진동수 쌍대성과 고전 불확정성(→ L3 다리)
4. **파동방정식의 출현과 한계** — 연속체 극한에서 파동이 나오는 과정, 분산·군속도·위상속도, 정보속도와의 구분

**타겟 독자**:
- 조화진동자를 풀지만 "왜 SHM이 그렇게 흔한지" 모르는 사람
- 공명을 알지만 $Q$값·공명 폭·위상 지연의 기전을 모르는 사람
- 푸리에를 쓰지만 그것이 *세계를 진동 모드로 분해*하는 것임을, 불확정성과의 관계를 모르는 사람
- 군속도와 위상속도를 혼동하거나 "파속 = 정보속도"로 착각하는 사람
- 파동방정식이 어떻게 슈뢰딩거·장론으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `approximation-perturbation-distilled`(L0) — **필수**. 평형 근처 2차 전개가 SHM의 기원
- `variational-principles-distilled`(L0) — 작은 진동의 라그랑지안 / `dimensional-scaling-distilled`(L0) — 소리·파동 속도의 차원 복원
- `classical-mechanics-distilled`(L1) — 작은 진동·정규모드의 역학적 토대

## 🔗 레포 연결

**🤝 시너지 (L1 내부)**: `electromagnetism-distilled`(전자기파 = 파동방정식의 빛 버전), `classical-field-theory-distilled`(사슬→줄의 연속체 극한이 장론의 입구), `chaos-distilled`(비선형·파라메트릭 공명).

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 단순조화진동 — 우주의 기본 모드 (5개 문서)
- **왜 SHM이 어디에나** — 평형 근처에선 어떤 퍼텐셜이든 포물선 → 선형 복원력, 우연이 아닌 필연(→ L0 approximation)
- **조화진동자의 해부** — 진폭·위상·에너지, 등시성(진폭과 무관한 주기)과 그 깨짐
- **감쇠 진동** — 과·임계·저감쇠의 세 영역, $Q$값의 의미와 에너지 손실
- **강제진동과 공명** — 정상상태 응답, 공명 폭, 진폭과 위상의 진동수 의존
- **비선형 진동 맛보기** — 진자의 비등시성, 경성/연성 용수철, 진폭 의존 진동수(→ L0 approximation, → chaos)

### Chapter 2: 연성 진동과 정규모드 (5개 문서)
- **두 개의 연성 진동자** — 박놀이(beats), 에너지의 주기적 교환, 모드 분리
- **정규모드** — 동시에 같은 진동수로 움직이는 패턴, 고유값 문제로서의 진동(→ L0 선형대수 교차)
- **N개 사슬과 분산관계** — 격자 진동, $\omega(k)$, 음향 모드와 브릴루앙 영역 맛보기(→ L3 창발물질)
- **연속체 극한** — 사슬 → 줄, 파동방정식의 탄생(→ classical-field-theory 다리)
- **모드의 직교성과 전개** — 임의 운동 = 정규모드의 중첩, 푸리에로 가는 입구

### Chapter 3: 파동방정식 (5개 문서)
- **파동방정식 유도** — 줄·관·탄성체에서 $\partial_t^2 u = c^2\partial_x^2 u$를 제1원리에서 유도
- **진행파와 정상파** — 달랑베르 해, 경계조건과 고유모드, 현의 배음
- **파동의 에너지·운동량** — 에너지 흐름, 군속도 vs 위상속도의 결정적 구분
- **분산과 소산** — 분산매질에서 파속의 분리, 파속 ≠ 정보속도(인과율과의 관계)
- **경계와 계면** — 반사·투과, 임피던스 정합, 전반사(→ electromagnetism 다리)

### Chapter 4: 푸리에 — 세계를 진동으로 분해 (5개 문서)
- **푸리에 급수** — 주기함수 = 조화 모드의 합, 수렴과 깁스 현상
- **푸리에 변환** — 비주기로의 확장, 시간↔진동수 쌍대성
- **불확정성(고전)** — $\Delta t\cdot\Delta\omega\ge 1/2$, 펄스와 대역폭의 거래, 양자 불확정성의 선조(→ L3)
- **선형계와 임펄스 응답** — 그린함수, 합성곱, LTI 시스템의 보편성
- **스펙트럼과 신호** — 파워 스펙트럼, 잡음, 측정의 한계(→ L0 measurement, → L2)

### Chapter 5: 공명과 응답 (4개 문서)
- **공명의 보편성** — 진자·LC회로·분자·다리(타코마)가 *같은 수학*임(→ classical-mechanics)
- **선형응답 이론** — 외부 자극에 대한 1차 응답, 감수율(susceptibility)(→ L2 요동-소산)
- **$Q$값과 손실** — 에너지 저장 대 손실, 공진기의 품질, 선폭과의 관계
- **파라메트릭·비선형 공명** — 그네 타기, 진동수 두 배 불안정, 매개변수 구동(→ chaos)

### Chapter 6: 빛·소리·물결 — 파동의 현상 (5개 문서)
- **간섭** — 중첩의 직접 귀결, 두 슬릿, 결맞음(coherence)의 의미
- **회절** — 호이겐스 원리, 단일 슬릿, 분해능 한계(→ L0 measurement)
- **도플러와 충격파** — 운동하는 원천, 마하 원뿔, 차원 논증(→ L0 dimensional, → L4)
- **음파와 매질** — 소리 속도의 차원 복원(→ L0 dimensional), 음향학의 기초
- **물결과 분산** — 표면파, 깊은/얕은 물의 분산, 쓰나미와 군속도

### Chapter 7: 종합·계산 (5개 문서)
- **파동방정식 수치해** — 유한차분, 안정성(CFL 조건), 정상파·간섭 재현(Python)
- **정규모드 수치** — 연성 진동자의 고유값 문제, 모드 형상 시각화(Python)
- **FFT 실습** — 신호를 스펙트럼으로, 필터링, 깁스 현상 관찰(Python)
- **파동→양자 다리** — 파동방정식과 슈뢰딩거 방정식, 물질파와 분산관계(→ L3)
- **종합** — "왜 진동이 물리의 기본 언어인가"와 푸리에·정규모드의 보편성(→ classical-field-theory, L3)

→ **총 34개 문서** 목표.

# 1) 정규모드 = 고유값 문제
#    연성 질량-용수철 사슬의 강성행렬 K, 질량행렬 M → 일반화 고유값 문제
#    eig(M⁻¹K) → 고유진동수와 모드 형상, 직교성 확인

n=10; K=2*np.eye(n)-np.eye(n,k=1)-np.eye(n,k=-1)
w2,modes=np.linalg.eigh(K)            # 진동수² 와 정규모드

# 2) 파동방정식 FDTD + CFL 안정성
#    u_tt = c² u_xx 를 유한차분; Courant 수 = cΔt/Δx
#    → C≤1 안정, C>1 발산을 직접 관찰 (안정성의 경계)
def wave1d(C):                        # C: Courant number
    N=400; u=np.exp(-((np.arange(N)-N//2)/10)**2); uo=u.copy(); ...
    # u_new = 2u - u_old + C²(u_{i+1}-2u_i+u_{i-1})  → C>1이면 폭발

# 3) FFT와 시간-진동수 불확정성
#    가우스 펄스의 폭 Δt 와 그 FFT 폭 Δω 의 곱이 ≳ 1/2 임을 측정
#    → 펄스를 좁힐수록 대역폭이 넓어짐 (고전 불확정성, → L3)
sig=np.exp(-(np.linspace(-5,5,1024))**2)
spec=np.abs(np.fft.fftshift(np.fft.fft(sig)))
# Δt·Δω 추정 → ≳ 0.5 확인

# 4) 공명 곡선·위상 지연
#    강제 감쇠 진동자의 정상상태 진폭 A(ω), 위상 φ(ω)를 스캔
#    → 공명 봉우리·Q값(폭)·위상이 0→π로 넘어가는 거동 시각화

# 5) 분산관계와 군속도
#    격자 사슬의 ω(k)=2ω₀|sin(k/2)| 측정, v_phase=ω/k vs v_group=dω/dk 비교
#    → 가장자리에서 군속도→0 (정상파) 확인

# 6) 간섭/회절 수치
#    두 슬릿·단일 슬릿의 회절 패턴을 중첩으로 계산 → 분해능 한계 시연

## 💡 핵심 분석 대상

```
왜 SHM이 어디에나 (평형 근처 보편성):
  임의 퍼텐셜 V(x)를 평형 x₀ 근처 전개:
    V(x) ≈ V(x₀) + ½ V''(x₀)(x−x₀)² + ...      (1차항=0, 평형)
        ↓  V'' > 0 이면
  복원력 F = −V''(x−x₀)  →  단순조화진동  ω=√(V''/m)
  ⇒ 평형이 안정이면 *무조건* 작은 진동은 SHM (→ L0 approximation)

연성 → 정규모드 → 연속체 → 파동:
  N개 진동자  ──고유값 문제──▶  정규모드 (직교)
       │  N→∞, 간격→0 (연속체 극한)
       ▼
  파동방정식  u_tt = c² u_xx
       달랑베르 해: u = f(x−ct) + g(x+ct)   (진행파)
       경계조건 → 정상파 (배음)   →  현·관·드럼

푸리에 = 세계의 분해:
  임의 신호 = Σ (또는 ∫) 조화 모드
  시간 ↔ 진동수 쌍대성
       Δt · Δω ≳ 1/2     ← 고전 불확정성 (펄스↔대역폭)
                              │ ℏ 곱하면
                              ▼
                          Δx · Δp ≳ ℏ/2   양자 불확정성 (→ L3)

세 속도 (혼동 금지):
  위상속도 v_p = ω/k        (마루의 속도)
  군속도   v_g = dω/dk      (포락선·에너지·정보의 속도)
  분산매질: v_p ≠ v_g,  v_g ≤ c (인과율)

공명의 보편성 (같은 방정식):
  진자 · LC회로 · 분자 흡수선 · 타코마 다리
        ⇒  mẍ + γẋ + kx = F₀cos(ωt)
        정상상태 진폭 A(ω) ∝ 1/√((ω₀²−ω²)² + (γω)²)
        Q = ω₀/γ  (좁을수록 날카로운 공명)
```
