# Symmetry & Conservation Distilled 레포지토리 제작 프롬프트

나는 "Symmetry & Conservation Distilled" 레포지토리를 만들려고 해.
"에너지는 보존된다"를 법칙으로 외우는 것과, 그것이 **시간이 균질하다(법칙이 시간에 따라 변하지 않는다)는 대칭성**에서 뇌터 정리로 *따라 나온다*는 것을 아는 것은 다르다.
"전자기력·약력·강력이 있다"고 나열하는 것과, 그 세 힘이 전부 **대칭을 점마다 국소화하라**는 단 하나의 요구(게이지 원리)에서 *강제로* 나온다는 것을 아는 것은 다르다.
$SU(3)\times SU(2)\times U(1)$을 기호로 보는 것과, 군(group)이 왜 "대칭의 언어"이고 입자가 왜 그 *표현(representation)*으로 분류되는지를 아는 것은 다르다.
대칭성이 어떻게 현대물리의 척추가 되었는지를 — 보존법칙·힘·입자·질량의 기원까지 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "대칭성이 보존법칙을 낳고(뇌터), 대칭을 국소화하면 힘이 나온다(게이지) — 대칭은 현대물리의 척추다"

**핵심 차별화**:
1. **뇌터 정리를 완전 유도** — "연속 대칭 ↔ 보존법칙"을 표어로 두지 않고, 작용 불변 + 변분에서 보존류 $\partial_\mu j^\mu=0$를 한 줄도 빼지 않고
2. **군(group)을 도구가 아니라 직관으로** — 네 공리가 왜 "대칭"을 정확히 포착하나, 리 대수의 교환관계가 어떻게 군 구조를 결정하나, 입자가 표현으로 분류되는 이유
3. **게이지 원리 = 힘의 기원** — 전역 대칭을 국소 대칭으로 *요구*하면 게이지 장(field)이 필연적으로 등장하고, 그것이 전자기·약·강력이 되는 과정
4. **깨진 대칭성의 위력** — 자발 대칭 깨짐·골드스톤·힉스 메커니즘으로 질량이 생기는 기원, "법칙은 대칭인데 상태는 비대칭"

**타겟 독자**:
- 보존법칙을 외우지만 그것이 *대칭에서 유도된다*는 것을 모르는 사람
- $SU(N), U(1)$ 기호는 보지만 군·표현·생성원의 물리적 의미를 모르는 사람
- "게이지 대칭"을 들어봤지만 그것이 *왜 힘을 지정하는지* 모르는 사람
- 힉스 메커니즘을 "입자에 질량을 준다"로만 아는 사람(깨진 대칭성의 구조를 모르는)
- 위층(L3 표준모형·L4 시공간 대칭)의 척추를 L0에서 미리 세우고 싶은 사람

**선행 학습**:
- `variational-principles-distilled`(L0) — **필수**. 뇌터 정리는 작용·오일러-라그랑주 위에서만 유도된다
- `dimensional-scaling-distilled`(L0) — 보존량·전하의 차원
- (선택) 군의 행렬 표현은 [IQ AI Lab · linear-algebra-deep-dive](https://github.com/iq-ai-lab)와 교차(고유값·표현), 본문은 자족적으로 전개

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 대칭이란 무엇인가 (5개 문서)
- **대칭의 정의** — "변환해도 안 변함", 불변량(invariant)이라는 개념, 대칭이 왜 깊은 정보인가
- **이산 vs 연속 대칭** — 거울/한 칸 회전 vs 연속 회전, 각각이 낳는 것의 결정적 차이(이산→선택규칙, 연속→보존류)
- **능동 vs 수동 변환** — 대상을 돌리기 vs 좌표를 돌리기, 같은 수학·다른 해석
- **대칭과 물리법칙** — 공간 균질성·등방성·시간 균질성이 법칙에 거는 제약
- **갈릴레이/로런츠 대칭** — 관성계 사이의 대칭, 상대성원리의 뿌리(→ L4 예고)

### Chapter 2: 군(group) — 대칭의 언어 (5개 문서)
- **군의 정의** — 닫힘·항등·역원·결합, 왜 이 네 공리가 "대칭의 집합"을 정확히 포착하나
- **이산군** — 순환군·이면체군·치환군, 결정·분자의 대칭과 분류
- **연속군(리 군)** — 회전군 $SO(3)$, $U(1)$, 매끄러운 대칭, 생성원(generator)의 의미
- **리 대수** — 무한소 변환, 교환관계 $[T_a,T_b]=if_{abc}T_c$가 군 구조를 결정
- **표현론 맛보기** — 군이 행렬로 작용한다, 입자가 *기약표현*으로 분류되는 이유(→ L3)

### Chapter 3: 뇌터 정리 — 완전 전개 (5개 문서)
- **뇌터의 통찰** — 연속 대칭 ↔ 보존법칙의 일대일, 역사적 맥락(일반상대성의 에너지 문제에서 출발)
- **정리의 유도** — 작용 불변 + 변분 → 보존류 $\partial_\mu j^\mu=0$ 완전 증명(→ `variational` 토대)
- **세 고전 보존** — 시간병진→에너지, 공간병진→운동량, 회전→각운동량(각각 명시적 유도)
- **장(field)의 뇌터** — 내부(internal) 대칭 → 전하 보존, 연속방정식, 보존 전하 $Q=\int j^0 d^3x$
- **뇌터 제2정리** — 국소(게이지) 대칭의 특수성, 항등식과 잉여 자유도, 게이지 이론으로 가는 문

### Chapter 4: 깨진 대칭성 (4개 문서)
- **명시적 vs 자발적 깨짐** — 법칙은 대칭인데 *상태*가 비대칭, 똑바로 세운 연필 비유
- **자발 대칭 깨짐(SSB)** — 강자성·결정의 사례, 진공의 선택, 골드스톤 정리의 진술
- **골드스톤 보손** — 깨진 연속대칭마다 무질량 모드, 포논·마그논(→ L3 창발물질)
- **힉스 메커니즘** — 게이지 + SSB, 골드스톤이 "먹혀" 게이지 보손이 질량을 얻는다, 질량의 기원(→ L3)

### Chapter 5: 게이지 대칭 — 힘의 기원 (5개 문서)
- **전역에서 국소로** — 위상을 점마다 자유롭게 바꿀 권리를 요구하면 무슨 일이?
- **게이지 장(field)의 필연** — 공변미분 $D_\mu=\partial_\mu - igA_\mu$, 연결(connection)로서의 퍼텐셜
- **$U(1)$ 게이지 = 전자기** — 맥스웰 방정식이 게이지 원리에서 나온다(→ L1 EM)
- **비가환 게이지(양-밀스)** — $SU(2)\times SU(3)$, 약력·강력, 자기상호작용하는 게이지장(→ L3)
- **게이지 원리의 의미** — "대칭이 상호작용을 *지정*한다"는 현대물리의 척추, 기하학적 해석

### Chapter 6: 시공간·이산 대칭 (4개 문서)
- **푸앵카레 대칭** — 로런츠 변환 + 병진, 위그너 분류(입자 = 질량·스핀), 왜 스핀이 표현 라벨인가(→ L4)
- **C, P, T** — 전하켤레·공간반전·시간역전, 각 변환의 정확한 의미
- **CP 깨짐과 CPT 정리** — 왜 우주는 반물질이 아니라 물질로 남았나(→ L4 cosmology 바리온 비대칭)
- **대칭과 선택규칙** — 대칭이 *금지*하는 전이, 분광학·붕괴의 규칙

### Chapter 7: 종합·계산 (8개 문서)
- **회전 대칭과 각운동량** — $SO(3)/SU(2)$ 대수에서 $\ell, m$ 양자수가 나온다(→ L3)
- **결정의 대칭과 밴드** — 공간군, 블로흐 정리, 밴드 구조가 대칭으로 강제되는 곳(→ L3 창발물질)
- **대칭으로 적분·계산 줄이기** — 대칭 논증이 계산을 공짜로 단순화하는 실전 사례
- **보존량 수치 검증** — 시뮬레이션에서 에너지·운동량·각운동량 보존을 측정(Python)
- **깨진 대칭 시뮬레이션** — 이중우물 퍼텐셜에서 SSB와 진공 선택을 관찰
- **게이지 불변 수치 확인** — 격자에서 게이지 변환 불변량(윌슨 루프 맛보기) 측정
- **대칭의 위계** — 어떤 대칭이 정확하고 어떤 게 근사·창발인가, 자연의 대칭 지도
- **종합** — "대칭성은 왜 현대물리의 가장 강력한 도구인가"

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, 마지막 세 단 종결:

```markdown
## 🎯 핵심 질문      — 어떤 대칭이 어떤 보존/힘/입자를 낳나
## 🌍 어디서 나타나나  — 이 대칭이 작동하는 물리 장면
## 🔍 직관의 함정     — "대칭은 그냥 예쁜 것" 류 오해, 보존을 공리로 착각하는 함정
## ⚙️ 제1원리 유도    — 대칭 → 뇌터 보존류, 또는 국소화 → 게이지장 (유도 명시)
## 🧪 실험·관측 증거  — 보존량 측정·선택규칙·게이지 보손 발견 등
## 🔬 경계           — 대칭이 깨지는 곳(SSB·이상(anomaly)·근사 대칭)
## 🧬 횡단 원리       — 대칭성이 다른 레이어에서 어떻게 반복되나 (이 레포의 핵심 축)
## 🪜 창발           — 위 레이어(표준모형·창발물질·우주론)에서 무엇이 나타나나
## 📐 예측·반증       — 대칭이 강제하는 검증 가능한 예측(금지 전이·입자 존재)
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (어떤 대칭에서 무엇이 따라 나오나)
🔬 **Boundary**  — (대칭이 깨지거나 근사인 조건: SSB·이상·명시적 깨짐)
🪜 **Emergence** — (위 레이어에서 같은 대칭이 낳는 것 + 검증 실험)
```

이 레포에서 **⚙️ 제1원리 유도**는 *대칭 변환을 명시적으로 적고* 뇌터 보존류 또는 게이지장을 끌어내며, **🔬 경계**는 "자발 깨짐", "양자 이상(anomaly)으로 고전 대칭이 양자에서 깨짐", "근사 대칭" 같은 구체적 한계를 다룬다.

## 🎨 스타일 가이드

1. **보존법칙을 공리로 두지 않는다** — 모든 보존은 대칭에서 *유도*한다. "에너지는 보존된다"가 아니라 "시간 균질성 → 에너지 보존"
2. **게이지 = 힘의 기원을 끝까지** — "대칭을 국소화하면 상호작용이 강제된다"를 공변미분 수준에서 보인다
3. **깨진 대칭을 정직하게** — SSB·골드스톤·힉스를 "질량을 준다"로 끝내지 않고 진공 선택·먹힘(eaten) 구조로
4. **표현 = 입자 라벨** — 군의 기약표현이 입자 분류임을, 추상에서 물리로 내린다
5. **극한·이상에서 부순다** — 고전 대칭이 양자에서 깨지는 이상(anomaly), 근사 대칭의 경계를 표시
6. 군 구조·SSB 퍼텐셜(멕시칸 햇)·게이지 연결은 다이어그램으로

## 🔬 검증 프로토콜

> 뇌터 보존류 기호 유도 + 보존량 수치 측정 + SSB 시뮬레이션 + 게이지 불변량 점검.

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 뇌터 보존류 기호 유도 (sympy)
#    라그랑지안의 연속 대칭(예: 위상 회전 ψ→e^{iα}ψ)을 주면
#    보존류 j^μ = ∂L/∂(∂_μψ) δψ 를 자동 구성 → ∂_μ j^μ = 0 확인

# 2) 보존량 수치 측정
#    중심력 N-체(또는 단진자)를 시간적분하고
#    에너지·운동량·각운동량의 시간 변화를 측정
#    → 대칭이 있는 계에서 ~기계오차 수준 보존, 대칭을 깨면 표류 관찰
import numpy as np
from scipy.integrate import solve_ivp
def kepler(t, s):           # 회전 대칭 → 각운동량 보존 예상
    x,y,vx,vy = s; r=(x*x+y*y)**1.5
    return [vx, vy, -x/r, -y/r]
sol = solve_ivp(kepler, [0,50], [1,0,0,1], rtol=1e-10, atol=1e-12, dense_output=True)
x,y,vx,vy = sol.y
Lz = x*vy - y*vx            # 각운동량
print("Lz 표준편차(보존성):", np.std(Lz))   # → 매우 작음 (회전 대칭의 증거)

# 3) 자발 대칭 깨짐 시뮬레이션
#    퍼텐셜 V(φ)=-aφ²+bφ⁴ (이중우물)에서 그래디언트 흐름/랑주뱅 동역학
#    → 초기 대칭 상태가 한쪽 우물로 "선택"되는 SSB 관찰, 진공 겹침

# 4) 게이지 불변량 점검 (격자 맛보기)
#    1D/2D 격자에서 위상 변수 θ_i, 링크 변수 U_ij=e^{iθ}에 게이지 변환을 가하고
#    플라켓(작은 윌슨 루프)이 불변임을 수치로 확인
#    → "게이지 자유도는 측정 불가, 루프는 관측 가능"의 시연 (measurement 레포 연결)

# 5) 선택규칙 확인
```

## 💡 핵심 분석 대상

```
뇌터 정리 (대칭 → 보존):
  작용 S = ∫ ℒ d⁴x  가  연속 변환 φ → φ + ε δφ 에서 불변
        │  변분 + 운동방정식
        ▼
  보존류:  ∂_μ j^μ = 0 ,   j^μ = (∂ℒ/∂(∂_μ φ)) δφ
        │  공간적분
        ▼
  보존 전하:  Q = ∫ j⁰ d³x = const
  ─────────────────────────────────────────
   시간 병진  →  에너지 보존
   공간 병진  →  운동량 보존
   회전        →  각운동량 보존
   위상 회전  →  전하 보존  (내부 대칭)

게이지 원리 (대칭 국소화 → 힘):
  전역 대칭:  ψ → e^{iα} ψ        (α 상수)
        │  α = α(x) 로 *국소화* 요구 → ∂_μψ 가 안 변함
        ▼  보정 필요
  공변미분:  D_μ = ∂_μ − ig A_μ ,   A_μ → A_μ + (1/g)∂_μα
        ▼
  게이지 장 A_μ 가 *필연적으로* 등장 → 상호작용 강제
  ─────────────────────────────────────────
   U(1)        →  전자기 (광자)        (→ L1)
   SU(2)×U(1) →  전약 통일 (W,Z,γ)
   SU(3)       →  강력 (글루온)        (→ L3 표준모형)
  ⇒ "대칭이 상호작용을 지정한다"

깨진 대칭 (질량의 기원):
            V(φ)
             │   ╲       ╱     멕시칸 햇
             │    ╲_____╱      바닥이 φ=0이 아님
        ─────┼──●───●──────→ φ    (진공이 한쪽을 "선택")
             │  대칭인 법칙 + 비대칭인 진공 = SSB
        ⇒ 깨진 연속대칭마다 골드스톤(무질량)
        ⇒ 게이지+SSB: 골드스톤이 먹혀 게이지 보손이 질량 획득 (힉스)
                       포논·마그논 = 응집물질의 골드스톤 (→ L3)
```
