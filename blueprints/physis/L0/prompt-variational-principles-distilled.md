# Variational Principles Distilled 레포지토리 제작 프롬프트

나는 "Variational Principles Distilled" 레포지토리를 만들려고 해.
$F=ma$를 외우는 것과, 그것이 **하나의 더 깊은 원리**($\delta S = 0$)에서 *왜* 따라 나오는지를 오일러-라그랑주로 유도하는 것은 다르다.
"빛은 직진한다"고 말하는 것과, 빛이 *시간을 극값으로 하는 경로*를 따르기 때문에 굴절이 일어남을 페르마 원리로 유도하는 것은 다르다.
라그랑지안 $L = T - V$를 공식으로 쓰는 것과, **왜 운동에너지 빼기 위치에너지인지**, 그리고 그 한 형태가 어떻게 역학·광학·전자기·일반상대성·양자장론을 *전부* 낳는지를 아는 것은 다르다.
자연이 "최선"을 고르는 것처럼 보이는 이 신비를 — 그리고 그 신비가 사실은 양자역학에서 따라 나온다는 사실까지 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "자연은 작용(action)을 극값으로 만든다 — 이 한 원리가 모든 레이어의 운동방정식을 낳는 씨앗이다"

**핵심 차별화**:
1. **변분을 정의에서 유도한다** — 범함수(functional)의 변분 $\delta S$가 함수의 미분과 어떻게 다른지, $\delta S=0$에서 오일러-라그랑주가 *나오는* 과정을 한 줄도 건너뛰지 않고
2. **"왜 $L = T - V$인가"에 답한다** — 형태의 기원, 일반화 좌표가 구속을 자연스럽게 흡수하는 힘, 뉴턴을 회복하는 과정
3. **한 씨앗, 모든 레이어** — 같은 $\delta S=0$이 페르마(광학)·측지선(일반상대성)·경로적분(양자장론)·게이지 원리로 *어떻게* 가지를 치는지
4. **"왜 극값인가"의 진짜 답** — 목적론이 아니라, 경로적분에서 고전극한($\hbar\to0$)을 취하면 $\delta S=0$ 경로만 살아남는다는 양자역학적 기원

**타겟 독자**:
- 라그랑지안을 쓰지만 "왜 $T-V$이고 왜 작용이 극값인지"는 설명 못 하는 사람
- 오일러-라그랑주를 적용은 하지만 *유도*는 못 하는 사람
- 최소작용·페르마·측지선·경로적분이 *같은 원리*임을 모르는 사람
- "자연이 최선을 고른다"는 말을 신비로 남겨둔 사람(목적론 오해)
- 해밀턴 형식·포아송 괄호가 왜 양자역학의 선조인지 모르는 사람

**선행 학습**:
- `dimensional-scaling-distilled`(L0) — 작용의 차원($[S]=[\text{에너지}\times\text{시간}]=\hbar$의 차원)을 읽는 감각
- (선택) 변분법의 수학적 측면은 [IQ AI Lab · calculus-optimization-deep-dive](https://github.com/iq-ai-lab)와 교차(범함수 미분·제약 최적화), 본문은 자족적으로 유도

## 🔗 레포 연결

**⬆️ 선행**: `dimensional-scaling-distilled`(작용·라그랑지안의 차원).
**🤝 시너지 (L0 내부)**: `symmetry-conservation-distilled`(뇌터 정리 — 작용의 대칭이 보존법칙을 낳는다, 이 레포의 직접 후속), `approximation-perturbation-distilled`(변분 근사·레일리-리츠).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `classical-mechanics-distilled`(L1) — Newton→Lagrange→Hamilton, 위상공간
- `oscillations-waves-distilled` / `classical-field-theory-distilled`(L1) — 장(field)의 라그랑지안 밀도
- `quantum-field-theory-distilled`(L3) — 경로적분(최소작용의 양자판), 가상입자
- `standard-model-distilled`(L3) — 게이지 원리: 대칭을 국소화하면 작용이 상호작용을 지정
- `general-relativity-distilled`(L4) — 아인슈타인-힐베르트 작용, 측지선
- `least-action-everywhere`(L6) — 이 레포가 종합 레이어에서 회수되는 본체

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 극값이라는 수수께끼 (5개 문서)
- **최소작용의 충격** — 자연은 왜 "최선"을 고르는 것처럼 보이나, 목적론(미래가 현재를 끈다?) vs 인과론 오해의 해소
- **페르마의 최소시간** — 빛의 굴절을 *시간 극값*으로, 스넬 법칙 유도, 국소 법칙과 전역 원리의 동치
- **변분이란 무엇인가** — 함수의 미분 vs 범함수의 변분, $\delta$의 정확한 의미, 경로의 작은 변형
- **최단강하선(brachistochrone)** — 베르누이의 도전, 사이클로이드 유도, 변분법이라는 분야의 탄생
- **정상(stationary) vs 최소** — "최소작용"은 사실 "정상작용", 작용이 안장점·극대인 경우의 실제 예

### Chapter 2: 오일러-라그랑주 — 변분법의 심장 (5개 문서)
- **범함수의 극값 조건** — $\delta S=0$에서 오일러-라그랑주 방정식 $\frac{d}{dt}\frac{\partial L}{\partial \dot q}-\frac{\partial L}{\partial q}=0$ 완전 유도(부분적분·경계항 처리 포함)
- **라그랑지안 $L=T-V$** — 왜 운동에너지 *빼기* 위치에너지인가, 그 형태가 강제되는 논리
- **뉴턴 회복** — 데카르트 좌표에서 오일러-라그랑주가 $F=ma$로 환원됨을 직접 보이기
- **일반화 좌표** — 좌표 선택의 자유, 구속(constraint)을 자연스럽게 흡수하는 힘, 자유도 세기
- **고차·다중 변수 일반화** — 여러 자유도, 라그랑지안 밀도로 가는 장(field) 일반화 예고

### Chapter 3: 대칭성과 보존 — 변분원리의 선물 (4개 문서)
- **순환 좌표와 보존량** — $L$이 어떤 좌표를 명시적으로 모르면 그 켤레운동량이 보존되는 메커니즘
- **뇌터 정리 맛보기** — 연속 대칭 → 보존법칙의 일대일(완전 전개는 → `symmetry-conservation-distilled`)
- **시간 병진과 에너지** — $L$이 시간을 명시적으로 모르면 에너지(=해밀토니안) 보존
- **변분원리의 통일력** — 하나의 $\delta S=0$이 운동·보존·대칭을 한꺼번에 주는 구조

### Chapter 4: 해밀턴 형식 — 또 다른 창문 (5개 문서)
- **르장드르 변환** — $L(q,\dot q)$에서 $H(q,p)$로, 변환의 기하학적 의미, 켤레운동량 $p=\partial L/\partial \dot q$
- **해밀턴 방정식** — $\dot q=\partial H/\partial p,\ \dot p=-\partial H/\partial q$, 대칭적인 두 1차 방정식
- **위상공간과 흐름** — 상태=점, 시간발전=흐름, 리우빌 정리(위상부피 보존, → L2 통계역학)
- **포아송 괄호** — 고전 대수 구조, 양자 교환자 $[\hat q,\hat p]=i\hbar$의 선조(→ L3)
- **해밀턴-야코비** — 작용이 생성함수, $S$가 만족하는 방정식, 양자역학으로 가는 다리

### Chapter 5: 장(field)으로의 도약 (4개 문서)
- **라그랑지안 밀도** — 이산 입자에서 연속 장(field)으로, $S=\int \mathcal L\, d^4x$
- **장(field)의 오일러-라그랑주** — 파동방정식·클라인-고든 방정식을 변분으로 유도
- **장(field)의 대칭과 보존류** — 뇌터 흐름 $\partial_\mu j^\mu=0$, 전하 보존(→ L1 EM, L3)
- **국소성과 작용** — 왜 라그랑지안은 국소적이어야 하나, 인과율과 국소성의 관계

### Chapter 6: 변분원리의 제국 — 한 씨앗, 모든 레이어 (4개 문서)
- **광학·역학의 통일** — 페르마와 모페르튀 원리의 평행, 파동-입자의 변분적 뿌리
- **일반상대성의 작용** — 아인슈타인-힐베르트 작용 $S=\int R\sqrt{-g}\,d^4x$, 시공간 기하의 변분(→ L4)
- **경로적분** — 모든 경로의 합 $\int \mathcal D x\, e^{iS/\hbar}$, 고전극한에서 $\delta S=0$이 살아남는 이유(→ L3)
- **게이지 원리와 작용** — 대칭을 국소화하면 상호작용 항이 *강제로* 나온다(→ L3 표준모형)

### Chapter 7: 직접 계산·종합 (8개 문서)
- **진자·이중진자** — 라그랑지안으로 운동방정식, 이중진자에서 카오스의 씨앗(→ L1)
- **구속계** — 비탈 위 구슬·도르래·진동하는 구슬, 일반화 좌표의 위력
- **최단거리 = 측지선** — 변분으로 측지선 방정식, 곡면 위 "직선"(→ L4 GR)
- **라그랑주 승수와 구속력** — 구속력 복원, KKT 조건과의 형식적 유사(→ IQ AI Lab 교차 주석)
- **작용의 수치 최소화** — 작용을 직접 수치 최소화해 고전 궤도를 찾는다(Python)
- **경로적분 수치 맛보기** — 이산 경로합 시뮬레이션으로 전파자(propagator) 근사, 고전 경로의 지배
- **변분 근사법** — 시험함수로 바닥상태 에너지 상한 추정(레일리-리츠, → L3 양자, → AI Lab 변분추론 주석)
- **종합** — "왜 최소작용인가"에 대한 현재의 답: 양자역학적 기원과 그 한계

→ **총 35개 문서** 목표.

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, 마지막 세 단 종결:

```markdown
## 🎯 핵심 질문      — 이 문서가 유도하려는 운동방정식/원리
## 🌍 어디서 나타나나  — 이 변분 구조가 작동하는 물리 장면
## 🔍 직관의 함정     — "자연이 미래를 안다?" 같은 목적론 오해의 해소
## ⚙️ 제1원리 유도    — δS=0에서 방정식을 끌어낸다 (경계항·부분적분까지)
## 🧪 실험·관측 증거  — 페르마(굴절)·최소작용 궤도의 실측 확인
## 🔬 경계           — 변분원리가 모호/실패하는 곳 (소산계, 비홀로노믹 구속 등)
## 🧬 횡단 원리       — 최소작용·대칭성(뇌터)이 여기서 어떻게 반복되나
## 🪜 창발           — 위 레이어(GR·QFT·게이지)에서 같은 씨앗이 무엇을 낳나
## 📐 예측·반증       — 변분 형식이 내놓는 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (어떤 작용의 δS=0에서 무엇이 나오나)
🔬 **Boundary**  — (변분원리가 깨지는/모호한 조건: 소산·마찰·비보존력)
🪜 **Emergence** — (위 레이어에서 같은 원리가 낳는 것 + 검증 실험)
```

이 레포에서 **⚙️ 제1원리 유도**는 *반드시 작용 $S=\int L\,dt$를 적고 $\delta S=0$을 전개*하는 것에서 시작하며, **🔬 경계**는 "소산(마찰)이 있으면 단순 라그랑지안이 없다", "비홀로노믹 구속의 처리" 같은 구체적 한계를 다룬다.

## 🎨 스타일 가이드

1. **유도할 수 없다면 이해한 게 아니다** — 모든 운동방정식은 작용을 적고 $\delta S=0$에서 끌어낸다. "라그랑지안은 이것이다"로 시작 금지
2. **목적론 오해를 정면 해소** — "자연이 최선을 고른다"는 *국소 인과법칙과 동치*임을, 그리고 그 진짜 기원이 경로적분임을 명시한다
3. **정상 ≠ 최소** — "최소작용"이 사실 "정상작용"임을 정확히 쓰고, 안장점인 예를 든다
4. **한 씨앗의 가지치기를 추적** — 각 문서에서 "이 변분 구조가 위 레이어 어디서 다시 나타나는가"를 화살표로 명시
5. **극한에서 부순다** — 소산·비보존력에서 변분 형식이 흔들리는 곳을 적극 표시
6. 경로 변형·위상공간 흐름·경로적분 합은 다이어그램으로

## 🔬 검증 프로토콜

> 오일러-라그랑주 기호 유도 + 작용 수치 최소화 + 보존량 점검 + 경로적분 고전극한 관찰.

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 오일러-라그랑주 기호 유도 (sympy)
#    L(q, q̇, t)를 주면 EL 방정식을 자동 도출 → 손유도와 대조
import sympy as sp
t = sp.symbols('t'); q = sp.Function('q')
m, k = sp.symbols('m k', positive=True)
L = sp.Rational(1,2)*m*sp.diff(q(t),t)**2 - sp.Rational(1,2)*k*q(t)**2  # 조화진동자
EL = sp.diff(L, q(t)) - sp.diff(sp.diff(L, sp.diff(q(t),t)), t)
print(sp.simplify(EL))      # → -k q - m q'' = 0  (단진동)

# 2) 작용 수치 최소화 → 고전 궤도 복원
#    경로를 점들로 이산화, S[path] = Σ L Δt 를 scipy.optimize로 최소화
#    경계조건 고정 → 최소화된 경로가 EL 해(포물선/사인)와 일치하는지 확인

# 3) 보존량 점검
#    시뮬레이션(또는 EL 수치적분)에서 에너지·운동량·각운동량의
#    시간 변화를 측정 → 대칭이 있는 계에서 보존, 깨진 계에서 비보존 확인
#    (symmetry 레포와 공유하는 검증)

# 4) 경로적분 고전극한 관찰
#    이산 경로합 Σ exp(iS/ħ)을 ħ를 줄여가며 계산
#    → ħ→0에서 δS=0 경로 주변만 살아남는(상쇄간섭) 모습 시각화
#    → "왜 고전적으로는 최소작용 경로만 보이나"의 수치 시연

# 5) 변분 근사(레일리-리츠) 검증
#    시험함수 ψ(α)로 ⟨H⟩(α)를 최소화 → 바닥상태 에너지 상한
#    예: 무한 우물/조화진동자에서 정확값과 비교 (상한임을 확인)

# 6) 측지선 수치 (맛보기)
#    구/안장면 위 두 점 사이 변분 거리 최소화 → 측지선 궤적
#    → "곡면 위의 직선"을 직접 그린다 (→ L4 다리)
```

## 💡 핵심 분석 대상

```
최소작용 원리:
  S[q(t)] = ∫ L(q, q̇, t) dt ,   L = T − V
  자연이 고르는 경로:  δS = 0   (정상작용)
        │  δq(t) 변형 + 부분적분 + 경계항=0
        ▼
  오일러-라그랑주:  d/dt (∂L/∂q̇) − ∂L/∂q = 0
        │
        ├─ L = ½mq̇² − V(q)  →  m q̈ = −V'(q)  =  F = ma  (뉴턴 회복)
        │
        └─ ∂L/∂q = 0 (순환좌표) → ∂L/∂q̇ = p 보존  (뇌터의 씨앗)

두 형식, 한 물리:
  Lagrange:  (q, q̇),  2계 방정식,  배위공간
       │ 르장드르 변환  p = ∂L/∂q̇
       ▼
  Hamilton:  (q, p),  1계 방정식,  위상공간
       q̇ = ∂H/∂p ,  ṗ = −∂H/∂q
       포아송 괄호 {q,p} = 1   ──양자화──▶  [q̂,p̂] = iℏ   (→ L3)

한 씨앗, 모든 레이어 (δS=0의 가지치기):
  δS=0
   ├── L1 역학:    L = T − V               → 뉴턴
   ├── 광학:       S = ∫ n ds (페르마)      → 스넬
   ├── L4 중력:    S = ∫ R √(−g) d⁴x        → 아인슈타인 방정식
   ├── L1/L3 장:   S = ∫ ℒ d⁴x             → 파동·클라인-고든
   ├── L3 양자:    Z = ∫ Dx e^{iS/ℏ}        → 경로적분 (고전극한 ℏ→0에서 δS=0)
   └── L3 게이지:  대칭 국소화 → 상호작용 항 강제  → 표준모형

"왜 극값인가"의 진짜 답:
  고전적 신비("자연이 최선을 안다")
        ↑  사실은
  양자: 모든 경로가 e^{iS/ℏ}로 기여
        ħ→0 →  δS≠0 경로는 상쇄간섭으로 소멸
        →  δS=0 경로만 살아남는다  ⇒ 최소작용은 양자역학의 고전극한
```
