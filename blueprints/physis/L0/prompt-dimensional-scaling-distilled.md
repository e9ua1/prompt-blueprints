"코끼리는 크니까 약하다"고 말하는 것과, 골격 강도는 $L^2$로, 무게는 $L^3$로 늘어나기 때문에 충분히 키우면 자기 무게에 부러진다는 것을 *스케일링 지수로* 유도하는 것은 다르다.

이 모든 "다름"을 — 가장 적은 입력에서 가장 많은 결론을 끌어내는 물리학자의 첫 번째 기술을 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "차원분석은 답의 절반을 공짜로 준다 — 풀기 전에 형태를 알고, 스케일을 바꿔 본질을 본다"

**핵심 차별화**:
1. **차원의 동질성을 모든 방정식의 숨은 제약으로** — 단위가 맞아야 한다는 사소해 보이는 사실이 어떻게 공식의 *형태*를 강제하는가
2. **버킹엄 π를 엔진으로 직접 돌린다** — 무차원 군을 "외우는" 게 아니라 차원 행렬에서 *뽑아내는* 절차, 그리고 모형 실험이 실물을 예언하는 상사성(similarity)의 원리
3. **스케일링 = 멱법칙의 물리** — 알로메트리·표면적-부피비·임계지수가 전부 한 가족임을, 스케일 불변성에서 유도
4. **추정을 기술에서 원리로** — 페르미 추정을 "감"이 아니라 자릿수·기하평균·불확실성 전파의 *통제된 절차*로

**타겟 독자**:
- 공식은 대입하지만 "이 양이 왜 이 차원이어야 하는가"는 설명 못 하는 사람
- 단위가 우연히 맞은 식과 물리적으로 맞는 식을 구분 못 하는 사람
- 멱법칙·로그-로그 직선을 보면서 "그래서 무엇이 불변인가"를 못 읽는 사람
- 봉투 뒷면 추정이 언제 충분하고 언제 위험한지 판단 못 하는 사람
- 위층(L1~L5)에서 보어 반지름·슈바르츠실트 반지름·호킹 온도를 *차원만으로* 복원하는 감각을 갖고 싶은 사람

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 차원이라는 언어 — 왜 공짜인가 (5개 문서)
- **물리량과 차원** — 기본 차원($L, M, T, \Theta, I, N, J$), 차원의 동질성(dimensional homogeneity) 원리가 *모든* 방정식에 거는 숨은 제약, 차원 ≠ 단위
- **단위계와 자연단위** — SI vs 자연단위($\hbar=c=1$), 단위를 바꿔도 불변인 것은 무엇인가, 플랑크 단위가 "근본 스케일"인 이유
- **차원분석의 한계** — 무차원 상수($2\pi, \tfrac12$)는 못 잡는다, 두 변수가 같은 차원일 때의 모호함, 숨은 변수에 속는 법
- **페르미 추정의 골격** — 자릿수의 기술, 무지에서 근사로, "시카고 피아노 조율사"의 물리 버전(공기 분자 충돌수 등)
- **차원으로 공식 복원하기** — 진자 주기·우물 속 입자 에너지를 차원만으로 형태 유도(상수 제외), "절반은 공짜"의 첫 시연

### Chapter 2: 버킹엄 파이 정리 — 차원분석의 엔진 (5개 문서)
- **무차원 군의 발견** — 변수 집합에서 무차원 조합을 뽑는 법, 차원 행렬과 그 영공간의 의미
- **버킹엄 π 정리** — $n$개 변수 $-$ $k$개 독립 차원 $=$ $(n-k)$개 무차원 수, 정리의 진술과 증명 스케치
- **π 정리 실전** — 구의 항력·진자·관 속 유체에 적용, 무차원 수 선택의 자유와 물리적 해석
- **상사성과 모형 실험** — 동역학적 상사가 풍동·축소모형이 실물을 예언하게 하는 원리, 상사 깨짐의 위험
- **무차원 수의 동물원** — $Re, Ma, Fr, Pe, We$… 각각이 "무엇 대 무엇의 비"인가, 한 표로 정리

### Chapter 3: 스케일링 법칙 — 멱법칙의 물리 (5개 문서)
- **멱법칙과 스케일 불변성** — $y \propto x^a$의 의미, 로그-로그 직선, 스케일을 바꿔도 형태가 같다는 것의 정의
- **기하학적 스케일링** — 면적 $\propto L^2$, 부피 $\propto L^3$, 표면적-부피비가 지배하는 현상(세포 크기·냉각·곤충 호흡)
- **알로메트리** — 왜 코끼리는 개미처럼 못 뛰나, 강도 $\propto L^2$ vs 무게 $\propto L^3$ → 붕괴 스케일, 갈릴레이의 원논증 재구성
- **대사 스케일링** — 클라이버 법칙(대사율 $\propto M^{3/4}$), 프랙탈 네트워크 가설, 3/4 지수 논쟁의 현주소
- **임계 지수 예고** — 상전이 근처의 멱법칙이 보편성을 낳는다, 스케일링이 재규격화군으로 가는 다리(→ L2)

### Chapter 4: 자기유사성과 프랙탈 (4개 문서)
- **자기유사성** — 부분이 전체를 닮는다, 결정론적 vs 통계적 자기유사
- **프랙탈 차원** — 비정수 차원의 의미, 해안선 역설, 박스 카운팅으로 차원 측정
- **척도 없는(scale-free) 현상** — 난류·지진(구텐베르크-리히터)·도시 인구, 멱법칙 분포의 편재성과 그 함정
- **스케일링과 재규격화군의 다리** — "스케일을 바꾸며 본다"가 RG의 씨앗(→ L2 상전이, → L6 창발)

### Chapter 5: 추정의 기술 — Fermi 심화 (4개 문서)
- **자릿수 사고** — 기하평균, 상·하한으로 묶기, 불확실성의 곱셈적 전파(→ measurement 레포)
- **스케일 논증으로 물리 풀기** — 별 중심 온도·번개 에너지·소리 속도를 차원+스케일로 추정
- **추정이 틀리는 법** — 무차원 상수가 클 때, 변수 빠뜨림, 차원이 우연히 맞을 때의 거짓 안심
- **추정 vs 정밀** — 언제 봉투 뒷면이 충분하고 언제 위험한가, 추정의 적정 사용역

### Chapter 6: 자연의 스케일 지도 (4개 문서)
- **길이의 스케일** — 플랑크 길이에서 관측 가능한 우주까지, 각 스케일을 지배하는 물리
- **에너지의 스케일** — eV에서 플랑크 에너지까지, 왜 가속기는 더 커져야 하나(분해능 ∝ 에너지)
- **시간·질량의 스케일** — 플랑크 시간, 입자 수명, 천체 질량의 범위
- **차원 상수들** — $c, \hbar, G, k_B$가 스케일의 경계를 긋는다, 상수가 레이어를 가르는 지도(→ 모든 레이어)

### Chapter 7: 종합 케이스 (6개 문서)
- **진자·용수철·LC 회로** — 같은 차원 구조가 같은 주기 공식을 낳는다, 유비의 깊이
- **항력과 종단속도** — 빗방울·낙하산·먼지, 레이놀즈 수로 갈라지는 두 영역($F\propto v$ vs $v^2$)
- **별의 구조 추정** — 차원분석만으로 질량-반지름 관계·중심 온도 추정(→ L4 astrophysics)
- **양자 길이 스케일 복원** — 보어 반지름·콤프턴 파장을 $\hbar, m, e, c$ 조합으로(→ L3)
- **블랙홀의 차원분석** — 슈바르츠실트 반지름·호킹 온도를 $c,\hbar,G,k_B$ 조합으로 복원(→ L4/L5)
- **종합** — 미지의 새 문제에 *차원 → 스케일 → 추정* 풀세트를 적용하는 통합 케이스

## 📐 문서 구조 — Principle → Boundary → Emergence

각 문서는 Physis 표준 10섹션으로, 마지막은 세 단으로 끝낸다:

```markdown
## 🎯 핵심 질문      — 이 문서가 유도/대답하려는 단 하나의 질문
## 🌍 어디서 나타나나  — 이 원리가 작동하는 자연·기술의 장면
## 🔍 직관의 함정     — 흔한 오해, 그 오해가 왜 비싼가
## ⚙️ 제1원리 유도    — 차원 동질성·스케일 불변성에서 형태를 끌어낸다 (암기 금지)
## 🧪 실험·관측 증거  — 측정·데이터로 확인, 효과의 크기와 자릿수
## 🔬 경계           — 어떤 스케일·조건에서 이 차원/스케일 논증이 깨지나 (무차원 상수가 클 때 등)
## 🧬 횡단 원리       — 대칭성·최소작용·엔트로피·정보·창발 중 무엇이 여기서 반복되나
## 🪜 창발           — 위 레이어에서 이 도구가 무엇을 복원/예언하나
## 📐 예측·반증       — 이 논증이 내놓는 검증 가능한 예측, 반증 조건
## 🤔 다음 질문       — 미해결 지점, 다음 문서로의 연결

---
🧩 **Principle** — (차원/스케일 메커니즘 한 문단)
🔬 **Boundary**  — (이 논증이 깨지는 스케일·조건)
🪜 **Emergence** — (위 레이어에서 새로 나타나는 것 + 그것을 검증할 실험)
```

이 레포에서 **⚙️ 제1원리 유도**는 *차원 행렬과 π 정리* 또는 *스케일 불변 가정*에서 형태를 끌어내는 과정을 명시하고, **🔬 경계**는 "차원분석이 못 잡는 무차원 상수가 $O(1)$이 아닐 때" 같은 구체적 실패 조건을, **📐 예측·반증**은 스케일링 지수의 측정 가능한 예측(예: 로그-로그 기울기)을 담는다.

## 🎨 스타일 가이드

1. **유도 없는 경이는 소음이다** — 모든 공식은 차원/스케일에서 *형태를* 끌어낸 뒤 제시한다. "이 식은 이렇다"로 시작하지 않는다
2. **무차원 상수는 정직하게 비운다** — 차원분석이 $\tfrac12$나 $2\pi$를 못 잡는다는 사실을 숨기지 않고, 어디까지가 공짜이고 어디부터 계산이 필요한지 명시한다
3. **극한에서 부순다** — 모든 스케일 논증에 "이 멱법칙이 깨지는 스케일"(예: 양자 효과가 끼어드는 길이, 점성이 무시 못 할 $Re$)을 반드시 표시한다
4. **로그-로그로 보는 습관** — 멱법칙은 로그-로그 그림으로, 기울기 = 지수임을 시각화한다
5. **추정은 통제된 절차로** — 페르미 추정은 "감"이 아니라 자릿수·기하평균·불확실성 전파의 명시적 단계로 적는다
6. 차원 행렬·스케일 지도·멱법칙 분포는 다이어그램으로

## 🔬 검증 프로토콜

> 차원 동질성 자동 점검 + 버킹엄 π 자동 추출 + 스케일링 지수 수치 측정 + 극한 붕괴 관찰.

```python
# 환경: Python 3 + numpy + sympy + matplotlib (+ pint 권장)

# 1) 차원 동질성 자동 검사
#    pint(또는 sympy.physics.units)로 후보 공식의 양변 차원을 비교
#    → 차원이 안 맞는 식은 물리적으로 틀렸음을 기계가 잡아낸다

# 2) 버킹엄 π 자동 추출
#    변수들의 차원 행렬 D를 만들고, null space(sympy.Matrix.nullspace)로
#    무차원 군을 뽑는다 → 손으로 뽑은 π와 일치 확인 (예: 항력 문제)
import sympy as sp
# 행: [L, M, T], 열: [rho, v, d, mu]  (항력에 관여하는 변수)
D = sp.Matrix([[ -3, 1, 1, -1],   # L
               [  1, 0, 0,  1],   # M
               [  0,-1, 0, -1]])  # T
print(D.nullspace())   # → Reynolds 수 Re = rho v d / mu 가 무차원 군으로 나온다

# 3) 스케일링 지수 측정 (멱법칙 백테스트)
#    합성/실측 데이터 (x, y)를 로그-로그로 선형회귀 → 기울기 = 지수 a
#    예: 알로메트리(질량 vs 대사율), 기하 스케일링(L vs 부피)
import numpy as np
x = np.logspace(0, 4, 50)
y = 3.0 * x**0.75 * np.exp(0.05*np.random.randn(50))   # 클라이버 모사
a = np.polyfit(np.log(x), np.log(y), 1)[0]
print("측정된 스케일링 지수 a ≈", round(a, 3))   # → 0.75 부근

# 4) 극한 붕괴 관찰
#    레이놀즈 수를 키우며 F∝v (저Re) → F∝v² (고Re) 전이를 수치로 확인
```
