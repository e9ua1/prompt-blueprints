# Measurement & Uncertainty Distilled 레포지토리 제작 프롬프트

나는 "Measurement & Uncertainty Distilled" 레포지토리를 만들려고 해.
모형이 데이터에 맞는 것을 보고 "이론이 맞다"고 말하는 것과, **자유 매개변수를 늘리면 무엇이든 맞출 수 있다**는 것을 알고 *예측력*으로 이론을 심판하는 것은 다르다.
유효숫자를 적는 것과, 오차가 어떻게 *전파*되고 왜 과대정밀이 거짓말인지를 아는 것은 다르다.
"실험으로 확인됐다"고 말하는 것과, 무엇이 *반증 가능*해야 과학이고, 5σ가 왜 그렇게 보수적이며, look-elsewhere effect가 어떻게 우연을 발견으로 둔갑시키는지를 아는 것은 다르다.
**물리적 앎의 바닥** — 무엇이 관측 가능하고, 무엇이 측정에 살아남으며, 무엇이 반증을 견디는가 — 를 끝까지 파헤치는 레포를 만들 거야. 이 레포는 이 연구소 *전체의 심판 기준*이다.

## 📋 프로젝트 목표

**컨셉**: "물리적 앎의 바닥은 측정이다 — 관측 가능한 것만 물리이고, 반증을 견디고 측정에 살아남은 것만 신뢰한다"

**핵심 차별화**:
1. **관측 가능성을 앎의 기준으로** — 측정 가능해야 물리량(조작적 정의), 게이지 자유도처럼 "측정 불가"는 물리가 아니다(→ L0 symmetry, L1 EM과 결합)
2. **오차를 분포로, 전파를 1차로** — 측정값은 분포다, 계통/통계 오차의 구분, 오차 전파 공식의 유도(→ L0 approximation)
3. **데이터에 맞추기의 함정** — 과적합, 자유 매개변수의 위험, "곡선맞춤은 물리가 아니다"(예측력 없는 적합의 무가치)(→ IQ AI Lab 교차)
4. **반증을 과학의 경계로** — 포퍼·뒤엠-콰인, 예측 vs 사후설명, 5σ·look-elsewhere·p-해킹까지 정직하게(→ Phronesis cognitive-bias 교차)

**타겟 독자**:
- 모형이 데이터에 맞으면 곧 참이라고 믿는 사람(과적합을 모르는)
- 유효숫자를 쓰지만 오차 전파·과대정밀의 의미를 모르는 사람
- "반증 가능성"을 들어봤지만 그것이 *왜* 과학의 경계인지 모르는 사람
- 5σ가 왜 그렇게 엄격하고, 다중비교가 어떻게 거짓 발견을 만드는지 모르는 사람
- 이 연구소의 모든 유도가 결국 *무엇으로 심판되는가*를 알고 싶은 사람

**선행 학습**:
- `dimensional-scaling-distilled`(L0) — 단위·차원·자릿수(오차와 한 몸)
- `approximation-perturbation-distilled`(L0) — 오차 전파 = 1차 테일러 전개
- (선택) 통계적 추론·베이즈는 [IQ AI Lab](https://github.com/iq-ai-lab) 및 [IQ Phronesis Lab · probabilistic-thinking-distilled](https://github.com/iq-phronesis-lab)와 교차, 본문은 자족적으로 전개

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 관측 가능성 — 물리적 앎의 바닥 (4개 문서)
- **무엇이 물리량인가** — 측정 가능해야 물리량, 조작적 정의(operational definition), "정의되지 않은 양"의 위험
- **관측 가능량(observable)** — 게이지 자유도처럼 *측정 불가능한 것은 물리가 아니다*(→ L0 symmetry, L1 EM)
- **측정이라는 행위** — 측정은 상호작용이고 교란을 수반한다, 고전에서도 그렇다(→ L3 양자측정 예고)
- **단위와 표준** — 단위의 재정의(2019 SI), 상수로 단위를 *고정*한다는 것의 의미(→ L0 dimensional)

### Chapter 2: 오차의 해부 (5개 문서)
- **계통오차 vs 통계오차** — 정확도(accuracy) vs 정밀도(precision)의 결정적 차이, 각각을 줄이는 법이 다른 이유
- **오차의 물리적 기원** — 잡음의 원천(열잡음·산탄잡음), 왜 어떤 잡음은 근본적인가(→ L2)
- **분포로서의 측정** — 측정값은 분포다, 평균·표준편차·표준오차의 구분
- **중심극한정리** — 왜 가우스 분포가 측정에 편재하나, 그 가정과 깨짐(→ L2 통계역학)
- **이상값과 강건성** — 언제 데이터를 버리나, 버림의 윤리, 강건 추정의 필요

### Chapter 3: 오차 전파 (4개 문서)
- **오차 전파 공식** — 함수의 불확실성, 1차 전개로 유도(→ L0 approximation), 언제 1차가 충분한가
- **독립 vs 상관 오차** — 공분산이 끼어들 때, 상관을 무시하면 생기는 과소/과대평가
- **상대오차와 유효숫자** — 유효숫자의 진짜 의미, 과대정밀이라는 거짓말, 자릿수로 보는 오차
- **차원과 오차** — 무차원 비로 오차를 보기, 어떤 양이 오차에 민감한가(→ L0 dimensional)

### Chapter 4: 모형과 실재 (5개 문서)
- **모형이란 무엇인가** — "지도 ≠ 영토", 모든 모형은 틀렸지만 일부는 유용하다는 것의 정확한 의미
- **데이터에 맞추기의 함정** — 과적합(overfitting), 자유 매개변수가 많으면 *무엇이든* 맞는다(폰 노이만의 코끼리)(→ AI Lab 교차)
- **좋은 적합 vs 나쁜 적합** — $\chi^2$, 잔차, 자유도, p-값의 의미와 흔한 오용
- **모형 선택** — 단순성(파시모니)·오컴, AIC/BIC의 직관, 복잡도 페널티의 논리(→ AI Lab 교차)
- **곡선맞춤이 물리가 아닌 이유** — 예측력 없는 적합은 기술(記述)일 뿐, *새 예측*을 내야 이론

### Chapter 5: 반증과 과학적 앎 (5개 문서)
- **포퍼의 반증주의** — 반증 가능성이 과학의 경계, "무엇으로도 반증 안 되는" 주장은 과학이 아니다
- **예측 vs 사후설명** — 새 예측을 내야 이론, 사후 끼워맞춤(post-diction)의 무가치
- **가설검정의 논리** — 귀무가설, 유의수준, 무엇을 증명할 수 있고 없나(부정의 비대칭)
- **베이즈 vs 빈도주의** — 증거가 믿음을 갱신하는 두 관점, 각각의 장단(→ AI Lab, Phronesis 교차)
- **반증의 한계** — 뒤엠-콰인 명제, 보조가설, 이론은 통째로 시험된다는 것의 함의

### Chapter 6: 통계적 추론의 물리 (4개 문서)
- **신호 대 잡음(SNR)** — 적분시간을 늘리면 왜 좋아지나($\sqrt{N}$), 한계는 어디인가
- **5σ의 의미** — 입자물리의 발견 기준, 왜 그렇게 보수적인가, 시행 횟수와의 관계(→ L3 힉스)
- **우연의 함정** — 다중비교, look-elsewhere effect, p-해킹이 우연을 발견으로 둔갑시키는 경로(→ Phronesis cognitive-bias)
- **측정의 근본 한계** — 표준양자한계 맛보기, 정밀측정의 최전선(중력파 간섭계 → L4)

### Chapter 7: 종합·실측 (4개 문서)
- **단위·차원·오차 통합** — 실제 측정 하나를 끝까지(설계 → 측정 → 전파 → 보고)
- **역사적 측정의 진화** — 빛의 속도·중력상수 $G$·전자전하 측정사, 오차가 줄어든 역사와 그 교훈
- **측정이 이론을 죽인 사례** — 마이컬슨-몰리(에테르), 흑체복사 자외선 파탄, 측정이 혁명을 강제한 순간(→ L3, L4)
- **종합** — "측정에 살아남는가, 반증을 견디는가가 유일한 심판" — 이 레포가 연구소 전체의 검증 기준인 이유

→ **총 31개 문서** 목표.

## 📐 문서 구조 — Principle → Boundary → Emergence

Physis 표준 10섹션, 마지막 세 단 종결:

```markdown
## 🎯 핵심 질문      — 무엇이 관측 가능하고, 무엇이 측정/반증에 살아남나
## 🌍 어디서 나타나나  — 이 측정/추론 원리가 작동하는 장면
## 🔍 직관의 함정     — "맞으면 참"·"정밀=정확" 같은 오해, 과적합·과대정밀
## ⚙️ 제1원리 유도    — 오차 전파·검정 통계·SNR 등을 정의에서 유도
## 🧪 실험·관측 증거  — 실제 측정/발견 사례, 효과 크기와 불확실성
## 🔬 경계           — 추론이 깨지는 곳 (다중비교·뒤엠-콰인·계통오차의 지배)
## 🧬 횡단 원리       — 정보·엔트로피·잡음이 측정에서 어떻게 반복되나
## 🪜 창발           — 위 레이어(양자측정·5σ·정밀우주론)에서 무엇이 나타나나
## 📐 예측·반증       — 이 측정이 반증 가능하게 만드는 것, 그 한계
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (이 측정/추론이 무엇을 정당화하나)
🔬 **Boundary**  — (추론이 깨지는 조건: 다중비교·보조가설·계통오차)
🪜 **Emergence** — (위 레이어의 측정 난제 + 그것이 검증하는 것)
```

이 레포에서 **⚙️ 제1원리 유도**는 *오차 전파·검정 통계·SNR을 식에서 유도*하고, **🔬 경계**는 "look-elsewhere로 5σ가 약해진다", "뒤엠-콰인: 반증은 이론을 콕 집지 못한다", "계통오차가 통계오차를 압도" 같은 구체적 한계를 다룬다.

## 🎨 스타일 가이드

1. **맞으면 참이 아니다** — 모든 적합에 "자유 매개변수 수 / 예측력 / 과적합 위험"을 명시한다. 곡선맞춤과 이론을 구분한다
2. **정밀 ≠ 정확** — 계통오차와 통계오차를 항상 분리하고, 과대정밀을 거짓말로 다룬다
3. **반증 가능해야 과학** — 각 주장에 "이것을 반증할 측정은 무엇인가"를 묻는다. 반증 불가는 형이상학으로 표시(→ L5 다중우주 정직)
4. **우연의 함정을 정직하게** — 다중비교·look-elsewhere·p-해킹을 *방어 교재*로 역분해(→ Phronesis 교차)
5. **이 레포가 심판이다** — 연구소 전체의 유도가 결국 측정·반증으로 심판됨을 일관되게 상기
6. 오차 분포·전파·과적합 곡선·5σ 꼬리는 다이어그램으로

## 🔬 검증 프로토콜

> 오차 전파 자동 + 과적합 재현 + 가설검정 시뮬레이션 + look-elsewhere 시연 + 측정사 자릿수 대조.

```python
# 환경: Python 3 + numpy + scipy + matplotlib (+ sympy)

# 1) 오차 전파 자동 검증 (sympy + 몬테카를로)
#    함수 f(x,y)의 1차 전파 공식 vs 입력에 잡음을 준 몬테카를로 표준편차 비교
#    → 1차 전파가 언제 충분하고 언제 틀리는지(강한 비선형) 직접 확인
import numpy as np
def f(x,y): return x**2 * np.sin(y)
x0,y0,sx,sy = 2.0,1.0,0.05,0.03
N=200000
xs=np.random.normal(x0,sx,N); ys=np.random.normal(y0,sy,N)
print("MC σ_f =", np.std(f(xs,ys)))   # ↔ 1차 전파식과 대조

# 2) 과적합 재현 (폰 노이만의 코끼리)
#    n개 점에 (n-1)차 다항을 맞추면 잔차=0이지만 예측은 엉망
#    → train 잔차↓ 인데 test 오차↑ 를 차수별로 플롯 (자유 매개변수의 함정)
from numpy.polynomial import polynomial as P
# 차수를 키우며 train/test RMSE 곡선 → "맞춤은 완벽, 예측은 붕괴" 시연

# 3) 가설검정 시뮬레이션 (귀무가설 분포)
#    신호 없는 데이터에서 검정통계량의 분포를 만들고
#    유의수준·검정력·1종/2종 오류를 수치로 → p-값의 의미를 체득

# 4) look-elsewhere effect 시연
#    "신호 없음" 스펙트럼을 여러 구간에서 반복 탐색 → 어딘가는 우연히 큰 봉우리
#    → 국소 p-값 vs 전역(trial-corrected) p-값의 차이 측정
#    → 왜 입자물리가 5σ를 요구하는지 수치로 정당화 (→ L3)

# 5) SNR과 적분시간
#    잡음에 묻힌 신호를 N번 평균 → SNR ∝ √N 확인, 계통오차가 있으면
#    √N로 안 좋아지는 바닥(systematic floor) 관찰

# 6) 측정사 자릿수 대조
#    역사적 c, G, e 측정값들의 변천을 오차막대와 함께 플롯
#    → 계통오차가 후대에 드러난 사례(초기 과소평가된 불확실성) 식별
```

## 💡 핵심 분석 대상

```
관측 가능성 = 앎의 바닥:
  측정 가능?  ──아니오──▶  물리량 아님 (게이지 자유도, 절대 위상…)
       │ 예
       ▼
  조작적 정의 → 단위·표준 (2019 SI: 상수로 고정)
  ⇒ "측정 불가는 물리가 아니다" (→ symmetry: 관측가능량 vs 게이지)

오차의 두 종류 (줄이는 법이 다르다):
   정밀도(precision) — 흩어짐 ↔ 통계오차 (√N로 감소)
   정확도(accuracy)  — 치우침 ↔ 계통오차 (√N로 안 줄어듦!)
        ●●● ● ●        (정밀하지만 부정확: 계통오차)
            ⊕           (참값)
   ⇒ 더 오래 재도 계통오차 바닥은 안 내려간다

오차 전파 (1차 테일러, → approximation):
  σ_f² = (∂f/∂x)² σ_x² + (∂f/∂y)² σ_y² + 2(∂f/∂x)(∂f/∂y)σ_xy
  ⇒ 상관(σ_xy) 무시하면 과대/과소평가

데이터에 맞추기의 함정 (과적합):
   오차
    │ ╲train (맞춤): 차수↑ → 0으로
    │  ╲___
    │      ╲___╱  test (예측): 어느 순간부터 ↑↑
    └──────────── 모형 복잡도(자유 매개변수)
  폰 노이만: "변수 4개면 코끼리, 5개면 코를 흔든다"
  ⇒ 곡선맞춤 ≠ 물리. *새 예측*을 내야 이론

반증 = 과학의 경계 (포퍼):
   반증 가능?  ──아니오──▶  형이상학 (→ L5 다중우주 정직 논쟁)
        │ 예
        ▼
   예측 → 측정 → 살아남으면 잠정 신뢰, 어긋나면 폐기
   ※ 뒤엠-콰인: 반증은 이론을 콕 집지 못한다 (보조가설)

5σ와 우연의 함정:
   확률밀도
     │      ╱╲
     │     ╱  ╲          5σ 꼬리 ≈ 3×10⁻⁷
     │ ___╱    ╲___      왜 이렇게 보수적?
     └──────────────── ⇒ look-elsewhere: 여러 곳을 보면
                            어딘가는 우연히 튄다 → 전역 p-값 보정 (→ L3 힉스)

⇒ 이 연구소의 모든 유도(L0~L5)는 결국
   "측정에 살아남는가 / 반증을 견디는가"로 심판된다.  ← 이 레포가 그 법정.
```
