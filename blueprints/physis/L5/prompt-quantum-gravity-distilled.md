# Quantum Gravity Distilled 레포지토리 제작 프롬프트

나는 "Quantum Gravity Distilled" 레포지토리를 만들려고 해.
"양자중력은 어렵다"고 말하는 것과, **왜 GR과 양자역학이 양립 불가**한지 — 중력이 왜 재규격화되지 않고, 플랑크 스케일에서 무슨 일이 벌어지는지를 — *정확히* 짚는 것은 다르다.
어떤 접근법(끈·고리·…)이 "정답"이라고 믿는 것과, **최종 이론이 없어도 반드시 참이어야 할 것들**(블랙홀 엔트로피의 미시 기원, 정보 역설의 해결, 배경 독립성)을 아는 것은 다르다.
이 레포는 *답을 파는 곳이 아니다*. 무엇이 확립되었고, 무엇이 유망하며, 무엇이 순수 추측인지를 — 과대포장 없이, 반증 가능성을 정면으로 — 끝까지 정직하게 파헤치는 레포다.

## 📋 프로젝트 목표

**컨셉**: "두 기둥이 충돌하는 곳 — 양자중력은 답이 아니라 *질문*이다. 무엇을 반드시 알아야 하는가를 정직하게"

**핵심 차별화**:
1. **문제를 정확히 정식화** — GR(연속·결정론적 기하)과 QM(이산·확률·요동)이 *왜* 양립 불가인지, 중력이 *왜* 재규격화 불가인지 차원으로(→ L3, L4)
2. **최종 이론 없이도 참인 것** — 블랙홀 엔트로피의 미시 기원, 정보 역설 해결, 배경 독립성 — 어떤 이론이든 통과해야 할 시험
3. **접근법의 지형도** — 끈·고리·인과집합·점근적 안전성을 *공정하게* 비교, 무엇이 그들을 가르나
4. **정직한 인식론** — 과대포장 거부, 확립/유망/추측의 명시적 분류, 반증 가능성 정면 대결(→ L0 measurement)

**타겟 독자**:
- "양자중력은 어렵다"는 알지만 *왜* GR과 QM이 충돌하는지 정확히 모르는 사람
- 특정 접근법을 정답으로 믿거나, 반대로 전부 헛소리로 치부하는 사람
- 최종 이론 없이도 *반드시 참*인 것이 있음을 모르는 사람
- 양자중력의 실험적 창이 거의 없다는 정직한 현실을 모르는 사람
- 이 영역에서 무엇이 과학이고 무엇이 형이상학인지 구분하고 싶은 사람(→ L0 measurement)

**선행 학습**:
- `general-relativity-distilled`(L4) — **필수**. 중력=기하·특이점
- `quantum-field-theory-distilled`(L3) — **필수**. 재규격화·왜 중력에서 깨지나
- `black-holes-distilled`(L4) — **필수**. 정보 역설·블랙홀 엔트로피 / `dimensional-scaling-distilled`(L0) — 플랑크 스케일

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 왜 양자중력인가 — 문제의 정식화 (5개 문서)
- **두 기둥의 충돌** — GR(연속·결정론적 기하)과 QM(이산·확률·요동)이 양립 불가인 이유(→ L3, L4)
- **플랑크 스케일** — $\ell_P, t_P, E_P$를 차원으로 복원, 양자+중력이 만나는 곳(→ L0 dimensional)
- **중력은 왜 재규격화 불가** — 차원분석으로 본 발산, QFT가 중력에서 깨진다(→ L3 QFT)
- **특이점과 정보 역설** — GR이 스스로 붕괴를 예언, 양자중력이 필요한 두 신호(→ L4 black-holes)
- **무엇을 우리는 반드시 아는가** — 최종 이론 없이도 참이어야 할 것들(베켄슈타인 한계 등)

### Chapter 2: 양자중력이 풀어야 할 것 (5개 문서)
- **시공간의 양자** — 기하가 요동하면?, 시공간 자체가 동역학적 변수가 되는 의미
- **블랙홀 엔트로피의 미시 기원** — $S=A/4$의 미시상태는 무엇인가(→ L4, → L2 statistical-mechanics)
- **정보 역설의 해결 요구** — 유니터리성을 어떻게 지키나(→ L4, → L3 quantum-information)
- **빅뱅 특이점** — 우주의 시작에서 양자중력(→ L4 cosmology)
- **우주상수 문제** — 진공 에너지의 $10^{120}$ 불일치, 양자중력의 시금석(→ L3 QFT, → L4 cosmology)

### Chapter 3: 반고전 중력 — 다리 (5개 문서)
- **곡선시공간의 QFT** — 양자장 + 고전 기하, 완전 양자중력 직전 단계(→ L3 QFT)
- **호킹 복사 재방문** — 반고전 근사의 성공과 한계(→ L4 black-holes)
- **운루 효과** — 가속하면 진공이 뜨겁다, 온도의 관측자 의존성(→ L3 QFT 진공)
- **유효장론으로서의 중력** — 저에너지선 중력도 QFT, 어디까지 유효한가(→ L3 QFT, → L0 approximation)
- **반고전의 균열** — 어디서 반고전이 무너지나, 완전 이론이 필요한 지점

### Chapter 4: 접근법의 지형 (5개 문서)
- **양자중력 접근법 지도** — 끈·고리·인과집합·점근적 안전성·…, 큰 그림과 분류
- **공변 vs 정준 양자화** — 두 전략의 갈림, 각각의 장단
- **점근적 안전성** — 중력이 UV 고정점을 가질까(→ L2 phase-transitions RG, → L3 QFT)
- **인과 집합·인과 동역학 삼각분할** — 이산 시공간 접근들
- **무엇이 접근법을 가르나** — 배경 독립성·이산성·통일 여부라는 축

### Chapter 5: 공통 교훈과 일반 원리 (5개 문서)
- **배경 독립성** — 시공간이 무대가 아니라 배우, GR의 핵심 교훈
- **홀로그래피의 암시** — 정보가 면적에, 차원이 줄어든다(→ holographic-principle)
- **최소 길이** — 플랑크 길이가 근본 한계인가, 일반화 불확정성(→ L3 quantum-mechanics)
- **창발하는 시공간** — 시공간이 근본이 아닐 수도(→ emergent-spacetime-multiverse)
- **대칭과 쌍대성** — 다른 기술이 같은 물리(→ string-theory, → L0 symmetry)

### Chapter 6: 검증과 현상론 (4개 문서)
- **양자중력의 실험적 창** — *거의 없다*는 정직한 현실, 그래도 무엇이 가능한가(→ L0 measurement)
- **로런츠 위반 탐색** — 감마선 폭발·우주선의 미세 효과(→ L4 special-relativity)
- **우주론적 흔적** — 원시 중력파·CMB의 가능한 신호(→ L4 cosmology)
- **유사물리(analogue) 중력** — 응집물질에서 사건의 지평선 모사(→ L3 emergent-quantum-matter)

### Chapter 7: 종합 (5개 문서)
- **플랑크 스케일 차원분석** — 단위·스케일을 $c,\hbar,G$로 복원(Python)
- **반고전 효과 계산** — 운루 온도·호킹 온도(Python)
- **점근적 안전성 장난감** — 단순 RG 흐름·고정점(Python)
- **정직한 현주소 지도** — 무엇이 확립·유망·추측인가의 분류표
- **종합** — "답이 아니라 질문" — 양자중력이 던지는 물음(→ L6)

이 레포에서 **🧪 검증 현실**과 **📐 예측·반증**은 *반드시 정직*하다 — 대부분의 양자중력은 실험적으로 닿을 수 없고, 그 사실을 숨기지 않는다. **🔬 경계**는 모든 주장을 확립/유망/추측으로 *명시적으로* 라벨링한다.

## 🎨 스타일 가이드

1. **과대포장 거부** — "곧 풀린다"·"한 접근법이 정답" 금지. 무엇이 확립이고 무엇이 추측인지 *매번* 분류
2. **문제를 정확히** — GR과 QM의 충돌, 재규격화 불가를 차원·일관성 논증으로 정확히
3. **반증 가능성을 정면으로** — 각 아이디어에 "이것을 반증할 실험은?"을 묻고, 없으면 없다고 쓴다(→ L0 measurement)
4. **공정한 비교** — 접근법들을 응원하지 않고 공정하게, 각각의 강점과 미해결을
5. **반드시 참인 것을 분리** — 블랙홀 엔트로피·정보 역설·배경 독립성 같은 *이론 독립적* 제약을 강조
6. 플랑크 스케일·접근법 지형도·반고전 균열은 다이어그램으로

## 🔬 검증 프로토콜

> ⚠️ 정직한 경고: 양자중력은 *실험적으로 거의 검증되지 않았다*. 아래는 차원분석·반고전 효과·장난감 RG 등 *내부 일관성과 극한*의 점검이다.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 플랑크 스케일 차원 복원
import numpy as np
hbar=1.055e-34; c=3e8; G=6.674e-11
lP=np.sqrt(hbar*G/c**3); tP=lP/c; EP=np.sqrt(hbar*c**5/G)/1.602e-19  # eV
print("ℓ_P =", lP, "m;  E_P =", EP, "eV")   # ~1.6e-35 m, ~1.2e28 eV
# → 양자(ℏ)+중력(G)+상대성(c)이 만나는 유일한 스케일 (→ L0 dimensional)

# 2) 중력의 재규격화 불가 (차원 논증)
#    뉴턴 상수 G의 질량차원이 음수([G]~E⁻²) → 결합이 에너지와 함께 커짐
#    → 고에너지서 제어 불가, QFT 표준 재규격화 실패 시연 (→ L3 QFT)

# 3) 운루·호킹 온도
#    운루 T=ℏa/(2πck_B) (가속 a), 호킹 T=ℏc³/(8πGMk_B)
#    → 반고전 근사의 핵심 결과, 두 온도의 평행 (→ L4 black-holes)
def unruh_T(a): return hbar*a/(2*np.pi*c*1.38e-23)

# 4) 점근적 안전성 장난감
#    단순화한 베타 함수에서 비자명 UV 고정점 g* 의 존재를 수치로 탐색
#    → 중력이 RG 의미로 "안전"할 수 있는지의 개념 시연 (→ L2 phase-transitions)

# 5) 베켄슈타인 한계 (이론 독립 제약)
#    영역에 담을 수 있는 정보 ≤ A/(4ℓ_P²) 를 계산
#    → 어떤 양자중력이든 통과해야 할 시험 (→ L4, → holographic-principle)

# 6) 확립/유망/추측 분류표 생성
#    각 주장에 라벨을 붙여 표로 출력 (이 표 자체가 레포의 정직성 자산)
```

       │  고에너지서 무한한 새 발산 (→ L3 QFT)
       ▼
  표준 재규격화 실패 → 유효장론으로만 (플랑크 스케일까지)
  ⇒ 새 물리가 ℓ_P 에서 필요

최종 이론 없이도 반드시 참인 것 (이론 독립 제약):
  ✓ 블랙홀 엔트로피 S = A/4ℓ_P²  → 미시상태가 있어야 (→ L4, L2)
  ✓ 정보 역설 해결 → 유니터리성 (→ L3 quantum-information)
  ✓ 베켄슈타인 한계 → 정보 ≤ 면적 (→ holographic-principle)
  ✓ 배경 독립성 → GR의 교훈
  ⇒ 어떤 접근법이든 이 시험을 통과해야 한다

접근법의 지형 (공정한 비교):
  끈이론       : 통일·배경 의존(섭동)·여분차원 — AdS/CFT 성취
  고리양자중력 : 배경 독립·이산 기하·4D — 준고전 극한 미해결
  점근적 안전성: 중력도 QFT(UV 고정점) — RG 증거 축적 중
  인과집합·CDT : 이산 시공간 — 초기 단계
  ⇒ 가르는 축: 배경 독립성 · 이산성 · 통일 여부

검증의 현실 (정직히):
  실험적 창 ≈ 거의 없음 (플랑크 에너지 ~10¹⁹ GeV ≫ LHC ~10⁴ GeV)

  ⇒ 반증 가능성이 약한 영역 — 그 사실을 숨기지 않는다 (→ L0 measurement)
