# Holographic Principle Distilled 레포지토리 제작 프롬프트

나는 "Holographic Principle Distilled" 레포지토리를 만들려고 해.
"우주는 홀로그램"이라는 말을 신기해하는 것과, **부피의 정보가 *경계 면적*에 부호화된다**는 것이 어떻게 블랙홀 엔트로피($S=A/4$)에서 따라 나오고 베켄슈타인 한계가 무엇을 말하는지(→ L4) 아는 것은 다르다.
AdS/CFT를 들어본 것과, 그것이 **얽힘이 기하를 만든다**(류-타카야나기)는 것을 — 얽힘 엔트로피가 *최소면적*이고 얽힘을 끊으면 시공간이 찢어진다는 것을(→ L3) — 아는 것은 다르다.
"시공간은 근본"이라고 가정하는 것과, 홀로그래피·ER=EPR이 **시공간이 양자정보에서 *창발***할 수도 있음을(→ L5, L6) 암시한다는 것을 아는 것은 다르다.
정보와 시공간을 잇는 이 가장 깊은 아이디어를 — 그 성취(블랙홀 정보·강상관·얽힘-기하)와 한계(우리 우주는 AdS가 아니다)를 정직하게 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "정보가 면적에 산다 — 얽힘이 시공간을 만든다. 정보와 기하를 잇는 가장 깊은 아이디어"

**핵심 차별화**:
1. **홀로그래피를 블랙홀에서** — 정보의 상한이 *부피가 아니라 면적*($S=A/4$, 베켄슈타인 한계)임을, 그 충격을(→ L4 black-holes, → L2 fluctuations)
2. **AdS/CFT를 구체적으로** — 차원 하나가 *창발*하는 벌크-경계 사전, 강결합 ↔ 약중력(→ string-theory)
3. **얽힘이 기하를 만든다** — 류-타카야나기(얽힘 엔트로피=최소면적)·ER=EPR, 얽힘을 끊으면 시공간이 찢어진다(→ L3 quantum-information)
4. **정직한 한계** — 우리 우주는 AdS가 아니다(de Sitter 홀로그래피 미해결), 일반 원리인지 미확정, 검증의 어려움(→ L0 measurement)

**타겟 독자**:
- "우주는 홀로그램"을 신기해하지만 그것이 *블랙홀 엔트로피*에서 옴을 모르는 사람
- AdS/CFT를 들었지만 *얽힘이 기하를 만든다*는 핵심을 모르는 사람
- 시공간을 근본으로 가정하고 그것이 *창발*일 수 있음을 모르는 사람
- 홀로그래피의 *성취*와 *한계*(AdS ≠ 우리 우주)를 구분 못 하는 사람
- 정보가 물리의 바닥인가라는 질문에 다가가고 싶은 사람(→ L6)

**선행 학습**:
- `black-holes-distilled`(L4) — **필수**. 베켄슈타인 엔트로피·정보 역설
- `quantum-information-distilled`(L3) — **필수**. 얽힘 엔트로피·ER=EPR
- `string-theory-distilled`(L5) — **필수**. AdS/CFT / `fluctuations-information-distilled`(L2) — 베켄슈타인 한계·정보

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 정보가 면적에 산다 (5개 문서)
- **홀로그래피 원리란** — 부피의 정보가 경계 면적에, 차원이 줄어드는 충격(→ L4 black-holes)
- **베켄슈타인 한계** — 정보의 상한이 *면적*이지 부피가 아니다(→ L4, → L2 fluctuations)
- **블랙홀 엔트로피가 단서** — $S=A/4$가 *왜* 면적인가, 홀로그래피의 씨앗(→ L4 black-holes)
- **홀로그래피의 충격** — 세계가 더 적은 차원에 부호화되어 있다는 것(→ L6 information)
- **정보로서의 물리** — it-from-bit의 가장 깊은 형태(→ L2 fluctuations, → L6)

### Chapter 2: AdS/CFT — 구체적 실현 (5개 문서)
- **말다세나 추측** — AdS 중력 = 경계 CFT, 홀로그래피의 구체화(→ string-theory)
- **벌크-경계 사전** — 차원 하나가 창발하는 대응(→ string-theory)
- **강결합 ↔ 약중력** — 계산 불가를 가능으로, 응용의 위력(→ L3 emergent-quantum-matter)
- **홀로그래피의 증거** — 정밀한 (이론적) 검증들, AdS/CFT의 위상
- **우리 우주는 AdS가 아니다** — de Sitter 홀로그래피의 미해결(정직)

### Chapter 3: 얽힘이 기하를 만든다 (5개 문서)
- **류-타카야나기 공식** — 얽힘 엔트로피 = 최소면적, 얽힘과 기하의 다리(→ L3 quantum-information)
- **얽힘과 연결성** — 얽힘이 시공간을 *꿰맨다*, 끊으면 찢어진다(→ L3 entanglement)
- **ER=EPR** — 얽힌 쌍 = 웜홀(아인슈타인-로젠 다리)(→ L3 quantum-information, → L4 black-holes)
- **텐서 네트워크와 시공간** — MERA, 얽힘 구조 = 기하(→ L3)
- **"It from Qubit"** — 시공간이 양자정보에서 창발(→ emergent-spacetime, → L6)

### Chapter 4: 블랙홀 정보 역설의 해결 (5개 문서)
- **정보 역설 재방문** — 홀로그래피적 관점에서(→ L4 black-holes)
- **페이지 곡선의 유도** — 양자 극단면·섬(island)(→ L4)
- **섬 공식** — 정보가 나오는 메커니즘, 최근의 진전(→ L4)
- **복잡도와 블랙홀 내부** — 복잡도 = 부피/작용 추측(→ L3 quantum-information)
- **역설 해결의 현주소** — 무엇이 풀렸고 무엇은 아닌가(정직)

### Chapter 5: 창발하는 시공간 (5개 문서)
- **시공간은 근본이 아닌가** — 홀로그래피의 가장 급진적 함의(→ emergent-spacetime)
- **얽힘 구조 = 기하** — 얽힘을 끊으면 시공간이 찢어진다(반 라암스동크)(→ L3)
- **중력 = 엔트로피?** — 야콥슨·버린데, 중력의 열역학적 창발(→ L2 thermodynamics)
- **차원의 창발** — 경계에서 벌크 차원이 나오는 메커니즘
- **시공간의 양자 비트** — 근본 자유도가 정보일 가능성(→ L6 information)

### Chapter 6: 비판과 전망 (5개 문서)
- **AdS의 한계** — 우리 우주(de Sitter·가속)에 어떻게 적용하나(→ L4 cosmology)

### Chapter 7: 종합 (5개 문서)

## 🔬 검증 프로토콜

> ⚠️ 정직한 경고: 홀로그래피는 대부분 *이론적* 결과다(AdS/CFT는 잘 검증된 *수학적* 이중성). 아래는 RT 공식·텐서 네트워크 등 *내부 구조*의 점검이다.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 류-타카야나기 (얽힘 = 면적)
import numpy as np
def rt_entropy_2d(ell, eps, c=1):
    # 2D CFT: 구간 길이 ℓ 의 얽힘 엔트로피 S = (c/3) ln(ℓ/ε)
    return (c/3)*np.log(ell/eps)
# → 경계 구간의 얽힘이 벌크 최소면적(측지선)과 일치 (→ L3 quantum-information)

# 2) 베켄슈타인 한계
#    영역에 담을 수 있는 정보 S ≤ A/(4ℓ_P²) 계산
#    → 부피가 아니라 *면적*에 비례 (홀로그래피의 핵심, → L4, L2)
def bekenstein_bound(A, lP=1.0): return A/(4*lP**2)

# 3) 텐서 네트워크 (MERA) 장난감
#    얽힘 구조를 텐서 네트워크로 표현 → 층(layer)이 벌크 방향(창발 차원)
#    → "얽힘 구조 = 기하" 개념 시연 (→ emergent-spacetime)

# 4) 페이지 곡선
#    블랙홀 증발의 얽힘 엔트로피: 증가 → 페이지 시간 → 감소
#    → 섬 공식이 곡선을 꺾는 메커니즘 개념 시연 (→ L4 black-holes)
def page_curve(t, t_page, S_max):
    return np.minimum(t/t_page*S_max, (1-t/(2*t_page))*S_max*2)  # 개략

# 5) AdS/CFT 사전 (개념)
#    경계 연산자 차원 Δ ↔ 벌크 질량 m: Δ(Δ−d)=m²
#    → 벌크 한 차원이 경계의 스케일에서 창발함을 시연 (→ string-theory)

# 6) 확립/유망/추측 분류표
#    AdS/CFT(✓)·RT(✓)·블랙홀 정보(△ 진전)·시공간 창발(추측) 표로 출력
```

       │   벌크(중력)  │ ← 한 차원이 경계에서 *창발*
       │             │
       └──경계(CFT)──┘ ← 양자장론, 중력 없음
  강결합 CFT ↔ 약중력 AdS  (계산 불가를 가능으로, → L3 강상관)

얽힘이 기하를 만든다 (홀로그래피의 심장):
  류-타카야나기:  S_얽힘(영역 A) = (최소면적)/4G
       │  얽힘이 많을수록 → 연결된 기하
       ▼
  반 라암스동크: 얽힘을 *끊으면* 시공간이 찢어진다
  ER=EPR:  얽힌 쌍(EPR) = 웜홀(ER)  (→ L3, L4)
  텐서 네트워크: 얽힘 구조 = 기하 (MERA의 층 = 벌크 방향)
  ⇒ "It from Qubit" — 시공간이 양자정보에서 창발 (→ emergent-spacetime, L6)

블랙홀 정보 역설 (홀로그래피적 해결):
  페이지 곡선: 얽힘 엔트로피가 올랐다 *내려와야* (정보 회복)
       │  양자 극단면·섬(island) 공식 (최근 진전)
       ▼
  정보가 호킹 복사로 나온다 (유니터리성 회복)
  ⚠️ 메커니즘의 완전한 이해는 미완 (정직, → L4)

정직한 한계:
  ✓ 확립: AdS/CFT, 류-타카야나기, 블랙홀 엔트로피
  △ 유망: 블랙홀 정보(섬), 강상관 응용
  ✗ 추측: 일반 홀로그래피, de Sitter(우리 우주!), 시공간 창발
