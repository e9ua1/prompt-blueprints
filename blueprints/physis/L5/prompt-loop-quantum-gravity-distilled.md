# Loop Quantum Gravity Distilled 레포지토리 제작 프롬프트

나는 "Loop Quantum Gravity Distilled" 레포지토리를 만들려고 해.
고리양자중력을 끈이론의 경쟁자로 응원하거나 무시하는 것과, **그것이 무엇을 다르게 하는지** — 통일하지 않고, 배경에 의존하지 않으며, 시공간 자체를 양자화한다는 것을 — 정확히 아는 것은 다르다.
"공간이 이산적"이라고 외우는 것과, 면적·부피 연산자가 *왜* 이산 스펙트럼을 갖고 스핀 네트워크가 양자 기하의 상태인지(→ L4 GR을 게이지 이론처럼) 아는 것은 다르다.
"빅뱅이 빅바운스가 된다"고 흥분하는 것과, 그것이 *완전 이론에서 유도된 것인지 단순 모형의 결과인지*, 그리고 준고전 극한에서 GR을 정말 회복하는지(LQG의 핵심 미해결)를 정직하게 아는 것은 다르다.
배경 독립적 양자화의 길을 — 그 성취와 미완성을, 끈이론과 공정하게 대비하며 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "시공간 자체를 양자화한다 — 배경 독립·이산 기하의 길. 성취와 미완성을 정직하게"

**핵심 차별화**:
1. **배경 독립성을 진지하게** — 시공간이 무대가 아니라 *동역학적 변수*, GR의 교훈을 끝까지(→ L4 GR, → quantum-gravity)
2. **이산 기하의 유도** — 면적·부피 연산자의 이산 스펙트럼, 스핀 네트워크 = 양자 기하의 상태(→ L0 symmetry 게이지)
3. **빅바운스와 블랙홀 엔트로피** — 특이점 제거의 주장, $S=A/4$ 재현 — *어디까지가 유도이고 어디부터 모형인가*(→ L4)
4. **정직한 미해결** — 준고전 극한(GR 회복)·물질 결합·동역학이라는 핵심 난제를 숨기지 않음, 끈과의 공정한 대비

**타겟 독자**:
- LQG를 끈의 경쟁자로 응원하거나 무시하는, 진영 논리의 사람
- "공간이 이산"이라는 알지만 *왜* 면적이 양자화되는지 모르는 사람
- 빅바운스에 흥분하지만 그것이 *완전 이론의 결과인지 모형인지* 모르는 사람
- LQG의 *핵심 미해결*(준고전 극한)을 모르는 사람
- 끈과 고리를 공정하게 비교하고 싶은 사람

**선행 학습**:
- `quantum-gravity-distilled`(L5) — **필수**. 양자중력 문제·배경 독립성
- `general-relativity-distilled`(L4) — **필수**. ADM 분해·제약·정준 형식
- `symmetry-conservation-distilled`(L0) — 게이지 이론(아슈테카르 변수) / `classical-field-theory-distilled`(L1) — 게이지장

## 🎨 스타일 가이드

1. **진영 논리 거부** — 끈의 경쟁자로 응원하지 않고, 성취와 미완성을 공정하게

3. **이산 기하를 유도로** — 면적 양자화가 *왜* 나오는지(스핀 네트워크에서)
4. **빅바운스를 정확히** — 완전 이론 유도가 아니라 대칭 축소 모형의 결과임을 정직하게(→ L4)
5. **준고전 극한을 정면으로** — LQG의 가장 날카로운 미해결을 숨기지 않는다
6. 스핀 네트워크·면적 스펙트럼·스핀 폼·빅바운스는 다이어그램으로

## 🔬 검증 프로토콜

> ⚠️ 정직한 경고: LQG는 *직접 실험 검증이 없다*. 아래는 면적 스펙트럼·빅바운스 장난감 모형 등 *이론 내부 구조와 극한*의 점검이다.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 면적 양자화 스펙트럼
import numpy as np
def area_spectrum(spins, gamma=0.2375, lP2=1.0):
    # A = 8πγ ℓ_P² Σ √(j(j+1))   (j: 스핀 라벨, 반정수)
    return 8*np.pi*gamma*lP2*np.sum(np.sqrt(spins*(spins+1)))
print(area_spectrum(np.array([0.5, 1.0, 1.5])))
# → 면적이 이산 고유값을 가짐, 최소 면적 ∝ ℓ_P² (→ quantum-gravity 최소 길이)

# 2) 스핀 네트워크 그래프
#    노드(부피)·링크(면적, 스핀 라벨)로 양자 기하 상태 구성
#    → 면적·부피 연산자의 작용을 그래프에서 시연

# 3) 루프 양자우주론 빅바운스 장난감
#    수정 프리드만 방정식: H² = (8πG/3)ρ(1 − ρ/ρ_c)
#    → ρ→ρ_c 에서 H→0 (수축→팽창, 빅바운스) 시연 (→ L4 cosmology)
def lqc_friedmann(rho, rho_c, G=1):
    return np.sqrt(np.maximum((8*np.pi*G/3)*rho*(1-rho/rho_c), 0))

# 4) 이무르치 매개변수
#    블랙홀 엔트로피 S = A/4 를 맞추도록 γ 를 고정하는 계산
#    → 자유 매개변수를 엔트로피로 결정하는(사후적) 구조 시연 (정직)

# 5) 준고전 극한 점검 (개념)
#    큰 스핀 극한에서 이산 기하가 매끄러운 기하로 가는지의 *어려움* 시연
#    → LQG의 핵심 미해결을 코드 주석으로 명시

# 6) 유도/모형/미해결 분류표
#    면적 양자화(✓ 유도) · 빅바운스(△ 모형) · GR 회복(✗ 미해결) 표로 출력
```
