# String Theory Distilled 레포지토리 제작 프롬프트

나는 "String Theory Distilled" 레포지토리를 만들려고 해.
끈이론을 "만물의 이론"으로 떠받들거나 "검증 불가한 수학 유희"로 비웃는 것과, **무엇이 실제 성취이고 무엇이 아직 미배달인지** — 중력자가 *자동으로* 나오고 블랙홀 엔트로피를 *세는* 성공, 그리고 $10^{500}$개 진공이라는 예측력의 위기를 — 정직하게 가르는 것은 다르다.
"끈은 진동한다"고 외우는 것과, 그 진동 모드가 어떻게 입자 스펙트럼이 되고 닫힌 끈의 무질량 스핀-2 모드가 *왜 필연적으로 중력자*인지(→ L4) 아는 것은 다르다.
쌍대성을 신기해하는 것과, T-쌍대성·S-쌍대성·AdS/CFT가 "근본이 관점 의존적"임을 — 시공간조차 창발일 수 있음을(→ L5) — 드러낸다는 것을 아는 것은 다르다.
가장 발전했으나 아직 미배달인 이 이론을 — 성취·약점·반증 가능성을 과대포장 없이 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "점에서 끈으로 — 중력이 자동으로 나오고, 쌍대성이 '근본'을 흔든다. 가장 발전했으나 미배달인 이론을 정직하게"

**핵심 차별화**:
1. **중력자의 필연** — 닫힌 끈의 무질량 스핀-2 모드 = 중력자, 끈이론이 *중력을 요구*하는 구조(→ L4 GR, → L1 oscillations)
2. **쌍대성의 교훈** — T·S·AdS/CFT 쌍대성이 "근본이 관점 의존"임을, 시공간 창발의 암시(→ L5 emergent-spacetime)
3. **블랙홀 엔트로피의 승리** — 끈이론이 $S=A/4$를 *미시상태로 센다*(스트로민저-바파), 가장 단단한 성취(→ L4 black-holes, → L2)
4. **풍경과 비판을 정직하게** — $10^{500}$ 진공, 반증 가능성 위기, 무엇이 성취이고 무엇이 미배달인가(→ L0 measurement)

**타겟 독자**:
- 끈이론을 "만물의 이론"으로 떠받들거나 "헛소리"로 비웃는, 양극단의 사람
- "끈은 진동한다"는 알지만 *왜 중력자가 필연*인지 모르는 사람
- 쌍대성을 신기해하지만 그것이 *근본 개념을 흔든다*는 것을 모르는 사람
- 끈이론의 *실제 성취*(블랙홀 엔트로피·AdS/CFT)와 *미배달*을 구분 못 하는 사람
- 끈이론이 과학인가라는 질문에 정직하게 답하고 싶은 사람(→ L0 measurement)

**선행 학습**:
- `quantum-gravity-distilled`(L5) — **필수**. 양자중력 문제의 정식화
- `quantum-field-theory-distilled`(L3) — **필수**. 발산·게이지·재규격화

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 점에서 끈으로 (5개 문서)
- **왜 끈인가** — 점입자의 발산을 끈이 매끄럽게, 중력이 자동으로 나오는 동기(→ L3 QFT)
- **끈의 작용** — 남부-고토/폴랴코프 작용, 세계면(worldsheet)(→ L0 variational)
- **진동 모드 = 입자** — 끈의 진동이 입자 스펙트럼이 되는 메커니즘(→ L1 oscillations 정규모드)
- **중력자의 필연** — 닫힌 끈의 무질량 스핀-2 모드 = 중력자(→ L4 GR)
- **끈이론의 약속과 미배달** — 무엇을 주장하고 무엇은 아직인가(정직한 출발)

### Chapter 2: 여분 차원과 일관성 (5개 문서)
- **임계 차원** — 왜 10차원인가, 이상(anomaly) 상쇄가 차원을 고정(→ L0 symmetry, → L3)
- **콤팩트화** — 여분 차원을 숨기기, 칼라비-야우 다양체
- **초대칭(SUSY)** — 끈이론이 요구하는 페르미온-보손 대칭(→ L3 standard-model)
- **끈의 종류와 통일** — 다섯 끈이론, M이론으로의 통일
- **여분 차원의 검증?** — 실험적 한계, 큰 여분 차원 탐색(→ L0 measurement)

### Chapter 3: 쌍대성 (5개 문서)
- **쌍대성이란** — 다른 기술, 같은 물리, 대칭의 일반화(→ L0 symmetry)
- **T-쌍대성** — 큰 반지름 = 작은 반지름, 최소 길이의 암시(→ quantum-gravity)
- **S-쌍대성** — 강결합 = 약결합, 비섭동 정보로의 창
- **M이론** — 다섯 끈이론 + 11차원 초중력의 통일
- **쌍대성의 교훈** — "근본"이 관점 의존, 시공간 창발의 암시(→ emergent-spacetime)

### Chapter 4: 브레인과 블랙홀 (5개 문서)
- **D-브레인** — 끈이 끝나는 곳, 동역학적 객체의 발견
- **게이지 이론과 브레인** — 브레인 위에 게이지 이론이 산다(→ L3 standard-model)
- **블랙홀 미시상태** — 끈이론이 $S=A/4$를 *센다*(스트로민저-바파)(→ L4 black-holes, → L2)
- **정보 역설과 끈** — 퍼지볼·미시상태 그림(→ L4)
- **블랙홀 엔트로피의 승리** — 끈이론의 가장 단단한 성취(→ L4)

### Chapter 5: AdS/CFT — 홀로그래피의 구현 (5개 문서)
- **말다세나 추측** — AdS 중력 = 경계 CFT, 홀로그래피의 구체화(→ holographic-principle)
- **사전(dictionary)** — 중력과 게이지 이론을 잇는 사전(→ L3)
- **강결합을 약중력으로** — 계산 불가를 가능으로, 응용(→ L3 emergent-quantum-matter 강상관)
- **얽힘과 기하** — 류-타카야나기, 얽힘 엔트로피 = 최소면적(→ L3 quantum-information, → emergent-spacetime)
- **AdS/CFT의 위상** — 가장 정밀한 홀로그래피, *그러나 우리 우주는 AdS가 아니다*(정직)

### Chapter 6: 풍경과 비판 (5개 문서)
- **끈 풍경(landscape)** — $10^{500}$개 진공, 예측력의 위기(→ L4 cosmology 다중우주)
- **인류원리 논쟁** — 설명인가 포기인가(→ emergent-spacetime)
- **반증 가능성 비판** — 끈이론은 과학인가(→ L0 measurement Popper)
- **끈이론의 성취** — 수학·게이지/중력 이중성·블랙홀(부정할 수 없는 것)
- **정직한 평가** — 무엇이 확립·유망·미배달인가의 분류

### Chapter 7: 종합 (6개 문서)

## 🔬 검증 프로토콜

> ⚠️ 정직한 경고: 끈이론은 *직접 실험 검증이 없다*. 아래는 모드 스펙트럼·쌍대성·홀로그래피 공식 등 *수학적 구조와 내부 일관성*의 점검이다.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 끈 진동 스펙트럼
import numpy as np
def string_spectrum(n_max, alpha=1.0):
    # 질량²  M² = (N − a)/α'  (N: 진동 준위, a: 영점)
    N=np.arange(0, n_max)
    return (N - 1)/alpha          # 보존끈 a=1; 타키온·무질량·대량 모드
# → n=1 에 무질량 모드(중력자·게이지장 포함), 사다리형 질량 (→ L1 oscillations)

# 2) T-쌍대성 장난감
#    반지름 R 의 콤팩트 차원에서 운동량 모드 n/R 와 감김 모드 wR/α'
#    → R ↔ α'/R 교환 시 스펙트럼 불변 확인 (최소 길이 √α', → quantum-gravity)
def t_dual_spectrum(R, n, w, alpha=1.0):
    return (n/R)**2 + (w*R/alpha)**2

# 3) 류-타카야나기 (얽힘 = 면적)
#    AdS에서 경계 구간의 얽힘 엔트로피 ∝ 최소면적(측지선 길이)
#    → S_A = (c/3) ln(ℓ/ε) 형태 재현 (→ L3 quantum-information)

# 4) 콤팩트화 차원 세기
#    10 = 4(관측) + 6(콤팩트) 의 모듈라이 수 맛보기
#    → 풍경의 기원: 콤팩트화 선택의 방대함 시연

# 5) AdS/CFT 사전 맛보기
#    경계 연산자 차원 Δ ↔ 벌크 장 질량 m 의 관계 Δ(Δ−d)=m²
#    → 벌크-경계 대응의 가장 단순한 사전 (→ holographic-principle)

# 6) 성취/미배달 분류표
#    중력자(✓)·블랙홀 엔트로피(✓ BPS)·AdS/CFT(✓) vs
#    표준모형 유도(✗)·풍경 예측(✗)·실험(✗) 를 표로 출력
```

  M이론:     5개 끈이론 + 11D 초중력  =  한 이론의 다른 모습
  ⇒ "무엇이 근본인가"가 관점에 의존 → 시공간조차 창발? (→ emergent-spacetime)

블랙홀 엔트로피 (가장 단단한 성취):
  스트로민저-바파: 특정(BPS) 블랙홀의 미시상태를 *센다*

  ⇒ 끈이론의 부정할 수 없는 승리
  ※ 단, 일반 블랙홀로의 확장은 미완 (정직)

AdS/CFT (홀로그래피의 구현):
   AdS 중력 (d+1차원 벌크)  ≡  CFT (d차원 경계)
       강결합 CFT  ↔  약중력 AdS  (계산 불가를 가능으로)
       얽힘 엔트로피 = 최소면적 (류-타카야나기, → L3)
  ⇒ 차원 하나가 *창발* — 가장 정밀한 홀로그래피 (→ holographic-principle)
  ※ 단, 우리 우주는 AdS가 아니다 (de Sitter) — 미해결 (정직)

풍경과 비판 (정직히):

  인류원리: 설명인가 포기인가  →  논쟁
