# Standard Model Distilled 레포지토리 제작 프롬프트

나는 "Standard Model Distilled" 레포지토리를 만들려고 해.
$SU(3)\times SU(2)\times U(1)$을 기호로 외우는 것과, **대칭이 어떻게 힘을 낳는지**(게이지 원리) — 대칭을 점마다 국소화하라는 요구가 전자기·약력·강력을 *강제로* 만들어내는지를 — 유도하는 것은 다르다.
"힉스가 질량을 준다"고 말하는 것과, 힉스 메커니즘이 *깨진 대칭성*(자발 대칭 깨짐 + 게이지)이고 골드스톤 보손이 "먹혀" 게이지 보손이 질량을 얻는 구조임을(→ L0) 아는 것은 다르다.
"쿼크는 갇혀 있다"고 외우는 것과, 점근적 자유와 색가둠이 *왜* 자유 쿼크를 금지하는지 아는 것은 다르다.
입자 동물원에 질서를 부여한 표준모형을 — 그리고 그것이 어디서 무너지며 무엇 너머로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "대칭이 힘을 낳는다(게이지 원리) — 힉스 = 깨진 대칭성, 세 힘의 통일, 그리고 그 빈틈"

**핵심 차별화**:
1. **게이지 원리 = 힘의 기원** — 대칭 국소화가 전자기·약·강력을 *강제*함을(→ L0 symmetry, → L3 QFT), 세 힘의 통일된 논리
2. **힉스 = 깨진 대칭성** — "질량을 준다"가 아니라 자발 대칭 깨짐 + 게이지, 골드스톤이 먹히는 구조(→ L0 symmetry, → L2 phase-transitions)
3. **QCD의 가둠** — 점근적 자유와 색가둠, *왜* 자유 쿼크가 없나, 질량의 대부분은 결합에너지(→ L0 approximation 비섭동)
4. **표준모형 너머를 정직하게** — 중력 없음·암흑물질·중성미자 질량·계층 문제, 무엇이 빈틈이고 무엇이 추측인가

**타겟 독자**:
- $SU(3)\times SU(2)\times U(1)$을 외우지만 *대칭이 힘을 낳음*을 모르는 사람
- "힉스가 질량을 준다"로만 알고 *깨진 대칭성*의 구조를 모르는 사람
- 색가둠을 외우지만 *왜* 쿼크가 홀로 못 나오는지 모르는 사람
- 표준모형의 성공만 알고 그 *빈틈*(중력·암흑물질 등)을 모르는 사람
- 표준모형이 어떻게 우주론·끈이론으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `quantum-field-theory-distilled`(L3) — **필수**. 게이지 장론·재규격화·달리는 결합
- `symmetry-conservation-distilled`(L0) — **필수**. 게이지·표현·자발 대칭 깨짐·힉스
- `phase-transitions-distilled`(L2) — 자발 대칭 깨짐 / `measurement-uncertainty-distilled`(L0) — 5σ 발견 기준

### Chapter 1: 입자 동물원의 질서 (5개 문서)
- **입자의 목록** — 쿼크·렙톤·게이지 보손·힉스, 무엇이 기본 입자인가
- **대칭이 입자를 분류한다** — 표현(representation)으로서의 입자, 양자수가 라벨(→ L0 symmetry)
- **세대 구조** — 3세대의 반복, 왜 세 벌인가(미해결)
- **게이지 군 $SU(3)\times SU(2)\times U(1)$** — 표준모형의 대칭을 한눈에, 각 인자의 역할
- **보존법칙과 양자수** — 바리온·렙톤 수, 색·맛, 무엇이 보존되고 무엇이 깨지나(→ L0 symmetry)

### Chapter 2: 게이지 원리 — 힘의 기원 (5개 문서)
- **게이지 원리 재방문** — 대칭 국소화 → 힘, 공변미분의 필연(→ L0 symmetry, → L3 QFT)
- **QED** — $U(1)$, 광자, 전자기력(→ L1 EM, → L3 QFT)
- **약력과 $SU(2)$** — W·Z 보손, 약한 상호작용, 패리티 위반의 충격
- **강력과 $SU(3)$** — 글루온, 색전하, 양-밀스 이론(→ L3 QFT)
- **게이지 보손의 자기상호작용** — 비가환의 결과, 글루온끼리 결합(아벨 QED와의 차이)

### Chapter 3: 힉스 메커니즘 (5개 문서)
- **게이지 보손의 질량 문제** — 게이지 불변은 질량항을 금지, 그런데 W·Z는 무겁다(모순)
- **자발 대칭 깨짐 재방문** — 멕시칸 햇, 진공의 선택(→ L0 symmetry, → L2 phase-transitions)
- **힉스 메커니즘** — 골드스톤이 "먹혀" 게이지 보손이 질량 획득, *질량의 기원*(→ L0 symmetry)
- **힉스 보손** — 2012 LHC 발견, 5σ(→ L0 measurement), 표준모형의 마지막 조각
- **페르미온 질량과 유카와** — 힉스가 페르미온에도 질량을, 결합의 위계(질량 스펙트럼의 수수께끼)

### Chapter 4: 강력과 가둠 (5개 문서)
- **양자색역학(QCD)** — 색·글루온, 강력의 장론(→ L3 QFT)
- **점근적 자유** — 고에너지서 약해지는 힘, 달리는 결합의 부호(→ L3 QFT RG)
- **색가둠** — 쿼크는 홀로 못 나온다, *왜* 자유 쿼크가 없나, 끈 장력
- **하드론** — 중간자·바리온, 쿼크 모형, 질량의 대부분은 *결합에너지*($E=mc^2$)
- **격자 QCD** — 비섭동 계산, 가둠·하드론 질량의 수치 증거(→ L0 approximation 비섭동)

### Chapter 5: 전약 통일과 맛 (5개 문서)
- **전약 통일** — $SU(2)\times U(1)$, 전자기와 약력의 통합, 바인베르크 각
- **중성미자** — 거의 질량 없는 입자, 약하게만 반응, 검출의 어려움
- **중성미자 진동** — 맛 섞임, 질량의 증거(표준모형 너머의 첫 실험적 단서)
- **CP 위반과 CKM** — 쿼크 맛 섞임, 물질-반물질 비대칭의 단서(→ L2 arrow-of-time, → L4 cosmology)
- **이상(anomaly)과 일관성** — 양자 이상의 상쇄, 표준모형이 정합적인 이유(→ L0 symmetry)

### Chapter 6: 표준모형 너머 (5개 문서)
- **표준모형의 성공** — 정밀 검증의 역사, 예측의 승리(→ L0 measurement)
- **표준모형의 빈틈** — 중력 없음·암흑물질·암흑에너지·중성미자 질량·계층 문제
- **대통일 이론(GUT)** — $SU(5)$ 등, 세 힘의 통일 꿈, 양성자 붕괴 예측
- **초대칭(SUSY)** — 페르미온-보손 대칭, 계층 문제 해결 시도, 아직 미발견(→ L5 string theory)
- **자연성과 계층 문제** — 왜 힉스 질량은 이렇게 작나, 미세조정의 수수께끼

```python
# 환경: Python 3 + numpy + scipy + sympy + matplotlib

# 1) 세 결합의 달리기와 (준)통일
import numpy as np
def run_couplings(mu, mZ=91.2):
    # 1루프 RGE: 1/α_i(μ) = 1/α_i(mZ) − (b_i/2π) ln(μ/mZ)
    b=np.array([41/10, -19/6, -7])     # U(1),SU(2),SU(3) 계수
    a0=np.array([1/59.0, 1/29.6, 1/8.5])
    return a0 + (b/(2*np.pi))*np.log(mu/mZ)
# → 에너지를 올리면 세 역결합이 한 점 근처로 (GUT 스케일 ~10¹⁶ GeV)

# 2) 힉스 퍼텐셜 자발 대칭 깨짐
#    V(φ)=−μ²|φ|²+λ|φ|⁴ → 최소 |φ|=v/√2 ≠ 0
#    → 진공기댓값 v, 게이지 보손 질량 m_W=gv/2 (→ L0 symmetry)
def higgs_V(phi, mu2=1.0, lam=0.5): return -mu2*phi**2 + lam*phi**4

# 3) 중성미자 진동 확률
#    P(ν_μ→ν_e) = sin²(2θ) sin²(1.27 Δm² L/E)
def osc_prob(L, E, dm2, theta):
    return np.sin(2*theta)**2 * np.sin(1.27*dm2*L/E)**2
# → L/E 스캔으로 진동 패턴 → 질량차 Δm²의 증거 (표준모형 너머)

# 4) 입자 붕괴 (페르미 황금률, sympy)
#    간단한 2체 붕괴의 위상공간·수명 추정 → 실측과 자릿수 대조

# 5) 패리티 위반 (약력)
#    좌/우 손지기(chirality)에 따른 약력 결합 차이를 도식화
#    → 약력이 거울 대칭을 깬다 (→ L0 symmetry C,P,CP)

# 6) 색가둠 직관 (끈 퍼텐셜)
#    V(r) ≈ −a/r + σr (쿨롱 + 선형) → r↑ 에서 선형 → 분리 불가
#    → 자유 쿼크가 없는 이유 시연
```

```
   SU(3)  →  글루온 ×8  →  강력 (자기상호작용)
  ⇒ "대칭이 상호작용을 *지정*한다"

힉스 = 깨진 대칭성 (질량의 기원):
            V(φ)
             │ ╲   ╱       V = −μ²|φ|² + λ|φ|⁴
        ─────┼──●──●──→|φ|   진공 |φ|=v≠0 (대칭 깨짐)
             │
       게이지 + SSB:  골드스톤 보손이 "먹혀"
                     게이지 보손이 질량 m_W = gv/2 획득
       유카와:       힉스가 페르미온에도 질량 (→ L0 symmetry)
  ⇒ "질량을 준다" = 깨진 대칭성의 구조

QCD 가둠 (자유 쿼크 없음):
  달리는 결합 α_s(μ):
       고에너지(짧은 거리): α_s ↓  → 점근적 자유 (쿼크 거의 자유)
       저에너지(긴 거리):   α_s ↑  → 가둠
  쿼크 간 퍼텐셜:  V(r) ≈ −4/3·α_s/r + σr
       r↑ → σr (선형) → 끈 끊어지며 새 쿼크쌍 생성 → 자유 쿼크 못 봄
  ⇒ 하드론 질량의 대부분 = 결합에너지 (E=mc², → L4 special relativity)

표준모형의 빈틈 (정직):
  ✗ 중력 (재규격화 불가, → L5)
  ✗ 암흑물질·암흑에너지 (관측되나 미설명, → L4)
  ✗ 중성미자 질량 (진동이 증거, SM은 0 예측)
  ✗ 계층 문제 (왜 힉스 질량이 플랑크보다 압도적으로 작나)
  ✗ 물질-반물질 비대칭 (CP 위반만으론 부족, → L4)
```
