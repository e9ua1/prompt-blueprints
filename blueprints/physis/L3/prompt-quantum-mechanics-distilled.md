# Quantum Mechanics Distilled 레포지토리 제작 프롬프트

나는 "Quantum Mechanics Distilled" 레포지토리를 만들려고 해.
슈뢰딩거 방정식을 풀어 에너지 준위를 구하는 것과, **왜 세계가 이산적인지** — 갇힌 파동의 경계조건이 어떻게 불연속 에너지를 강제하는지를 — 유도하는 것은 다르다.
"중첩은 동시에 둘"이라고 외우는 것과, 중첩이 *측정 전 무규정*이며 불확정성이 측정 한계가 아니라 *상태 자체의 성질*임을 — $\Delta x\Delta p\ge\hbar/2$를 교환자에서 — 아는 것은 다르다.
"측정하면 붕괴한다"고 말하는 것과, 그 붕괴가 *법칙인지 근사인지*가 물리학 최대의 미해결 문제임을 아는 것은 다르다.
직관이 왜 실패하는지를 — 그리고 양자역학이 어떻게 장론·정보·창발물질로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "왜 세계는 이산적인가 — 중첩·불확정성·측정의 진짜 의미, 직관이 실패하는 이유"

**핵심 차별화**:
1. **이산성을 유도** — 에너지 양자화가 *갇힌 파동의 경계조건*에서 나옴을(흑체·원자), 고전이 실패한 실험들에서(→ L2 흑체)
2. **중첩·불확정성을 정확히** — "동시에 둘"의 오해 교정, 불확정성을 교환자 $[\hat x,\hat p]=i\hbar$에서 유도(측정 한계 아닌 상태의 성질)
3. **고전과의 다리** — 포아송→교환자, 해밀턴-야코비→슈뢰딩거, $\hbar\to0$ 대응원리(→ L1 classical-mechanics)
4. **측정 문제를 정직하게** — 붕괴가 법칙인지 근사인지의 미해결을 표시하고 다음 레포로(→ entanglement-measurement)

**타겟 독자**:
- 슈뢰딩거 방정식은 풀지만 *왜 세계가 이산적*인지 유도 못 하는 사람
- 중첩을 "동시에 둘"로, 불확정성을 "측정 교란"으로 오해하는 사람
- 양자 보존량·각운동량·스핀이 *대칭에서* 나옴을 모르는 사람
- 측정 문제가 *미해결*임을 모르고 붕괴를 당연시하는 사람
- 양자역학이 어떻게 QFT·양자정보·창발물질로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — **필수**. 포아송 괄호·해밀턴-야코비(양자의 선조)
- `oscillations-waves-distilled`(L1) — **필수**. 파동방정식·정규모드·고전 불확정성
- `symmetry-conservation-distilled`(L0) — 각운동량·보존량 / `approximation-perturbation-distilled`(L0) — 섭동·WKB·변분

## 🔗 레포 연결

**⬆️ 선행**: `classical-mechanics-distilled`·`oscillations-waves-distilled`(L1), `symmetry-conservation-distilled`(L0).
**🤝 시너지 (L3 내부)**: `entanglement-measurement-distilled`(측정 문제의 본격 전개), `quantum-field-theory-distilled`(조화진동자·경로적분이 장론의 빌딩블록), `quantum-information-distilled`(큐비트·정보로서의 양자).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `emergent-quantum-matter-distilled`(L3) — 다체 양자가 만드는 창발 입자
- `standard-model-distilled`(L3) — 대칭·스핀·각운동량의 깊은 형태
- `astrophysics-distilled` / `black-holes-distilled`(L4) — 별의 구조(축퇴압)·원소(→ L2 양자통계)
- `cosmology-distilled`(L4) — 인플레이션의 양자 요동
- `least-action-everywhere`(L6) — 경로적분이 회수되는 곳

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 왜 양자인가 — 고전의 붕괴 (5개 문서)
- **고전이 실패한 곳** — 흑체복사·광전효과·원자 안정성·저온 비열, 양자가 *강제된* 실험들(→ L2 흑체)
- **양자화의 첫 단서** — 플랑크·아인슈타인·보어, "왜 이산인가"의 첫 답과 그 잠정성
- **물질파** — 드브로이, 파동-입자 이중성, 전자 회절의 충격(→ L1 oscillations)
- **이중슬릿** — 양자의 핵심 미스터리, 간섭과 "어느 경로"의 양립 불가
- **양자역학의 충격** — 결정론·실재론·국소성 중 무엇을 포기해야 하나(예고)

### Chapter 2: 상태와 중첩 (5개 문서)
- **상태벡터와 힐베르트 공간** — 양자상태 = 벡터, 중첩의 의미(→ L0 선형대수 교차)
- **중첩의 진짜 의미** — "동시에 둘"이 아니라 측정 전 무규정, 흔한 오해의 교정
- **관측가능량과 연산자** — 에르미트 연산자, 고유값 = 측정 가능값, 관측가능성(→ L0 measurement)
- **브라-켓과 내적** — 디랙 표기, 확률진폭, 정규직교 기저
- **양자 중첩의 실험** — SQUID·분자 간섭, 거시적 중첩의 한계(→ entanglement 결잃음)

### Chapter 3: 측정과 확률 (5개 문서)
- **보른 규칙** — 확률진폭의 제곱, *왜 제곱인가*, 확률의 등장
- **측정 공준** — 붕괴(collapse)·사영(projection), 측정 후 상태
- **기댓값과 분산** — 관측가능량의 통계, 반복 측정으로 드러나는 분포
- **양립불가능 관측가능량** — 교환하지 않는 연산자, 동시 측정의 불가능
- **측정 문제의 씨앗** — 붕괴는 법칙인가 근사인가(→ entanglement-measurement 본격)

### Chapter 4: 불확정성과 대칭 (5개 문서)
- **불확정성 원리** — $\Delta x\Delta p\ge\hbar/2$의 유도(교환자에서), 측정 한계가 아닌 *상태의 성질*
- **교환자와 포아송** — $[\hat x,\hat p]=i\hbar$, 고전 포아송 괄호의 양자판(→ L1 classical-mechanics)
- **대칭과 보존(양자)** — 대칭 연산자, 보존량 $=[\hat O,\hat H]=0$, 뇌터의 양자판(→ L0 symmetry)
- **각운동량** — $SO(3)/SU(2)$, 양자수 $\ell,m$, 사다리 연산자(→ L0 symmetry)
- **스핀** — 고전 대응 없는 자유도, 슈테른-게를라흐, 스피너(→ L0 symmetry)

### Chapter 5: 슈뢰딩거 방정식과 풀이 (6개 문서)
- **슈뢰딩거 방정식** — 시간발전, *어디서 오나*(해밀턴-야코비의 양자판)(→ L1 classical-mechanics)
- **정상상태와 에너지** — 시간 독립 방정식, 에너지 고유상태, 시간발전의 위상
- **우물과 장벽** — 무한·유한 우물, *이산 에너지의 기원*(경계조건), 영점 에너지
- **터널링** — 고전 금지 영역 침투, WKB(→ L0 approximation), 알파 붕괴·주사터널현미경
- **조화진동자** — 사다리 연산자, 영점 에너지, *모든 장론의 빌딩블록*(→ L1 oscillations, → QFT)
- **수소 원자** — 완전 해, 양자수의 기원, 주기율표의 씨앗

### Chapter 6: 양자 동역학과 근사 (5개 문서)
- **시간발전과 그림** — 슈뢰딩거 vs 하이젠베르크 그림, 유니터리 발전
- **섭동론(양자)** — 시간 독립·종속, 에너지 보정, 페르미 황금률(→ L0 approximation)
- **변분법(양자)** — 바닥상태 에너지 상한, 레일리-리츠(→ L0 variational, approximation)
- **WKB와 반고전** — $\hbar\to0$ 극한, 보어-조머펠트(→ L0 approximation 대응원리)
- **경로적분 맛보기** — 모든 경로의 합, 고전극한에서 최소작용(→ L0 variational, → QFT)

### Chapter 7: 종합·계산 (7개 문서)
- **슈뢰딩거 수치해** — 1D 정상상태 고유값 문제(유한차분)(Python)
- **시간발전 시뮬레이션** — 파속의 분산·터널링·우물 통과(Python)
- **조화진동자·수소 수치** — 에너지 준위·파동함수 시각화(Python)
- **불확정성 수치 검증** — $\Delta x\Delta p$ 측정, 최소 불확정성(가우스) 상태(Python)
- **양자→고전 다리** — 결맞은 상태, 에렌페스트 정리, 대응원리(→ L1, → entanglement 결잃음)
- **해석의 문턱** — 무엇이 측정인가, 다음 레포로의 다리(→ entanglement-measurement)
- **종합** — "왜 세계는 이산적인가"와 양자역학의 구조적 통합(→ L3 전체, L6)

## 🎯 핵심 질문      — 어떤 양자 현상을, 어떤 원리에서 유도하나

## ⚙️ 제1원리 유도    — 슈뢰딩거·교환자·경계조건에서 결과를 끌어낸다
## 🧪 실험·관측 증거  — 이중슬릿·터널링·원자 스펙트럼의 실측
## 🔬 경계           — 양자 기술이 흐려지는 곳 (측정 문제·거시 결잃음)
## 🧬 횡단 원리       — 대칭(보존)·최소작용(경로적분)·정보가 여기서 어떻게 반복되나
## 🪜 창발           — 위 레이어(장론·창발물질·천체)에서 무엇이 나타나나
## 📐 예측·반증       — 에너지 준위·간섭·불확정성 등 검증 가능한 예측
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---

🔬 **Boundary**  — (양자 기술이 흐려지는 조건: 측정·결잃음·고전극한)
🪜 **Emergence** — (위 레이어에서 같은 구조가 낳는 것 + 검증 실험)

이 레포에서 **⚙️ 제1원리 유도**는 *슈뢰딩거 방정식 또는 교환자 대수*에서 끌어내며, **🔬 경계**는 "측정 문제(붕괴의 정체)는 미해결", "거시 결잃음으로 고전성 출현(→ entanglement)" 같은 한계를 정직하게 표시한다.

## 🔬 검증 프로토콜

> 슈뢰딩거 고유값 + 시간발전(스플릿-스텝) + 불확정성 측정 + 대응원리.

```python
# 환경: Python 3 + numpy + scipy + matplotlib  (양자 도구 qutip 선택적)

# 1) 1D 슈뢰딩거 고유값 (유한차분)
import numpy as np
def schrodinger_1d(V, x, hbar=1.0, m=1.0):
    dx=x[1]-x[0]; N=len(x)
    lap=(np.diag(-2*np.ones(N))+np.diag(np.ones(N-1),1)+np.diag(np.ones(N-1),-1))/dx**2
    H=-hbar**2/(2*m)*lap+np.diag(V)
    E,psi=np.linalg.eigh(H); return E,psi
# 무한우물 → E_n ∝ n², 조화진동자 → E_n=(n+½)ℏω 확인 (이산성!)

# 2) 시간발전 (스플릿-스텝 푸리에)
#    파속을 V(x) 속에서 발전 → 분산·반사·터널링 관찰
#    → 장벽 터널링 확률을 WKB 예측과 대조 (→ L0 approximation)

# 3) 불확정성 검증
#    가우스 파속에서 Δx, Δp를 측정 → Δx·Δp ≥ ℏ/2, 가우스가 등호 달성 확인
def uncertainty(psi, x):
    p=np.abs(psi)**2; p/=p.sum()
    xm=(x*p).sum(); dx=np.sqrt(((x-xm)**2*p).sum())
    # p-공간은 FFT로 → dp 계산
    return dx  # × dp ≥ 0.5

# 4) 각운동량 대수 (sympy/numpy)
#    스핀-1/2 Pauli, [Sx,Sy]=iSz 확인; 사다리 연산자로 고유값 사다리
#    → SU(2) 대수가 양자수를 강제함을 시연 (→ L0 symmetry)

# 5) 대응원리 (에렌페스트)
#    ⟨x⟩, ⟨p⟩의 시간발전이 고전 방정식을 따르는지 확인
#    → 결맞은 상태에서 양자가 고전 궤도를 재현 (→ L1 classical-mechanics)

# 6) 수소 원자 동경 방정식
#    유효퍼텐셜로 동경 슈뢰딩거 풀이 → E_n ∝ −1/n², 양자수 ℓ,m 확인
```

## 💡 핵심 분석 대상

```
왜 세계는 이산적인가 (갇힌 파동):
  자유 입자: 연속 에너지
       │  경계조건(우물에 가둠)
       ▼
  정상파만 허용 → 파장 λ_n = 2L/n → E_n ∝ n²   (이산!)
  ⇒ 양자화 = 갇힌 파동의 경계조건 (현의 배음과 같은 구조, → L1 oscillations)

불확정성 = 상태의 성질 (측정 교란 아님):
  [x̂, p̂] = iℏ
       │  코시-슈바르츠 (교환자 → 분산 부등식)
       ▼
  Δx · Δp ≥ ℏ/2     ← 어떤 상태든, 측정 전에도
  ⇒ 위치와 운동량을 동시에 규정하는 상태가 *존재하지 않는다*
     (푸리에 쌍대성의 양자판, → L1 oscillations 고전 불확정성)

고전 → 양자 다리 (대응원리):
  포아송 {q,p}=1   ──ℏ──▶  [q̂,p̂]=iℏ
  해밀턴-야코비 S   ──────▶  슈뢰딩거 ψ=e^{iS/ℏ}
  경로적합 δS=0     ──ℏ→0──▶  최소작용 회복 (→ L0 variational)
  ⇒ 양자가 더 근본, 고전은 ℏ→0 극한

측정 문제 (미해결):
  ψ = α|0⟩ + β|1⟩
       │  유니터리 발전 (결정론, 가역)
       │       vs
       ▼  측정 → |0⟩ 또는 |1⟩ (확률, 비가역, 붕괴?)
  두 법칙의 충돌 — 붕괴는 법칙인가 근사인가?
  ⇒ 물리학 최대의 미해결 (→ entanglement-measurement, 결잃음)
```
