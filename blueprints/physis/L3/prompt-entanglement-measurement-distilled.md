# Entanglement, Measurement & Decoherence Distilled 레포지토리 제작 프롬프트

나는 "Entanglement, Measurement & Decoherence Distilled" 레포지토리를 만들려고 해.
얽힘을 "두 입자가 연결됨"으로 이해하는 것과, **벨 부등식이 어떻게 국소 실재론을 *검증 가능하게* 반증하는지** — 그리고 실험이 그것을 위반해 "자연은 국소적이지 않다"를 강제하는지를 — 이해하는 것은 다르다.
"측정하면 붕괴한다"고 외우는 것과, 측정 문제(유니터리 발전 vs 붕괴의 충돌)가 *왜 미해결*이고 슈뢰딩거의 고양이가 무엇을 폭로하는지 아는 것은 다르다.
"거시 세계는 고전적"이라고 당연시하는 것과, **결잃음(decoherence)이 *어떻게* 고전성을 창발**시키는지, 그리고 그것이 측정 문제를 *얼마나* 푸는지(전부는 아니다)를 아는 것은 다르다.
양자역학의 해석들을 — 무엇이 검증 가능하고 무엇이 형이상학인지 정직하게 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "벨 부등식 — 자연은 국소적이지 않다. 측정은 미해결, 결잃음은 고전성을 창발시킨다"

**핵심 차별화**:
1. **벨 부등식을 검증으로** — 국소 실재론의 *검증 가능한* 한계를 유도하고, 양자가 그것을 위반함을(루프홀 없는 실험까지)
2. **측정 문제를 회피하지 않음** — 유니터리 vs 붕괴의 충돌, 폰 노이만 사슬, 고양이·위그너의 친구가 폭로하는 것
3. **결잃음의 메커니즘과 한계** — 환경과의 얽힘이 *어떻게* 고전성을 창발시키나, 그리고 측정 문제의 *어디까지만* 푸나(정직)
4. **해석들의 정직한 비교** — 코펜하겐·다세계·봄·객관적 붕괴·QBism, 무엇이 검증 가능하고 무엇이 형이상학인가(→ L0 measurement)

**타겟 독자**:
- 얽힘을 "연결"로만 알고 벨 부등식이 *무엇을 반증*하는지 모르는 사람
- 측정 붕괴를 당연시하고 그것이 *미해결 문제*임을 모르는 사람
- "거시는 고전적"을 당연시하고 결잃음의 메커니즘을 모르는 사람
- 양자 해석들을 들어봤지만 무엇이 *검증 가능*한지 구분 못 하는 사람
- 얽힘이 어떻게 양자정보·시공간(ER=EPR)으로 *이어지는지* 보고 싶은 사람

### Chapter 3: 결잃음(decoherence) (5개 문서)
- **환경과의 얽힘** — 계는 고립되지 않는다, *환경이 측정한다*

- **포인터 상태와 선택** — 환경이 고르는 고전적 기저(einselection), 왜 위치인가
- **왜 거시는 고전적인가** — 결잃음 시간의 극단적 짧음, 고전성의 *창발*(→ L2)
- **결잃음이 푸는 것과 못 푸는 것** — 측정 문제의 *일부만* 해결(정직한 한계)

### Chapter 4: 양자 비국소성 (5개 문서)
- **비국소성의 정확한 의미** — 신호는 못 보낸다(무신호 정리), 그런데 비국소적

- **GHZ와 비통계적 모순** — 부등식 없는 비국소성, 한 번의 측정으로 드러나는 모순

- **양자 문맥성** — 코헨-스페커 정리, 측정 맥락 의존성

### Chapter 5: 해석들 (6개 문서)
- **코펜하겐** — 표준 해석, 붕괴의 실용주의, 그 모호함

- **해석들의 정직한 비교** — 무엇이 검증 가능하고 무엇이 형이상학인가(→ L0 measurement, → L5)

## 🎨 스타일 가이드

1. **벨을 검증으로** — 국소 실재론이 *검증 가능하게* 반증됨을, 부등식 유도와 실험으로
2. **측정 문제를 회피 안 함** — 붕괴가 미해결임을 정면으로, 고양이·위그너의 친구로
3. **결잃음의 한계를 정직하게** — 고전성을 창발시키지만 측정 문제를 *전부* 풀진 않음

5. **수치로 부순다** — CHSH·결잃음·얽힘 엔트로피·텔레포테이션을 직접 계산

## 🔬 검증 프로토콜

> CHSH 계산 + 결잃음(밀도행렬) + 얽힘 엔트로피 + 텔레포테이션 회로.

```python
# 환경: Python 3 + numpy + scipy + matplotlib  (qutip 선택적)

# 1) CHSH 부등식 (양자 vs 고전 vs 치렐슨)
import numpy as np
def chsh_quantum():
    # 벨 상태 |Φ+⟩ 에서 적절한 측정각으로 상관 E(a,b)=−cos(a−b)
    angles=[(0,np.pi/4),(0,3*np.pi/4),(np.pi/2,np.pi/4),(np.pi/2,3*np.pi/4)]
    S=sum(s*(-np.cos(a-b)) for s,(a,b) in zip([1,1,1,-1],angles))
    return abs(S)   # → 2√2 ≈ 2.83 (고전 한계 2 위반, 치렐슨 한계 달성)
print(chsh_quantum())

# 2) 결잃음 (밀도행렬 비대각 소멸)
#    중첩 (|0⟩+|1⟩)/√2 의 밀도행렬에 위상 잡음(환경 결합) 적용
#    → 비대각 항이 exp(−t/τ)로 소멸 → 혼합상태(고전 확률)로 (→ L2)
def dephase(rho, gamma, t):
    rho=rho.copy(); off=np.exp(-gamma*t)
    rho[0,1]*=off; rho[1,0]*=off; return rho

# 3) 얽힘 엔트로피
#    벨 상태의 환원 밀도행렬 ρ_A = Tr_B|ψ⟩⟨ψ| → S=−Tr(ρ_A ln ρ_A)
#    → 최대 얽힘 = ln2 확인, 곱상태 = 0 (→ quantum-information)
def entanglement_entropy(rho_A):
    ev=np.linalg.eigvalsh(rho_A); ev=ev[ev>1e-12]
    return -np.sum(ev*np.log(ev))

# 4) 양자 텔레포테이션
#    임의 상태 |ψ⟩ + 벨 쌍 → 벨 측정 + 고전 비트 → 보정 → |ψ⟩ 복원
#    → 충실도(fidelity) 1 확인 (얽힘 + 고전통신, 신호 전송 아님)

# 5) GHZ 비통계적 모순
#    |GHZ⟩=(|000⟩+|111⟩)/√2 에서 측정 결과가 국소 실재론과 직접 모순
#    → 한 번의 측정 집합으로 모순 (부등식 불필요)

# 6) 무신호 정리 확인
#    얽힌 쌍에서 한쪽 측정이 다른 쪽 *국소* 통계를 안 바꿈을 수치로
#    → 비국소적이지만 신호 전송 불가
```

```
벨 부등식 (국소 실재론의 검증 가능한 한계):
  국소 실재론 가정:
    ① 실재론: 측정 전에 값이 정해져 있다 (숨은 변수 λ)

    |S| = |E(a,b) − E(a,b') + E(a',b) + E(a',b')| ≤ 2
       ↓ 양자 예측
    |S| = 2√2 ≈ 2.83   (위반!)
       ↓ 실험 (아스페→루프홀 없는, 2015)
    위반 확인  ⇒ ①②를 동시에 못 가진다 → 자연은 국소적이지 않다(또는 비실재)

측정 문제 (미해결):
  |ψ⟩|준비⟩ ──유니터리──▶ Σ c_i |i⟩|장치_i⟩   (중첩, 결정론, 가역)
                                    │ 그런데 우리는 하나만 본다
                                    ▼
                              |k⟩|장치_k⟩      (확률 |c_k|², 비가역)
  ⇒ 두 법칙(유니터리 vs 붕괴)의 충돌 — 어디서 전환되나?
     폰 노이만 사슬: 측정선을 어디 긋든 자의적

결잃음 (고전성의 창발, 그러나 일부만):
  계 + 환경:  (α|0⟩+β|1⟩)|E⟩ ──▶ α|0⟩|E₀⟩ + β|1⟩|E₁⟩
       │  환경 자유도 추적(Tr_E)
       ▼
  ρ_계 = |α|²|0⟩⟨0| + |β|²|1⟩⟨1|   (비대각 소멸, ~exp(−t/τ))
  ⇒ 간섭 사라짐 → 고전 확률처럼 보임 (→ L2 arrow-of-time)
  ※ 그러나 "왜 하나가 선택되나"(붕괴)는 *여전히* 미해결 (정직)

해석들 (검증 가능성으로):
  코펜하겐  : 붕괴 가정 (실용적, 모호)
  다세계    : 붕괴 없음, 모두 일어남 (확률 문제)
  봄        : 결정론 + 비국소 인도파
  GRW/펜로즈: 객관적 붕괴 (← 검증 가능!)
  ⇒ 대부분 같은 예측 → (현재) 실험 구분 불가 = 형이상학 영역 (→ L0 measurement)
```
