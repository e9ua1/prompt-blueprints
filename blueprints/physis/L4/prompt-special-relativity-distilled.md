# Special Relativity Distilled 레포지토리 제작 프롬프트

나는 "Special Relativity Distilled" 레포지토리를 만들려고 해.
로런츠 변환 공식을 외워서 시간 지연을 계산하는 것과, **빛의 속도가 빛의 성질이 아니라 시공간의 구조 상수**임을 — 두 공준에서 시간과 공간이 하나로 묶이는 과정을 — 유도하는 것은 다르다.
"움직이면 시간이 느려진다"고 말하는 것과, **동시성 자체가 관측자마다 다르다**는 더 깊은 충격을, 그리고 그것이 인과율과 어떻게 얽히는지 아는 것은 다르다.
$E=mc^2$를 공식으로 쓰는 것과, 그것이 *왜 필연*이고 질량이 에너지의 한 형태인지 유도하는 것은 다르다.
시간과 공간이 하나의 시공간으로 통합된다는 것을 — 그리고 그것이 어떻게 일반상대성·핵에너지·원소의 기원으로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "빛의 속도는 빛의 성질이 아니라 시공간의 구조 상수다 — 시간과 공간이 하나로 통합되고, 질량은 에너지다"

**핵심 차별화**:
1. **$c$ = 시공간의 구조 상수** — 빛의 성질이 아니라 *인과의 최대 속도*, 빛은 그저 그 속도로 가는 것(질량이 없어서)
2. **동시성의 상대성을 정면으로** — 시간 지연·길이 수축보다 깊은 충격, "동시"가 관측자마다 다르다는 것이 모든 것의 뿌리
3. **$E=mc^2$의 필연** — 공식이 아니라 유도, 질량 = 에너지가 핵융합·핵분열로 어떻게 이어지나(→ astrophysics, standard-model)
4. **전자기에서 태어난 상대성** — 맥스웰이 $c$를 예언했고, 전기와 자기가 하나임을 상대성이 드러낸다(→ L1 EM)

**타겟 독자**:
- 로런츠 변환은 쓰지만 *$c$가 왜 불변*이고 시공간의 구조 상수인지 모르는 사람
- 시간 지연을 알지만 *동시성의 상대성*이 더 깊은 충격임을 모르는 사람
- $E=mc^2$를 외우지만 *왜 필연*인지 유도 못 하는 사람
- 전기와 자기가 *상대성으로 통합*됨을 모르는 사람
- 특수상대성이 어떻게 일반상대성·핵에너지로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `electromagnetism-distilled`(L1) — **필수**. 맥스웰이 $c$를 예언, 전기·자기의 통합
- `symmetry-conservation-distilled`(L0) — **필수**. 갈릴레이→로런츠 대칭, 푸앵카레 군
- `measurement-uncertainty-distilled`(L0) — 마이컬슨-몰리(측정이 이론을 죽인 사례)

## 🔗 레포 연결

**⬆️ 선행**: `electromagnetism-distilled`(L1), `symmetry-conservation-distilled`(L0).
**🤝 시너지 (L4 내부)**: `general-relativity-distilled`(등가원리 — 가속이 중력과 구분 불가, 이 레포의 직접 후속).
**🪜 창발 (위 레이어가 다시 쓴다)**:

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 빛의 속도라는 수수께끼 (5개 문서)
- **두 공준** — 상대성원리 + 광속 불변, 왜 이 둘에서 *모든 것*이 나오나
- **마이컬슨-몰리** — 에테르의 죽음, 측정이 이론을 죽인 사례(→ L0 measurement)
- **$c$는 시공간의 구조 상수** — 빛의 성질이 아니라 인과의 최대 속도, 빛은 무질량이라 그 속도로 간다
- **갈릴레이 상대성의 붕괴** — 속도 덧셈이 왜 틀렸나(→ L0 symmetry 갈릴레이→로런츠)
- **동시성의 상대성** — "동시"가 관측자마다 다르다, 가장 깊은 충격

### Chapter 2: 로런츠 변환과 시공간 (5개 문서)
- **로런츠 변환** — 두 공준에서 *유도*, 시간 지연·길이 수축의 기원
- **시간 지연** — 움직이는 시계는 느리다, 뮤온 실험(→ L0 measurement)
- **길이 수축** — 움직이는 자는 짧다, 상호성의 역설
- **민코프스키 시공간** — 시간과 공간의 통합, 불변 간격 $s^2=-(ct)^2+x^2$(→ L0 symmetry)
- **시공간 도표** — 세계선·광추, 사건의 기하학적 표현

### Chapter 3: 인과율과 4-벡터 (5개 문서)
- **광추와 인과 구조** — 시간꼴·공간꼴·빛꼴 간격, 무엇이 무엇에 영향 줄 수 있나
- **인과율과 광속 한계** — 왜 $c$를 못 넘나, 타키온의 역설(인과 위반)
- **4-벡터** — 시공간 벡터, 불변량, 로런츠 공변성(→ L0 symmetry)
- **4-속도와 4-운동량** — 고유시간, 상대론적 운동량의 정의
- **속도 덧셈과 도플러** — 상대론적 속도 합성, 상대론적 도플러 효과(→ L1 oscillations)

### Chapter 4: 질량-에너지 (5개 문서)
- **$E=mc^2$의 필연** — 어디서 나오나, 질량이 에너지의 한 형태인 이유
- **상대론적 에너지·운동량** — $E^2=(pc)^2+(mc^2)^2$, 무질량 입자의 경우
- **질량 결손과 결합에너지** — 핵융합·핵분열의 에너지(→ astrophysics, → standard-model)
- **운동량-에너지 보존** — 충돌·붕괴, 불변 질량의 활용
- **무질량 입자와 광자** — 빛의 운동량, 복사압의 상대론(→ L1 EM)

### Chapter 5: 전자기와 상대성 (4개 문서)
- **전기와 자기는 하나** — 상대성이 전자기를 통합한다(→ L1 EM)
- **장텐서의 변환** — $F_{\mu\nu}$, 한 계의 전기장이 다른 계의 자기장(→ L1 classical-field-theory)
- **상대성은 전자기에서 태어났다** — 맥스웰이 $c$를 예언, SR의 역사적 뿌리(→ L1 EM)
- **상대론적 전자기 라그랑지안** — 공변 형식, 변분으로 맥스웰(→ L0 variational, → L1)

### Chapter 6: 역설과 응용 (5개 문서)
- **쌍둥이 역설** — 누가 늙나, 가속의 비대칭이 푼다
- **사다리-헛간 역설** — 동시성의 상대성으로 해소
- **벨의 우주선 역설** — 길이 수축의 미묘함, 실로 묶인 두 우주선
- **가속과 등가원리 예고** — 가속계의 시공간, GR로 가는 다리(→ general-relativity)
- **응용** — GPS·입자가속기·핵에너지, SR의 실측 검증(→ L0 measurement)

### Chapter 7: 종합·계산 (5개 문서)
- **로런츠 변환 시뮬레이션** — 시공간 도표·시간 지연·동시성 계산(Python)

- **종합** — "$c$는 시공간의 구조 상수"의 통합과 시공간의 통일(→ general-relativity, L6)

## 🔬 검증 프로토콜

> 로런츠 변환·시공간 도표 + 상대론적 동역학 + 불변량 점검 + 도플러.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 로런츠 변환과 불변 간격
import numpy as np
def lorentz_boost(beta):
    g=1/np.sqrt(1-beta**2)
    return np.array([[g, -g*beta],[-g*beta, g]])   # (ct, x)
# 두 사건의 간격 s²=−(cΔt)²+Δx² 가 부스트 후에도 불변임을 확인 (→ L0 symmetry)

# 2) 시간 지연·동시성
#    한 관성계에서 동시인 두 사건이 다른 계에선 동시가 아님을 수치로
#    → 동시성의 상대성 시연; 뮤온 수명 vs 비행거리 대조

# 3) 상대론적 충돌·붕괴
#    4-운동량 보존으로 충돌·붕괴 풀이; 불변 질량 √(E²−|p|²c²) 보존 확인
#    → 질량 결손 → E=mc² 에너지 (→ astrophysics)
def invariant_mass(E, px, py, pz, c=1):
    return np.sqrt(E**2 - (px**2+py**2+pz**2)*c**2)

# 4) 속도 덧셈
#    상대론적 합성 u' = (u+v)/(1+uv/c²) → 어떤 합도 c를 못 넘음 확인

# 5) 상대론적 도플러·광행차
#    움직이는 광원의 진동수 이동 f' = f √((1−β)/(1+β)), 별빛의 광행차
#    → 빛의 상대론적 거동 (→ L1 oscillations)

# 6) 장(field)의 변환 (전기↔자기)
#    한 계의 순수 전기장에 부스트 → 자기장 성분 출현
#    → "전기와 자기는 하나" 수치 시연 (→ L1 EM)
```

## 💡 핵심 분석 대상

```
c는 시공간의 구조 상수 (빛의 성질이 아니라):
  두 공준:
    ① 상대성원리: 모든 관성계에서 물리법칙 동일
    ② 광속 불변: c는 모든 관성계에서 같다
       ↓  이 둘에서
  로런츠 변환:  ct' = γ(ct − βx),  x' = γ(x − βct),  γ=1/√(1−β²)
  ⇒ c는 *어떤 신호도 못 넘는 인과의 최대 속도*
     빛은 무질량이라 마침 그 속도로 간다 (빛이 특별한 게 아님)

동시성의 상대성 (가장 깊은 충격):
  한 계에서 동시(Δt=0)인 두 사건
       │  로런츠 변환
       ▼
  다른 계에선 Δt' = −γβΔx/c ≠ 0   (동시 아님!)
  ⇒ "동시"는 절대가 아니다 → 시간 지연·길이 수축이 여기서 따라 나온다

시공간의 통합 (민코프스키):
  불변 간격:  s² = −(cΔt)² + Δx² + Δy² + Δz²   (모든 계에서 같다)
  광추:
        ct │   ╲ 미래 ╱      시간꼴: 인과 가능
           │    ╲   ╱        빛꼴: s²=0 (빛)
        ───┼─────╳─────→ x   공간꼴: 인과 불가
           │    ╱   ╲
           │   ╱ 과거 ╲
  ⇒ 시간과 공간은 하나의 시공간 (→ general-relativity)

E=mc² (질량 = 에너지):
  E² = (pc)² + (mc²)²
       ├─ 정지(p=0):  E = mc²   (질량 자체가 에너지)
       └─ 무질량(m=0): E = pc    (광자)
  질량 결손: 핵 결합에너지 → 핵융합/핵분열 (→ astrophysics, standard-model)
  ⇒ 별이 빛나는 이유, 원자폭탄의 원리

전기와 자기는 하나 (상대성):
  정지 전하 → 전기장만
  움직이는 전하 → 전기장 + 자기장 (부스트가 섞는다)
  ⇒ F_μν 하나, 맥스웰이 c를 예언 → SR의 뿌리 (→ L1 EM)
```
