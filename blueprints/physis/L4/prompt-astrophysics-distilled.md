# Astrophysics Distilled 레포지토리 제작 프롬프트

나는 "Astrophysics Distilled" 레포지토리를 만들려고 해.
별을 "타는 가스 공"으로 아는 것과, **별의 일생이 양자(L3)+열역학(L2)+중력(L4)의 합작**이라는 것 — 정유체 평형부터 핵융합 터널링, 축퇴압까지 모든 레이어가 한 천체에서 만나는 것을 — 이해하는 것은 다르다.
"별이 핵융합으로 빛난다"고 외우는 것과, 그 융합이 *양자 터널링* 없이는 불가능하고(→ L3) 질량 결손이 $E=mc^2$로 에너지가 됨을(→ L4) 아는 것은 다르다.
"우리는 별의 먼지다"를 시적으로 말하는 것과, 무거운 원소가 *어떻게* 별과 초신성에서 만들어지는지(→ standard-model, cosmology) 아는 것은 다르다.
백색왜성이 *왜* $1.4 M_\odot$를 못 넘는지(축퇴압이 중력에 지는 한계)를 — 그리고 그것이 블랙홀로 이어지는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "'우리는 별의 먼지다'의 물리 — 별의 일생은 양자+열역학+중력의 합작이고, 원소는 별에서 태어난다"

**핵심 차별화**:
1. **별 = 모든 레이어의 합작** — 정유체 평형(중력 vs 압력), 핵융합(양자 터널링), 축퇴압(파울리 배타)이 한 천체에서(→ L1, L2, L3)
2. **차원분석으로 별을 푼다** — 질량-반지름·중심온도를 차원만으로 추정, "절반은 공짜"(→ L0 dimensional)
3. **원소의 기원** — 핵융합이 철까지, 중성자 포획이 그 너머, 초신성·중성자별 병합(→ standard-model, cosmology)
4. **축퇴압과 한계** — 파울리 배타가 중력을 막는다, 찬드라세카르 한계 $1.4M_\odot$, 그 너머는 블랙홀(→ L3, → black-holes)

**타겟 독자**:
- 별을 "타는 가스"로만 알고 *모든 레이어의 합작*임을 모르는 사람
- 핵융합을 외우지만 *양자 터널링* 없이 불가능함을(→ L3) 모르는 사람
- "별의 먼지"를 시로만 알고 원소가 *어떻게* 만들어지는지 모르는 사람
- 백색왜성·중성자별의 한계가 *축퇴압*에서 옴을(→ L3) 모르는 사람
- 천체물리가 어떻게 블랙홀·우주론과 *맞물리는지* 보고 싶은 사람

**선행 학습**:
- `classical-mechanics-distilled`(L1) — 정유체 평형(중력 vs 압력)
- `quantum-mechanics-distilled`(L3) — **필수**. 터널링(핵융합)·축퇴압(파울리)
- `dimensional-scaling-distilled`(L0) — **필수**. 별의 차원분석 / `special-relativity-distilled`(L4) — $E=mc^2$ 질량 결손

## 🔗 레포 연결

**⬆️ 선행**: `quantum-mechanics-distilled`(L3), `dimensional-scaling-distilled`(L0), `classical-mechanics-distilled`(L1).
**🤝 시너지 (L4 내부)**: `general-relativity-distilled`(중력파·강한 중력), `black-holes-distilled`(컴팩트 천체·강착), `cosmology-distilled`(핵합성·화학 진화·표준촛불).
**🪜 창발 (위 레이어가 다시 쓴다 / 되돌아보는 연결)**:
- `black-holes-distilled`(L4) — 중력 붕괴가 한계를 넘으면 블랙홀
- `cosmology-distilled`(L4) — 원소의 우주적 기원, 거리 사다리(표준촛불)
- `standard-model-distilled`(L3) — 핵합성·중성미자(되돌아보는 연결)
- `emergence-distilled`(L6) — 별 = 여러 레이어가 합작하는 창발적 천체

**🔁 통합 레포**: 별은 L0(차원)·L1(역학)·L2(열역학)·L3(양자)·L4(중력)가 *동시에* 작동하는 천연 통합 사례.

```
       │  고전적으론 융합 불가
       ▼  양자 터널링 (가모프, → L3)
  P_tunnel ∝ exp(−√(E_G/E))  → 드물지만 일어남 → 별이 탄다
  ⇒ 터널링 없으면 별도 없고 우리도 없다

원소의 기원 (우리는 별의 먼지):
  빅뱅: H, He, 약간의 Li (→ cosmology BBN)
  별 핵융합: He → C, O, ... → Fe (가장 안정, 결합E 최대)
       │  철 너머는 흡열 (융합으로 못 만듦)
       ▼
  초신성·중성자별 병합: 중성자 포획(r-, s-과정) → Au, U, ...
  ⇒ 몸속 원소의 기원이 별·초신성 (→ standard-model, cosmology)

축퇴압과 한계 (양자가 중력을 막는다):
  백색왜성: 전자 축퇴압 (파울리, → L3)
       상대론적: P ∝ ρ^{4/3} → 질량 상한!
       ▼
  찬드라세카르 한계:  M_Ch ≈ 1.4 M_⊙
       넘으면 → 중성자별 (중성자 축퇴) → 또 넘으면 → 블랙홀 (→ black-holes)
  ⇒ M_Ch ~ (ℏc/G)^{3/2}/m_p²  ← 기본 상수 조합 (→ L0 dimensional)
```
