# Cosmology Distilled 레포지토리 제작 프롬프트

나는 "Cosmology Distilled" 레포지토리를 만들려고 해.
"우주는 빅뱅으로 시작했다"고 외우는 것과, **빅뱅의 세 기둥**(팽창·우주배경복사·원소 존재비)이 어떻게 그것을 *강제*하는지를 — 프리드만 방정식에서 우주의 동역학을 — 유도하는 것은 다르다.
"암흑물질·암흑에너지가 있다"고 말하는 것과, 회전곡선·중력렌즈·가속 팽창이 *왜* 보이지 않는 것을 요구하고, 우주상수 문제가 왜 물리학 최악의 예측 불일치인지(→ L3 QFT) 아는 것은 다르다.
"인플레이션이 일어났다"고 외우는 것과, 그것이 지평선·평탄성 문제를 *어떻게* 풀고 양자 요동이 은하의 씨앗이 되었는지(→ L3) 아는 것은 다르다.
우주가 어떻게 시작했고 무엇으로 되어 있는지를 — 그리고 왜 물질이 반물질보다 많은지(→ L3)를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "우주는 어떻게 시작했나 — 빅뱅의 세 기둥, 암흑 우주의 수수께끼, 인플레이션, 그리고 왜 물질이 반물질보다 많은가"

**핵심 차별화**:
1. **빅뱅을 세 기둥에서** — 팽창·CMB·핵합성이 빅뱅을 *강제*함을, 프리드만 방정식으로 우주의 동역학을(→ general-relativity)
2. **암흑 우주를 증거에서** — 회전곡선·렌즈·가속 팽창이 암흑물질·암흑에너지를 요구, 우주상수 문제($10^{120}$)(→ L3 QFT)
3. **인플레이션의 논리** — 지평선·평탄성 문제를 *어떻게* 풀고, 양자 요동이 구조의 씨앗인지(→ L3)
4. **바리온 비대칭** — 왜 물질이 반물질보다, 사하로프 조건과 CP 위반(→ L3 standard-model, → L2 arrow-of-time)

**타겟 독자**:
- "빅뱅"을 외우지만 *세 기둥*이 그것을 강제함을 모르는 사람
- 암흑물질·암흑에너지를 말하지만 *어떤 증거*가 요구하는지 모르는 사람
- 우주상수 문제가 *물리학 최악의 예측 불일치*임을(→ L3) 모르는 사람
- 인플레이션이 *어떤 문제*를 풀고 구조의 씨앗을 어떻게 뿌렸는지 모르는 사람
- 우주론이 어떻게 입자물리·최전선으로 *이어지는지* 보고 싶은 사람

**선행 학습**:
- `general-relativity-distilled`(L4) — **필수**. FLRW 계량·프리드만 방정식
- `statistical-mechanics-distilled`(L2) — **필수**. 흑체복사(CMB)·열역사
- `standard-model-distilled`(L3) — **필수**. 바리온 비대칭·핵합성 / `quantum-field-theory-distilled`(L3) — 인플레이션 양자 요동·우주상수

### Chapter 1: 팽창하는 우주 (5개 문서)
- **허블 팽창** — 은하의 후퇴, 우주는 팽창한다, 허블-르메트르 법칙
- **FLRW 우주** — 균질·등방 우주의 계량, 우주론 원리(→ general-relativity)
- **우주의 척도인자** — 적색편이와 거리, 팽창의 역사 $a(t)$
- **프리드만 방정식** — 우주의 동역학, 에너지 밀도가 팽창을 결정(→ general-relativity)
- **우주의 운명** — 팽창·수축·가속, 임계밀도와 곡률

### Chapter 2: 빅뱅과 초기 우주 (6개 문서)
- **빅뱅의 증거** — 팽창·CMB·원소 존재비, 세 기둥
- **우주배경복사(CMB)** — 빅뱅의 메아리, 완벽한 흑체복사(→ L2 statistical-mechanics)
- **핵합성(BBN)** — 첫 3분, 가벼운 원소(수소·헬륨·리튬)의 기원(→ astrophysics, → standard-model)
- **재결합과 마지막 산란** — 우주가 투명해진 순간, CMB의 기원
- **우주의 열역사** — 식어가는 우주, 입자의 시대들(→ L2, → L3)
- **시간의 화살과 초기조건** — 낮은 엔트로피로 시작, 과거 가설(→ L2 arrow-of-time)

### Chapter 3: 암흑물질 (5개 문서)
- **회전곡선** — 은하가 너무 빨리 돈다, 보이지 않는 질량(→ astrophysics)
- **중력렌즈와 암흑물질** — 질량 지도, 총알 은하단(암흑물질의 직접 증거)(→ general-relativity)
- **CMB와 구조 형성** — 암흑물질이 남긴 흔적, 음향 봉우리
- **암흑물질 후보** — WIMP·액시온, 무엇인가(미해결, → standard-model 너머)
- **수정 중력 대안** — MOND, 논쟁의 현주소(정직한 양론)

### Chapter 4: 암흑에너지와 가속 (5개 문서)
- **가속 팽창의 발견** — Ia형 초신성, 우주는 *가속*한다(→ astrophysics, → L0 measurement)
- **암흑에너지** — $\Lambda$·진공 에너지, 우주의 약 70%
- **우주상수 문제** — QFT 진공 에너지 예측 vs 관측 ($10^{120}$ 차이!)(→ L3 QFT)
- **우주의 구성** — 보통물질 5%·암흑물질 25%·암흑에너지 70%
- **우주의 미래** — 가속이 계속되면, 열적 죽음·빅 립(→ L2 thermodynamics)

### Chapter 5: 인플레이션 (5개 문서)
- **표준 빅뱅의 문제** — 지평선 문제·평탄성 문제·단극자 문제
- **인플레이션** — 급팽창이 푼다, 지수적 팽창의 메커니즘
- **양자 요동과 구조** — 인플레이션의 양자 요동이 은하의 씨앗(→ L3 QFT)
- **CMB 비등방성** — 요동의 흔적, 정밀 우주론(WMAP·플랑크)(→ L0 measurement)
- **인플레이션의 검증과 논쟁** — 다중우주 예고, 반증 가능성 논쟁(→ L5, → L0 measurement)

### Chapter 6: 우주의 근본 질문 (6개 문서)
- **바리온 비대칭** — 왜 물질이 반물질보다 많나, 사하로프 조건(→ L3 standard-model CP)
- **우주의 상전이** — 초기 우주의 대칭 깨짐(전약·QCD 전이)(→ L2 phase-transitions, → L3)
- **구조 형성** — 작은 요동에서 은하·은하단·우주 거대구조로

- **다중우주** — 영원한 인플레이션, 끈 풍경(→ L5)
- **우주론의 한계** — 빅뱅 이전?, 초기 특이점, 양자중력 필요(→ L5)

프리드만 방정식 (우주의 동역학):
  (ȧ/a)² = (8πG/3)ρ − k/a² + Λ/3
       ρ = ρ_r/a⁴ (방사) + ρ_m/a³ (물질) + ρ_Λ (암흑에너지)
       ▼  시대별 지배
  방사 지배 → 물질 지배 → 암흑에너지 지배(가속)
  ⇒ 에너지 밀도가 팽창의 운명을 결정 (→ general-relativity)

우주의 구성 (대부분 모른다):
  보통물질  5%  ████
  암흑물질  25% ████████████████████
  암흑에너지 70% ███████████████████████████████████████████████████
  ⇒ 95%가 미지. 우주상수 문제: QFT 예측 vs 관측 = 10¹²⁰ 차이! (→ L3 QFT)

인플레이션 (문제 해결 + 구조의 씨앗):
  표준 빅뱅의 문제:
    지평선: 왜 멀리 떨어진 CMB가 같은 온도? (인과 접촉 불가)
    평탄성: 왜 우주가 이렇게 평탄? (미세조정)
       ▼  급팽창 (e^{Ht}, N≳60 e-foldings)
  지평선·평탄성 해결 + 양자 요동 → 은하의 씨앗 (→ L3 QFT)
  ⇒ CMB 비등방성(ΔT/T~10⁻⁵)이 그 화석 (→ L0 measurement)

바리온 비대칭 (왜 물질이 남았나):
  빅뱅: 물질 = 반물질 (대칭)이어야
       │  사하로프 조건 (→ L3 standard-model)
       ▼  ① 바리온 수 위반  ② C·CP 위반  ③ 열평형 이탈
  물질이 10⁻⁹ 만큼 더 → 쌍소멸 후 물질만 남음
  ⇒ 우리가 존재하는 이유 (→ L3 CP, → L2 arrow-of-time)
