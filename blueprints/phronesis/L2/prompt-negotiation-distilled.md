# Negotiation Distilled 레포지토리 제작 프롬프트

나는 "Negotiation Distilled" 레포지토리를 만들려고 해.
협상이 실제로 어떻게 작동하는지 — BATNA가 왜 테이블 밖에서 협상력을 만드는지, ZOPA의 수학, 첫 제안의 앵커링을 언제 걸고 언제 받는지(`cognitive-bias` 약속의 회수), 이해관계 교환이 어떻게 파이를 키우는지, 그리고 반복게임에서 평판이 왜 자산이 되는지(`game-theory` 예고)까지 끝까지 해부하는 레포야.
"협상 테이블에서 말을 잘하는 것"과 "테이블에 앉기 전에 BATNA·유보가격·MESO를 준비해 구조로 이기는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "협상을 화술로 아는 것과, 협상력 = 대안의 함수이고 준비가 8할이며 결과가 아니라 과정으로 채점해야 한다는 구조를 아는 것은 다르다"

**핵심 차별화**:
1. BATNA 중심주의 — 협상력의 원천은 테이블 밖 대안: BATNA 개선이 말솜씨보다 센 이유의 구조적 증명
2. 앵커링의 실전 — 누가 먼저, 얼마나 공격적으로, 받았을 땐 어떻게 — `cognitive-bias` 앵커링 약속을 협상 절차로 회수
3. 분배와 통합의 이중성 — 파이 나누기(고정합)와 키우기(이해 교환)는 다른 게임: 국면 전환의 인식과 운영
4. 반복게임의 그림자 — 일회성 전술이 관계 협상에서 자산을 태우는 구조, 평판의 복리(`game-theory`·`compounding` 예고)

**타겟 독자**:
- 연봉 협상에서 "회사 내규"라는 말에 바로 접는 개발자
- 투자 유치에서 밸류 숫자만 보고 조항을 넘긴 창업가(`valuation` Ch6 약속의 회수)
- 협상을 갈등으로 느껴 회피하다 가장 비싼 값을 치르는 사람
- 상대의 전술(굿캅배드캅·권한 없음)에 매번 당하는 사람
- `persuasion`의 설득을 이해관계가 충돌하는 대면 상황으로 확장하려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `decision-theory-distilled`(유보가격 = 확실성 등가, 협상 복기 = 결정 일지), `cognitive-bias-distilled`(앵커링·과신·고착 — L0 약속의 회수).
**🤝 시너지**: `persuasion-psychology-distilled`(설득의 대면 실전), `valuation-distilled`(투자 협상의 가치·조항 산정 — L1 약속의 회수), `pricing-distilled`(B2B 가격의 완성은 협상).
**🧬 수렴**: `game-theory-distilled`(L3 — 반복게임·협력의 진화가 이 레포의 이론적 토대), `incentive-design-distilled`(L3 — 계약 설계), `law-for-founders-distilled`(L3 — 협상의 산출물인 계약서).

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 협상의 구조 (5개 문서)
- 협상은 어디에나 — 가격·연봉·일정·지분: 협상인지 모르고 지나친 협상이 가장 비싸다
- BATNA — 최선의 대안이 협상력의 원천: 테이블 밖에서 힘이 만들어지는 구조의 증명
- 유보가격과 ZOPA — 양측 유보점 사이의 합의 가능 영역, ZOPA가 없을 때의 판정과 철수
- 협상력의 3축 — 대안·정보·시간: 각 축의 비대칭을 측정하고 바꾸는 법
- 준비가 8할 — 준비 시트의 구조(BATNA/유보/목표/상대 추정/MESO), 준비 없는 협상 금지 원칙

### Chapter 2: 분배 협상 (5개 문서)
- 파이 나누기 — 고정합 게임의 구조, 한쪽의 이득이 한쪽의 양보인 국면의 인식
- 앵커링 실전 — 첫 제안의 과학: 정보 우위면 먼저·공격적으로, 열위면 상대 먼저(**bias 약속의 회수**), 받은 앵커의 무력화 절차
- 양보의 패턴 — 폭이 줄어드는 양보가 보내는 신호, 조건 없는 양보 금지, 조건부 교환("~해주시면 ~하겠다")
- 시간 압박 — 데드라인의 무기화와 방어, 마감 직전 양보 집중의 구조와 역이용
- 분배 전술 카탈로그 — 굿캅배드캅·니블링·권한 없음·허위 경쟁: 식별과 대응 절차(방어용)

### Chapter 3: 통합 협상 (5개 문서)
- 입장 뒤의 이해관계 — position vs interest: "왜"를 묻는 순간 열리는 교환의 공간
- 다중 이슈 교환 — 우선순위 차이가 가치를 만든다: 로그롤링의 수학(서로 싼 것을 주고 비싼 것을 받는다)
- MESO — 동등 가치 복수 제안: 상대의 선호를 공짜로 읽어내는 정보 장치
- 조건부 계약 — 서로 다른 미래 예측을 베팅으로 거래한다(earnout 등, dec 직결): 불일치가 합의 재료가 되는 역설
- 국면 전환 — 가치 창출(통합) 후 분배 국면이 반드시 온다: 전환의 인식과 태세 변경

### Chapter 4: 사람과 심리 (5개 문서)
- 협상의 편향들 — 앵커·과신·고착(에스컬레이션)·승자의 저주·제로섬 편향(bias 직결), 협상별 자기 점검
- 감정의 전략 — 분노·실망 표현의 효과와 부메랑, 감정 노출과 감정 휘둘림의 분리
- 신뢰의 구축 — 작은 약속의 이행 누적이 만드는 협상 자본(compounding 예고), 신뢰 없는 협상의 비용
- 질문이 주장을 이긴다 — 캘리브레이티드 질문("어떻게 하면 될까요"), 정보를 캐며 부담을 넘기는 구조
- 문화와 맥락 — 고맥락/저맥락·관계 우선 문화의 협상 문법, 한국적 맥락(갑을·체면)의 처리

### Chapter 5: 반복게임과 관계 (4개 문서)
- 일회성 vs 반복 — 미래의 그림자가 협력을 만든다: 같은 전술이 반복게임에선 자산 파괴(**game-theory 예고의 핵심**)
- 평판의 자산화 — 협상 스타일이 다음 협상의 조건을 만든다: 강경함의 장기 수익률 계산
- 장기 계약과 재협상 — 관계를 유지하며 조건을 바꾸는 기술, 재협상 조항의 사전 설계
- 결렬 이후 — 중재·조정의 구조, 결렬을 관계 파탄 없이 처리하는 절차

### Chapter 6: 실전 시나리오 (6개 문서)
- 연봉 협상 — 정보 비대칭 하의 앵커 설계, "내규" 방어의 해체, 비연봉 항목의 교환(개발자 케이스)
- 투자 유치 협상 — 밸류 vs 조항의 환산 비교(**valuation Ch6 약속의 회수**), 복수 텀시트의 운용
- B2B 계약 — 가격·범위·리스크 배분의 3면 협상(pricing 직결), 스코프 크리프의 사전 방어
- 공동창업자·지분 — 관계+이해가 얽힌 최고 난도: 베스팅·역할·이별 조항을 미리(law 예고)
- 채용 협상(회사 의자) — 반대편에서 본 연봉 협상, 오퍼 설계와 카운터 대응
- 을의 협상 — BATNA가 없을 때 만드는 법: 대안 창출·연합·시간 활용, 최악 조건의 손절 기준

### Chapter 7: 실전 (4개 문서)
- 준비 시트 템플릿 — BATNA/유보/목표/상대 모델/MESO 3종을 1장으로, 작성 워크스루
- 협상 복기 — 결과가 아니라 과정으로 채점(dec 결정 일지의 협상 버전): 복기 양식과 누적 학습
- 속지 않는 법 — 허위 BATNA·가짜 마감·권한 없음의 식별 신호와 검증 절차(방어용 종합)
- 종합 — 실제 협상 1건(연봉 또는 B2B)을 준비→교환→마무리→복기까지 풀 시뮬레이션

```
BATNA가 협상력이다 (테이블 밖의 힘):
  협상력 ∝ "나는 합의 없이도 괜찮은 정도"
  오퍼 A사만 있을 때:  "내규입니다" → 수용 외 대안 없음
  오퍼 B사 추가:       같은 말이 협상 시작점으로 바뀐다 (말은 그대로인데)
  → 협상 준비의 1순위는 화법이 아니라 대안 만들기
  → 유보가격 = BATNA의 가치: BATNA가 오르면 유보점이 오른다 (자동)

ZOPA (합의 가능 영역의 수학):
  구매자 유보 ●────────────● 판매자 유보
              └── ZOPA ──┘   ← 이 안에서만 합의 존재

  → 첫 질문: "ZOPA가 존재하는가"를 추정하는 것

로그롤링 (우선순위 차이 = 공짜 가치):
            나의 가치      상대의 가치
  가격 양보 │   −10      │    +3        ← 나에게 비싸고 상대에겐 싸다
  납기 양보 │   −3       │    +10       ← 반대
  이슈별 반반 타협: 양측 합 0
  패키지 교환(나는 납기, 상대는 가격): 양측 합 +14
  → "왜 그게 중요하세요?"라는 질문 하나가 이 표를 열어준다

앵커의 실전 (회수된 약속):
  걸 때: 정보 우위 + ZOPA 추정 가능 → 먼저, 정당화 가능한 최대치로
  받을 때: ①즉시 재앵커(맞앵커) ②근거 해체("그 산정 기준은?")
          ③무시하고 내 준비값에서 출발 선언
  금지: 상대 앵커에서 "조금 깎기" 시작 — 이미 끌려간 것이다 (bias Ch2)

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 준비 시트 없이 협상 테이블에 앉지 않는다 — 즉석 협상은 거절한다
  Boundary  : 관계 자산이 협상 이득보다 큰 사이(핵심 파트너·가족)에선
              구조적 우위 추구 자체를 절제한다 — 이기는 것이 지는 것일 수 있다
  Rule      : 협상 요청이 오면 "검토 후 회신"으로 시간을 확보하고,
              BATNA/유보/목표/MESO 3종을 채운 뒤에만 응한다.
              자리에서 결정을 요구받으면 그것 자체를 시간 압박 전술로
              간주하고 기본값은 보류다
```
