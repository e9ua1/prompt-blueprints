# Persuasion Psychology Distilled 레포지토리 제작 프롬프트

나는 "Persuasion Psychology Distilled" 레포지토리를 만들려고 해.
사람 마음이 움직이는 메커니즘 — Cialdini의 원리들이 왜 진화적으로 합리적인 지름길인지, System 1/2 듀얼 프로세스가 설득의 두 경로(중심·주변)를 어떻게 가르는지, 사회적 증거가 어떤 조건에서 역효과를 내는지, 그리고 설득과 조작의 경계를 어디에 그어야 하는지를 끝까지 해부하는 레포야.
"설득 테크닉을 수집하는 것"과 "마음이 움직이는 메커니즘을 알고 윤리 경계 안에서 설계하며, 당하는 쪽에선 즉시 알아채는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "설득 기법 목록을 외우는 것과, 각 기법이 어떤 인지적 지름길에 올라타는지 알아서 만들 줄도 막을 줄도 아는 것은 다르다"

**핵심 차별화**:
1. 진화적 근거까지 — 상호성·사회적 증거·권위는 버그가 아니라 협력 사회의 합리적 지름길(`cognitive-bias` 계산적 기원의 사회적 버전), 지름길이라서 악용 가능하다
2. 역효과 조건의 명시 — 사회적 증거의 부메랑·심리적 반발·역화 효과: 설득 기법마다 "이게 거꾸로 터지는 조건"을 함께
3. 효과 크기의 정직성 — 설득 효과는 대중서가 말하는 것보다 작다: 원 실험·재현성·실측 효과 크기를 명시(bias의 재현성 추적을 계승)
4. 공격과 방어의 쌍 — 모든 원리를 만드는 쪽(제품·세일즈)과 당하는 쪽(다크 패턴·사기 식별) 양면으로 — **이 레포는 L2의 원점이다**

**타겟 독자**:
- 랜딩 페이지·온보딩에 "심리 기법"을 넣었는데 왜 안 먹히는지 모르는 창업가
- 영업·마케팅을 배운 적 없이 제품만 만들어온 개발자
- 다크 패턴과 정당한 설득의 경계가 흐릿한 PM
- 사기·사이비·과대광고에 가족이 넘어가는 걸 막고 싶은 사람
- `cognitive-bias`의 편향 지식을 응용(공격)과 방어 양면으로 확장하려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `cognitive-bias-distilled`(편향의 메커니즘 — 설득은 그 메커니즘의 응용이다, L0 약속의 회수).
**🤝 시너지**: `copy-narrative-distilled`(설득의 문장 버전), `pricing-distilled`(WTP는 인식 — 설득의 숫자 버전).
**🧬 수렴**: `negotiation-distilled`(설득의 대면 실전), `funnel-growth-distilled`(설득 효과의 측정 — A/B가 심판), `positioning-brand-distilled`(설득을 기억에 저장하는 구조). **이 레포가 L2 테제 "마케팅·세일즈·협상은 마음을 움직이는 하나의 메커니즘의 변주"의 원점이다.**

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 설득이라는 메커니즘 (5개 문서)
- 설득 vs 조작 — 경계 기준 3가지(투명성·상대 이익·가역성)를 먼저 세운다, 이 레포의 헌법
- 듀얼 프로세스와 설득 — System 1(지름길)·System 2(논증), 어느 시스템에 말을 거는가
- 두 경로 모델(ELM) — 중심 경로(논증의 질) vs 주변 경로(신호), 관여도가 경로를 정한다
- 설득의 4요소 — 메시지·메신저·수신자·맥락, 같은 말이 다르게 작동하는 이유
- 효과 크기의 진실 — 광고·설득 효과의 실측(생각보다 작다), 대중서 신화와 데이터의 거리

### Chapter 2: Cialdini 원리 I — 상호성·일관성·사회적 증거 (5개 문서)
- 상호성 — 빚의 회계가 진화적으로 합리적인 이유, 선물·양보(door-in-the-face)의 작동 구조
- 일관성과 커미트먼트 — foot-in-the-door, 공개 선언의 자기 구속, 정체성과의 결합
- 사회적 증거 — 불확실성×유사성 조건에서 작동하는 메커니즘, 후기·숫자의 설계
- 사회적 증거의 역효과 — "다들 그래요"가 부정 규범을 광고하는 부메랑(국립공원 실험), 역효과 조건 정리
- 정보 폭포 — 개인의 합리적 추종이 집단 오류가 되는 수학(bias 집단사고와 분업)

### Chapter 3: Cialdini 원리 II — 호감·권위·희소성·통일성 (5개 문서)
- 호감 — 유사성·칭찬·협력의 작동 경로, 관계가 판단을 우회하는 구조
- 권위 — 신호(직함·복장·말투)와 실체의 분리, 합리적 위임이 맹종이 되는 지점
- 희소성 — 손실회피의 응용(bias 직결), 수량·시간 한정의 메커니즘과 거짓 희소성의 식별
- 통일성 — "우리"의 경계가 만드는 설득력, 공동 창조·소속의 설계
- 원리의 조합과 충돌 — 겹쳐 쓸 때의 시너지와 과적재의 역효과, 조합 설계 절차

### Chapter 4: 프레이밍과 맥락 (6개 문서)
- 이득/손실 프레임 — 전망이론의 설득 적용, 어느 프레임이 언제 이기나(예방 vs 획득 상황)
- 앵커링의 설득 버전 — 첫 숫자·첫 제안이 기준을 만든다(negotiation 예고), 가격 표시의 앵커 설계
- 디폴트와 선택 설계 — 기본값의 중력을 설득에 쓰기, 옵트인/아웃의 윤리 경계
- 대비 효과 — 맥락이 가치를 만든다, 순서·배치가 같은 것을 다르게 보이게 하는 구조
- 순서와 타이밍 — 초두·최신 효과, Pre-suasion(질문이 프레임을 심는다)
- 서사 운송 — 스토리가 반론을 끄는 메커니즘(narrative transportation), 증거 vs 이야기의 분업(copy 예고)

### Chapter 5: 저항과 역화 (5개 문서)
- 심리적 반발 — 자유를 위협하면 반대로 움직인다(reactance), 강요가 실패하는 구조
- 역화 효과 — 반박이 신념을 강화하는 조건, 정정 보도가 실패하는 이유와 논쟁
- 면역 이론 — 약한 공격을 미리 맞으면 방어가 생긴다(inoculation), 반론 선제 처리의 근거
- 확증의 벽 — 설득은 이미 기운 사람을 넘어뜨리는 일: 태도 변화 vs 행동 변화의 분리
- 신뢰의 비대칭 — 쌓기는 느리고 무너지기는 빠른 구조, 설득 자본으로서의 신뢰(compounding 예고)

### Chapter 6: 윤리와 방어 (5개 문서)
- 경계의 판정 — Ch1 기준 3가지를 실사례 10개에 적용하는 판정 연습
- 다크 패턴 해부 — 강제 연속결제·숨김 해지·거짓 카운트다운을 메커니즘 단위로 역분해
- 사기의 설득 구조 — 폰지·로맨스 스캠·사이비의 공통 시퀀스(고립→상호성→커미트먼트 에스컬레이션)
- 설득당하지 않는 시스템 — 시간 지연·제3자 확인·결정 환경 설계(bias 방어 시스템의 사회적 버전)
- 힘의 책임 — 설득력은 비대칭 무기다: 만드는 자의 자기 규율 규칙

### Chapter 7: 실전 (5개 문서)
- 제품 속의 설득 — 온보딩·랜딩·CTA·빈 화면에 원리 적용(윤리 경계 체크 포함)
- B2B 세일즈의 설득 구조 — 다중 의사결정자·리스크 회피 조직의 설득은 다르다
- 조직 내 설득 — 상사·동료·이해관계자: 이해관계 지도와 프레임 선택
- 측정 — 설득은 A/B가 심판한다: 직감 금지, 효과 검증의 절차(funnel 직결)
- 종합 — 실제 설득 과제 1개(예: 가입 전환)를 메커니즘→설계→윤리 체크→측정으로 풀 설계

→ **총 36개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 심리학 교양이 아니라 설계·방어 매뉴얼
2. **모든 기법에 역효과 조건** — 작동 조건 없는 기법 소개 금지, "거꾸로 터지는 경우"를 같은 비중으로
3. **효과 크기를 숨기지 않는다** — 원 실험·재현성·실측 효과를 명시, 신화는 신화라고 쓴다
4. **반례에 살아남는가** — 모든 판단 규칙에 깨지는 조건 명시
5. **윤리 체크를 절차에 내장** — 모든 설계 예시는 Ch1의 3기준 통과 여부를 표기한다
6. 듀얼 프로세스·ELM 경로·사기 시퀀스는 다이어그램으로

## 🔬 검증 프로토콜

> 원 실험 재현성 추적 + A/B 자기 실험 + 다크 패턴 수집·역분해.

```python
# 환경: Python 3 + 자기 프로젝트(랜딩/블로그)를 실험장으로

# 1) 재현성 추적표 (bias 레포 방법론 계승)
#    다루는 효과마다: 원 논문·표본·효과 크기·재현 결과 3단계 라벨
#    → "견고/약화/신화" — 이 표가 레포의 백본

# 2) 사회적 증거 A/B
#    내 랜딩/블로그 CTA: 숫자 증거 유/무 두 버전
#    → funnel 레포의 표본 크기·멈춤 규칙 적용해 측정 (직감 금지)

# 3) 프레임 자기 실험
#    같은 제안을 이득/손실 프레임 두 버전으로 지인 n명에게
#    → 선택 비율 차이 기록, 문헌 효과 크기와 대조

# 4) 다크 패턴 필드 수집
#    구독 해지 플로우 10개 서비스 캡처 → 사용된 기법 라벨링
#    → 메커니즘(어느 지름길 악용)·Ch1 기준 위반 항목 매핑

# 5) 사기 시퀀스 역분해
#    공개된 사기 사건 판결문/기사 2건 → 단계별 사용 원리 타임라인
#    → 공통 시퀀스 추출 (방어 교재의 원료)

# 6) 반발 관찰
#    강한 명령형 vs 자율 보존형("선택은 당신 몫") CTA 비교
#    → reactance의 실재를 내 데이터로 확인
```

## 💡 핵심 분석 대상

```
설득의 두 경로 (ELM — 어디에 말을 걸 것인가):
  고관여 (돈·시간이 크게 걸림)
    → 중심 경로: 논증의 질·증거가 결정, 효과는 느리지만 지속
  저관여 (스쳐 지나가는 선택)
    → 주변 경로: 신호(권위·호감·디자인)가 결정, 빠르지만 휘발
  → B2B 세일즈에 주변 신호만 쓰면 실패, 배너 광고에 논증을 쓰면 낭비
  → 첫 질문은 항상 "수신자의 관여도는?"

사회적 증거의 부메랑 (역효과의 구조):
  의도: "쓰레기 투기가 많습니다 — 하지 마세요"
  전달: "다들 버리는구나" (서술 규범) > "버리지 마라" (명령 규범)
  → 부정 행동의 빈도를 알리는 것 자체가 그 행동을 정상화한다
  → 규칙: 증거는 항상 원하는 행동의 다수성을 보여줘야 한다
          ("90%가 기한 내 납부합니다")

설득 vs 조작의 판정 (이 레포의 헌법):
  ① 투명성: 기법이 드러나도 상대가 수긍하는가
  ② 상대 이익: 설득된 선택이 상대에게도 이로운가
  ③ 가역성: 쉽게 되돌릴 수 있는가 (해지·환불의 마찰)
  셋 다 예 → 설득 / 하나라도 아니오 → 조작의 영역
  → 거짓 카운트다운: ①✗ ②✗ → 조작. 실후기 노출: ①○ ②○ ③○ → 설득

사기의 공통 시퀀스 (방어 교재):
  접근(호감·유사성) → 작은 상호성 → 커미트먼트 에스컬레이션
  → 고립(외부 확인 차단) → 희소성·긴급(System 2 차단) → 수확
  → 방어 규칙: "긴급+고립+선지급" 세 신호 동시 등장 = 무조건 시간 지연

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 설득 설계는 상대의 System 2가 켜져도 살아남아야 한다
  Boundary  : 안전·긴급 상황(대피 안내 등)에선 즉각 순응 유도가
              정당하다 — 숙고를 기다릴 수 없는 경우
  Rule      : 모든 설득 장치에 "상대가 이 장치의 존재를 알면 기분이
              어떨까" 테스트를 돌린다. 불쾌·배신감이 예상되면 폐기하고,
              수긍이 예상되면 A/B로 효과를 검증한 뒤에만 적용한다
```
