# Game Theory Distilled 레포지토리 제작 프롬프트

나는 "Game Theory Distilled" 레포지토리를 만들려고 해.
합리적 개인이 왜 집단으로 멍청해지는지 — 죄수의 딜레마에서 개인 최선이 집단 최악이 되는 구조, 반복게임의 미래의 그림자가 협력을 만들어내는 조건(Axelrod), 학위가 왜 비싼지를 설명하는 시그널링(비용이 신호다), 2위 가격 경매에서 정직이 지배전략이 되는 마법, 그리고 뱅크런·표준 전쟁 같은 자기실현적 균형까지 끝까지 해부하는 레포야.
"게임이론 용어를 아는 것"과 "눈앞의 상황을 플레이어·보수·정보·반복성으로 매핑해 균형을 예측하고, 필요하면 게임 자체를 바꾸는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "내쉬 균형을 정의할 줄 아는 것과, 균형이 최선이 아님을 알고 보수 구조를 바꿔 다른 균형으로 옮기는 것은 다르다"

**핵심 차별화**:
1. 균형 ≠ 최선 — 개인 합리성과 집단 합리성의 분리가 이 레포의 척추: 가격 전쟁·과대광고·군비 경쟁이 전부 같은 행렬이다
2. 미래의 그림자 — 반복게임의 할인인자가 협력의 조건(`money`의 할인이 세 번째 재등장!), `negotiation` 반복게임 약속의 이론적 완결
3. 비용이 신호다 — Spence 시그널링: 학위·보증·과시적 투자가 정보 비대칭을 푸는 구조(`micro` 레몬 해법의 정식화)
4. 게임을 바꾸는 법 — 균형 예측에서 멈추지 않고 보수·플레이어·규칙을 바꾸는 설계 관점(`incentive-design` 메커니즘 디자인으로 가는 다리)

**타겟 독자**:
- 경쟁사 가격 인하에 반사적으로 따라 내리는 창업가(딜레마의 구조를 못 보는)
- 협력이 "착함"의 문제라고 생각하는 사람(구조의 문제임을 모르는)
- 광고 경매에 입찰하면서 경매 설계를 모르는 마케터(`funnel` 약속의 회수)
- 표준·플랫폼 선택을 성능으로만 판단하는 개발자(조정 게임임을 모르는)
- `negotiation`·`incentive-design`·`strategy-moats`의 이론적 토대를 채우려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `probabilistic-thinking-distilled`(기댓값·혼합 전략), `microeconomics-distilled`(과점에서 바통을 받는다).
**🤝 시너지**: `negotiation-distilled`(협상은 게임의 실전 — 반복게임 약속의 회수), `incentive-design-distilled`(메커니즘 디자인 = 역게임이론, 이 레포의 설계 편).
**🧬 수렴**: `strategy-moats-distilled`(표준 전쟁·경쟁 균형), `markets-investing-distilled`(시장 = 거대한 게임: 상대가 누구인가의 완결), `feedback-loops-everywhere`(자기실현적 균형 = 되먹임). **이 레포가 L3 테제 "구조가 행동을 만든다"의 원점이다.**

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 게임이라는 렌즈 (5개 문서)
- 전략적 상호작용 — 내 보수가 남의 선택에 달릴 때: 의사결정론과 게임이론의 경계(dec와의 분업)
- 게임의 해부 — 플레이어·전략·보수·정보: 상황을 행렬/트리로 적는 절차
- 지배전략 — 상대가 뭘 하든 최선인 수: 있을 때의 단순함과 드묾
- 내쉬 균형 — 서로가 서로에게 최선 대응: "왜 거기서 멈추나"의 의미, 복수 균형의 문제
- 균형 ≠ 최선 — 개인 합리성의 합이 집단 비합리가 되는 분리(**이 레포의 척추**): 죄수의 딜레마 예고

### Chapter 2: 죄수의 딜레마와 협력 (6개 문서)
- 딜레마의 해부 — 배신이 지배전략인 보수 구조의 유도: 왜 똑똑할수록 함께 망하나
- 현실의 딜레마들 — 가격 전쟁(pricing 약속 회수)·과대광고·야근 경쟁·군비: 같은 행렬의 변장들
- 반복과 미래의 그림자 — 무한 반복에서 협력이 균형이 되는 조건: 할인인자 δ의 유도(**money 할인의 세 번째 재등장**)
- Axelrod 토너먼트 — 팃포탯의 승리와 그 조건(negotiation 약속의 회수): 토너먼트 직접 재현
- 협력의 4덕목 — 친절·보복·용서·명료: 각각이 없을 때 무너지는 방식
- 협력의 붕괴 조건 — 끝이 보일 때(역진 귀납)·익명성·관측 노이즈: 협력 설계의 경계

### Chapter 3: 조정과 신호 (6개 문서)
- 조정 게임 — 옳은 답이 아니라 같은 답이 중요한 게임: 복수 균형과 포컬 포인트(Schelling)
- 표준 전쟁 — QWERTY·VHS·충전 규격: 네트워크 효과 위의 조정 게임(moats 약속 예고), 승부의 결정 요인
- 시그널링 — 학위는 왜 비싼가: 비용이 있어야 신호가 된다(Spence)의 유도, 분리 균형
- 스크리닝 — 메뉴로 정보를 캐다: pricing 자기 선택의 게임이론 완결(**약속의 회수**)
- 신호의 인플레이션 — 모두가 신호에 투자하면 군비경쟁이 된다: 학력 인플레의 구조
- 치프톡의 한계 — 말은 언제 신호가 되나: 이해 일치도와 신빙성의 관계

### Chapter 4: 신뢰성과 위협 (5개 문서)
- 신뢰할 수 있는 약속 — 위협·약속의 신빙성 조건: 말이 아니라 구조가 만든다
- 배수진의 역설 — 선택지를 줄여서 이긴다: 다리를 불태우는 전략의 수학(Schelling)
- 순차 게임과 역진 귀납 — 트리를 끝에서 거꾸로 푸는 절차, 최후통첩의 분석과 실험의 배신
- 선발 vs 후발 — 먼저 두는 이득과 보는 이득: 선점 우위의 조건(moats 예고)
- 평판 게임 — 일회성 게임의 연쇄를 반복게임으로 만드는 자산(negotiation·compounding 직결)

### Chapter 5: 경매와 매칭 (5개 문서)
- 경매의 설계 공간 — 영국식·네덜란드식·비공개 1위/2위: 규칙이 행동을 정한다
- 2위 가격의 마법 — 정직 입찰이 지배전략이 되는 증명(Vickrey): 메커니즘 디자인의 원형(incentive 예고)
- 광고 경매의 실제 — GSP·VCG와 입찰 전략: funnel 광고 경매 약속의 회수
- 승자의 저주 — 공통 가치 경매에서 이긴 자가 과대평가자인 구조(bias 직결): 입찰 보정 절차
- 매칭 시장 — 가격 없는 배분(Roth): 레지던트·학교 배정, 안정 매칭의 직관

### Chapter 6: 집단의 게임 (5개 문서)
- 공유지의 비극 — micro Ch6의 게임 정식화: n인 딜레마와 제도 해법의 게임 구조
- 투표의 역설 — 콩도르세 순환·전략 투표: 집단 선호가 정의되지 않는 구조
- 자기실현적 균형 — 뱅크런·버블·화폐: 믿음이 현실을 만드는 게임(macro·feedback-loops 직결)
- 다수의 무지 — 모두가 반대하면서 모두가 따르는 균형: 침묵의 구조와 깨지는 순간
- 티핑과 혁명 — 선호 위장과 임계 모델(Granovetter·Kuran): 갑작스러운 변화의 게임 구조

### Chapter 7: 실전 (6개 문서)
- 게임 분석 절차 — 플레이어·보수·정보·반복성 매핑 시트: 상황을 게임으로 적는 훈련
- 게임을 바꾸는 법 — 보수 변경·플레이어 추가/제거·규칙 변경·커미트먼트: 균형 이동의 설계(incentive로 가는 다리)
- 경쟁의 게임 — 가격 전쟁의 회피 구조(신호·차별화·세분화), 암묵적 담합과 법의 경계(law 직결)
- 협상의 게임이론 — negotiation 전체의 이론적 정리: BATNA = 외부 옵션, 양보 = 순차 게임
- 게임이론의 한계 — 합리성 가정의 실패 지점(행동 게임이론: 최후통첩·공공재 실험), 모델과 현실의 거리
- 종합 — 실제 경쟁 상황 1건을 매핑→균형 예측→게임 변경 설계까지 풀 분석

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 모든 문서는 "내 게임에서 무엇을 바꿀 것인가"로 끝난다
2. **행렬로 적어야 분석이다** — 말로 하는 게임 분석 금지: 보수 행렬/트리를 적는 것이 분석의 시작
3. **균형 예측에서 멈추지 않는다** — 항상 "이 게임을 어떻게 바꿀 수 있나"까지: 분석가가 아니라 설계자의 의자
4. **반례에 살아남는가** — 모든 균형 예측에 합리성 가정의 한계와 실험 결과를 병기
5. **수학은 2×2에서** — 일반 정리보다 2×2 행렬·간단한 δ 계산으로: 깊이는 유지하되 진입 장벽은 낮게
6. 보수 행렬·게임 트리·임계 모델은 다이어그램으로

```python
# 환경: Python 3 + numpy (이 레포의 백미: Axelrod 토너먼트 직접 구현)

# 1) Axelrod 토너먼트 재현
#    전략 8종(팃포탯·올배신·올협력·그러지·랜덤·팃포투탯·탐침·페이블락)
#    → 라운드로빈 200회 반복게임 토너먼트 → 순위 재현
#    → 노이즈(5% 오인) 추가 → 팃포탯의 보복 나선과 관대한 변형의 부상 확인

# 2) 미래의 그림자 계산
#    죄수의 딜레마 보수(T>R>P>S)에서 협력 유지 조건 δ ≥ (T−R)/(T−P) 유도
#    → 보수를 바꿔가며 "협력에 필요한 미래 가중치" 변화 관찰
#    → 사업 관계의 δ(재계약 확률)로 번역하는 연습

# 3) 경매 시뮬레이션
#    1위 가격 vs 2위 가격 경매, 가치 분포에서 입찰자 생성
#    → 2위 가격에서 정직 입찰이 최선임을 시뮬레이션으로 확인
#    → 승자의 저주: 공통 가치 + 추정 노이즈 → 낙찰자의 체계적 손실 측정

# 4) 임계(티핑) 모델
#    참여 임계값이 분포된 100명 군중 시뮬레이션(Granovetter)
#    → 임계 분포의 작은 변화가 전체 폭발/침묵을 가르는 비선형 재현

# 5) 자기실현 균형 (뱅크런 미니 모형)
#    예금자 n명, 인출 비율이 임계를 넘으면 은행 파산
#    → "남들이 뺀다고 믿으면 빼는 게 합리" 균형 2개 공존 확인

# 6) 실사례 매핑 (살아있는 검증)
#    내 주변 경쟁 상황 3건을 행렬로 작성 → 균형 예측 → 추후 결과 대조
```

## 💡 핵심 분석 대상

```
죄수의 딜레마 (균형 ≠ 최선의 원형):
              상대 협력      상대 배신
  나 협력  │  (3, 3)      │  (0, 5)
  나 배신  │  (5, 0)      │  (1, 1) ← 유일한 균형
  → 배신이 지배전략 → 둘 다 배신 (1,1) → 둘 다 (3,3)을 놓친다
  → 가격 전쟁·과대광고·야근 경쟁이 전부 이 행렬이다
  → 탈출구는 착해지기가 아니라 게임 바꾸기: 반복·계약·평판·규제

미래의 그림자 (협력의 조건 — 할인의 세 번째 재등장):
  무한 반복 + 팃포탯 상대일 때 협력이 이득인 조건:
  R/(1−δ) ≥ T + δ·P/(1−δ)  →  δ ≥ (T−R)/(T−P)
  → δ = "다음 라운드가 있을 확률 × 미래의 가치"
  → 협력은 도덕이 아니라 δ의 함수: 거래가 계속될수록, 끝이 안 보일수록
  → 실전: 협력을 원하면 δ를 키워라 (장기 계약·재구매 구조·좁은 업계)

시그널링 (비용이 신호다):
  능력자에겐 학위 비용 4, 비능력자에겐 8 / 학위 프리미엄 6
  → 능력자만 학위 취득 (6>4), 비능력자는 포기 (6<8) → 분리 균형
  → 신호의 조건: "거짓말하기엔 너무 비쌀 것"
  → 보증·선투자·공개 약속이 작동하는 이유 / 말(치프톡)이 안 통하는 이유
  → 부작용: 모두가 투자하면 신호 인플레 (학력 군비경쟁)

게임을 바꾸는 5개의 손잡이 (분석에서 설계로):
  ① 보수 변경: 계약·벌금·보상으로 행렬 자체를 수정 (incentive로)
  ② 반복화: 일회성을 반복으로 (δ 키우기)
  ③ 플레이어 변경: 제3자 보증·연합·심판 도입
  ④ 정보 변경: 신호·공개·투명화로 균형 선택
  ⑤ 커미트먼트: 배수진으로 내 선택지를 묶어 상대의 최선 대응을 바꾼다
  → "이 균형이 싫다"의 다음 문장은 다섯 손잡이 중 하나여야 한다

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 나쁜 결과가 반복되면 사람이 아니라 게임의 보수 구조를 의심한다
  Boundary  : 진짜 일회성 게임(다시 안 볼 상대·익명)에선 구조 설계의
              여지가 작다 — 이때는 방어(검증·에스크로)가 우선이다
  Rule      : 경쟁자의 공격적 수(가격 인하 등)에 대응하기 전에 행렬을
              적는다. 내 대응이 (배신,배신) 균형으로 가는 한 수라면
              따라가지 않고 게임 변경(차별화·세분화·신호)을 먼저 시도한다
```
