# Probabilistic Thinking Distilled 레포지토리 제작 프롬프트

나는 "Probabilistic Thinking Distilled" 레포지토리를 만들려고 해.
세상을 단정이 아니라 확률 분포로 보는 법 — 베이즈 업데이트가 실제로 어떻게 믿음을 갱신하는지, 기댓값과 분산이 결정에서 각각 무슨 역할인지, Kelly 기준이 왜 풀베팅을 파산으로 증명하는지를 유도와 시뮬레이션으로 끝까지 해부하는 레포야.
"확률 용어를 아는 것"과 "불확실한 결정에 확률을 입혀 베팅 크기까지 정하는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "확률을 배운 것과, 내 다음 결정의 성공 확률·기댓값·적정 베팅 크기를 숫자로 적을 수 있는 것은 다르다"

**핵심 차별화**:
1. 베이즈는 공식이 아니라 갱신 절차 — 사전확률×우도비→사후확률을 실제 결정(채용·검진·시장 신호)에 돌린다
2. 에르고딕성 — 앙상블 평균과 시간 평균의 분리, "기댓값이 +인데 반복하면 파산"이 성립하는 조건
3. Kelly 기준 완전 유도 — log 효용에서 f* = p − q/b까지, 오버베팅 페널티의 비대칭성
4. 캘리브레이션 — 확률 추정이 맞는지 *측정 가능*하다는 사실 자체(브라이어 점수, 추정 훈련)

**타겟 독자**:
- "될 것 같다/안 될 것 같다" 이분법으로 사업 결정을 내리는 창업가
- 베이즈 정리를 외우지만 base rate를 무시한 채 추정하는 개발자
- 기댓값이 양수면 무조건 베팅해야 한다고 믿는 사람
- 자기 추정이 과신인지 측정해본 적 없는 사람
- `decision-theory`·`markets-investing`으로 확률을 결정·투자에 연결하려는 독자

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 확률이라는 언어 (5개 문서)
- 두 가지 확률 — 빈도(동전)와 믿음의 정도(창업 성공), 왜 둘 다 필요한가
- 조건부 확률 — P(A|B)≠P(B|A), 검사의 오류(prosecutor's fallacy)
- 독립과 상관 — 독립 가정이 깨질 때(공분산), 동시 실패의 과소평가
- 분포로 보기 — 점 추정 대신 분포, 꼬리가 결정을 바꾸는 경우
- 결정론 vs 확률론 — "확실해야 움직인다"는 사고가 비싼 이유

### Chapter 2: 베이즈 업데이트 (6개 문서)
- 베이즈 정리 유도 — 조건부 확률 정의에서 3줄로, 직관 버전(자연 빈도)
- Base Rate — 사전확률 무시가 만드는 오판, 기저율이 지배하는 조건
- 검진의 역설 — 정확도 99% 검사의 양성이 실제 환자일 확률 계산
- 우도비 — 증거의 강도를 숫자로, 강한 증거와 약한 증거의 구분
- 사전확률 설정 — 어디서 가져오나(reference class), 주관과 자의의 경계
- 연쇄 업데이트 — 증거가 쌓일 때, 독립 가정의 함정(이중 계산)

### Chapter 3: 기댓값과 분산 (5개 문서)
- 기댓값 — EV 계산과 의미, "평균적으로"가 숨기는 것
- 분산과 리스크 — 같은 EV, 다른 분산이면 다른 결정인 이유
- EV 극대화가 틀리는 곳 — 효용 곡률·파산 가능성·반복 불가능한 결정
- 큰 수의 법칙 — 수렴의 조건과 속도, "장기적으로"의 실제 길이
- 에르고딕성 — 앙상블 평균 vs 시간 평균, 곱셈 과정에서 둘이 갈라지는 증명

### Chapter 4: 베팅과 Kelly (5개 문서)
- 베팅 크기라는 문제 — 무엇에 거나만큼 얼마나 거나가 중요한 이유
- Kelly 기준 유도 — log 성장률 최대화에서 f* = p − q/b까지 완전 유도
- 오버베팅의 비대칭 — Kelly 초과 베팅의 페널티 곡선, 2×Kelly = 성장률 0
- Fractional Kelly — 추정 오차 하에서 절반 Kelly가 합리적인 이유
- 파산 확률 — 유한 자본의 수학, "EV+인데 파산"의 메커니즘

### Chapter 5: 추정과 캘리브레이션 (5개 문서)
- 페르미 추정 — 분해→경계→곱셈, 자릿수 맞추기의 기술
- 구간 추정 — 90% 신뢰구간 만들기, 구간이 좁은 것은 실력이 아니라 과신
- 캘리브레이션 측정 — 브라이어 점수, 내 70%가 실제로 70%인가
- 외부 관점 — reference class forecasting, 내부 관점의 체계적 낙관
- 추정 훈련 프로토콜 — 기록→채점→보정의 루프 설계

### Chapter 6: 시그널과 노이즈 (4개 문서)
- 신호 대 잡음 — 관측 = 신호 + 노이즈, 노이즈에 반응하는 비용
- 작은 표본 — 표본이 작을수록 극단값, 소규모 지표의 변동을 읽는 법
- 운과 실력 — 분리 가능 조건(반복·피드백), 결과로 실력을 추정하는 함정
- 예측의 한계 — 복잡계·되먹임이 있는 시스템에서 예측이 무너지는 지점

### Chapter 7: 실전 적용 (5개 문서)
- 창업 결정에 확률 입히기 — 성공 확률·페이오프·베팅 크기로 분해하는 절차
- 확률적 사고 루틴 — 결정 일지에 확률 적기, 사후 채점(decision-theory 연결)
- 흔한 확률 오류 종합 — 도박사의 오류·뜨거운 손·합취 오류(conjunction)
- 시뮬레이션으로 검증 — 직관이 막히면 몬테카를로, 시뮬레이션 설계법
- 종합 — 하나의 실제 결정을 베이즈→EV→Kelly로 끝까지 처리하는 통합 케이스

→ **총 35개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 모든 문서는 어떤 결정이 어떻게 달라지는지로 끝난다
2. **유도를 생략하지 않는다** — 베이즈·Kelly·LLN은 공식 인용이 아니라 유도. 단, 고교 수준 대수로 도달 가능하게 단계를 쪼갠다
3. **시뮬레이션으로 직접 본다** — 주장마다 몬테카를로로 재현 가능해야 한다 (코드 포함)

5. **숫자 예시는 자연 빈도로** — "1000명 중 10명"이 "1%"보다 직관에 닿는다
6. 베이즈 갱신·Kelly 곡선·에르고딕 분기는 다이어그램으로

## 🔬 검증 프로토콜

> Python(numpy) 몬테카를로 + 수식 직접 유도 + 셀프 캘리브레이션 테스트.

```python
# 환경: Python 3 + numpy (시뮬레이션이 이 레포의 Instruments다)

# 1) 검진의 역설 재현
#    유병률 1%, 민감도 99%, 특이도 99% → 10만 명 시뮬레이션
#    → 양성 중 실제 환자 비율 ≈ 50% (직관 33%~90%와 대조)

# 2) Kelly 시뮬레이션
#    p=0.6, b=1 베팅을 f = 0.1/0.2(Kelly)/0.4/1.0으로 1000회 반복
#    → 성장률 곡선: Kelly에서 최대, 2×Kelly에서 0, 풀베팅은 파산 확률 → 1

# 3) 에르고딕성 분기
#    +50%/−40% 동전 게임: 앙상블 평균(+5%/회) vs 개별 경로 시간 평균(음수)
#    → 1만 경로 시뮬레이션으로 중앙값 자산 추적

# 4) 작은 표본의 극단값
#    전환율 5% 동일한 채널을 n=20/200/2000으로 샘플링
#    → 관측 전환율의 분산이 표본 크기에 어떻게 좌우되는지

# 5) 셀프 캘리브레이션
#    상식 퀴즈 50문항에 90% 신뢰구간 부여 → 실제 적중률 측정
#    → 브라이어 점수 채점, 과신 정도 수치화
```

## 💡 핵심 분석 대상

```
베이즈 갱신 (믿음의 회계):
  사후 odds = 사전 odds × 우도비
  ┌─────────────┐    증거 E     ┌─────────────┐
  │ 사전 P(H)    │ ──────────→ │ 사후 P(H|E)  │
  └─────────────┘  ×P(E|H)/P(E|¬H) └───────────┘
  → base rate(사전)가 낮으면 강한 증거도 결론을 못 뒤집는다
  → "검사 정확도 99%"보다 "유병률 1%"가 답을 지배

에르고딕성 분기 (가장 비싼 교훈):
  게임: 매회 +50% or −40% (코인토스)
  앙상블 평균:  E = 0.5(1.5) + 0.5(0.6) = 1.05  → +5%/회 (좋아 보임)
  시간 평균:    g = √(1.5 × 0.6) = √0.9 ≈ 0.949 → −5%/회 (파산 경로)
  → 곱셈으로 쌓이는 과정(자산·사업)에서 EV는 내 경로가 아니다
  → 분산 가능하면 EV로, 한 경로에 갇히면 시간 평균으로 판단

Kelly 페널티의 비대칭:
  성장률
   max ┤      ╭──╮
       │    ╱      ╲
       │  ╱          ╲
     0 ┼╱──────────────╲──────
       0   f*    2f*     1.0  베팅 비율
  → 언더베팅: 성장 일부 포기 (완만한 손실)
  → 오버베팅: 성장률 0 지나 음수 (파국적)
  → 추정이 불확실하면 작게 거는 쪽이 항상 덜 비싸다

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 반복 가능하고 분산 가능한 베팅은 기댓값으로 판단한다
  Boundary  : 한 번뿐이거나(전 재산 창업) 파산이 가능한 베팅에선 무효
  Rule      : 되돌릴 수 없는 베팅은 EV가 아니라 "최악 경로 생존"부터 확인하고,
              베팅 크기는 추정 오차를 반영해 Kelly의 절반 이하로 잡는다
```
