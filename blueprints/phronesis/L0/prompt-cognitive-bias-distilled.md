# Cognitive Bias Distilled 레포지토리 제작 프롬프트

나는 "Cognitive Bias Distilled" 레포지토리를 만들려고 해.
편향이 왜 존재하는지 — 버그가 아니라 계산 비용을 아끼는 휴리스틱의 부산물이라는 기원부터, 손실회피·앵커링·확증편향이 각각 어떤 메커니즘으로 판단을 비트는지, 그리고 왜 "편향을 아는 것"이 편향을 막지 못하며 의지가 아닌 시스템으로 막아야 하는지를 끝까지 해부하는 레포야.
"편향 목록을 외우는 것"과 "내 다음 결정에서 작동할 편향을 예측하고 환경을 미리 설계하는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "편향 50개를 아는 것과, 편향 지식이 행동을 못 바꾸는 이유를 알고 시스템으로 방어하는 것은 다르다"

**핵심 차별화**:
1. 편향의 계산적 기원 — 무한한 정보·유한한 연산의 트레이드오프, 휴리스틱이 *대체로 옳은* 조건과 깨지는 조건
2. 디바이어싱의 실패 — 편향 교육이 행동을 못 바꾸는 실증, 지식이 아니라 결정 환경이 답인 이유
3. 비판론까지 — Kahneman 일변도가 아니라 Gigerenzer의 생태적 합리성, 재현성 위기까지 포함한 균형
4. 방어는 설계 — 체크리스트·프리모텀·디폴트·독립 추정이 *왜* 작동하는지 메커니즘 수준에서

**타겟 독자**:
- 편향 위키를 정독했는데 같은 실수를 반복하는 사람
- 자기 사업 계획만은 객관적이라고 믿는 창업가(과신+계획 오류의 교과서)
- 코드 리뷰·채용·추정에서 앵커링에 끌려다니는 개발자
- 편향 이야기가 전부 참이라고 믿는 사람(재현성 위기를 모르는)
- `persuasion-psychology`(L2)로 넘어가 편향의 응용·방어를 보려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `probabilistic-thinking-distilled`(base rate 무시·도박사의 오류는 확률 오류이기도 하다).
**🤝 시너지**: `decision-theory-distilled`(편향은 결정 입력의 오염, 결정 위생이 공동 해법), `statistics-literacy-distilled`(생존 편향·평균 회귀 오독은 통계 문맹과 겹친다).
**🧬 수렴**: `persuasion-psychology-distilled`(L2 — 같은 메커니즘의 공격적 사용), `negotiation-distilled`(L2 — 앵커링의 실전), `markets-investing-distilled`(L1 — 행동재무학은 편향의 시장 버전).

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 편향의 기원 (5개 문서)
- 버그가 아니라 비용 절감 — 제한된 합리성, 속도×정확도 트레이드오프의 산물
- System 1/2 — 듀얼 프로세스의 실체와 한계, 직관이 신뢰 가능한 조건(Kahneman-Klein 합의)
- 휴리스틱과 편향 프로그램 — 대표성·가용성·앵커링의 원 실험, 무엇을 증명했고 무엇은 아닌가
- 생태적 합리성 — Gigerenzer 반론: 휴리스틱이 환경에 맞으면 *더 정확*하다, 빠르고 검소한 나무
- 재현성 위기와 편향 연구 — 어떤 편향이 견고하고 어떤 것이 흔들리는가, 프라이밍의 몰락

### Chapter 2: 판단 편향 (6개 문서)
- 앵커링 — 무관한 숫자가 추정을 끄는 메커니즘(불충분 조정·선택적 접근)
- 가용성 — 떠오르기 쉬움≠빈도, 미디어가 위험 인식을 비트는 경로
- 대표성 — 닮음으로 확률을 대체, base rate 무시·합취 오류(prob 연결)
- 확증편향 — 탐색·해석·기억 세 단계 각각의 왜곡, 반증이 부자연스러운 이유
- 후견지명 — "그럴 줄 알았다"가 학습을 차단하는 메커니즘, 결정 일지가 해독제인 이유
- 과신 — 과대평가·과대정밀·과대순위의 구분, 전문가일수록 심한 영역

### Chapter 3: 가치 편향 (5개 문서)
- 손실회피와 전망이론 — 가치 함수의 비대칭(λ≈2), 준거점 의존이 만드는 행동
- 소유 효과 — 가진 것의 과대평가, 거래·가격 협상에서의 작동
- 매몰비용 — 회수 불가 비용이 결정에 침입하는 심리 경로(decision-theory와 분업: 그쪽은 수학, 이쪽은 심리)
- 현상유지와 디폴트 — 기본값의 중력, 옵트인/옵트아웃 격차의 실증
- 프레이밍 — 같은 사실, 다른 표현, 다른 선택 — 이득/손실 프레임의 메커니즘

### Chapter 4: 사회적 편향 (5개 문서)
- 사회적 증거 — 다수 추종의 합리적 뿌리와 폭주(정보 폭포), 역효과 조건
- 권위 — 전문성 신호에 대한 순응, 합리적 위임과 맹종의 경계
- 호감과 상호성 — 관계가 판단을 무력화하는 경로, 영업이 쓰는 이유(L2 예고)
- 집단사고 — 응집력이 반대를 침묵시키는 메커니즘, 만장일치의 경고 신호
- 근본 귀인 오류 — 상황을 성격으로 오독, 채용·평가에서의 비용

### Chapter 5: 시간 편향 (4개 문서)
- 현재 편향 — 쌍곡 할인, 미래의 나에게 일을 미루는 수학
- 계획 오류 — 내부 관점의 체계적 낙관, reference class가 해독제(prob 연결)
- 피크엔드 — 경험의 기억은 평균이 아니라 정점과 끝, 제품·서비스 설계 함의
- 미래 자기 과소평가 — 선호의 변화를 예측 못 하는 편향, 장기 계약의 위험

### Chapter 6: 방어 시스템 설계 (5개 문서)
- 디바이어싱의 실패 증거 — 교육·경고의 미미한 효과, 왜 아는 것으로 부족한가
- 체크리스트 — 작동 메커니즘(System 2 강제 호출), 의료·항공의 실증, 결정용 설계법
- 프리모텀과 레드팀 — 반대 시나리오의 제도화, 심리적 안전과의 결합
- 디폴트와 환경 설계 — 의지 대신 기본값을 바꾼다, 선택 설계의 윤리 경계
- 독립 추정과 취합 — 앵커 차단 프로토콜(동시 공개·사전 기록), 노이즈 감소

### Chapter 7: 실전 (5개 문서)
- 창업가의 편향 세트 — 과신×확증×계획 오류×생존 편향의 복합 작동, 단계별 방어
- 투자·채용의 편향 — 첫인상 앵커·호감·후광, 구조화 인터뷰가 이기는 이유
- 편향 악용 식별 — 다크 패턴·가격 앵커·희소성 연출을 메커니즘으로 역분해(L2 연결)
- 자기 편향 감사 — 내 결정 기록에서 편향 시그니처 찾기, 반복 패턴의 발견
- 종합 — 실제 결정 하나에 방어 시스템 풀세트를 적용하는 통합 케이스

→ **총 35개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 편향 박물관이 아니라 방어 매뉴얼
2. **실험의 출처와 재현성을 명시** — 효과 크기·재현 실패 여부를 숨기지 않는다. 흔들리는 편향은 흔들린다고 쓴다
3. **반례에 살아남는가** — 모든 편향에 "이 휴리스틱이 오히려 정확한 환경"을 명시 (Gigerenzer 시점)
4. **의지 호소 금지** — "주의하라"로 끝나는 문서는 실패. 모든 처방은 절차·환경·디폴트의 변경
5. **악용 사례를 방어 교재로** — 마케팅·협상의 편향 사용을 메커니즘 단위로 역분해 (L2의 예고편이자 백신)
6. 가치 함수·듀얼 프로세스·정보 폭포는 다이어그램으로

## 💡 핵심 분석 대상

```
편향의 기원 (버그가 아니라 트레이드오프):
  무한한 정보 × 유한한 연산 × 시간 압박
        ↓
  휴리스틱 (대체로 빠르고 대체로 옳음)
        ↓ 환경이 어긋나는 곳에서
  체계적 오류 = "편향"
  → 같은 휴리스틱이 수렵 환경에선 정답, 금융 시장에선 오답
  → 그래서 교육으론 안 지워진다 (하드웨어 수준)

전망이론 가치 함수 (손실회피):
        가치
         ↑      이득 (오목·완만)
         │    ╭────
  ───────┼──╱────────→ 준거점 기준 변화량
       ╱ │
     ╱   │  손실 (볼록·가파름, 기울기 ≈ 2배)
  → 같은 1만원: 잃는 고통 > 얻는 기쁨 × 2
  → 준거점을 누가 정하느냐가 협상·가격의 전장 (L2 직결)

디바이어싱의 위계 (작동하는 순서):
  의지·다짐        : 효과 ≈ 0
  지식·교육        : 미미 (아는 것 ≠ 피하는 것)
  절차 (체크리스트·프리모텀·독립 추정) : 중간~큼
  환경 (디폴트·선택지 구조·인센티브)   : 가장 큼
  → 처방은 항상 아래 두 층에서 나와야 한다

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 중요 추정은 앵커 노출 전에 독립적으로 먼저 적는다
  Boundary  : 영역 전문성이 높고 피드백이 즉각적인 반복 판단
              (소방관의 직관 같은)에선 직관 우선이 오히려 정확
  Rule      : 협상·연봉·견적·일정 추정에선 상대 숫자를 보기 전에
              내 숫자와 근거를 기록한다. 회의 추정은 동시 공개로
              진행하고, 순차 발언 추정치는 앵커 오염으로 간주한다
```
