# Statistics Literacy Distilled 레포지토리 제작 프롬프트

나는 "Statistics Literacy Distilled" 레포지토리를 만들려고 해.
숫자가 어떻게 거짓말하는지 — 상관이 왜 인과가 아닌지(그리고 언제 인과 주장이 가능한지), 심슨의 역설이 어떻게 결론을 통째로 뒤집는지, p값이 실제로 무엇을 말하고 무엇을 말하지 않는지, 생존 편향이 왜 보이는 데이터 전체를 오염시키는지를 끝까지 해부하는 레포야.
"통계를 배운 것"과 "남의 숫자에 안 속고 내 지표를 바르게 읽는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "통계 용어를 아는 것과, 데이터 앞에서 '분모가 뭐지? 누가 빠졌지? 우연일 확률은?'을 반사적으로 묻는 것은 다르다"

**핵심 차별화**:
1. 인과 추론의 사다리 — 상관≠인과에서 멈추지 않고, 교란·역인과를 지나 *언제 인과를 주장할 수 있는가*(RCT·자연실험)까지
2. 심슨의 역설을 메커니즘으로 — 집계 방향이 결론을 뒤집는 조건(교란변수의 분포 차이)을 손계산으로
3. p값의 정확한 정의 — "가설이 참일 확률"이 아니라는 것, p-해킹이 *왜 쉬운지* 자유도의 정원으로
4. 보이지 않는 데이터 — 생존·선택 편향은 분석 기법이 아니라 "표본이 어떻게 만들어졌나"라는 질문임

**타겟 독자**:
- 대시보드 지표가 움직일 때마다 원인을 단정하는 창업가
- A/B 테스트에서 p<0.05만 보고 출시를 결정하는 개발자(L2 직결)
- 뉴스의 "X가 Y 위험을 30% 높인다"를 그대로 믿는 사람
- 성공 사례만 모인 책으로 전략을 배우는 사람(생존 편향)
- `probabilistic-thinking`의 추론을 데이터 읽기로 확장하려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `probabilistic-thinking-distilled`(조건부 확률·base rate가 토대).
**🤝 시너지**: `cognitive-bias-distilled`(생존 편향·평균 회귀 오독은 편향이자 통계 문맹), `mental-models-distilled`(분포 세계관·평균의 함정 공유).
**🧬 수렴**: `funnel-growth-distilled`(L2 — A/B 테스트 통계가 직접 착지점), `markets-investing-distilled`(L1 — 백테스트 과적합·운과 실력), `economic-history-distilled`(L4 — 역사 데이터 읽기의 함정).

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 통계라는 렌즈 (4개 문서)
- 기술 vs 추론 — 요약하기와 일반화하기, 각각 무엇이 위험한가
- 데이터는 말하지 않는다 — 같은 데이터·다른 질문·다른 결론, 질문 설계가 절반
- 분포 읽기 — 평균·중앙값·최빈값이 갈라지는 분포, 어떤 대표값을 언제(mm 연결)
- 요약 통계의 함정 — Anscombe 콰르텟: 같은 통계량, 전혀 다른 데이터

### Chapter 2: 상관과 인과 (6개 문서)
- 상관≠인과 — 역인과·교란·우연, 세 가지 대안 설명을 항상 통과시키기
- 교란변수 — 숨은 제3변수의 메커니즘, 아이스크림과 익사 너머의 실전 식별
- 심슨의 역설 — 집계가 결론을 뒤집는 조건, 분할/통합 어느 쪽이 맞는지 정하는 기준
- 인과 추론의 사다리 — 관찰→개입→반사실, 각 층에서 가능한 주장(Pearl)
- RCT와 자연실험 — 무작위화가 교란을 끊는 원리, 실험 불가능할 때의 차선들
- 회귀의 의미와 한계 — "통제했다"의 실제 의미, 통제 변수가 만드는 새 왜곡(collider)

### Chapter 3: 표본과 편향 (5개 문서)
- 표본은 어떻게 만들어졌나 — 모든 분석에 앞서는 단 하나의 질문
- 생존 편향 — 돌아온 폭격기의 탄흔, 성공학·백테스트·후기 데이터의 공통 구멍
- 선택 편향 — 자기선택·탈락·응답 편향, 표본이 스스로를 고르는 경로들
- 작은 표본의 법칙 — 소표본의 극단값, "최고 성과 지점"이 대부분 소표본인 이유(prob 연결)
- 평균 회귀 — 극단 다음은 평균, 개입 효과 착각(혼낸 뒤 잘하는 이유)의 정체

### Chapter 4: 검정과 유의성 (6개 문서)
- p값의 정확한 정의 — "H0가 참일 때 이 정도 데이터가 나올 확률", 아닌 것 5가지
- p-해킹 — 자유도의 정원(분기하는 길), 멈춤 규칙·하위집단·지표 교체가 만드는 가짜 발견
- 다중비교 — 20개 지표를 보면 1개는 우연히 유의, 보정의 원리
- 검정력과 표본 크기 — 못 찾은 것≠없는 것, 검정력 부족 실험의 양방향 위험
- 효과 크기 vs 유의성 — 유의하지만 무의미한 차이, n이 크면 모든 것이 유의해지는 함정
- 신뢰구간과 베이즈 — 구간 읽기, 빈도주의 vs 베이즈 관점의 실용적 차이(prob 연결)

### Chapter 5: 기저율과 조건부 (4개 문서)
- 기저율 무시 — P(A|B)와 P(B|A)의 혼동이 실전에서 비싼 장면들
- 검진의 역설 — 거짓 양성의 수학, 희귀할수록 양성이 못 믿을 신호가 되는 구조
- 스크리닝 설계 — 채용·사기 탐지·이상 감지에 같은 수학, 임계값의 트레이드오프
- 베이즈 직관 훈련 — 자연 빈도로 변환하는 습관, 조건부 문제 반사신경 만들기

### Chapter 6: 실무 통계 읽기 (4개 문서)
- 뉴스 통계 해부 — 상대 위험 vs 절대 위험("30% 증가"의 분모), 헤드라인 역추적 절차
- 그래프 왜곡 — 축 절단·면적 착시·체리피킹 구간, 시각화 거짓말 카탈로그
- 지표 정의의 함정 — 분모가 뭔가, 정의 변경이 만드는 가짜 추세(실업률·전환율)
- 백분율의 함정 — %p vs %, 성장률의 비대칭(−50% 후 +50%), 작은 분모의 폭주

### Chapter 7: 실전 (4개 문서)
- A/B 테스트의 통계 — 표본 크기 사전 계산·멈춤 규칙·novelty 효과, 올바른 실험 절차(L2 funnel 직결)
- 사업 지표의 통계적 함정 — 코호트 혼합·계절성·평균 회귀가 만드는 가짜 신호
- 숫자로 거짓말하는 법 — 공격 기법 전체를 역으로 정리한 방어 체크리스트
- 종합 — 실제 데이터 주장 하나를 표본→교란→검정→효과 크기로 끝까지 해부하는 통합 케이스

→ **총 33개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 시험용 통계가 아니라 방어용 통계
2. **모든 역설은 손계산으로** — 심슨·검진·다중비교는 작은 숫자 표로 직접 뒤집어 보인다
3. **반례에 살아남는가** — "상관≠인과"에도 경계가 있다: 개입이 아니라 예측이 목적이면 상관으로 충분
4. **공격을 배워 방어한다** — 숫자로 속이는 기법을 먼저 보여주고 해독 절차를 준다
5. **시뮬레이션이 증인** — p-해킹·생존 편향·평균 회귀는 코드로 재현해 눈으로 확인
6. 인과 사다리·자유도의 정원·심슨 분할은 다이어그램으로

## 🔬 검증 프로토콜

> Python 시뮬레이션 + 손계산 표 + 실제 기사/지표 해부.

```python
# 환경: Python 3 + numpy/pandas

# 1) p-해킹 재현 (자유도의 정원)
#    완전 무작위 데이터(효과 0), 변수 20개 × 하위집단 3개 분석
#    → p<0.05 "발견" 개수 집계 → 우연만으로 발견이 쏟아지는 것 확인
#    → 멈춤 규칙 해킹: p<0.05 되는 순간 멈추기 시뮬레이션 → 거짓 양성률 측정

# 2) 심슨의 역설 손계산 + 재현
#    버클리 입학 데이터 구조 재현: 학과별 합격률 vs 전체 합격률 역전
#    → 교란변수(지원 학과 분포)가 어느 임계 비율에서 역전을 만드는지 탐색

# 3) 생존 편향 시뮬레이션
#    펀드 1000개, 실력 0(순수 운), 5년 후 하위 50% 청산 반복
#    → 생존 펀드의 평균 수익률이 만들어내는 가짜 알파 측정

# 4) 평균 회귀 재현
#    실력 + 노이즈 모델로 성과 생성 → 1차 상위 10%의 2차 성과 추적
#    → "개입 없이도" 하락하는 폭 = 개입 효과 착각의 크기

# 5) 검정력 계산
#    전환율 5% vs 5.5% 차이를 80% 검정력으로 잡는 데 필요한 n 계산
#    → 흔한 A/B 테스트 표본이 얼마나 부족한지 수치로

# 6) 기사 해부 (주 1회 루틴)
#    "X가 Y를 30% 높인다" 류 기사 → 원 논문 추적
#    → 절대 위험·표본·설계(관찰/실험)·이해관계 4점 채점표 기록
```

## 💡 핵심 분석 대상

```
심슨의 역설 (집계가 결론을 뒤집는다):
            치료 A           치료 B
  경증   │ 81/87 (93%)  >  234/270 (87%)
  중증   │ 192/263 (73%) >  55/80 (69%)
  ─────────────────────────────────────
  전체   │ 273/350 (78%) <  289/350 (83%)  ← 역전!
  → A가 두 그룹 모두에서 이기는데 전체에선 진다
  → 원인: A에 중증 환자가 몰림 (교란변수의 분포 차이)
  → 판정 기준: 교란변수(중증도)가 처치 "이전"에 정해졌다면 분할이 정답

인과 추론의 사다리 (Pearl):
  3층 반사실  : "그때 안 했더라면?"     ← 모델 필요
  2층 개입    : "하면 어떻게 되나?"     ← 실험(RCT) 필요
  1층 관찰    : "함께 움직이나?"        ← 데이터만으로 가능
  → 관찰 데이터(1층)로 개입 주장(2층)을 하는 것이 모든 통계 사기의 원형
  → 단, 목적이 예측이면 1층으로 충분 (반례 경계)

p-해킹: 자유도의 정원
  지표 선택 × 하위집단 × 공변량 조합 × 멈춤 시점 × 이상치 처리
  = 수백 갈래의 분석 경로
  → 효과가 0이어도 어느 경로 하나는 p<0.05에 도달
  → 방어: 사전 등록(경로를 미리 고정), 모든 분석 경로 공개

생존 편향 (보이는 것이 표본이 아니다):
  성공한 스타트업의 공통점 → "성공의 비결"?
  실패한 스타트업도 같은 특성을 가졌다면 그 특성은 무정보
  → 올바른 질문: P(성공|특성) — 분모에 실패자를 포함해야 계산 가능
  → 데이터 받으면 첫 질문: "여기 못 들어온 케이스는 누구인가"

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 데이터 주장 앞에서 표본 생성 과정을 먼저 심문한다
  Boundary  : 전수 데이터(우리 서비스 전체 로그)면 표본 편향 질문은
              불필요 — 대신 지표 정의와 기간 선택을 심문한다
  Rule      : 외부 통계는 ①분모 ②빠진 표본 ③관찰/실험 ④절대 위험
              4가지를 확인하기 전엔 의사결정에 투입하지 않는다.
              내부 지표는 코호트 분리·계절 보정 전의 추세를 믿지 않는다
```
