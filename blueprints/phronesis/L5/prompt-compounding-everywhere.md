# Compounding Everywhere 레포지토리 제작 프롬프트

나는 "Compounding Everywhere" 레포지토리를 만들려고 해.
IQ Phronesis Lab의 Synthesis 레이어 — L1에서 "같은 할인·복리가 스케일만 바꿔 반복된다"고 선언했던 그 척추를 전 영역으로 확장해 수확하는 레포야. 자본의 복리(L1), 리텐션과 고객 기반의 복리(L2), 신뢰·평판의 복리(협상·게임이론), 학습의 복리, 그리고 **음의 복리** — 기술 부채(IQ Dev Lab과의 교차점)·조직 부채·신뢰 부채까지: x_{t+1} = x_t(1+r)이라는 한 줄이 어디서 작동하고 어디서 깨지는지를 끝까지 해부하는 레포다.
"복리가 좋다는 격언을 아는 것"과 "내 자산·습관·부채 전체를 복리/선형/음의 복리로 분류하고 복리의 3조건(보존·재투자·시간)을 감사하는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "복리를 돈의 개념으로 아는 것과, 재투자 구조가 있는 모든 곳(고객·신뢰·지식·부채)에서 같은 지수 과정을 식별하고 끊기지 않게 설계하는 것은 다르다"

**핵심 차별화**:
1. 복리의 3조건 — 보존(파산·리셋 없음)·재투자(산출이 원금에 합류)·시간: 셋 중 하나라도 깨지면 복리가 아니다 — "복리"라는 말의 남용을 검증하는 기준
2. 음의 복리 — 기술 부채·조직 부채·신뢰 부채·금융 부채: 같은 수학의 반대 방향, 이자가 붙고 있는 곳의 식별 절차(**IQ Dev Lab과의 공식 교차점**)
3. 에르고딕성의 재림 — 복리의 최대 적은 절단(파산·중단·인출): `prob`의 에르고딕성이 모든 영역에서 "생존이 수익률에 우선"으로 번역되는 구조
4. 지루한 앞부분의 수학 — 지수 곡선은 변곡점 전까지 선형보다 못해 보인다: 그만두는 시점이 항상 변곡점 직전인 이유의 정량화

**타겟 독자**:
- "복리"를 격언으로만 소비해온 사람
- 리텐션·신뢰·학습이 같은 수학임을 직감하지만 정식화 못 한 독자
- 기술 부채의 이자를 체감하면서 금융 부채와 같은 구조임을 연결 못 한 개발자
- 꾸준함의 가치를 믿지만 왜 항상 변곡점 직전에 그만두는지 모르는 사람
- L1 테제의 완결을 보고 싶은 독자

## 🔗 레포 연결

**⬆️ 선행 (Synthesis는 선행이 전부다)**: `money-and-interest`(복리·할인의 원점)·`personal-finance`(변동성 드래그)·`probabilistic-thinking`(에르고딕성·Kelly). 이 셋 없이 읽으면 자기계발서가 된다.
**🤝 시너지**: `feedback-loops-everywhere`(복리 = 가장 단순한 강화 루프 — 분업: 그쪽은 루프 일반론, 이쪽은 지수 과정), `leverage-everywhere`(레버리지는 복리의 배율을 산다 — 파산 확률과 함께).
**🧬 수렴 회수처**: `funnel`(리텐션 복리)·`ue`(NRR)·`brand`(일관성의 복리)·`negotiation`·`gt`(신뢰·평판·δ)·`macro`(부채 사이클)·`crf`(플라이휠·자멸의 신뢰 부채)·`moats`(ROIC×재투자) — **그리고 IQ Dev Lab(기술 부채)과의 기관 간 교차.**

## 🎯 1단계: 전체 구조 설계

> Synthesis 레포는 6챕터 체제 — 챕터가 주제가 아니라 **같은 구조가 등장하는 영역**이다.

### Chapter 1: 구조의 정식화 (4개 문서)
- 복리의 일반형 — x_{t+1} = x_t(1+r): 본질은 이자율이 아니라 **재투자 구조**(산출이 원금에 합류하는 배관)
- 지수 직관의 부재 — 인간은 선형으로 외삽한다(체스판 쌀알·연못 수련): bias의 지수 성장 과소평가, 양방향의 비용
- 복리의 3조건 — 보존·재투자·시간: "복리"를 자칭하는 모든 것의 검증 기준(이 레포의 판정 도구)
- 음의 복리 — 같은 수학, 반대 부호: 부채·부패·방치가 스스로 증식하는 구조의 일반형

### Chapter 2: 돈의 복리 (4개 문서)
- 자본 복리의 재정리 — 시간의 지배·수수료 침식·변동성 드래그(money·pf 회수): L1 핵심의 1장 요약과 일반형으로의 승격
- 신용의 복리 — 부채 사이클 = 사회 전체의 음의 복리(macro 회수): 금리>성장이면 자동 악화되는 부등식
- 기업 가치의 복리 — 성장 = ROIC × 재투자율(valuation·moats 회수): 해자가 복리의 보호막인 이유(재투자 수익률의 방어)
- 절단의 수학 — 에르고딕성의 재림(prob 회수): 복리는 곱셈이라 0을 한 번 곱하면 끝 — 생존이 수익률에 우선하는 증명

### Chapter 3: 사업의 복리 (5개 문서)
- 고객 기반의 복리 — 리텐션·NRR이 만드는 누적(funnel·ue 회수): 잔존율 5%p의 장기 분기 재계산
- 축적형 채널 — 콘텐츠·SEO의 복리(funnel 회수): 광고(소모형)와 자산(축적형)의 분류 기준
- 브랜드의 복리 — 일관성의 누적(brand 회수): 기억 구조에 쌓이는 이자, 리브랜딩 = 원금 절단
- 플라이휠 — 아마존의 복리 루프(crf 회수): 복리 배관을 의도적으로 설계하는 절차(feedback-loops와 분업: 구조는 그쪽, 지수 산출은 이쪽)
- 운영의 복리 — 프로세스·데이터의 개선이 개선을 낳는 구조(moats 프로세스 파워 회수): 토요타의 수학

### Chapter 4: 사람의 복리 (5개 문서)
- 학습의 복리 — 지식이 지식의 흡수율을 높인다: 이 연구소(Knowledge Triad) 자체의 존재 근거, 기초의 재투자 수익률
- 신뢰·평판의 복리 — 작은 약속 이행의 누적(negotiation·gt 회수): δ가 높은 관계에서 평판이 자산인 수학
- 관계망의 복리 — 약한 연결의 누적과 교차: 네트워크 가치의 비선형(mm 멱법칙과 결합)
- 습관·건강의 복리 — 1%의 분기: 일일 미세 차이의 장기 지수, 그리고 이 프레임의 남용 경계(자기계발 신화 검증)
- 커리어의 복리 — 복리 곡선을 타는 선택 vs 선형 트레이드: 학습·평판·지분이 쌓이는 자리의 식별

### Chapter 5: 음의 복리 (5개 문서)
- 기술 부채 — 이자가 붙는 지름길(**IQ Dev Lab과의 공식 교차점**): 부채의 원금·이자·상환을 코드에 번역, 의도적 부채와 방치 부채의 구분
- 조직 부채 — 미룬 결정·안 한 채용 교정·문서화 부재의 누적: 스타트업이 속도와 교환하는 것의 이자율
- 신뢰 부채 — 작은 거짓의 복리: 분식 에스컬레이션의 수학(crf 자멸 단계 회수), 한 번의 절단이 전체를 지우는 비대칭
- 금융 부채의 재독 — 개인·기업·국가의 같은 부등식(pf·fs·macro 회수): 이자율>성장률 판정표
- 음의 복리 감사 — 어디서 이자가 붙고 있나: 식별 신호(반복 비용의 증가 추세)와 상환 우선순위 절차

### Chapter 6: 종합과 실전 (5개 문서)
- 복리 감사 — 내 자산·활동·부채 전체를 복리/선형/음의 복리로 분류하는 표준 절차(이 레포의 핵심 산출물)
- 복리의 3대 적 — 절단(파산)·중단(일관성 붕괴)·인출(재투자 중단): 각각의 방어 설계
- 지루한 앞부분 — 지수가 선형에 뒤지는 구간의 길이 계산: 그만둠이 변곡점 직전에 몰리는 이유, 버티는 구조의 설계(측정 가능한 선행 지표)
- 복리로 거짓말하는 법 — 과거 수익률 외삽·생존편향 복리 신화·"하루 1%" 산수의 함정 — 방어용
- 종합 케이스 — 내 삶/사업의 복리 포트폴리오 재설계: 양의 복리 증설 + 음의 복리 상환 계획

→ **총 28개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 격언이 아니라 감사·분류·설계 절차로
2. **3조건 검증 필수** — "복리"라 부르려면 보존·재투자·시간을 통과시킨다: 통과 못 하면 선형이라 부른다
3. **숫자로 재계산** — 모든 복리 주장은 구체 수치(기간·이율·분기점)로: "복리의 마법" 같은 수사 금지
4. **반례에 살아남는가** — 복리 프레임의 남용(하루 1% 신화·무한 외삽)을 같은 비중으로 해체
5. **음의 복리를 동급으로** — 양의 복리 찬가가 아니라 양방향의 수학: 감사의 절반은 부채 식별
6. 지수 vs 선형 분기·재투자 배관·감사 매트릭스는 다이어그램으로

```
  → 새 영역을 만나면: 원금·이율·배관 3칸을 채워본다 — 채워지면 복리다

복리의 3조건 (남용의 검증기):
  ① 보존: 리셋·파산이 없는가 (에르고딕 절단 체크)
  ② 재투자: 산출이 원금에 합류하는가 (배관의 존재)
  ③ 시간: 지수가 일하기에 충분한 기간인가
  "독서는 복리다" → ②가 의심: 잊히는 지식은 재투자가 아니다
    (조건을 만들면 복리가 된다: 연결·기록·사용 — 이 연구소의 방법)
  → 격언을 검증 가능한 주장으로 바꾸는 것이 이 레포의 일

지루한 앞부분 (그만둠의 수학):
  일 +100(선형) vs 일 +1%(지수, 원금 1000)
  → 교차는 약 240일 후 — 8개월간 지수가 "져 보인다"
  → 인간의 평가 주기(주·월)가 교차 전에 여러 번 돌아온다
  → 그만둠이 변곡점 직전에 몰리는 건 우연이 아니라 구조
  → 방어: 결과 지표가 아니라 배관 지표(재투자율·잔존율)를 본다

음의 복리 식별 (감사의 절반):
  신호: 같은 유형의 비용이 시간에 따라 증가 추세인가
   코드: 같은 기능 수정에 드는 시간이 늘어난다 → 기술 부채 이자
   조직: 같은 결정에 필요한 회의가 늘어난다 → 조직 부채 이자
   관계: 같은 부탁에 필요한 설득이 늘어난다 → 신뢰 부채 이자
  → 이자 추세가 확인되면 상환(리팩토링·결정·사과)의 기댓값을 계산한다
  → 상환은 비용이 아니라 음의 복리의 절단이다

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 복리 자산은 절단(파산·중단)으로부터의 보호가 수익률 개선에
              우선한다 — 곱셈 과정에서 0은 복구되지 않는다
  Boundary  : 옵션성 탐색(작고 가역적인 실험)은 절단 보호 대상이 아니다 —
              잃어도 원금이 안 다치는 베팅은 오히려 많이 끊어도 된다(dec)
  Rule      : 분기 복리 감사에서 ①각 복리 자산의 절단 시나리오와 방화벽
              ②재투자 배관의 누수(인출·중단) ③음의 복리 이자 추세
              3가지를 점검한다. 새 기회 평가는 "이율"보다 "배관과 보존"을
              먼저 본다 — 배관 없는 고수익은 선형 소득일 뿐이다
```
