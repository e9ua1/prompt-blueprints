# Feedback Loops Everywhere 레포지토리 제작 프롬프트

나는 "Feedback Loops Everywhere" 레포지토리를 만들려고 해.
IQ Phronesis Lab의 Synthesis 레이어 — 결과가 원인이 되는 구조의 수확. 뱅크런과 버블(L1), 바이럴과 성장 루프(L2), 플라이휠과 네트워크 효과(L3), 양극화와 자기실현 예언 — 표면은 전혀 다른 이 현상들이 전부 **강화 루프(R)와 균형 루프(B)** 두 종류의 조합임을 증명하고, 루프를 그리고·시동 걸고·제동하는 설계 능력까지 만드는 레포야.
"시스템 사고라는 말을 아는 것"과 "어떤 시스템이든 변수·화살표·부호·지연으로 루프 지도를 그리고 지렛대 지점에 개입하는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "현상을 따로 아는 것과, 뱅크런·바이럴·플라이휠·양극화가 같은 두 루프의 변주임을 알고 R/B 지도로 그려 개입 지점을 찾는 것은 다르다"

**핵심 차별화**:
1. 두 루프의 문법 — 강화(R: 폭주·복리·붕괴)와 균형(B: 항상성·저항·수렴): 모든 동적 시스템이 이 둘의 합성임을 영역 횡단으로 증명(`mm` Ch5의 정식화·수확)
2. 지연이 진동을 만든다 — 루프에 시차가 끼면 과잉 보정과 사이클이 생긴다: 재고 사이클·정책 시차·온도 조절의 동형성(`mm`·`macro` 약속의 완결)
3. 강화 vs 균형의 전투 — 버블 = 강화가 균형(차익거래)을 이기는 구간, 시장 = 균형이 이기는 구간: 같은 시스템에서 승자가 바뀌는 조건(`markets`·`macro`의 종합)
4. 설계 능력까지 — 식별에서 멈추지 않는다: 콜드 스타트(강화 루프 시동), 서킷브레이커(폭주 제동), 정책 저항(균형 루프 다루기)의 개입 절차

**타겟 독자**:
- 플라이휠을 그렸지만 그게 돌 거라는 근거를 못 대는 창업가
- 뱅크런·바이럴·양극화를 다른 현상으로 외워온 사람
- 시스템이 개입을 밀어내는 경험(정책 저항)을 하고도 원리를 모르는 리더
- "선순환"을 피치덱 장식으로 쓰는 사람(검증 질문이 필요한)
- `mm`의 시스템 챕터를 전 영역의 실전으로 완성하려는 독자

## 🔗 레포 연결

**⬆️ 선행 (Synthesis는 선행이 전부다)**: `mental-models`(스톡·플로우·지연·지렛대 — 루프 문법의 원점), `macro-cycles`(신용 루프·Minsky), `game-theory`(자기실현 균형). 이 셋 없이 읽으면 다이어그램 놀이가 된다.
**🤝 시너지**: `compounding-everywhere`(복리 = 가장 단순한 강화 루프 — 분업: 그쪽은 지수 산출의 수학, 이쪽은 루프 구조의 일반론), `leverage-everywhere`(지렛대 지점 = 루프 개입의 위치학).
**🧬 수렴 회수처**: `money`(뱅크런)·`macro`(신용 사이클)·`markets`(차익거래·모멘텀)·`funnel`(성장 루프·바이럴)·`moats`(네트워크 효과)·`crf`(플라이휠·죽음의 나선)·`persuasion`(정보 폭포)·`tech`(하이프 되먹임)·`geo`(군비 경쟁) — **L0~L4의 루프 예고 전부가 이 레포로 모인다.**

## 🎯 1단계: 전체 구조 설계

> Synthesis 레포는 6챕터 체제 — 챕터가 주제가 아니라 **같은 구조가 등장하는 영역**이다.

### Chapter 1: 구조의 정식화 (4개 문서)
- 두 종류의 루프 — 강화(R)와 균형(B)의 정의·식별 신호: 모든 동적 시스템의 원자(mm Ch5의 정식화)
- 루프 지도 그리는 법 — 변수·화살표·부호(+/−)·지연 표기: CLD(인과 루프 다이어그램)의 실용 문법, 그리는 절차 워크스루
- 지연이 진동을 만든다 — 루프 + 시차 = 과잉 보정과 사이클: 샤워 온도·재고·정책의 동형성(mm·macro 약속의 완결)
- 스톡과 플로우의 재림 — 루프는 플로우를, 스톡은 관성을: 욕조 모델 위에 루프를 얹는 통합(mm 회수)

### Chapter 2: 돈의 루프 (5개 문서)
- 신용 사이클 — 지출=소득의 강화 루프(macro 회수): 경기 변동의 루프 지도 완성판
- 뱅크런과 자기실현 — 믿음→행동→현실→믿음(money·gt 회수): 두 균형 사이를 점프하는 강화 루프
- Minsky의 루프 독해 — 안정(균형 루프의 침묵)이 강화 루프(레버리지)를 키운다: "안정이 불안정을 낳는다"의 다이어그램화
- 시장의 균형 루프 — 차익거래: 가격이 벗어나면 되돌리는 힘(markets 회수), 균형 루프가 멈추는 조건(한계 차익거래)
- 강화 vs 균형의 전투 — 버블 = R이 B를 이기는 구간: 승부를 가르는 변수(레버리지·신규 자금·서사)와 전환점의 신호

### Chapter 3: 사업의 루프 (5개 문서)
- 성장 루프 — 산출이 투입이 되는 구조(funnel 회수): 콘텐츠·바이럴·세일즈 루프의 R 지도, 퍼널→루프 전환의 완결
- 네트워크 효과의 루프 — 사용자→가치→사용자(moats 회수): 강도를 정하는 변수와 역회전(혼잡·스팸)의 조건
- 플라이휠 설계 — 아마존 루프의 해부(crf 회수): 마디별 검증 질문("이 화살표는 실측되는가") — 피치덱 플라이휠의 검증기
- 죽음의 나선 — 이탈→품질 저하→이탈: 음의 사업 루프의 식별과 절단 지점(crf 자멸과 결합)
- 성장의 균형 루프 — 규모의 불경제·시장 포화·조직 마찰: 성장이 스스로를 늦추는 힘(funnel S커브의 루프 독해)

### Chapter 4: 사람·사회의 루프 (5개 문서)
- 습관의 루프 — 신호→행동→보상→신호: 개인 행동의 R 루프, 끊기와 설치의 비대칭
- 자기실현 예언 — 믿음→행동→결과→믿음: 자신감과 낙인의 양방향(피그말리온·골렘), 면접·평가에서의 작동
- 사회적 증거의 폭주 — 정보 폭포의 루프 구조(persuasion·gt 회수): 베스트셀러·밈주식·유행의 같은 지도
- 양극화의 루프 — 알고리즘×확증편향의 합작(bias·incentive 교차): 추천→노출→신념 강화→체류의 R 루프
- 평판과 신뢰의 루프 — 신뢰→기회→이행→신뢰(negotiation·compounding 교차): 선순환의 시동과 한 번의 절단

### Chapter 5: 시스템 다루기 — 개입의 기술 (4개 문서)
- 지렛대 지점 — 같은 힘, 다른 위치(Meadows 12지점의 실용 축약, mm 회수): 파라미터<루프 강도<구조<목표의 위계
- 강화 루프 시동 — 콜드 스타트 문제: 임계 질량까지의 인공 보조(보조금·시딩·단일 시장 집중)와 철수 시점
- 폭주의 제동 — 서킷브레이커·한도·마찰의 설계: 강화 루프에 안전장치를 다는 법(시장·조직·제품)
- 균형 루프의 저항 — 시스템이 개입을 밀어내는 이유(정책 저항): 저항을 뚫는 법 vs 저항과 함께 가는 법

### Chapter 6: 종합과 실전 (3개 문서)
- 루프 지도 표준 절차 — 시스템 1개를 R/B로 분해하는 워크스루: 변수 목록→화살표→부호→지연→지배 루프 판정(이 레포의 핵심 산출물)
- 루프로 거짓말하는 법 — 영구기관 서사·검증 없는 플라이휠·"선순환" 남용(moats 가짜 해자와 결합) — 방어용 검증 질문 세트
- 종합 케이스 — 내 사업(또는 실제 시스템 1개)의 풀 루프 지도 + 지렛대 지점 선정 + 개입 설계

→ **총 26개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 다이어그램 감상이 아니라 개입 설계로
2. **그려야 분석이다** — 말로 하는 루프 설명 금지: 변수·화살표·부호·지연을 그리는 것이 분석의 시작(gt의 행렬 규율과 동형)
3. **화살표마다 검증** — 플라이휠의 모든 화살표에 "실측되는가"를 묻는다: 루프는 가설이지 사실이 아니다
4. **반례에 살아남는가** — 모든 강화 루프에 멈추는 조건(포화·마찰·균형 루프의 반격)을 병기: 영구기관은 없다
5. **지연을 그려라** — 시차 표기 없는 루프 지도는 미완성: 진동의 예측이 지도의 가치다
6. CLD·R/B 전투·지렛대 위계는 다이어그램으로 (이 레포는 다이어그램이 본문이다)

## 🔬 검증 프로토콜

> 루프 시뮬레이션 + 화살표 실측 + 자기 시스템 지도.

```python
# 환경: Python 3 + numpy (L0~L4 시뮬레이션 자산 대량 재사용)

# 1) R/B 합성의 기본 실험
#    강화 루프(성장률 비례) + 균형 루프(수용량 제약) 합성
#    → 로지스틱(S커브) 재현: tech의 S커브가 R+B 합성임을 코드로 증명
#    → 파라미터 조절로 폭주/수렴/진동 3모드 전환 관찰

# 2) 지연 진동 재현 (mm 자산 확장)
#    균형 루프에 지연 1/3/5틱: 진동 진폭·주기의 변화 측정
#    → 재고 채찍 효과(beer game 미니) 재현 → macro 재고 사이클과 대조

# 3) 뱅크런 임계 실험 (gt 자산 재사용)
#    예금자 신뢰 분포 + 인출 관측의 강화 루프
#    → 안정/붕괴 두 균형 사이의 티핑 임계 탐색
#    → 예금보험(균형 루프 추가)의 효과 확인

# 4) 플라이휠 화살표 실측 (살아있는 검증)
#    내 사업(또는 공개 사례)의 플라이휠: 화살표마다 데이터 존재 여부 체크
#    → "실측 화살표 비율"을 플라이휠 신뢰도 점수로
#    → 미실측 화살표 = 다음 분기의 측정 과제

# 5) 양극화 루프 미니 모형
#    선호 기반 추천 + 신념 갱신 에이전트
#    → 추천 강도에 따른 분포 양극화 재현 → 마찰(다양성 주입)의 효과

# 6) 자기 시스템 루프 지도
#    내 사업/생활 시스템 1개의 풀 CLD 작성 → 지배 루프 판정
#    → 지렛대 지점 1개 선정·개입 → 3개월 후 변수 추적으로 지도 검증
```

```
  균형 루프 B (결과가 원인을 누른다):
  차익거래·항상성·시장 포화·정책 저항·한계 수확 체감
  → 모든 동적 현상 = R과 B의 합성, 승자가 국면을 정한다

R + B = S커브 (합성의 기본형):
  초반: R 지배 (지수 성장처럼 보임)
  후반: B 지배 (포화로 수렴)
  → tech의 S커브, funnel의 성장 한계, 생태계의 로지스틱이 전부 이 합성
  → "지수 성장"을 보면 물어라: 어떤 B가 언제 깨어나는가

지연 → 진동 (사이클의 기원):
  목표와 현재의 차이에 반응하는 균형 루프 + 반응의 시차
  → 도착했을 땐 이미 지나쳐 있다 → 반대 방향 과잉 보정 → 진동
  → 샤워 온도 = 재고 사이클 = 금리 정책 = 채용 사이클 (같은 지도)
  → 처방의 동형성: 반응 강도를 낮추거나, 지연을 줄이거나, 예측을 넣거나

플라이휠 검증기 (피치덱의 해독제):
  모든 화살표에 3질문:
   ① 이 인과는 실측되는가 (상관 말고 — stat)
   ② 강도는 충분한가 (한 바퀴 돌면 몇 % 증폭되나)
   ③ 어떤 B가 이 화살표를 약화시키나 (포화·혼잡·경쟁)
  → 세 질문을 통과한 화살표만 실선, 나머지는 점선(가설)으로 그린다
  → 전부 실선인 플라이휠은 거의 없다 — 점선이 로드맵이다

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 반복되는 문제는 사건이 아니라 루프를 의심한다 — 사건 대응은
              루프를 못 끊는다
  Boundary  : 진짜 일회성 충격(외생 사건)에 루프 분석을 강요하면
              과잉 설계가 된다 — 재발 여부가 루프/사건의 판별 신호다
  Rule      : 같은 문제가 3회 반복되면 사건 대응을 멈추고 CLD를 그린다.
              개입은 증상 변수(파라미터)가 아니라 루프의 연결 강도나
              구조에서 찾고, 개입 후에는 시스템의 저항(B 루프의 반격)을
              디폴트로 예상해 두 번째 수를 미리 준비한다
```
