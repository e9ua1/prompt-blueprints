# Incentives Everywhere 레포지토리 제작 프롬프트

나는 "Incentives Everywhere" 레포지토리를 만들려고 해.
IQ Phronesis Lab의 Synthesis 레이어 — 새 지식을 쌓는 레포가 아니라, L0~L4 전체에 흩어져 있던 하나의 구조를 수확하는 레포야. 그 구조는: **행동이 이상해 보이면 사람이 아니라 보수 구조를 보라.** 금융 중개인의 권유, 신용평가사의 등급, 미디어의 공포, 과학의 재현성 위기, 규제 포획, 분식회계 — 표면은 전혀 다른 이 현상들이 전부 같은 인센티브 구조의 변주임을 영역 횡단으로 증명하는 레포다.
"각 영역의 문제를 따로 아는 것"과 "어떤 시스템을 만나든 플레이어→보수→정보→시간 지평을 매핑하는 하나의 렌즈를 갖는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "인센티브가 중요하다는 격언을 아는 것과, 처음 보는 시스템의 행동을 보수 구조에서 역산하는 절차를 갖는 것은 다르다"

**핵심 차별화**:
1. 수확 레이어 — `incentive-design`(L3)이 인센티브의 *설계*라면, 이 레포는 모든 영역에서 인센티브를 *읽는 렌즈*: 분업이 명확하다
2. 동형성 매핑 — 신용평가사 이해상충 ↔ 출판 편향 ↔ 규제 포획 ↔ 분식회계가 같은 구조(평가자가 피평가자에게 보상받는다)임을 표로 증명
3. 조언자 감사 — 은행원·중개인·미디어·전문가, 그리고 이 레포 자신까지: 내게 정보를 주는 모든 주체의 유인을 점검하는 절차
4. 렌즈의 오남용 경계 — 모든 것을 유인으로 환원하는 냉소주의와의 구분: 렌즈가 깨지는 곳(정체성·규범·역량)을 명시

**타겟 독자**:
- "왜 저렇게 행동하지?"를 성격·도덕으로 설명해온 사람
- 금융·미디어·전문가의 조언을 유인 점검 없이 소비하는 사람
- L0~L4를 거치며 흩어진 인센티브 예고들을 한 장의 지도로 만들고 싶은 독자
- 시스템의 실패를 개인의 실패로 오진해온 리더
- 냉소와 분석의 차이를 알고 싶은 사람

## 🔗 레포 연결

**⬆️ 선행 (Synthesis는 선행이 전부다)**: `incentive-design-distilled`(이론의 본체 — Goodhart·주인-대리인·메커니즘 디자인), `game-theory-distilled`(보수 구조의 문법), `microeconomics-distilled`(정보 비대칭). 이 셋 없이 읽으면 격언집이 된다.
**🤝 시너지**: `cognitive-bias-distilled`(유인과 편향은 행동의 두 엔진 — 구분 절차 포함), `statistics-literacy-distilled`(재현성 위기의 유인 설명).
**🧬 수렴 회수처**: `financial-statements`(분식)·`corporate-rise-fall`(자멸의 단계)·`markets-investing`(중개 유인)·`macro`(정책 유인)·`economic-history`(대마불사)·`persuasion`(다크패턴) — **L0~L4의 인센티브 예고 전부가 이 레포로 모인다.**

## 🎯 1단계: 전체 구조 설계

> Synthesis 레포는 6챕터 체제 — 챕터가 주제가 아니라 **같은 구조가 등장하는 영역**이다.

### Chapter 1: 렌즈의 정식화 (4개 문서)
- 동형성이라는 방법 — 표면이 다른 곳에서 같은 구조 찾기: Synthesis 레이어의 방법론 선언(이 문서가 L5 전체의 서문)
- 렌즈의 정식화 — 플레이어·보수·정보·시간 지평의 4변수: 어떤 시스템이든 이 4칸을 채우는 절차
- 렌즈의 경계 — 구축 효과·정체성·규범·역량(incentive-design Ch1 계승): 유인으로 설명되지 않는 행동의 영역
- 분석 절차 — 이상한 행동→수혜자 식별→보수 경로 역추적→구조 검증: cui bono의 규율화(음모론과의 구분 포함)

### Chapter 2: 돈의 세계에서 (5개 문서)
- 금융 중개의 유인 — 수수료 구조가 권유를 만든다: 회전 매매·고마진 상품 권유의 구조(markets 행동 격차와 결합)
- 평가자의 이해상충 — 신용평가사는 발행자에게 보상받는다: 2008의 한 축, 같은 구조의 변주들(감사인·감정평가)
- 전망 산업의 유인 — 틀려도 같이 틀리면 안전하다(Keynes 미인대회): 컨센서스 군집의 구조(eh·tech 예측 성적표의 유인 설명, 약속 회수)
- 보험·대출의 양방향 유인 — 역선택과 도덕적 해이의 실전 재독(micro 회수): 계약 설계가 유인 설계인 이유
- 지표 부패의 사슬 — 분식은 KPI 게이밍의 회계 버전(fs·crf 자멸 단계의 회수): 경영진 보상→목표 고정→조작의 인과

### Chapter 3: 조직과 시장에서 (5개 문서)
- 부서 이기주의는 합리적이다 — 조직 정치의 유인 구조: 사일로·예산 사수·정보 은닉의 보수 분석
- 외주와 자문의 유인 — 시간 과금 vs 결과 보상: 프로젝트가 길어지는 구조적 이유, 정렬 계약의 설계
- 플랫폼 삼각 유인 — 플랫폼·공급자·사용자의 충돌 지도(incentive Ch6 회수): 수수료·노출 알고리즘이 만드는 행동
- 광고 모델의 원죄 — 체류 극대화와 사용자 효용의 충돌: 무료 서비스의 진짜 고객("네가 상품이다"의 정확한 구조)
- 인재 흐름의 유인 — 왜 인재가 그 산업으로 몰리나: 보상 구조가 만드는 세대별 커리어 지형(금융→테크→AI)

### Chapter 4: 정보의 세계에서 (5개 문서)
- 미디어의 유인 — 클릭·공포·속보 경쟁의 구조: 뉴스가 체계적으로 비관에 기우는 이유(prob 가용성과 결합)
- 과학의 유인 — 출판 편향·p-해킹은 개인 비리가 아니라 구조다: 재현성 위기의 유인 설명(stat 약속의 회수 — "publish or perish")
- 전문가의 책임 비대칭 — 경고는 보상받고 낙관은 처벌받는다(또는 그 역): 영역별 비대칭의 지도
- 알고리즘의 유인 — 분노·극단이 보상받는 추천 구조: 양극화의 기계적 기원(feedback-loops와 교차)
- 인플루언서·후기의 유인 — 협찬·제휴 구조가 만드는 정보 오염: 신뢰 신호의 구매 가능성(persuasion 사회적 증거의 부패)

### Chapter 5: 제도와 역사에서 (4개 문서)
- 규제 포획 — 규제자의 유인(회전문·정보 의존): 규제가 기득권의 해자가 되는 역설(moats 규제 해자의 어두운 면)
- 정치의 시간 지평 — 선거 주기 vs 장기 문제: 단기 보상 구조가 만드는 체계적 미루기(macro 정책 시차와 결합)
- 관료제의 유인 — 책임 회피가 합리인 구조: 규정 준수 > 결과의 보수 체계, 혁신이 처벌받는 곳
- 역사의 인센티브 재독 — eh 사례를 유인으로 다시 읽기: 대마불사(구제의 학습)·금본위 고수(신뢰 자산)·1997 차입 경영(약속의 회수)

### Chapter 6: 종합과 실전 (4개 문서)
- 인센티브 지도 표준 절차 — 어떤 시스템이든 4변수 매핑: 작성 워크스루와 양식(이 레포의 핵심 산출물)
- 나의 조언자 감사 — 은행원·중개인·미디어·전문가·이 레포까지: 정보 소스별 유인 점검표, "공짜 조언의 가격"
- 렌즈의 오남용 — 냉소주의·음모론과 분석의 구분: 유인 환원주의의 4가지 오류(증거 없는 귀인·단일 유인·의도 혼동·자기 면제)
- 종합 케이스 — 실제 시스템 1개(예: 부동산 중개 생태계)를 플레이어 전원의 유인 지도로 풀 매핑

→ **총 27개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 냉소가 아니라 행동 변경(소스 교체·계약 재설계·검증 추가)으로 끝난다
2. **동형성 매핑 표 필수** — 모든 문서에 최소 3개 영역의 같은 구조를 표로: 이 표가 Synthesis의 존재 증명이다
3. **개인 비난 금지** — 분석의 화살표는 항상 구조로: "나쁜 사람"이 결론이면 분석 실패
4. **반례에 살아남는가** — 유인 설명이 실패하는 사례(내부고발자·무보상 기여)를 같은 비중으로
5. **자기 적용 필수** — 이 레포 자신의 유인(저자의 동기·확증 위험)도 감사 대상에 포함한다
6. 유인 지도·이해상충 삼각형·동형성 표는 다이어그램으로

#    → 구조 동일성·차이점·각 영역의 방어 장치 비교

# 2) 조언자 감사 실습 (살아있는 검증)

# 3) 권유의 유인 추적

#    → 권유자의 수수료 구조 역산 → 권유와 수수료의 정렬도 측정

# 4) 재현성 위기의 유인 데이터
#    출판 편향 메타연구 수집 → 양성 결과 비율·철회 추이
#    → stat 레포의 p-해킹 시뮬레이션과 결합해 "구조의 산출물"임을 논증

# 5) 반례 데이터베이스
#    유인에 반하는 행동 사례 10건(내부고발·오픈소스 무상 기여·익명 기부)
#    → 각 사례에서 작동한 비유인 동력(정체성·규범) 분류
#    → 렌즈의 경계를 데이터로 긋는다

# 6) 자기 유인 감사
#    이 레포 자체: 저자(나)의 유인은 무엇인가, 어떤 확증 위험이 있는가
#    → 1페이지 공개 문서로 작성 (방법론의 무결성 증명)
```

  ④ 시간 지평: 각자의 청산 시점 (분기 실적 vs 10년 평판)
  → 이상 행동의 대부분은 ②와 ④의 조합으로 풀린다
  → "단기 보상 + 장기 비용의 외부화"가 가장 흔한 범인

cui bono의 규율 (음모론과의 구분):
  분석: 수혜자 식별 → 보수 경로의 증거 → 구조 검증 → 반례 탐색
  음모론: 수혜자 식별 → 의도 단정 (증거·반례 생략)
  → 차이는 결론이 아니라 절차다: 유인은 경향을 만들 뿐
    모든 개별 행동을 결정하지 않는다 (확률적 주장 — prob의 규율)

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 조언의 가치는 내용이 아니라 조언자의 보수 구조부터 평가한다
  Boundary  : 유인 충돌이 있어도 평판이 장기 자산인 조언자(반복 거래·
              좁은 업계)는 단기 유인을 누를 수 있다 — δ가 높은 관계는
              충돌 등급을 낮춰 평가한다 (gt 미래의 그림자)
  Rule      : 돈이 걸린 조언을 받으면 "이 사람은 내가 무엇을 할 때
              돈을 버는가"를 먼저 적는다. 내 행동과 조언자 수익이
              정렬되지 않으면, 조언을 버리는 게 아니라 독립 검증 1개를
              추가한 뒤에만 채택한다
```
