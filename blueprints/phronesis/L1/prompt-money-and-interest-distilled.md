# Money & Interest Distilled 레포지토리 제작 프롬프트

나는 "Money & Interest Distilled" 레포지토리를 만들려고 해.
돈이 실제로 어떻게 만들어지는지 — 은행이 예금을 빌려주는 게 아니라 대출이 예금을 *창조*한다는 사실부터, 금리가 왜 돈의 가격인지, 현재가치·할인이 어떻게 유도되는지(이 레이어 전체의 척추), 수익률 곡선이 무엇을 말하는지, 기준금리가 내 대출금리까지 오는 전달 경로를 끝까지 해부하는 레포야.
"금리 뉴스를 읽는 것"과 "그 금리가 어디서 만들어져 어떤 경로로 내 현금흐름에 도달하는지 아는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "돈을 버는 법을 아는 것과, 돈이 무엇이고 어떻게 창조·소멸되며 그 가격(금리)이 모든 가치평가의 분모가 되는 구조를 아는 것은 다르다"

**핵심 차별화**:
1. 신용창조의 진실 — 통화승수 교과서 모델이 아니라 "대출이 예금을 만든다"(BoE 2014)는 실제 메커니즘, 돈의 창조와 소멸을 원장 수준에서
2. 할인의 완전 유도 — PV = CF/(1+r)^t 를 차익거래 불가 원리에서 유도. L1 전체(LTV·DCF·채권가격)가 이 한 줄의 변주임을 선언하는 원점
3. 수익률 곡선 읽기 — 기대이론·기간프리미엄 분해, 장단기 역전의 침체 예측력과 *틀렸던 경우*까지
4. 전달 경로 지도 — 기준금리→은행 조달→대출·전세·자산가격→내 사업, 각 마디의 시차와 마찰

**타겟 독자**:
- 금리 인상 뉴스를 보지만 자기 사업·대출과의 연결 고리를 모르는 창업가
- "은행은 예금을 모아 빌려준다"는 교과서 모델을 믿는 사람
- 채권 가격과 금리가 왜 반대로 움직이는지 외우기만 한 사람
- DCF·LTV를 쓰면서 분모(할인율)가 어디서 오는지 모르는 개발자
- `valuation`·`macro-cycles`로 가기 전 분모의 정체를 잡으려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `probabilistic-thinking-distilled`(기댓값·복리의 수학 감각).
**🤝 시너지**: `macro-cycles-distilled`(신용창조의 집계가 부채 사이클), `personal-finance-distilled`(할인·복리의 개인 스케일).
**🧬 수렴**: `valuation-distilled`(할인율이 DCF의 분모), `unit-economics-distilled`(LTV는 할인된 마진), `compounding-everywhere`(복리·할인은 같은 지수함수의 양방향). **이 레포가 L1 테제 "같은 할인·복리가 스케일만 바꿔 반복된다"의 원점이다.**

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 돈이란 무엇인가 (5개 문서)
- 돈의 세 기능 — 교환·가치저장·계산단위, 셋이 분리될 때 생기는 일
- 상품화폐에서 신용화폐로 — 금에서 장부로, "돈은 누군가의 부채다"
- 화폐의 신뢰 기반 — 법정화폐가 작동하는 이유(세금·네트워크·강제력)
- 돈의 층위 — M0/M1/M2, 본원통화와 파생된 돈, 어느 층이 "진짜 돈"인가
- 디지털 화폐 — 스테이블코인·CBDC는 돈인가, 세 기능 기준의 판정

### Chapter 2: 신용창조 — 대출이 예금을 만든다 (6개 문서)
- 통화승수 신화 — 교과서 모델 vs 실제(BoE 2014), 인과의 방향이 반대다
- 대출의 원장 — 은행이 대출하는 순간 예금이 생기는 복식부기 추적
- 지급준비금의 실제 역할 — 대출 제약이 아니라 결제 수요, 준비금이 먼저가 아니다
- 돈의 소멸 — 대출 상환이 통화량을 줄이는 메커니즘, 디레버리징의 정체
- 은행간 결제와 지준시장 — 콜시장·지준 이동, 기준금리가 작동하는 실제 장소
- 뱅크런의 구조 — 만기 불일치라는 본질적 취약성, 자기실현 예언(feedback-loops 예고)

### Chapter 3: 금리 — 돈의 가격 (6개 문서)
- 금리는 무엇의 가격인가 — 시간선호·유동성 포기·리스크의 합성 가격
- 현재가치와 할인의 유도 — 차익거래 불가에서 PV 공식까지, **L1 전체의 척추**
- 복리의 수학 — 복리 주기와 e의 등장, 연속복리, 단리와의 격차가 벌어지는 속도
- 실질 vs 명목 — 피셔 방정식, 인플레 기대가 금리에 들어가는 경로
- 금리의 분해 — 무위험 + 기간 프리미엄 + 신용 스프레드, 내 대출금리 해부
- 마이너스 금리 — 어떻게 가능한가(현금 보관 비용·안전 수요), 무엇이 깨지나

### Chapter 4: 수익률 곡선 (5개 문서)
- 곡선이 말하는 것 — 기대이론·기간프리미엄·시장분할, 세 해석의 분리
- 장단기 역전 — 침체 예측의 메커니즘과 실적, 틀렸던 경우의 공통점
- 채권 가격과 금리의 역관계 — 고정 현금흐름 할인에서 직접 유도(외우지 않는다)
- 듀레이션 — 금리 1%p에 가격이 몇 % 움직이나, 만기·쿠폰과의 관계
- 곡선 읽기 실전 — 스프레드 지표(10y-2y, 10y-3m), 현재 곡선 해석 절차

### Chapter 5: 중앙은행 (6개 문서)
- 중앙은행의 존재 이유 — 최종대부자, 뱅크런 시대가 만든 제도(Ch2 직결)
- 전달 경로 — 기준금리→콜→은행채·코픽스→대출금리, 마디별 시차와 마찰
- 공개시장조작과 QE — 국채 매입이 돈을 "푸는" 실제 회계, QE 오해 바로잡기
- 인플레이션 타게팅 — 왜 2%인가, 기대 관리라는 본업
- 중앙은행의 한계 — 밀어도 안 가는 끈(유동성 함정), 공급발 인플레 앞의 무력
- 한국은행과 Fed — 소규모 개방경제의 제약, 금리 격차와 자본 이동(macro 환율 예고)

### Chapter 6: 인플레이션과 화폐가치 (5개 문서)
- 인플레의 화폐적 원인 — 너무 많은 돈이 너무 적은 재화를 쫓을 때, 조건의 명시
- 하이퍼인플레이션 — 재정 화폐화→신뢰 붕괴의 가속 루프, 바이마르·짐바브웨
- 디플레이션이 더 무서운 이유 — 실질 부채 증가·지출 연기의 자기강화
- 인플레의 재분배 — 채무자 vs 채권자, 자산 보유자 vs 임금 생활자, 숨은 세금
- 측정의 함정 — CPI 바스켓·주거비 처리·체감과의 괴리(stat 지표 정의 직결)

### Chapter 7: 실전 (5개 문서)
- 금리가 내 삶에 도달하는 경로 — 대출·전세·예금·자산가격 경로별 시차 지도
- 금리 사이클 읽기 — 인상기·동결기·인하기의 패턴, 지금 어디인가 판단 절차
- FOMC·금통위 해독 — 성명서·점도표 읽는 법, 시장이 반응하는 건 서프라이즈뿐
- 사업자의 금리 감각 — 금리 = 내 자본비용의 바닥, 허들레이트 설정(valuation 예고)
- 종합 — 금리 인상 1회가 신용창조→은행→내 사업까지 전파되는 풀 추적

## 💡 핵심 분석 대상

```
신용창조 (대출이 예금을 만든다):
  [은행 대차대조표]           [가계 대차대조표]
  자산: 대출채권 +1억    ⇄    자산: 예금 +1억
  부채: 예금   +1억           부채: 대출 +1억
  → 어디서도 기존 예금이 줄지 않았다 = 돈이 "창조"됐다
  → 상환하면 역방향 = 돈이 "소멸"한다
  → 통화량의 주 엔진은 중앙은행이 아니라 은행 대출 수요

할인 — L1 전체의 척추:
  1년 뒤 100만원 = 지금 100/(1+r) 만원   (차익거래 불가에서 유도)
  ┌─ 같은 공식의 변주 ──────────────────────┐
  │ 채권 가격   = Σ 쿠폰·원금의 PV          │ ← 이 레포
  │ LTV         = Σ 미래 마진의 PV          │ ← unit-economics
  │ 기업 가치   = Σ FCF의 PV (DCF)          │ ← valuation
  │ 평생 자산   = 복리(할인의 역방향)        │ ← personal-finance
  └──────────────────────────────────────────┘
  → r(분모)이 움직이면 모든 자산 가격이 같은 방향으로 재평가된다
  → "금리 인상에 성장주가 더 빠지는" 이유: 현금흐름이 먼 미래일수록 분모 충격이 크다

전달 경로 (기준금리 → 내 삶):
  기준금리 ─→ 콜금리 ─→ 은행 조달(은행채·코픽스) ─→ 대출금리
     │            (즉시)         (수주)              (1~3개월)
     └─→ 기대 변화 ─→ 채권금리·환율·자산가격 (발표 순간 선반영)
  → 빠른 건 기대 경로, 느린 건 은행 경로 — 체감 시차의 정체

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 고정 현금흐름 자산의 가치는 금리와 반대로 움직인다
  Boundary  : 신용 리스크가 지배하는 자산(부실 채권)은 금리보다
              생존 확률이 가격을 정한다 — 분모가 아니라 분자 문제
  Rule      : 금리 방향에 베팅하지 말고 노출을 측정한다 — 내 자산·
```
