# Valuation Distilled 레포지토리 제작 프롬프트

나는 "Valuation Distilled" 레포지토리를 만들려고 해.
가치가 어떻게 계산되는지 — DCF를 FCF·WACC·영구성장가치까지 완전 유도하고, 멀티플이 DCF의 압축임을 수식으로 보이고, 스타트업에선 왜 VC Method와 멱법칙이 평가를 지배하는지, 캡테이블에서 희석이 어떻게 누적되는지, Term Sheet의 청산우선권·희석방지 조항이 *왜 존재하는지*를 페이오프 구조로 해부하는 레포야.
"밸류에이션 숫자를 받아드는 것"과 "그 숫자가 어떤 가정의 함수이고 어느 조항이 그 숫자를 뒤집는지 아는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "기업가치 얼마라는 결론을 아는 것과, 가치 = 미래 현금흐름의 할인이라는 한 줄에서 모든 평가법이 유도되고 가정 1%p가 결론을 뒤흔드는 구조를 아는 것은 다르다"

**핵심 차별화**:
1. 한 줄에서 전부 유도 — PV 원리(`money`의 척추)에서 DCF→멀티플→VC Method가 전부 같은 식의 변형임을 보인다
2. 정밀한 오답 — DCF의 본체는 결과값이 아니라 민감도: TV가 80%인 모델, WACC 1%p의 가치 변동을 직접 계산
3. Term Sheet의 페이오프 — 청산우선권·참가·희석방지를 조항 암기가 아니라 페이오프 그래프로(`decision-theory` 옵션성의 실전)
4. 희석의 누적 — 시드→시리즈C까지 캡테이블 시뮬레이션, 옵션풀을 프리에 넣는 트릭의 정량 효과

**타겟 독자**:
- 투자 유치를 앞두고 밸류와 조항의 트레이드오프를 모르는 창업가
- PER이 싸다/비싸다를 말하지만 PER이 무엇의 압축인지 모르는 투자자
- DCF를 엑셀로 만들지만 TV 가정이 결론을 지배함을 모르는 사람
- 청산우선권 1x participating이 뭘 의미하는지 계약서에 사인하고도 모르는 창업자
- `financial-statements`의 FCF와 `unit-economics`를 가치로 연결하려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `money-and-interest-distilled`(할인 — 이 레포는 그 척추의 기업 스케일 전개), `financial-statements-distilled`(FCF의 제조처).
**🤝 시너지**: `unit-economics-distilled`(스타트업 가치의 미시 기초), `decision-theory-distilled`(Term Sheet 조항 = 옵션 페이오프).

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 가치란 무엇인가 (4개 문서)
- 가치의 정의 — 미래 현금흐름의 현재가치, 이 한 줄의 유도(money 직결)와 모든 평가법의 좌표
- 가격 vs 가치 — 투표기와 저울(Graham), 둘의 괴리가 기회이자 함정인 조건
- 정밀한 오답 — 가치평가는 점이 아니라 범위, 민감도가 본체라는 선언
- 누구에게의 가치인가 — 지배권 프리미엄·시너지·소수지분 할인, 같은 회사 다른 가격

### Chapter 2: DCF 완전 유도 (6개 문서)
- FCF의 도출 — EBIT에서 FCFF까지, 무엇을 빼고 더하나(fs 직결), FCFF vs FCFE
- 할인율 — WACC 유도: 자본비용의 의미, 부채의 세금 방패
- CAPM과 그 불만 — 베타의 논리와 실증 문제, 대안(빌드업)과 실무 타협(markets 연결)
- 영구성장가치 — TV = FCF×(1+g)/(r−g) 유도, g와 r의 줄다리기, TV 비중 80%의 의미
- 민감도 분석 — WACC·g 매트릭스, 가정 1%p의 가치 변동률 계산
- DCF 직접 구축 — 3-statement→FCF→가치까지 통합 실습(fs Ch5의 연장)

### Chapter 3: 상대가치 — 멀티플 (5개 문서)
- 멀티플 = DCF의 압축 — PER을 성장·ROE·할인율의 함수로 분해 유도(저스티파이드 PER)
- 멀티플 패밀리 — PER·EV/EBITDA·PSR·PBR, 분자-분모 정합성과 용도
- 비교기업이라는 환상 — 비교가능성의 실제 조건, 피어 선택이 만드는 조작 여지
- 멀티플의 함정 — 이익 조작(fs 분식 직결)·사이클 정점 이익·일회성 항목
- 업종별 핵심 멀티플 — 왜 그 업종은 그 멀티플인가(현금흐름 구조로 설명)

### Chapter 4: 스타트업 가치평가 (6개 문서)
- DCF가 안 통하는 이유 — 음의 현금흐름·극단 분산·옵션성, 그래도 원리는 같다
- VC Method 유도 — 엑싯 가치×목표 배수에서 현재 밸류 역산, 가정의 노출
- 멱법칙 포트폴리오 — VC 수익 구조(한 건이 펀드를 만든다)가 개별 평가에 미치는 영향(mm 멱법칙 직결)
- 단계별 관행 — 시드~시리즈B의 밸류 형성 로직, 한국 시장의 레인지와 동학
- 비교거래·최근 라운드의 함정 — 시장 분위기의 외삽, 다운라운드 회피 심리
- SAFE·전환사채 — 가격을 미루는 구조, 캡·디스카운트의 페이오프

### Chapter 5: 희석과 캡테이블 (5개 문서)
- 캡테이블 수학 — 지분율·신주 발행·기존 주주 희석의 기본 연산
- 프리 vs 포스트 머니 — 정의와 혼동이 만드는 실수(같은 "100억 밸류"의 두 의미)
- 희석의 누적 — 시드→C까지 시뮬레이션, 창업자 지분의 전형적 경로
- 옵션풀 셔플 — 풀을 프리머니에 넣는 관행의 정량 효과(누가 희석을 부담하나)
- ESOP·스톡옵션 — 부여·베스팅·행사의 구조, 직원 관점의 가치 계산

### Chapter 6: Term Sheet — 조항의 존재 이유 (5개 문서)
- 청산우선권 — 1x non-participating의 페이오프 그래프, 다운사이드 보호의 수학
- 참가적 우선주·캡 — 페이오프가 어떻게 달라지나, "더블 딥"의 정량화(dec 옵션성 직결)
- 희석방지 — 풀래칫 vs 가중평균, 다운라운드에서 누가 얼마나 보호받나
- 이사회·동의권·드래그얼롱 — 지배 구조 조항의 가격, 통제권과 밸류의 교환
- 조항 vs 밸류 — 높은 밸류+나쁜 조항 < 낮은 밸류+깨끗한 조항인 시나리오 계산(negotiation 예고)

### Chapter 7: 실전 (5개 문서)
- 상장사 풀 밸류에이션 — 실제 기업 1개를 DCF+멀티플 교차로, 가정 공개
- 라운드 시뮬레이션 — 가상 스타트업 시드→A→B: 밸류·조항·캡테이블 동시 추적
- 가치평가로 거짓말하는 법 — TV 부풀리기·피어 체리피킹·옵션풀 트릭 — 방어용 카탈로그
- 협상에서의 가치 — 가치 범위 산정과 BATNA 설정(negotiation 직결), 다운라운드의 결정
- 종합 — "이 회사 얼마인가"라는 질문 하나를 모든 도구로 통과시키는 통합 케이스

6. **창업자와 투자자 양쪽 시점** — 같은 조항을 두 의자에서 본다

## 💡 핵심 분석 대상

```
모든 평가법은 한 줄의 변형 (L1 척추의 전개):
  가치 = Σ CF_t / (1+r)^t                    ← money에서 유도한 원리
   ├─ 전부 추정해 합산        → DCF
   ├─ 정상 이익 × 압축 계수   → 멀티플 (계수 = 성장·리스크의 패키지)
   └─ 엑싯 한 점만 추정해 역산 → VC Method
  → 기법 선택 = "어느 가정을 노출하고 어느 가정을 숨길 것인가"의 선택

TV의 지배 (DCF의 아킬레스건):
  5년 예측 + 영구성장가치(TV)에서 TV 비중이 70~85%가 흔하다
  TV = FCF×(1+g)/(r−g)  ← 분모가 r−g라서
  r=10%, g=3% → 분모 7% / g를 4%로 → 분모 6% → TV +17%
  → "정교한 5년 예측"보다 g 0.5%p가 결론을 더 흔든다
  → DCF 검토의 첫 질문: "TV 비중과 g의 근거는?"

청산우선권 페이오프 (조항이 밸류를 이기는 구간):
  투자 100억, 지분 20%, 1x non-participating
  수령액
   │        지분 전환이 유리 ╱ (엑싯 > 500억)
   │                      ╱
  100├──────────────────╱   ← 우선권 구간 (엑싯 100~500억: 무조건 100억)
   │      ╱
   0└──╱──────────────────→ 엑싯 가치
  → 엑싯 300억이면: 투자자 100억(33%), 창업자 몫은 지분율보다 작다
  → "포스트 500억 밸류"의 진짜 의미는 조항과 함께만 정해진다

옵션풀 셔플:
  포스트 125억, 투자 25억, "풀 10%는 프리머니에서"
  → 풀 희석을 기존 주주(창업자)만 부담, 투자자 지분은 무손
  → 실효 프리머니 = 명목 프리머니 − 풀 가치: 협상 시 환산해 비교하라

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 밸류는 조항과 한 몸이다 — 헤드라인 숫자 단독 비교를 거부한다
  Boundary  : 조항이 표준(1x non-part, 가중평균)으로 고정된 시장·단계에선
              밸류 비교가 유효하다 — 이때는 조항 협상 여지 자체가 작다
  Rule      : 모든 오퍼는 엑싯 시나리오 3개(낮음·기대·높음)에서 창업자
              실수령액으로 환산해 비교한다. 환산 결과가 헤드라인 밸류
              순위와 다르면 조항이 범인이다 — 그 조항부터 협상한다
```
