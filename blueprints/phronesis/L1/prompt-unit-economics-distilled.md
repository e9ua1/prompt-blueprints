# Unit Economics Distilled 레포지토리 제작 프롬프트

나는 "Unit Economics Distilled" 레포지토리를 만들려고 해.
"한 명 팔 때마다 버는가 잃는가" — 전체 손익이 숨기는 단위의 진실, LTV = m/c 공식이 이탈률에서 유도되는 과정, CAC에 무엇을 넣고 빼는지가 만드는 조작 여지, 코호트가 평균의 거짓말을 어떻게 잡아내는지, 런웨이 계산이 왜 비선형인지를 끝까지 해부하는 레포야.
"대시보드 지표를 보는 것"과 "이 사업이 구조적으로 돈을 버는 기계인지 단위 수준에서 판정하는 것"의 차이를 만드는 레포다.

## 📋 프로젝트 목표

**컨셉**: "전사 매출이 크는 것과, 고객 한 단위의 경제가 양수이고 그 양수가 규모에서 유지되는 것은 다르다"

**핵심 차별화**:
1. LTV 완전 유도 — 월마진 m, 이탈률 c에서 LTV = m/c가 나오는 등비급수 유도, 할인 적용 버전(m/(c+r))까지 — `money`의 할인이 사업 스케일로 재등장
2. CAC의 회계 — 분자에 무엇을 넣나(인건비·툴·브랜드)가 만드는 조작 여지, 혼합 vs 한계 CAC의 분리
3. 코호트 우선주의 — 평균 지표는 코호트 혼합 변화에 속는다(`stat` 심슨의 사업 버전), 코호트 테이블이 진실의 원천
4. 규모의 가정 심문 — "커지면 좋아진다"가 참인 구조와 거짓인 구조(한계 CAC 상승·서비스 비용 비선형)의 구분

**타겟 독자**:
- 매출은 크는데 적자 폭도 같이 크는 이유를 설명 못 하는 창업가
- LTV/CAC 3배를 주문처럼 외우지만 유도 과정과 한계를 모르는 사람
- 평균 리텐션만 보고 코호트별 악화를 놓치는 PM·개발자
- 투자자 미팅에서 단위경제 질문에 막히는 예비 창업가
- `financial-statements`의 회계와 사업 구조 분석을 연결하려는 독자

## 🔗 레포 연결

**⬆️ 선행**: `money-and-interest-distilled`(할인 — LTV의 분모), `financial-statements-distilled`(고정·변동비, 마진의 회계적 출처).
**🤝 시너지**: `statistics-literacy-distilled`(코호트=심슨 방어, 귀인=인과 추론), `pricing-distilled`(L2 — 가격이 단위경제의 가장 민감한 레버).
**🧬 수렴**: `funnel-growth-distilled`(L2 — 리텐션 곡선이 LTV를 정한다), `valuation-distilled`(단위경제가 스타트업 가치의 미시 기초), `compounding-everywhere`(NRR>100%는 고객 기반의 복리).

## 🎯 1단계: 전체 구조 설계

### Chapter 1: 단위경제라는 질문 (4개 문서)
- 전체가 숨기는 것 — 흑자 사업+적자 사업의 합산, 단위로 쪼개야 보이는 진실
- 단위의 정의 — 고객·주문·좌석·기사, 단위 선택이 결론을 바꾼다(마켓플레이스의 양면)
- 두 종류의 적자 — 단위경제 양수의 성장 적자 vs 단위경제 음수의 구조 적자, 판별법
- 규모의 가정 심문 — "커지면 좋아진다"의 조건: 고정비 희석 vs 한계비용 구조

### Chapter 2: 공헌이익 (5개 문서)
- 고정비 vs 변동비 — 회계 분류와 다른 행동 기준 분류, 준변동비의 처리
- 공헌이익 — 단위당 가격−변동비, 고정비 회수 속도의 의미
- 손익분기점 유도 — BEP = 고정비/공헌이익률, 가격·원가 변화의 BEP 민감도
- 영업 레버리지 — 고정비 구조가 이익 변동을 증폭하는 수학(leverage-everywhere 예고)
- 민감도 분석 — 가격 1%·물량 1%·변동비 1% 중 무엇이 이익을 제일 움직이나(pricing 예고)

### Chapter 3: CAC (5개 문서)
- CAC의 회계 — 분자(광고비만? 인건비·툴·콘텐츠?)와 분모(신규? 복귀 포함?)의 선택지
- 혼합 vs 채널별 CAC — 평균이 숨기는 채널 간 격차, 한계 채널의 식별
- 한계 CAC — 채널 포화로 다음 고객이 더 비싸지는 곡선, 성장 계획의 핵심 가정
- 귀인 문제 — 유료가 유기적을 가로채는 구조, 라스트클릭의 거짓말(stat 인과 직결)
- CAC Payback — 회수 기간이 현금 압박을 정한다(fs 운전자본 직결), 기준선과 업종 차

### Chapter 4: LTV (6개 문서)
- LTV 유도 — 등비급수에서 LTV = m/c까지, 가정(일정 이탈률)의 명시
- 리텐션 곡선과 LTV — 곡선 모양(평탄화 vs 지수 감소)이 LTV 공식 적용 가능성을 정한다(funnel 예고)
- 할인된 LTV — m/(c+r), 미래 마진의 현재가치(**money 할인의 재등장**)
- LTV/CAC 3배 규칙 — 어디서 왔고 언제 무의미한가(회수 기간·성장률에 따라)
- LTV 과대평가의 전형 — 초기 코호트 외삽·매출(마진 아님) 사용·이탈률 낙관, 사례 해부
- 확장 수익 — NRR(순매출유지율), 기존 고객이 자라는 구조의 복리(compounding 예고)

### Chapter 5: 코호트 분석 (4개 문서)
- 코호트가 평균을 이긴다 — 코호트 혼합 변화가 만드는 가짜 추세(stat 심슨의 사업 버전)
- 코호트 테이블 — 만들기·읽기, 대각선·세로·가로가 각각 말하는 것
- 성숙과 외삽 — 미성숙 코호트의 외삽 위험, 안전한 외삽 절차
- 세그먼트 단위경제 — 어떤 고객·채널·플랜이 돈이 되나, 평균 고객은 없다

### Chapter 6: 번레이트와 런웨이 (4개 문서)
- 그로스 번 vs 넷 번 — 정의와 용도, 매출 성장이 넷 번을 바꾸는 구조
- 런웨이의 비선형 — 단순 나눗셈의 함정, 성장·이탈 가정에 따른 시나리오 런웨이
- Default Alive/Dead — 폴 그레이엄의 질문, 현재 성장률로 흑자 도달 전 현금이 버티나
- Burn Multiple — 태운 돈 대비 늘린 매출, 자본 효율의 단일 지표와 한계

### Chapter 7: 실전 (5개 문서)
- 모델별 단위경제 — SaaS·커머스·마켓플레이스·구독의 단위 정의와 핵심 지표 차이
- 개선의 우선순위 — CAC↓·LTV↑·마진↑·회수 단축, 민감도로 순서를 정하는 절차
- 투자자의 질문 — 단위경제 슬라이드에 오는 질문과 그 의도(valuation 직결)
- 단위경제로 거짓말하는 법 — 정의 조작·코호트 체리피킹·혼합 CAC — 방어용 카탈로그
- 종합 — 가상 스타트업 1개의 단위경제 풀 모델: 정의→공헌이익→CAC/LTV→코호트→런웨이

→ **총 33개 문서** 목표.

## 🎨 스타일 가이드

1. **결정을 바꾸는가로 검증** — 결정을 바꾸지 못하는 지식은 잡학이다. 모든 지표는 "이 숫자가 바뀌면 무슨 행동이 바뀌나"에 답해야 한다
2. **유도를 생략하지 않는다** — LTV·BEP·런웨이는 공식 암기가 아니라 가정 명시 + 유도
3. **정의의 조작 여지를 먼저** — 모든 지표 문서는 "이 지표를 좋아 보이게 만드는 법"을 포함한다(방어가 목적)
4. **반례에 살아남는가** — 3배 규칙·payback 기준선마다 깨지는 사업 구조를 명시
5. **코호트 없는 평균을 의심** — 평균 지표 주장엔 항상 코호트 분해를 요구하는 습관
6. 리텐션 곡선·코호트 테이블·민감도 토네이도는 다이어그램으로

# 1) LTV 유도 검증

#    → 할인율 1% 추가: m/(c+r) ≈ 16.7만 확인

# 2) 코호트 혼합의 가짜 추세 (심슨 재현)
#    채널A(리텐션 좋음)·채널B(나쁨) 코호트 생성, B 비중 점증
#    → 채널별 리텐션 불변인데 전체 평균 리텐션 악화 재현

# 3) 한계 CAC 곡선
#    채널 포화 모델(CAC = a + b·지출): 예산 2배 시 신규 고객 증가율 계산
#    → 혼합 CAC가 한계 CAC를 숨기는 정도 측정

# 4) 런웨이 시나리오
#    단순(현금/번) vs 성장 반영 vs 이탈 악화 시나리오 3종
#    → Default Alive/Dead 판정이 가정에 따라 뒤집히는 지점

# 5) 공개 기업 역산
#    상장 SaaS·커머스 S-1/IR 1개: 공개 숫자로 CAC·LTV·payback 역산
#    → 회사 발표 지표와의 차이 = 정의 선택의 효과 측정

# 6) 민감도 토네이도
#    가상 모델: 가격/이탈률/CAC/변동비 ±10% → 이익 영향 순위 산출

## 💡 핵심 분석 대상

```
LTV 유도 (등비급수 → m/c):
  생존 확률: 1, (1-c), (1-c)², ...   (c = 월 이탈률)
  LTV = m · Σ(1-c)^t = m/c            (월마진 m, 일정 이탈 가정)
  할인 포함: LTV = m/(c+r)             ← money의 할인이 여기 재등장
  깨지는 조건: 이탈률이 일정하지 않으면(초기 급락 후 평탄) 공식 대신
              코호트 곡선 적분으로 — 공식은 곡선의 요약일 뿐

두 종류의 적자 (구분이 생사를 가른다):
  성장 적자: 단위경제 양수 + CAC 선투자 → 코호트가 익으면 흑자
  구조 적자: 단위경제 음수 → 클수록 더 잃는다 ("볼륨으로 만회" 불가)
  판별: 성숙 코호트의 누적 공헌이익 − CAC > 0 인가?
  → 같은 손익계산서 적자가 정반대의 의사결정(증액 vs 피벗)을 요구

코호트 혼합의 가짜 추세 (심슨의 사업 버전):
  채널A 리텐션 60%, 채널B 40% — 둘 다 불변
  B 비중 30% → 70% 로 증가
  → 전체 평균 리텐션 54% → 46% "악화" (아무것도 나빠지지 않았는데)
  → 평균 지표의 추세는 코호트 분해 전엔 정보가 아니다

회수 기간이 현금을 정한다:
  CAC 12만, 월 공헌이익 1만 → payback 12개월
  월 신규 1000명 성장 시: 매월 1.2억이 12개월간 묶인다
  → LTV/CAC가 5배여도 회수가 길면 성장이 현금을 태운다 (fs 운전자본의 쌍둥이)

판단 규칙 예시 (Principle → Boundary → Rule):
  Principle : 성장 투자는 성숙 코호트의 단위경제가 양수일 때만 증액한다
  Boundary  : 네트워크 효과·규모 임계가 명시적 전략인 사업(마켓플레이스
              초기)은 단위경제 음수 구간이 계획일 수 있다 — 단, 임계
              도달의 가설과 시한이 문서화된 경우에 한한다
  Rule      : 분기마다 최신 성숙 코호트의 [누적 공헌이익 − 한계 CAC]를
              계산한다. 양수면 한계 채널까지 증액, 음수면 마케팅 증액을
              동결하고 가격·이탈·원가 중 민감도 1위부터 고친다
```
