# Embodied & Enactive Mind Distilled 레포지토리 제작 프롬프트

나는 "Embodied & Enactive Mind Distilled" 레포지토리를 만들려고 해.
"마음은 뇌에 있다"고 말하는 것과, **뇌-신체-환경이 하나의 결합 시스템을 이루며 마음이 그 시스템 전체의 속성이라는 주장이 어떤 실험·논증·현상학적 통찰에서 나오는지** — 그리고 이것이 "뇌에서 계산이 일어난다"는 사실을 부정하는 것이 아니라 계산의 단위를 다르게 설정하는 것임을 — 이해하는 것은 다르다.
로봇이 "정보를 처리하고 행동을 계획한다"는 것과, **Rodney Brooks가 왜 그 설계 방식을 버리고 "표상 없는 로봇"을 만들었는지** — 포섭 아키텍처가 어떻게 내부 표상 없이 복잡한 환경 적응 행동을 만들어내는지를 — 그리고 그 성공과 한계가 무엇인지를 — 이해하는 것은 다르다.
"감각운동 우연성"을 전문 용어로 아는 것과, **지각이 내부 표상의 재활성화가 아니라 세계와의 감각운동 커플링임을 — 색깔을 "본다"는 것이 내부 색 표상이 아니라 색에 대한 감각운동 지식(이 조명에서 어떻게 움직이면 어떤 변화가 일어나는가)임을** — 직접 추적하는 것은 다르다.
4E 인지(체화·내장·행화·확장)가 단순한 반직관적 주장이 아니라 신경과학·로봇공학·현상학·진화생물학의 수렴하는 증거에서 나온 주장임을 — 그리고 그것이 AI 개발·의식 연구·임상 실천에 어떤 함의를 갖는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "마음은 뇌 안에만 있지 않다 — 4E 인지의 논증·증거·함의, 그리고 표상 없는 마음의 가능성과 한계"

**핵심 차별화**:
1. **4E를 각각 분리해서** — 체화(Embodied)·내장(Embedded)·행화(Enactive)·확장(Extended)이 각각 어떻게 다른 주장이고, 어떤 독립 증거를 가지며, 어떻게 연결되는지를
2. **감각운동 우연성을 핵심으로** — O'Regan·Noë의 이론이 어떻게 지각을 "행동 잠재성"으로 재기술하는지를 구체적으로. 색 지각·공간 지각·객체 지각에서 직접 적용
3. **표상 없는 AI와의 연결** — Brooks의 포섭 아키텍처가 어떻게 내부 표상 없이 작동하는지, 그 성공과 실패가 체화 인지의 주장에 어떤 증거가 되는지
4. **기능주의에 대한 도전의 정밀화** — 체화 인지가 기능주의를 부정하는 것인지, 정교화하는 것인지, 아니면 다른 것인지를 명시

**타겟 독자**:
- "마음 = 뇌"를 당연하게 받아들이는 사람
- 4E 인지를 들어봤지만 각각이 무엇이고 어떤 증거가 있는지 모르는 사람
- 표상 없는 인지가 가능한지 모르는 사람
- 체화 인지가 AI 개발에 어떤 함의를 갖는지 보고 싶은 사람
- 메를로퐁티의 현상학이 신경과학과 어떻게 연결되는지 궁금한 사람

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 고전적 계산주의를 넘어서 (4개 문서)
- **고전 계산주의의 가정** — 뇌 = 입력·처리·출력, 표상이 중심, 몸과 환경은 주변
- **고전 계산주의의 문제들** — 프레임 문제·심볼 접지·속도 문제·상황 의존성
- **4E 인지의 등장** — Varela·Thompson·Rosch의 *The Embodied Mind*(1991), 하이데거와의 연결
- **4E의 전체 지도** — 체화·내장·행화·확장이 어떻게 다른 주장이고 어떻게 연결되는가

### Chapter 2: 체화(Embodied) — 몸이 마음을 만든다 (6개 문서)
- **체화 인지의 핵심 주장** — 마음의 구조가 신체 구조에 의해 형성된다
- **체화된 개념** — 추상 개념이 구체적 신체 경험에 기반한다(Lakoff), 감각운동 시뮬레이션
- **신체 피드백 효과** — 자세·표정·움직임이 사고와 감정에 미치는 영향, 증거와 논란
- **발달과 체화** — 어린이가 신체 경험을 통해 개념을 구축하는 방식(Piaget)
- **신체 도식** — 메를로퐁티의 신체 도식 개념, 맹인의 지팡이가 신체의 일부가 되는 방식
- **체화와 신경과학** — 운동 계획·내수용감각·체성 감각이 "순수 인지" 과제에 개입하는 증거

### Chapter 3: 내장(Embedded) — 환경이 인지를 구성한다 (4개 문서)
- **내장 인지의 주장** — 인지는 환경과의 연속적 상호작용에서 일어난다, 오프로딩
- **인지 오프로딩** — 외부 구조를 이용해 인지 부담을 줄이는 방식(메모지·달력·공간 배치)
- **상황 인지** — 과제 환경이 인지를 어떻게 구조화하는가(Hutchins의 선박 항법 연구)
- **내장 vs 체화의 차이** — 두 주장이 어떻게 다르고, 어떤 증거가 각각을 지지하는가

### Chapter 4: 행화(Enactive) — 지각은 행동 잠재성이다 (6개 문서)
- **행화 인지의 핵심** — 지각은 표상의 재활성화가 아니라 세계와의 감각운동 커플링
- **감각운동 우연성** — O'Regan·Noë: 색을 본다는 것은 색에 대한 감각운동 지식을 행사하는 것
- **색 지각에서의 감각운동 우연성** — 조명이 바뀌어도 색이 같아 보이는 이유를 내부 표상이 아닌 행동 잠재성으로
- **변화 맹시의 행화 해석** — 표상이 아니라 행동 잠재성이 지각의 단위임을 지지하는 증거
- **행화 인지의 신경 증거** — 운동 계획·미러 뉴런·감각운동 통합의 연구
- **행화 vs 예측처리** — 두 이론이 어떻게 다르고, 어떻게 통합될 수 있는가

### Chapter 5: 확장(Extended) — 마음은 두개골 밖으로 나간다 (5개 문서)
- **Clark & Chalmers의 "확장된 마음"** — 오토와 잉가: 외부 노트북이 마음의 일부인가
- **결합 원칙(Parity Principle)** — 내부 과정이 외부 과정과 기능적으로 동일하면 동등하게 취급
- **확장된 마음의 사례들** — 스마트폰·언어·수학적 도구가 마음을 어떻게 확장하는가
- **확장 비판** — 모든 것이 마음인가, 범위 문제, 내부·외부의 비대칭성
- **확장 인지와 AI** — LLM이 인간 인지를 확장하는 방식, 인지 오프로딩의 급진적 형태

### Chapter 6: 표상 없는 인지와 로봇공학 (5개 문서)
- **Brooks의 포섭 아키텍처** — 표상 없이 반응적으로 작동하는 로봇의 설계, "세계가 자체 모델"
- **포섭 아키텍처의 성공** — 어떤 과제에서 표상 없는 접근이 표상 기반보다 나은가
- **포섭의 한계** — 목표 지향적 행동·추론·언어에서 포섭의 실패
- **체화 AI** — 신체와 환경을 가진 AI 시스템이 어떻게 다른 능력을 보이는가
- **심볼 접지 문제** — 기호가 어떻게 세계와 연결되는가, 체화 인지의 해결 시도

### Chapter 7: 종합·계산 (3개 문서)
- **감각운동 우연성 시뮬레이션** — 색 지각을 행동 잠재성으로 재기술하는 모델(Python)
- **포섭 아키텍처 구현** — 간단한 환경에서 표상 없는 반응 로봇 시뮬레이션(Python)
- **종합** — "마음이 어디까지 퍼져있는가"의 현재 지도, 열린 질문들

## 🎨 스타일 가이드

1. **4E를 각각 독립적으로** — 체화·내장·행화·확장은 서로 다른 주장이다. 하나가 맞다고 모두 맞는 것이 아니다. 각각의 독립 증거를 제시
2. **감각운동 우연성을 구체적으로** — 추상적 주장이 아니라, 색 지각·공간 지각·객체 지각에서 구체적으로 어떻게 "행동 잠재성"으로 기술되는지
3. **포섭 아키텍처를 공정하게** — Brooks의 접근이 어떤 과제에서 성공하고 어디서 실패하는지를. 체화 인지의 증거이면서 한계이기도 하다
4. **기능주의와의 관계를 명확히** — 체화 인지가 기능주의를 완전히 부정하는 것이 아니라, 기능의 단위를 뇌에서 신체-환경 시스템으로 확장하는 것으로 해석 가능
5. **확장된 마음을 과대포장하지 않는다** — Clark & Chalmers의 주장이 매력적이지만 진지한 반론이 있다. 두 측면 모두
6. 4E 지도·감각운동 커플링 구조·포섭 아키텍처 층위·내부-외부 경계 문제는 다이어그램으로

## 🔬 검증 프로토콜

```python
import numpy as np

# 1) 감각운동 우연성 모델 — 색 지각을 행동 잠재성으로
class SensoriMotorColorPerception:
    """
    색 지각 = 조명 변화에 대한 반사율의 감각운동 우연성 지식
    "이 조명 방향에서 이렇게 움직이면 이 색 변화가 일어난다"
    """
    def __init__(self, n_orientations=8, n_distances=4):
        # 각 방향·거리에서 색의 반사율 변화 패턴
        self.sm_contingencies = np.random.randn(n_orientations, n_distances, 3)
    
    def perceive_color(self, illumination, surface):
        """
        색을 내부 표상이 아니라 감각운동 우연성 벡터로 표현
        → 조명이 바뀌어도 우연성 패턴이 동일 = 색 항등성
        """
        sensorimotor_signature = surface * self.sm_contingencies
        return sensorimotor_signature  # 이것이 색의 표상

# 2) 포섭 아키텍처 (Subsumption Architecture)
class SubsumptionRobot:
    """
    Brooks의 설계: 층위별 행동, 표상 없음
    더 높은 층이 낮은 층을 "포섭(subsume)"
    """
    def __init__(self):
        self.sensor_data = {}
    
    def update_sensors(self, obstacles, goal_direction, bumped):
        self.sensor_data = {
            'obstacles': obstacles,  # 전방 장애물
            'goal':      goal_direction,  # 목표 방향
            'bumped':    bumped  # 충돌 감지
        }
    
    def layer0_avoid_contact(self):
        """가장 낮은 층: 충돌 회피"""
        if self.sensor_data.get('bumped', False):
            return 'backward'
        if self.sensor_data.get('obstacles', False):
            return 'turn'
        return None
    
    def layer1_wander(self):
        """랜덤 탐색"""
        return 'forward' if np.random.random() > 0.2 else 'turn'
    
    def layer2_explore(self):
        """목표 방향으로 탐색"""
        goal = self.sensor_data.get('goal', 0)
        if abs(goal) < 0.3:  # 목표 방향 정렬
            return 'forward'
        return 'turn_toward_goal'
    
    def act(self):
        """포섭: 상위 층이 하위 층 억제"""
        # 층 0이 위험 감지하면 무조건 우선
        action = self.layer0_avoid_contact()
        if action: return action
        # 층 2가 목표 있으면 층 1 포섭
        action = self.layer2_explore()
        if action: return action
        # 기본: 탐색
        return self.layer1_wander()
    # → 내부 세계 모델 없이 복잡한 행동 가능
    # → 그러나 계획·언어·추상 추론 불가

# 3) 인지 오프로딩 효과 시뮬레이션
def cognitive_offloading(task_complexity, external_memory_size):
    """
    외부 기억(메모장, 공간 배치)이 작업기억 부담을 어떻게 줄이는가
    """
    wm_capacity = 4  # 작업기억 용량 (Cowan)
    if task_complexity <= wm_capacity:
        errors = task_complexity * 0.05  # 낮은 오류율
    elif task_complexity <= wm_capacity + external_memory_size:
        errors = (task_complexity - external_memory_size) * 0.05
    else:
        errors = task_complexity * 0.3   # 높은 오류율
    return errors

# → 외부 기억이 인지 성능을 어떻게 향상시키는가 시뮬레이션
```

## 💡 핵심 분석 대상

```
4E 인지의 지도:

  체화(Embodied):     마음의 구조 ← 신체 구조
  ↓ 범위 확장
  내장(Embedded):     인지 ← 환경과의 상호작용
  ↓ 더 급진적
  행화(Enactive):     지각 = 행동 잠재성, 표상 최소화
  ↓ 가장 급진적
  확장(Extended):     마음의 일부가 두개골 밖에 있다

감각운동 우연성 — 색 지각의 재기술:
  고전: "빨간 색 표상이 활성화된다"
  행화: "이 표면에서 조명 방향을 바꾸면
         이 패턴의 반사율 변화가 일어난다는
         감각운동 지식을 행사한다"
  
  핵심 차이: 표상 vs 행동 잠재성
  
  강점: 색 항등성·조명 변화에 강건
  약점: 추상 개념(정의·자유)을 어떻게 설명하는가

포섭 아키텍처의 교훈:
  성공: 장애물 회피, 방향 탐색, 환경 적응
        → "세계가 자체 모델" — 내부 지도 불필요
  
  실패: 계획 (3단계 이상 미래 시뮬레이션)
         언어·추론·추상 목표
         낯선 환경으로의 전이
  
  ⇒ 표상 없는 인지의 가능성과 한계
  ⇒ 기능주의 vs 행화의 경계선을 정확히 그어줌

체화와 경험:
  체화 인지가 설명하는 것:
  ├─ 왜 추상 개념이 신체 은유를 사용하는가
  ├─ 왜 자세·움직임이 인지에 영향 미치는가
  └─ 왜 인지 오프로딩이 효과적인가
  
  설명적 간극이 여전히 남는 곳:
  → 신체가 마음의 일부라도, 왜 신체 경험에
    *느낌*이 있는가는 여전히 남는다
  ⇒ 체화 인지는 간극의 위치를 바꾸지 않는다
    (뇌에서 신체-환경 시스템으로)
    그러나 간극 자체는 사라지지 않는다
```
