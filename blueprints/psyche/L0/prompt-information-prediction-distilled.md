# Information & Prediction Distilled 레포지토리 제작 프롬프트

나는 "Information & Prediction Distilled" 레포지토리를 만들려고 해.
"뇌는 정보를 처리한다"고 말하는 것과, **섀넌의 정보가 정확히 무엇이고, 그것이 의미·경험과 어떻게 다른지** — 정보이론이 뇌를 기술하는 언어가 될 수 있는 조건과 한계를 — 이해하는 것은 다르다.
"베이즈 추론"을 통계 기법으로 아는 것과, **뇌 전체가 하나의 베이즈 추론 기계라는 주장이 어떤 근거에서 나오며, 지각·학습·행동이 사전확률과 가능도의 통합으로 설명될 때 무엇이 새롭게 보이는지**를 — 그리고 그 설명이 어디서 멈추는지를 — 추적하는 것은 다르다.
능동 추론(active inference)을 "새 용어"로 보는 것과, 그것이 **지각과 행동을 통일하는 단일 원리 — 자유에너지 최소화 — 로 기술하는 시도**이고, 뇌가 왜 세계를 *수동적으로 수신*하는 것이 아니라 *능동적으로 예측하고 오차를 최소화*하는지를 아는 것은 다르다.
정보·예측·자유에너지가 마음의 언어가 될 수 있는지를 — 그리고 그 언어로 표현되지 않는 경험의 잔여물이 무엇인지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "뇌는 예측 기계다 — 정보이론과 베이즈 추론으로 마음의 알고리즘을 기술한다"

**핵심 차별화**:
1. **정보이론의 정밀한 적용** — 섀넌 정보가 의미·경험과 다른 점, 뇌 과학에서 정보이론을 쓸 때 정확히 무엇을 말하는 것인지, 그 남용 진단
2. **베이즈 뇌 가설의 논증 구조** — 베이즈 정리에서 지각·학습·의사결정이 어떻게 통일되는지, 이것이 단순한 은유가 아니라 구체적 예측을 낳는다는 것을
3. **예측 처리(Predictive Processing)를 층위별로** — 계층적 예측 오류 전파, 하향(예측)과 상향(오류) 신호의 분리, 이것이 Marr의 어느 층위 설명인가(→ levels L0)
4. **자유에너지 원리의 야망과 한계** — 칼 프리스턴의 통일 이론: 지각·행동·학습·생명이 모두 자유에너지 최소화, 그 수학적 구조와 경험의 설명 가능성

**타겟 독자**:
- "뇌는 정보를 처리한다"는 말이 무엇을 뜻하는지 정확히 모르는 사람
- 베이즈 추론을 통계 기법으로만 알고 뇌과학에서의 의미를 모르는 사람
- 예측 처리 이론을 들었지만 왜 그것이 중요한지 실감 못 하는 사람
- 자유에너지 원리를 "어려운 수식"으로 피하는 사람
- 정보·예측이 경험·의식과 어떻게 연결되고 어디서 한계를 갖는지 보고 싶은 사람

**선행 학습**:

- `computation-representation-distilled`(L0) — **필수**. 표상으로서의 예측

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 정보이론의 뇌과학 (5개 문서)
- **섀넌 정보란** — 불확실성의 감소, H = -Σ p log p, 의미와 무관한 정보
- **상호정보량(Mutual Information)** — 두 변수가 얼마나 연관됐는가, 뇌에서의 측정
- **정보이론의 뇌과학 적용** — 신경 부호의 효율성, 희소 부호화, 채널 용량과 뇌
- **정보 ≠ 의미 ≠ 경험** — 섀넌 정보가 하지 않는 말들, 남용의 진단
- **통합 정보(φ)의 첫 등장** — IIT의 정보는 다르다, Tononi의 φ 예고(→ theories L4)

### Chapter 2: 베이즈 추론 — 확률로 보는 마음 (5개 문서)
- **베이즈 정리의 구조** — P(H|E) = P(E|H)P(H)/P(E), 사전·가능도·사후의 의미
- **베이즈 뇌 가설** — 뇌는 세계의 베이즈 모델을 유지하고 갱신한다
- **지각의 베이즈 해석** — 감각 신호 = 증거, 지각 = 최적 추론, 착시의 재해석
- **학습의 베이즈 해석** — 새 경험 → 사전확률 갱신, 강화학습과의 연결(→ L2)
- **베이즈 비판** — 계산 비용·사전확률의 출처·비합리적 인간 행동

### Chapter 3: 예측 처리 이론 (6개 문서)
- **예측 처리의 핵심 아이디어** — 뇌는 수동 수신기가 아니라 능동 예측 기계
- **계층적 예측 오류 전파** — 위→아래: 예측(하향), 아래→위: 예측 오류(상향)
- **정밀 가중치(Precision Weighting)** — 오류에 얼마나 주의를 기울일 것인가, 주의의 설명
- **지각 = 제어된 환각** — 우리는 예측된 세계를 본다, 착각·환각·꿈의 통일적 설명
- **예측 처리와 뉴런** — 이 이론이 신경 구현과 어떻게 맞는가, 예측 부호화의 신경 증거(→ L1)
- **예측 처리의 한계** — 어떤 현상이 설명되지 않는가, 경험의 현상적 특성은

### Chapter 4: 능동 추론과 자유에너지 원리 (5개 문서)
- **자유에너지란** — 베이즈 추론에서 나오는 상한(upper bound), 최소화하면 왜 좋은가
- **지각과 행동의 통일** — 능동 추론: 세계를 예측에 맞게 바꾸거나(행동), 예측을 갱신하거나(지각)
- **생성 모델** — 세계의 내부 모델, 무엇을 생성하는가, 어떻게 학습되는가
- **자유에너지와 놀라움** — -log P(감각 신호): 예상 못 한 것을 피하는 것이 왜 생존과 연결되나
- **자유에너지의 야망** — 생명·적응·학습·지각·행동을 하나로: 통일 이론인가, 과대포장인가

### Chapter 5: 정보와 의식 (4개 문서)
- **통합 정보 이론(IIT) 입문** — φ가 크면 의식이 있다, 그 논리와 수학 구조(→ theories L4)
- **전역 작업공간과 정보** — GWT에서 의식 = 정보의 전역 방송(→ theories L4)
- **정보이론으로 의식을 측정하는 시도** — 마취 깊이·PCI·φ의 실험적 적용
- **정보에서 경험으로** — 정보이론이 경험의 *내용*은 설명하지만, *있다는 것*은 설명하는가(→ hard-problem L4)

### Chapter 6: 예측 오류와 정신병리 (4개 문서)
- **조현병 = 예측 오류 조절 실패** — 정밀 가중치 이상으로 본 조현병의 증상
- **우울증 = 비관적 사전확률** — 음성적 사전 믿음이 모든 경험을 채색하는 방식
- **자폐 = 과도한 정밀도** — 예측보다 오류를 과신, 감각 과민·반복 행동의 예측 처리 해석
- **이 모델의 임상적 가치와 한계** — 예측 처리가 정신의학에 가져오는 것과 과대해석 경계

### Chapter 7: 종합·계산 (5개 문서)
- **베이즈 추론 구현** — 간단한 지각 모델: 가우시안 사전확률 + 가능도 → 사후확률(Python)
- **예측 오류 최소화 시뮬레이션** — 1D 예측 처리 모델, 하향/상향 신호 시각화(Python)
- **자유에너지 계산** — 간단한 생성 모델에서 자유에너지 계산 및 최소화(Python)
- **통합 정보 φ 계산** — 작은 네트워크에서 φ 수치 계산(Python)
- **종합** — "뇌는 예측 기계다"의 통합, 그리고 경험이 남기는 잔여(→ L4, L6)

→ **총 34개 문서** 목표.

    # 가우시안 케이스: 사후 = 가우시안
    posterior_var  = 1 / (1/prior_var + 1/likelihood_var)
    posterior_mean = posterior_var * (prior_mean/prior_var + likelihood_mean/likelihood_var)
    return posterior_mean, posterior_var

    prediction_error = observation - prediction
    update           = precision_likelihood / (precision_prior + precision_likelihood) * prediction_error
    new_prediction   = prediction + update
    return new_prediction, prediction_error

def free_energy(q_mean, q_var, p_mean, p_var, observation, likelihood_var):

## 💡 핵심 분석 대상

```
예측 처리 계층:
  높은 층 (추상적 예측)
       │  하향: "이것은 얼굴이다" 예측
       ▼
  중간 층 (부분 예측)
       │  하향: "눈·코·입 위치" 예측
       ▼
  낮은 층 (감각 예측)
       │  ← 상향: 예측 오류 (실제 - 예측)
  감각 입력

  → 오류가 작으면: 예측 갱신 없음 (지각 = 확인)
  → 오류가 크면:   위 층으로 오류 전파 → 모델 갱신
  ⇒ 지각 = 최적 추론, 착각 = 강한 사전확률의 승리

자유에너지의 의미:
  F = 놀라움(surprise)의 상한
  F = KL[q||p] - log P(관측|q)
  ↑ 이 두 항을 동시에 최소화
       ├─ 세계를 예측에 맞게 바꾸기 (행동, 능동 추론)
       └─ 예측을 세계에 맞게 바꾸기 (지각, 수동 추론)
  ⇒ 지각과 행동의 통일

경험의 잔여:
  정보이론으로 설명되는 것:
  ├─ 어떤 신호를 주의하는가 (정밀 가중치)
  ├─ 어떻게 예측이 갱신되는가 (베이즈 갱신)
  └─ 어떤 행동이 선택되는가 (자유에너지 최소화)
  
  설명되지 않는 것:
  → 왜 거기에 *느낌*이 있는가
  → 빨강이 "이런" 느낌인 것은 어디서 오는가
  ⇒ 설명적 간극의 정보이론적 위치 (→ L4)
```
