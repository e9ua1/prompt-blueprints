# Levels of Explanation Distilled 레포지토리 제작 프롬프트

나는 "Levels of Explanation Distilled" 레포지토리를 만들려고 해.
"뉴런이 발화하니까 고통스럽다"고 말하는 것과, **그 두 진술이 다른 설명 층위에 속하며 전자가 후자를 자동으로 설명하지 않는다**는 것을 — Marr의 세 층위가 왜 그 구분을 정밀하게 가능하게 하는지를 — 이해하는 것은 다르다.
환원주의를 "모든 것은 물리학으로 설명된다"고 받아들이는 것과, **환원이 정확히 무엇이고, 무엇을 설명하고, 어디서 층위 이동이 일어나는지**를 — 다중 실현 가능성이 왜 기능적 설명을 물리적 설명으로 대체할 수 없게 만드는지를 — 추적하는 것은 다르다.
컴퓨터 프로그램이 하드웨어로 "완전히 설명된다"는 말이 무엇을 놓치는지와, **같은 소프트웨어가 다른 하드웨어에서 구현되는 사실이 알고리즘 층위의 독립적 실재성을 어떻게 보여주는지**를 아는 것은 다르다.
설명의 층위가 어떻게 쌓이는지를 — 그리고 마음을 탐구할 때 우리가 어느 층위에서 질문하고 있는지를 항상 추적하는 훈련이 이 연구소 전체에서 왜 필수인지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "층위를 혼동하면 설명을 못 본다 — Marr의 세 층위로 마음 과학의 설명 구조를 해부한다"

**핵심 차별화**:
1. **Marr의 세 층위를 정밀하게** — 계산(무엇을 하나) · 알고리즘(어떻게 하나) · 구현(무엇으로 하나). 세 층위가 독립적인 이유와, 어떤 질문은 어느 층위에서만 답할 수 있는지를 구체적 사례로
2. **다중 실현 가능성의 함의** — 같은 알고리즘이 다른 기질에서 구현된다는 사실이 기능주의의 근거이자 물리 환원의 한계이기도 한 이유(→ mind-body-map, → computational-mind L3)
3. **층위 혼동의 진단** — "뉴런이 곧 마음"·"경험은 환상"·"뇌가 결정을 내린다"가 어떤 층위 혼동을 저지르는지를 — 범주 오류의 정밀 해부
4. **마음 과학 전체의 설명 지도** — 신경과학(구현)·인지과학(알고리즘)·의식 연구(계산+1인칭)가 각각 어느 층위에서 작동하는지 배치

**타겟 독자**:
- "뇌가 마음을 만든다"를 완전한 설명으로 받아들이는 사람
- 신경과학이 발전하면 심리학이 불필요해진다고 생각하는 사람
- 다중 실현 가능성의 의미와 기능주의와의 연결을 모르는 사람
- 어떤 현상을 설명할 때 어느 층위의 설명을 요구해야 하는지 혼란스러운 사람
- 이 연구소(IQ Psyche Lab)가 왜 7개 층위로 나뉘는지 원리적으로 알고 싶은 사람

**선행 학습**:
- `mind-body-map-distilled`(L0) — **필수**. 설명적 간극·층위 문제의 첫 번째 만남

## 🔗 레포 연결

**⬆️ 선행**: `mind-body-map-distilled`(L0).
**🤝 시너지 (L0 내부)**: `computation-representation-distilled`(알고리즘 층위에서 표상이란 무엇인가), `information-prediction-distilled`(정보 처리 층위에서 본 마음), `first-person-methods-distilled`(1인칭 기술은 어느 층위인가).
**🪜 창발 (위 레이어가 다시 쓴다)**:
- `neurons-neural-codes-distilled`(L1) — 구현 층위의 실체: 뉴런이 무엇을 계산하는가
- `perception-distilled`(L2) — 알고리즘 층위의 지각: 지각을 Marr식으로 분해하면
- `computational-mind-distilled`(L3) — 마음 = 계산인가, 층위 질문의 정점
- `hard-problem-distilled`(L4) — 세 층위 어디에도 들어맞지 않는 경험이 있다
- `emergence-distilled`(L6) — 층위들 사이의 창발: 아래 층위가 위 층위를 어떻게 만드나

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 층위의 필요 (4개 문서)
- **설명이란 무엇인가** — "왜"에 답하는 것, 동일 현상의 다른 기술이 어떻게 모두 참일 수 있는가
- **층위 혼동의 사례들** — "사랑은 뇌의 화학반응" · "자유의지는 착각" · "결정은 뉴런이 한다" — 어떤 층위를 어떻게 혼동하는가
- **왜 마음 과학에서 특히 중요한가** — 신경과학·심리학·철학이 같은 현상의 다른 층위를 보는 이유
- **Marr의 배경과 동기** — 시각 계산 이론, 왜 시각 연구에서 층위 구분이 탄생했나

### Chapter 2: Marr의 세 층위 (5개 문서)
- **계산 층위 (Computational)** — 시스템이 *무엇을* 하는가, 무엇을 달성하는가, 왜 그것인가
- **알고리즘 층위 (Algorithmic)** — *어떻게* 하는가, 절차와 표상, 입력-처리-출력
- **구현 층위 (Implementational)** — *무엇으로* 하는가, 기질, 물리적 실체
- **층위들의 독립성** — 같은 계산을 다른 알고리즘으로, 같은 알고리즘을 다른 구현으로
- **층위 간 하향/상향 제약** — 구현이 알고리즘을 제약하는 방식, 계산이 알고리즘을 안내하는 방식

### Chapter 3: 다중 실현 가능성 (5개 문서)
- **다중 실현이란** — 고통이 인간의 C섬유, 문어의 다른 뉴런, 원칙적으로 실리콘에서도 구현 가능한가
- **다중 실현이 기능주의를 낳는다** — 마음의 본질은 기능(알고리즘), 구현이 아니라는 주장의 근거
- **다중 실현과 환원의 한계** — 알고리즘 층위의 법칙이 구현 층위의 언어로 완전히 표현되지 않는 이유
- **반론: 실제로는 좁게 실현된다** — Jaegwon Kim의 비판, 실질적으로 같은 종류만 같은 마음?
- **다중 실현과 AI의 의식** — 기능주의가 맞다면 적절한 기능을 가진 AI는 의식을 가지는가(→ L3)

### Chapter 4: 층위별 설명의 분석 (5개 문서)
- **신경과학의 층위** — 뉴런·시냅스·회로는 주로 어느 층위, 그것이 설명할 수 있는 것과 없는 것
- **인지심리학의 층위** — 기억·주의·지각은 알고리즘 층위, 신경과학과 어떻게 다른 설명을 하는가
- **정신분석·현상학의 층위** — 이 접근들은 어느 층위에서 작동하는가, 과학에서의 위치
- **의식 연구의 특수성** — NCC(신경 상관물)는 어느 층위, 경험 자체는 층위 체계 안에 있는가
- **층위와 창발** — 위 층위의 속성이 아래 층위에서 '나오는' 방식의 정밀한 기술(→ emergence L6)

### Chapter 5: 범주 오류와 그 진단 (5개 문서)
- **범주 오류란** — Ryle의 개념, "마음"을 물리 객체처럼 찾으려는 오류
- **"뇌가 결정한다"의 오류** — 어느 층위에서 결정이 이루어지는가, 자유의지 논쟁과의 연결(→ L5)
- **"경험은 환상이다"의 오류** — 어느 층위에서 환상이고 어느 층위에서 실재인가
- **"AI는 정말 이해하지 못한다"의 구조** — 알고리즘 층위와 계산 층위의 혼동 진단(→ L3)
- **범주 오류를 교정하는 훈련** — 질문을 받았을 때 어느 층위를 요구하는지 먼저 묻기

### Chapter 6: 마음 과학의 설명 지도 (5개 문서)
- **이 연구소 7층위와 Marr의 관계** — L1~L5가 각각 어느 Marr 층위를 주로 다루는가
- **신경과학 ↔ 인지과학 ↔ 의식 연구** — 같은 현상의 세 층위 기술이 어떻게 보완하는가
- **위에서 아래로: 하향 인과** — 계산 목표가 알고리즘을 형성하고 구현을 제약하는 방식
- **아래에서 위로: 창발** — 뉴런에서 인지가, 인지에서 자아가 나오는 방식의 층위 기술
- **설명 완전성의 기준** — 한 현상이 "완전히 설명됐다"는 것은 어떤 조건인가

### Chapter 7: 종합·적용 (4개 문서)
- **통증의 세 층위 분석** — 고통이라는 하나의 현상을 Marr의 세 층위로 완전히 분해(사례 연구)
- **시각의 세 층위 분석** — Marr 자신의 예시를 따라 엣지 검출에서 객체 인식까지(Python 시각화)
- **층위 매핑 실습** — 신경·인지·의식 논문들을 읽고 어느 층위의 설명인지 분류 훈련
- **종합** — "층위를 묻지 않으면 설명을 못 본다" — Psyche Lab 전체의 설계 원리

## 🎨 스타일 가이드

1. **층위를 항상 먼저 묻는다** — 어떤 설명을 만나든 "이것은 어느 층위의 설명인가"를 먼저 물어 훈련한다
2. **층위 혼동을 교정하되 조롱하지 않는다** — "뇌가 결정한다"는 말이 어떤 층위를 혼동하는지 정밀하게 보여주되, 그 직관의 힘도 인정한다
3. **Marr를 넘어서** — Marr의 틀이 시각 이외 분야에서 어떻게 변형·확장되는지를 추적, 틀 자체의 한계도 명시
4. **1인칭을 층위 체계 안에 위치시킨다** — 경험이 세 층위 중 어디에 속하는가, 아니면 층위 체계를 벗어나는가를 정직하게
5. **이 연구소의 설계 원리로** — 왜 Psyche Lab이 뉴런(L1)→인지(L2)→계산(L3)→의식(L4)→자아(L5)로 쌓였는지, Marr의 틀로 설명
6. 층위 구조·다중 실현·하향/상향 제약은 다이어그램으로

## 💡 핵심 분석 대상

```
Marr의 세 층위:

계산 층위 (What & Why)
  "3D 장면에서 표면 불연속(경계)을 찾는다"
  "왜? 물체 인식·파지를 위해"
       │
       ▼
알고리즘 층위 (How)
  "강도 변화 → Sobel 연산 → 엣지 후보 → NMS 후처리"
  표상: 픽셀 배열, 방향 지도
       │
       ▼
구현 층위 (With What)
  V1 단순 세포 · 병렬 회로 (인간)
  CUDA GPU (컴퓨터)
  ⇒ 알고리즘이 같으면 구현이 달라도 된다 = 다중 실현

층위 독립성의 함의:
  신경과학(구현)이 심리학(알고리즘)을 대체하지 않는다
  심리학이 철학(계산)을 대체하지 않는다
  ⇒ 이 연구소가 L1~L5로 쌓인 이유

층위 혼동의 전형:
  "사랑은 도파민이다"
       │  구현 층위 기술
       │  ≠ 알고리즘 층위("보상 예측 오차가 강화한다")
       │  ≠ 계산 층위("가치 있는 관계를 유지하고 확장한다")
  ⇒ 셋 다 참, 셋 다 불완전

경험의 위치 문제:
  계산 층위: 목표(생존·번식)로 기술 가능?
  알고리즘 층위: 처리 과정으로 기술 가능?
  구현 층위: 뉴런 상태로 기술 가능?
       │
       ▼
  경험으로서 *있다*는 것 → 세 층위 어디에도 온전히 들어맞지 않는다
  ⇒ 설명적 간극의 층위론적 위치 (→ L4 Hard Problem)
```
