# Methods for the First Person Distilled 레포지토리 제작 프롬프트

나는 "Methods for the First Person Distilled" 레포지토리를 만들려고 해.
"경험을 과학으로 다룰 수 없다"고 포기하는 것과, **1인칭 데이터를 3인칭 방법론으로 접근할 수 있는 정밀한 방법이 있고, 그 각각이 어떤 조건에서 신뢰 가능한지**를 — 내성(introspection)이 얼마나 믿을 수 있으며 어떤 조건에서 무너지는지를 — 이해하는 것은 다르다.
신경 상관물(NCC)을 "의식의 신경 기반을 찾는 것"으로 아는 것과, **NCC가 정확히 무엇을 찾는 것이고, 상관(correlation)이 원인(cause)이 아닌 이유와, NCC 연구가 의식 이론을 어떻게 제약하지만 완전히 결정하지는 못하는지**를 추적하는 것은 다르다.
정신물리학을 "역치를 재는 것"으로 아는 것과, **Weber-Fechner·신호탐지이론이 주관적 경험을 어떻게 수량화하고, 이 방법이 1인칭과 3인칭 사이의 다리를 어떻게 놓는지** — 그리고 그 다리가 어디서 끊기는지를 — 이해하는 것은 다르다.
1인칭을 과학의 대상으로 만드는 방법론의 지형을 — 그리고 어떤 방법도 닿지 못하는 경험의 핵심이 무엇인지를 정직하게 표시하는 — 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "경험을 측정하는 방법들 — 정신물리학·내성·현상학·NCC·헤테로현상학의 정밀 비교"

**핵심 차별화**:
1. **1인칭의 과학적 지위** — "주관적 = 과학 밖"이 아니라, 1인칭 데이터를 과학적으로 다루는 방법의 조건과 한계를 정밀하게. 어떤 방법이 어떤 주장을 정당화하는가
2. **내성의 신뢰성 문제** — 내성이 경험의 정확한 보고인가, 내성 자체가 경험을 변화시키는가, 언제 내성이 무너지는가를 실험 데이터로
3. **정신물리학의 성취와 한계** — Weber-Fechner·신호탐지이론·역치가 1인칭을 수량화하는 방식, 그러나 *있다는 것*(what it is like)을 포착하는가
4. **NCC 방법론의 정밀화** — 상관 vs 원인, NCC의 발견이 의식 이론을 어떻게 제약하는가, 의식의 목차 NCC vs 내용 NCC의 구분

**타겟 독자**:
- "의식은 주관적이라 과학으로 못 다룬다"고 단정하는 사람
- 내성이 경험의 직접 보고라고 믿는 사람
- NCC 연구를 하지만 그것이 무엇을 증명하고 무엇을 증명 못 하는지 모르는 사람
- 현상학적 방법이 신경과학과 어떻게 연결될 수 있는지 궁금한 사람
- 이 연구소가 1인칭 경험을 어떻게 과학적으로 다루는지 원리적으로 알고 싶은 사람

**선행 학습**:
- `mind-body-map-distilled`(L0) — **필수**. 설명적 간극이 왜 방법론을 요구하는가
- `levels-of-explanation-distilled`(L0) — 각 방법이 어느 층위에서 작동하는가

### Chapter 1: 1인칭 데이터의 지위 (4개 문서)
- **1인칭이란 무엇인가** — Nagel의 "박쥐이기 위한 것이 어떤 것인가", 1인칭 데이터의 특성
- **3인칭 방법의 기본 가정** — 재현 가능성·공적 관찰 가능성·상호주관성, 1인칭이 여기서 부딪히는 이유
- **1인칭을 과학에 포함시키는 전략** — 자기 보고·행동 척도·생리적 상관, 각각의 성격
- **이 레포의 규율** — 방법이 도달하는 곳과 도달 못 하는 곳을 매번 명시 — "설명하되, 경험을 지우지 않는다"

### Chapter 2: 내성 — 경험의 직접 접근은 가능한가 (5개 문서)
- **내성의 직관적 위상** — "나의 경험은 내가 제일 잘 안다"는 직관, 그것이 성립하는 조건
- **내성의 신뢰성 실험** — 닐슨(Nisbett & Wilson): 사람들은 자신의 정신 과정에 접근 못 한다
- **내성이 경험을 바꾼다** — 언어화가 경험을 재구성하는 방식, Schooler의 언어 그림자 효과
- **변성 상태에서의 내성** — 마취·수면·환각 상태에서 내성이 어떻게 달라지는가
- **내성의 적절한 사용** — 언제 내성 보고를 신뢰하고 어떻게 교차 검증하는가

### Chapter 3: 정신물리학 — 경험을 수량화하다 (5개 문서)
- **정신물리학의 탄생** — Fechner, 주관적 경험을 물리 자극과 연결하려는 시도
- **Weber-Fechner 법칙** — ΔI/I = 상수, 자극 변화 감지의 로그 법칙과 그 한계
- **신호탐지이론(SDT)** — 역치가 아니라 기준(criterion)과 민감도(d'), 주의·동기 분리
- **역치와 그 너머** — 의식 역치·무의식 처리, 계측 가능한 의식의 경계
- **정신물리학의 한계** — 행동 측정이 경험의 *내용*을 포착하는가, 아니면 경험의 *기능*만 포착하는가

### Chapter 4: 신경 상관물(NCC) 방법론 (5개 문서)
- **NCC란 정확히 무엇인가** — "경험 X의 최소 신경 충분 조건", 정의의 정밀화
- **NCC 탐색 패러다임** — 양안경쟁·마스킹·마취, 의식/무의식 조건 대비 설계
- **상관 ≠ 원인** — NCC 발견이 의식의 신경 원인을 확립하지 않는 이유, 혼동 변수
- **목차 NCC vs 내용 NCC** — Koch·Crick의 구분: 의식의 켜짐/꺼짐 vs 특정 내용
- **NCC가 이론을 제약하는 방식** — GWT·IIT·예측처리가 NCC 발견에서 무엇을 예측하는가 차이

### Chapter 5: 현상학과 헤테로현상학 (5개 문서)
- **현상학적 방법** — 후설·하이데거·메를로퐁티: 경험을 그 자체로 기술하는 방법
- **현상학의 핵심 개념** — 지향성·시간성·체화·상호주관성의 현상학적 의미
- **헤테로현상학(Heterophenomenology)** — Dennett: 3인칭 방법으로 1인칭 보고를 *이론으로서* 다루기
- **현상학 + 신경과학의 시도** — 신경현상학(Varela), 두 방법의 상호 제약
- **현상학의 한계와 기여** — 현상학이 신경과학에 줄 수 있는 것, 과학이 현상학에 줄 수 있는 것

### Chapter 6: 변성 상태와 방법론 (4개 문서)
- **마취 — 의식의 꺼짐** — 마취 깊이와 의식의 관계, PCI(Perturbational Complexity Index) 도구
- **수면·꿈 — 의식의 변조** — REM 수면의 보고, 루시드 드림의 방법론적 가치
- **명상 — 훈련된 주의** — 경험 보고의 정교화, 명상이 내성 정확성을 높이는가
- **환각제 — 경험의 재구성** — 신경 상관물과 1인칭 보고의 극단적 해리, 방법론적 도전

### Chapter 7: 종합·도구 (5개 문서)
- **정신물리학 실험 구현** — 역치 탐색·SDT 분석 파이프라인(Python)
- **내성 신뢰성 시뮬레이션** — 보고 편향의 통계적 모델링(Python)
- **NCC 패러다임 분석** — 양안경쟁 데이터의 분석 프레임(Python)

## 🎨 스타일 가이드

1. **방법론의 한계를 숨기지 않는다** — 각 방법이 무엇을 정당화하고 무엇을 정당화하지 못하는가를 매 문서에서 명시. 과장 없이
2. **내성을 너무 쉽게 버리지도 말고, 너무 믿지도 않는다** — 내성은 부분적으로 신뢰 가능하고 부분적으로 오염된다. 그 조건을 정밀하게
3. **NCC와 인과를 엄격하게 분리** — NCC 발견이 의식의 원인을 확립하지 않는다는 것을 매 문서에서
4. **현상학을 과학의 대화 상대로** — 후설·메를로퐁티를 "과학 이전의 것"으로 취급하지 않는다. 과학이 놓치는 것을 현상학이 지적한다
5. **실험 설계를 구체적으로** — 방법론을 추상적으로 설명하지 않는다. 어떤 실험을 어떻게 설계하는가를 구체적으로
6. 방법론 지형도·NCC 설계·SDT 곡선·PCI 계산 흐름은 다이어그램으로

# 1) 계단법(Staircase) 역치 탐색
import numpy as np
def staircase_threshold(responses, step_up=2, step_down=1):
    """79% 역치 탐색 (3down-1up)"""
    threshold_estimates = []
    intensity = 1.0
    for correct in responses:
        if correct:
            if len(threshold_estimates) >= 3 and all(threshold_estimates[-3:]):
                intensity -= step_down * 0.1
        else:
            intensity += step_up * 0.1
        threshold_estimates.append(intensity)
    return np.mean(threshold_estimates[-20:])  # 수렴값

# 2) 신호탐지이론 (SDT) 분석
from scipy.stats import norm
def sdt_analysis(hits, false_alarms, n_signal, n_noise):
    hit_rate = hits / n_signal
    fa_rate  = false_alarms / n_noise
    # 극단값 보정 (log-linear)
    hit_rate = np.clip(hit_rate, 0.01, 0.99)
    fa_rate  = np.clip(fa_rate,  0.01, 0.99)
    d_prime  = norm.ppf(hit_rate) - norm.ppf(fa_rate)   # 민감도
    criterion = -0.5 * (norm.ppf(hit_rate) + norm.ppf(fa_rate))  # 기준
    return d_prime, criterion
# → 주의·동기와 무관한 순수 감각 민감도 추출

# 3) 양안경쟁 NCC 분석 프레임
def binocular_rivalry_analysis(neural_signals, percept_reports, time_points):
    """
    의식 내용 전환 시점(percept_reports)와 신경 신호(neural_signals) 비교
    전환 전후 window에서 신호 변화 → NCC 후보
    """
    transition_times = np.where(np.diff(percept_reports) != 0)[0]
    erps = []
    for t in transition_times:
        window = neural_signals[t-50:t+100]  # 50ms 전, 100ms 후
        erps.append(window)
    return np.mean(erps, axis=0)  # 전환 관련 신경 반응

# 4) PCI (Perturbational Complexity Index) 개요 구현
def pci_simplified(eeg_response):
    """
    TMS 자극 후 EEG 반응의 압축 복잡도
    의식 = 높은 복잡도, 마취/수면 = 낮은 복잡도
    """
    import zlib
    binary_response = (eeg_response > np.median(eeg_response)).astype(int)
    compressed      = zlib.compress(binary_response.tobytes())
    pci             = len(compressed) / len(binary_response)
    return pci  # 높을수록 의식 있음

- *On the Origin of Objects* (Brian Cantwell Smith) — 3인칭에서 1인칭으로의 방법론 전환

## 💡 핵심 분석 대상

```
방법론의 지형도:

  1인칭 경험 (목표)
       ↑
  ─────────────────────────────────────────
  방법         접근 방식          한계
  ─────────────────────────────────────────
  내성          직접 보고         오염·변형
  정신물리학    자극-반응 관계     기능만 포착
  SDT           민감도·기준 분리  현상적 내용 X
  NCC           신경 상관         원인 확립 X
  현상학        구조적 기술       상호주관성?
  헤테로현상학  3인칭 이론화      경험 자체 X
  ─────────────────────────────────────────
  ⇒ 어떤 방법도 홀로 완전하지 않다

NCC의 정밀한 위치:
  NCC ≠ 의식의 원인
  NCC = 의식 상태 X가 있을 때 충분한 신경 패턴 N
  
  발견 가능한 것:
  ├─ 의식/무의식 전환의 신경 서명
  ├─ 특정 내용(빨강)의 신경 상관
  └─ 의식 깊이의 지표 (PCI)
  
  확립 불가능한 것:
  └─ "N이 X를 일으킨다" (→ 개입 실험 필요)
  └─ "N이 X를 완전히 설명한다" (→ 설명적 간극)

내성의 역설:
  내성: 경험에 가장 직접적 접근
  그러나:
  ├─ 보고가 경험 자체를 바꾼다
  ├─ 언어가 경험을 범주화·왜곡한다
  ├─ 무의식 과정은 내성 불가
  └─ 보고 편향·기억 재구성
  ⇒ 내성은 경험의 창이 아니라 해석이다
  → 그러나 다른 창이 없다면?
  ⇒ 이 역설이 방법론 연구의 핵심
```
