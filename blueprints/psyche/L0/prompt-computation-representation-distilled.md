# Computation & Representation Distilled 레포지토리 제작 프롬프트

나는 "Computation & Representation Distilled" 레포지토리를 만들려고 해.
"컴퓨터가 정보를 처리한다"고 말하는 것과, **물질이 어떻게 *무언가에 관한 것*(aboutness)이 될 수 있는가** — 지향성(intentionality)이 왜 철학의 가장 오래된 난제 중 하나이고, 어떤 조건에서 기호 배열이 "의미를 가진다"고 할 수 있는지를 — 이해하는 것은 다르다.
기호적 AI와 신경망을 "구현 방식의 차이"로 보는 것과, **기호 표상(symbol)과 분산 표상(distributed representation)이 마음의 작동을 근본적으로 다르게 기술한다**는 것을 — 그리고 두 방식이 각각 어떤 현상을 잘 설명하고 어디서 실패하는지를 — 추적하는 것은 다르다.
처치-튜링 논제를 "모든 것은 계산이다"로 확장하는 것과, 그 논제가 정확히 무엇을 주장하고 **무엇을 주장하지 않는지** — 그리고 계산이 이해(understanding)와 같은 것인지, 중국어 방 논변이 어떻게 그 경계를 겨냥하는지를 — 아는 것은 다르다.
표상이란 무엇이고, 계산은 무엇을 설명하며, 물질에서 의미가 나오는 경로가 있다면 그것은 어디인지를 — 이 연구소 전체의 인지과학적 토대를 쌓는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "물질이 어떻게 *무언가에 관한 것*이 되나 — 지향성·표상·계산의 삼각형"

**핵심 차별화**:
1. **지향성의 문제를 정면으로** — "이 상태는 고양이를 *표상한다*"가 무슨 뜻인가, 물리 세계에서 지향성이 어떻게 가능한가, 파생적 vs 내재적 지향성의 구분
2. **기호 표상 vs 분산 표상** — 고전 기호주의(GOFAI)와 연결주의의 차이를 표상 구조에서 추적, 각각이 설명하는 것과 못 하는 것의 정밀 비교(→ brains-vs-networks L3)
3. **처치-튜링 논제의 정밀화** — 계산 가능성의 정확한 의미, "마음은 프로그램"이라는 기능주의의 근거와 한계, 중국어 방 논변이 어느 층위를 공격하는가(→ levels L0)
4. **표상 없이 마음이 있는가** — 급진적 체화 인지(4E)에서 표상 개념 자체를 거부하는 주장과, 그에 대한 응답(→ embodied-mind L3)

**타겟 독자**:
- "뇌는 정보를 처리한다"고 하지만 정보와 표상이 정확히 무엇인지 모르는 사람
- 기호 AI와 신경망의 차이를 구현 방식으로만 보는 사람
- 처치-튜링 논제가 "모든 것은 컴퓨터"를 의미한다고 생각하는 사람
- 지향성(aboutness)이 왜 물리주의에서 어렵고, 어떤 해결책들이 있는지 모르는 사람
- 표상 개념이 인지과학 전체에서 어떤 역할을 하는지 보고 싶은 사람

**선행 학습**:
- `mind-body-map-distilled`(L0) — **필수**. 물리주의·기능주의의 기반
- `levels-of-explanation-distilled`(L0) — **필수**. 알고리즘 층위에서 표상이 나타난다

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 지향성 — 물질이 무언가에 관한 것이 되다 (5개 문서)
- **지향성이란** — Brentano의 재발견, "물질적 대상은 지향성이 없다"는 직관
- **내재적 vs 파생적 지향성** — 뇌 상태의 지향성은 내재적인가, 책의 단어는 파생적, 그 경계
- **지향성의 물리주의적 설명 시도** — 인과적 이론·목적론적 이론·정보이론적 이론, 각각의 성공과 실패
- **콰인의 지향성 제거론** — 지향적 어휘를 물리 어휘로 대체할 수 있는가
- **지향성과 의식의 관계** — 의식이 없으면 지향성이 없는가, 무의식적 표상이 있는가

### Chapter 2: 표상이란 무엇인가 (5개 문서)
- **표상의 조건** — X가 Y를 표상하려면 무엇이 필요한가, 이소모피즘·인과·기능의 조건들
- **기호 표상 (Symbolic)** — GOFAI의 기호: 명시적·이산적·조합적, 논리로 조작 가능
- **분산 표상 (Distributed)** — 연결주의의 표상: 활성화 패턴·중첩·창발적 의미
- **아날로그 vs 디지털 표상** — 연속적 상태와 이산적 상태의 표상, 각각의 특성
- **표상의 구성성(compositionality)** — "빨간 공"을 표상하는 것이 "빨간"과 "공"에서 나오는 방식

### Chapter 3: 처치-튜링 논제와 계산 (5개 문서)
- **처치-튜링 논제란** — 계산 가능한 것 = 튜링 기계가 계산 가능한 것, 정확한 범위
- **논제의 오독** — "마음은 컴퓨터다"·"모든 과정은 계산이다"가 왜 논제를 넘어서는가
- **계산과 인과** — 물리 계산이 의미를 가지려면 인과적 구조가 필요한가
- **계산주의의 기능주의적 근거** — 마음이 계산이라면 기질 독립적, 다중 실현 지원(→ levels)
- **계산의 경계** — 학습·적응·창의성이 계산으로 설명되는가, 비계산적 마음이 있는가

### Chapter 4: 중국어 방과 그 파장 (5개 문서)
- **중국어 방 논변** — Searle의 설정: 기호를 완벽하게 조작하지만 이해하지 못한다
- **시스템 반론** — 방 전체가 이해한다, Searle의 재반론
- **로봇 반론과 뇌 시뮬레이터 반론** — 논변의 다양한 변형과 응답
- **논변이 겨냥하는 것** — 통사론(syntax)만으로는 의미론(semantics)이 나오지 않는다는 주장
- **LLM 시대의 중국어 방** — 대형 언어 모델은 이해하는가, 논변이 여전히 유효한가

### Chapter 5: 표상의 두 전통 — 기호주의 vs 연결주의 (5개 문서)
- **고전 기호주의 (GOFAI)** — 뉴얼·사이먼의 물리 기호 시스템 가설, 성공과 한계
- **연결주의의 도전** — 루멜하트·매클리랜드, 분산 표상·창발, 왜 다른 설명인가
- **연결주의의 성공과 한계** — 패턴 인식·학습·일반화 vs 체계적 구성성·추론
- **하이브리드 접근** — 기호와 분산을 합치는 시도, 현대 신경-기호 AI
- **어느 편이 마음을 더 잘 설명하나** — 정직한 현황, 미해결로 표시(→ brains-vs-networks L3)

### Chapter 6: 표상 없는 마음 — 체화 인지의 도전 (4개 문서)
- **4E 인지와 표상 비판** — Brooks, van Gelder: 표상 없이 행동이 가능하다
- **감각운동 우연성 이론** — O'Regan·Noë: 지각은 행동 잠재성, 내부 표상 불필요
- **다이나믹 시스템 이론** — 마음 = 뇌-몸-환경의 동역학, 표상 없는 인지
- **반론: 표상을 버릴 수 있는가** — 표상 없이 목표 지향적 행동·기억·계획을 설명하는 어려움

### Chapter 7: 종합·계산 (6개 문서)
- **표상 탐지 실험** — 신경망의 내부 표상을 해석하는 기법 소개(PCA·probing)
- **분산 표상 시뮬레이션** — Word2Vec 구조로 분산 표상의 특성 직접 탐색(Python)
- **기호 조작 시뮬레이션** — 간단한 술어 논리 시스템 구현 → 중국어 방의 최소 시연(Python)
- **표상 구성성 검증** — "빨간 공" 표상이 부분에서 구성되는 방식 수치화(Python)
- **지향성 없는 시스템** — 표상 없이 목표 달성하는 반응적 시스템(Brooks 로봇) 시뮬레이션
- **종합** — "물질이 무언가에 관한 것이 되는 방식"의 현황과 미해결(→ L3, L6)

→ **총 35개 문서** 목표.

## 🎨 스타일 가이드

1. **지향성을 물리 세계의 문제로** — "의미는 약속"이라는 사회적 설명 전에, 물리 기질이 어떻게 지향성을 가질 수 있는지의 어려움을 먼저 정직하게 직면
2. **기호 vs 분산을 공정하게** — GOFAI를 "실패한 AI"로 단정하지 않는다. 각각이 설명하는 것과 못 하는 것을 정밀하게 대조
3. **중국어 방의 힘과 한계를** — 논변을 "이미 논파됐다"고 넘기지 않는다. 어떤 반론이 어느 전제를 공격하는지, 논쟁의 현재 상태를 정직하게
4. **LLM을 데이터로** — GPT/Claude 같은 대형 언어 모델이 이 논쟁에서 어떤 증거가 되는지, 과대해석 없이
5. **표상 불필요론에 공정한 공간을** — 체화 인지의 도전을 무시하지 않는다. 어떤 조건에서 표상이 불필요한가
6. 지향성 삼각형·기호/분산 비교·처치-튜링 경계는 다이어그램으로

## 💡 핵심 분석 대상

```
지향성의 삼각형:
  물리 상태 X  ─────── aboutness ────────► Y (대상)
       │
  어떻게 X가 Y에 관한 것이 되는가?
  
  인과적 이론:    X가 Y에 의해 인과됨
  목적론적 이론:  X는 Y를 추적하도록 선택됨
  정보이론적 이론: X는 Y에 대한 정보를 담음
  ⇒ 셋 다 부분적 성공, 셋 다 반례 존재

기호 vs 분산 표상:
  기호 표상                   분산 표상
  ────────────────────────────────────────
  명시적 (고양이 = CAT)      암묵적 (활성화 패턴)
  이산적 (있거나 없거나)      연속적 (강도 분포)
  국소적 (한 노드 = 한 개념)  분산적 (모든 노드에 걸쳐)
  구성성 강함                 구성성 약함
  해석 용이                   해석 어려움
  → 뇌는 어느 쪽에 더 가까운가? → 둘 다? (→ L1, L3)

처치-튜링 논제의 정확한 범위:
  주장:  "효과적으로 계산 가능 = 튜링 기계로 계산 가능"
  
  넘지 않는 것:
  ✗  "마음은 튜링 기계다"
  ✗  "의식은 계산이다"
  ✗  "물리 세계는 컴퓨터다"
  
  남는 질문:
  → 마음이 계산이라면, 어떤 종류의 계산인가?
  → 계산이 지향성을 가질 수 있는가?
  → 경험이 계산에서 나오는가?
```
