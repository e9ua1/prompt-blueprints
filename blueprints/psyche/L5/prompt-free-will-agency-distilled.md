# Free Will & Agency Distilled 레포지토리 제작 프롬프트

나는 "Free Will & Agency Distilled" 레포지토리를 만들려고 해.
"리벳 실험이 자유의지를 부정한다"고 말하는 것과, **리벳 실험이 정확히 무엇을 측정하고 무엇을 측정하지 않는지** — 준비 전위(readiness potential)가 의식적 의도에 선행한다는 것이 왜 자유의지 전체를 부정하지 않는지, 그리고 리벳 자신이 왜 자유의지를 완전히 부정하지 않았는지를 — 이해하는 것은 다르다.
결정론이 "모든 것이 이미 정해져 있다"는 것으로 아는 것과, **양립가능론(compatibilism)이 결정론과 자유의지가 어떻게 양립할 수 있다고 주장하는지** — 자유의지가 "원인 없는 행동"이 아니라 "올바른 종류의 원인에서 나오는 행동"이라는 재정의가 어떤 설득력을 갖고 어떤 한계에 부딪히는지를 — 추적하는 것은 다르다.
"행위주체감(sense of agency)"을 아는 것과, **내 행동의 저자라는 느낌이 어떤 신경 메커니즘에서 나오고, 그것이 실제 인과력과 어떻게 다를 수 있는지** — 파킨슨·정신분열·자동증에서 행위주체감이 어떻게 달라지는지를 — 이해하는 것은 다르다.
자유의지 논쟁을 — 철학적 직관만이 아니라 신경과학·인지심리학·실험철학의 데이터와 함께, 검증이 닿는 곳과 닿지 못하는 곳을 정직하게 나누어 — 끝까지 파헤치는 레포를 만들 거야.

### Chapter 2: 리벳 실험 — 정밀한 해부 (7개 문서)
- **리벳 실험의 설계** — 손목 굽힘 과제, EEG 준비 전위, Wrist clock 측정법
- **준비 전위(RP)란** — RP의 신경 기원(보완 운동 피질), RP가 측정하는 것과 측정하지 않는 것
- **리벳의 결과** — RP가 의식적 의도 보고에 약 550ms 선행한다는 발견
- **리벳의 자신의 해석** — 리벳이 왜 완전한 자유의지 부정이 아니라 "거부권(veto power)" 모형을 제안했는가
- **리벳 실험에 대한 방법론 비판** — 의식적 의도를 Wrist clock으로 측정하는 것의 한계
- **하이네스 실험** — fMRI로 7-10초 전에 행동 예측, 리벳 결과를 어떻게 확장하는가
- **리벳 실험이 실제로 증명하는 것과 아닌 것** — 무엇이 확립됐고, 무엇이 여전히 열려있는가

### Chapter 3: 양립가능론 — 결정론과 자유의지의 공존 (5개 문서)
- **양립가능론의 핵심 전략** — 자유의지를 "원인 없는 행동"에서 "올바른 종류의 원인"으로 재정의
- **반응적 태도 이론(Strawson)** — 자유의지를 인간 관계의 실천적 문제로 재구성
- **이유 반응성 이론(Fischer)** — 자신의 행동이 이유에 반응할 수 있을 때 자유의지
- **양립가능론의 강점** — 왜 대부분의 철학자가 양립가능론을 지지하는가
- **양립가능론의 한계** — 직관 펌핑(manipulation argument), 뒤로 가는 결정론

### Chapter 4: 행위주체감 — "내가 했다"의 느낌 (6개 문서)
- **행위주체감의 정의** — 행동이 자신에서 나온다는 느낌, 의도·행동·결과의 통합
- **행위주체감의 신경 기반** — 전보완 운동 피질·도서섬엽·소뇌의 역할, 전방 모델
- **비교기 이론(Comparator Model)** — 예측된 결과와 실제 결과의 비교가 행위주체감을 만드는 방식
- **행위주체감의 실험적 조작** — 의도적 결합(intentional binding), TMS로 행위주체감 억제
- **행위주체감 장애** — 정신분열(행동이 외부에서 온다), 파킨슨(행위주체감 감소), 자동증
- **행위주체감과 자유의지** — 행위주체감이 있으면 자유의지가 있는가, 행위주체감과 실제 인과력의 분리

### Chapter 5: 신경결정론과 책임 (5개 문제)
- **신경결정론의 주장** — 모든 행동은 선행 신경 상태에 의해 결정된다

```python
import numpy as np
import matplotlib.pyplot as plt

# 1) 리벳 준비 전위 시뮬레이션
def simulate_readiness_potential(n_trials=100, srate=256):
    """
    손목 굽힘 전 평균 RP 시뮬레이션
    RP 시작: 움직임 약 -1500ms
    의식적 의도 보고: 움직임 약 -200ms
    """
    time = np.linspace(-2000, 500, int(2500 * srate / 1000))  # ms
    movement_onset = 0  # ms 기준
    
    # RP: 점진적 음전위 (-1500ms부터)
    rp = np.zeros(len(time))
    onset_idx = np.searchsorted(time, -1500)
    rp[onset_idx:] = np.linspace(0, -15, len(time) - onset_idx)  # μV
    
    # 의식적 의도 시점 (Wrist clock 방법)
    # 평균적으로 움직임 -200ms 전
    conscious_w_time = -200  # ms
    conscious_idx    = np.searchsorted(time, conscious_w_time)
    
    # RP가 의식적 의도에 약 350ms 선행
    rp_onset_time = -550  # ms (리벳의 실제 발견)
    
    return time, rp, conscious_w_time, rp_onset_time

# 2) 행위주체감 비교기 모델
def agency_comparator(intended_action, actual_outcome,
                       noise_level=0.1):
    """
    전방 모델: 의도된 행동 → 예측된 결과
    비교기: 예측된 결과 vs 실제 결과
    일치 → 높은 행위주체감
    불일치 → 낮은/부재 행위주체감
    """
    predicted_outcome = intended_action + np.random.randn() * noise_level
    prediction_error  = np.abs(predicted_outcome - actual_outcome)
    
    # 행위주체감: 오차가 작을수록 높음
    agency_strength = np.exp(-prediction_error ** 2 / 0.1)
    return agency_strength, prediction_error

# 정상 자발적 행동
ag_normal, _ = agency_comparator(0.5, 0.5, noise_level=0.05)
# TMS로 강제된 행동 (의도 없음)
ag_forced, _ = agency_comparator(0.0, 0.5, noise_level=0.05)
# 정신분열 (내적 행동이 외부에서 온다고 귀인)
ag_schizophrenia, _ = agency_comparator(0.5, 0.5, noise_level=0.5)

# 3) 의도적 결합(Intentional Binding)
def intentional_binding(action_time_ms, outcome_time_ms,
                         has_agency=True):
    """
    행위주체감이 있을 때 행동과 결과의 시간적 간격이 압축되어 지각됨
    action_time: 버튼 누름 시점 (ms)
    outcome_time: 음이 발생하는 시점 (ms)
    """
    actual_interval = outcome_time_ms - action_time_ms
    
    if has_agency:
        # 행위주체감 있음: 간격이 짧아 보임 (약 15-20% 압축)
        compression = 0.18
        perceived_action   = action_time_ms   + compression * actual_interval
        perceived_outcome  = outcome_time_ms  - compression * actual_interval
    else:
        # 행위주체감 없음: 압축 없음
        perceived_action   = action_time_ms
        perceived_outcome  = outcome_time_ms
    
    perceived_interval = perceived_outcome - perceived_action
    binding_effect     = actual_interval - perceived_interval
    return perceived_interval, binding_effect

# 4) 양립가능론의 이유 반응성 검증
def reasons_responsiveness(agent_state, reason_presented):
    """
    Fischer의 이유 반응성 이론:
    같은 상황에서 다른 이유가 제시됐을 때 다르게 행동하는가
    → 이유에 반응할 수 있으면 = 양립가능론적 자유의지 있음
    """
    base_action = agent_state.get('default_action', 0)
    
    # 이유가 행동을 변화시키는가
    reason_influence = reason_presented.get('strength', 0) * 0.7
    modified_action  = base_action + reason_influence
    
    is_responsive = abs(modified_action - base_action) > 0.1
    return is_responsive, modified_action
```

```
리벳 실험 타임라인:
  -1500ms: 준비 전위(RP) 시작
  - 550ms: RP 급격히 증가 (리벳의 핵심 측정 지점)
  - 200ms: 피험자가 "W 시점"을 보고 (의식적 의도)
     0ms: 손목 굽힘 움직임
  
  리벳의 해석: RP가 W보다 약 350ms 선행
  → 의식적 의도 이전에 뇌가 행동을 "결정"
  
  과대해석의 함정:
  "의식적 의도가 행동을 일으키지 않는다"
  ← 이는 리벳 실험이 증명하지 않은 것
  ← W 측정법의 신뢰성 문제
  ← RP가 '결정'인지 '준비'인지 불명확

자유의지의 세 가지 버전:
  1. 비결정론적 자유의지:
     행동이 선행 원인에서 완전히 자유로움
     → 물리적으로 불가능 (또는 양자 무작위성이 도움 안 됨)
  
  2. 양립가능론적 자유의지:
     결정론과 양립 가능한 의미에서 자유
     → 올바른 종류의 원인(이유·심의)에서 나오면 자유
     → 리벳 실험은 이것을 부정하지 않는다
  
  3. 실용적 행위주체성:
     자유의지의 형이상학과 무관하게
     심의하고 선택하는 능력이 있다
     → 책임·처벌의 실용적 근거로 충분

행위주체감과 실제 인과력의 분리:
  의도적 결합:
  버튼 누름 → 200ms 후 음
  행위주체감 있음: 100ms처럼 느껴짐 (압축)
  행위주체감 없음: 200ms 그대로 느껴짐
  
  TMS 실험:
  TMS로 손가락 움직임 유발
  → 행위주체감 없음 ("스스로 한 게 아니다")
  → 실제 인과력: 있음
  → 행위주체감: 없음
  ⇒ 둘은 분리 가능
```
