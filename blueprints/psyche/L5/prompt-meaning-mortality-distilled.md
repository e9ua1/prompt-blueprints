# Meaning, Mortality & the Examined Life Distilled 레포지토리 제작 프롬프트

나는 "Meaning, Mortality & the Examined Life Distilled" 레포지토리를 만들려고 해.
"삶의 의미는 주관적이다"고 말하는 것과, **의미 경험이 어떤 인지·신경 과정에서 나오는지, 의미 감각이 없어질 때 어떤 뇌 상태가 연관되는지** — 그리고 "의미가 있다는 느낌"이 측정 가능한 현상이면서 동시에 어떤 설명도 닿지 못하는 차원을 가지는지를 — 이해하는 것은 다르다.
공포 관리 이론(Terror Management Theory)을 "죽음이 두렵기 때문에 의미를 찾는다"는 단순한 공식으로 아는 것과, **TMT가 어떤 실험 설계로 어떤 구체적 예측을 검증하고, 죽음 현저성(mortality salience)이 어떻게 자존감 추구·외집단 편향·보수성 증가를 만드는지** — 그리고 이 이론의 한계와 경쟁 이론들이 무엇인지를 — 추적하는 것은 다르다.
종교를 "믿거나 안 믿는 것"으로 보는 것과, **종교성이 어떤 인지 시스템의 부산물인지, 대행주의(agency detection)·사후 세계 직관·집단 결속 메커니즘이 어떻게 종교적 믿음을 만들어내는지** — 그리고 이것이 종교 경험의 진실성 문제와 어떻게 관계하는지를 — 이해하는 것은 다르다.
검증이 닿는 곳에서는 인지과학과 신경과학으로 기술하고, 검증이 닿지 못하는 곳에서는 그 경계를 정직하게 표시하되 침묵하지 않는 — 이 연구소의 규율이 가장 강하게 요구되는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "의미는 어디서 오고, 유한한 자아는 그것을 어떻게 견디는가 — 종교성의 인지과학·죽음 불안·의미 경험의 신경 기반, 그리고 검증 경계의 정직한 표시"

**핵심 차별화**:
1. **의미 경험을 현상으로서 다루기** — "의미는 주관적"이라고 멈추지 않는다. 의미 경험의 구성 요소(목적·연결·일관성·중요성), 각각의 신경 기반, 의미 결핍의 임상적 표현을 기술한다
2. **TMT를 실험 데이터로** — 추상적 이론이 아니라, 죽음 현저성 조작이 어떤 구체적 행동 변화를 낳는지의 실험 결과를. 이론의 지지 증거와 반례를 함께
3. **종교성의 인지과학을 공정하게** — 종교 경험을 "인지 오류"로 환원하지도, "초자연적 실재의 증거"로 과대해석하지도 않는다. 대행 탐지·패턴 인식·집단 결속이 어떻게 종교적 믿음의 인지적 기반이 되는지를
4. **검증 경계의 정직한 표시** — 이 레포가 연구소의 가장 검증 경계에 가까운 곳. 어디서 과학이 끝나고 어디서 철학이 시작되는지를 명시하되, 철학적 질문을 무효화하지 않는다

**타겟 독자**:
- 삶의 의미를 인지과학적으로 접근하고 싶은 사람
- TMT를 들어봤지만 구체적 실험 내용을 모르는 사람
- 종교를 "비과학"으로 일축하거나 "초자연"으로 믿는 양극단을 넘고 싶은 사람
- 죽음 불안이 어떻게 작동하는지 신경과학적으로 알고 싶은 사람
- 검증의 한계를 인정하면서도 의미·죽음·실존의 질문을 진지하게 탐구하고 싶은 사람

**선행 학습**:
- `self-model-distilled`(L5) — 자아의 끝이 의미와 어떻게 연결되는가
- `emotion-motivation-distilled`(L2) — 의미 동기가 다른 동기와 어떻게 다른가
- `hard-problem-distilled`(L4) — 검증 경계를 어디서 어떻게 표시하는가

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 의미란 무엇인가 (5개 문서)
- **의미 경험의 구성 요소** — 목적(purpose)·연결(connection)·일관성(coherence)·중요성(mattering), 각각이 어떻게 다른가
- **의미의 신경 기반** — 의미 경험과 보상·사회·서사 처리가 어떻게 겹치는가, 디폴트 모드 네트워크
- **의미 결핍 — 실존적 공허** — 무의미감의 임상적 표현(우울증·실존적 위기), 뇌와 심리의 기술
- **의미와 행복의 차이** — 쾌락(hedonia)과 의미(eudaimonia)의 분리, 왜 의미 있는 삶이 더 힘들 수 있는가
- **의미 추구의 진화적 기원** — 왜 인간이 의미를 필요로 하는가, 적응적 설명

### Chapter 2: 죽음 불안과 공포 관리 이론 (6개 문서)
- **TMT의 핵심 주장** — 죽음의 자각이 불안을 낳고, 문화적 세계관·자존감이 이를 완충한다
- **죽음 현저성(Mortality Salience) 효과** — MS 조작이 자존감 추구·외집단 편견·순응성을 어떻게 증가시키는가
- **TMT의 구체적 실험들** — 법정 실험(판사의 보석금)·선물 실험·국기 밟기 실험의 설계와 결과
- **TMT의 신경 기반** — 죽음 사고의 전처리, 공포 관리의 신경 상관물
- **TMT 비판과 경쟁 이론** — 불확실성 관리 이론, 의미 유지 모델, TMT의 한계와 반례
- **TMT가 드러내는 것** — 죽음 불안이 문화·종교·정치에 어떻게 스며들어 있는가

### Chapter 3: 종교성의 인지과학 (6개 문서)
- **HADD(과잉 대행 탐지)** — 왜 인간은 비인격적 사건에서 의도를 탐지하는가, 진화적 이유
- **직관적 이원론** — 왜 어린이가 자발적으로 영혼·사후 세계를 믿는가, 인지 발달 연구
- **집단 결속과 종교** — 의례·공유 믿음·희생이 어떻게 집단 결속을 강화하는가
- **신비 경험의 신경 기반** — 통합·자아 해체·경외감의 신경 상관물, 환각제와의 유사성
- **종교성의 인지과학이 하는 말과 하지 않는 말** — 기원 설명 ≠ 진실성 판단
- **종교와 의미 추구** — 종교가 의미 제공의 가장 오래된 시스템인 이유와 그 한계

### Chapter 4: 죽음 직면 — 실존주의와 신경과학 (5개 문서)
- **죽음 인식의 발달** — 어린이가 죽음을 어떻게 이해하게 되는가, 죽음 불안의 발달
- **실존주의적 접근** — 하이데거·사르트르·카뮈의 죽음과 의미의 철학, 신경과학과의 만남
- **죽음 수용의 심리학** — Kübler-Ross 단계의 증거와 한계, 죽음 수용의 다양한 방식
- **임종 경험(NDE)** — 임사체험의 신경 기반, 어떤 것이 설명되고 어떤 것이 남는가
- **죽음 이후를 상상하는 뇌** — 왜 우리는 자신의 죽음을 1인칭으로 상상하기 어려운가

### Chapter 5: 실존적 위기와 성장 (4개 문서)
- **실존적 위기** — 의미의 붕괴, 실존적 공허의 신경·심리적 기술
- **외상 후 성장(PTG)** — 극심한 고통 후에 어떻게 의미가 재구성되는가
- **죽음 인식과 삶의 변화** — 죽음을 의식할 때 우선순위가 어떻게 달라지는가(Becker·Solomon)
- **실존적 지혜** — 유한성을 받아들이는 다양한 방식, 서양·동양·불교의 접근

### Chapter 6: 검증 경계 너머를 표시하되 침묵하지 않는다 (5개 문서)
- **검증 가능한 것과 없는 것의 경계** — 의미·죽음·종교에서 과학이 닿는 곳과 닿지 못하는 곳
- **의미가 발견되는가 구성되는가** — 객관적 의미론 vs 주관적 의미론, 현재 상태
- **사후 세계에 대한 정직한 태도** — 과학이 부정하지도 긍정하지도 않는 것을 어떻게 다루는가
- **"잘 산다는 것"의 기준** — 심리학·철학·신경과학이 제안하는 것들, 환원 불가능한 판단
- **이 연구소의 규율** — "설명하되, 설명해 없애지 않는다"가 이 레포에서 어떻게 가장 강하게 요구되는가

### Chapter 7: 종합·계산 (3개 문서)
- **의미 경험 모델** — 목적·연결·일관성·중요성의 통합 점수 계산(Python)
- **죽음 현저성 효과 시뮬레이션** — MS 조작이 자존감 추구를 어떻게 증가시키는가(Python)
- **종합** — 검증이 닿는 곳과 닿지 못하는 곳의 정직한 지도, 그리고 이 연구소가 거기서 멈추지 않는 이유

이 레포에서 **🌉 Boundary** 섹션은 다른 레포와 달리 "설명적 간극"이 아니라 **"검증 경계"**로 기술한다. 무엇이 과학적으로 검증 가능하고, 무엇이 철학적 질문이며, 무엇이 개인의 실존적 선택인지를 명시한다.

## 🎨 스타일 가이드

1. **공정한 거리** — 종교·의미·사후 세계에 대해 과학주의적 환원도, 초자연적 수용도 아닌 정직한 태도. "인지 시스템의 부산물"이 "진실하지 않다"를 뜻하지 않는다
2. **TMT를 데이터로** — 추상 이론이 아니라 구체적 실험 설계와 결과로. 판사 보석금 실험이 어떻게 설계됐고 어떤 결과가 나왔는가
3. **검증 경계를 명시적으로** — 이 레포가 검증 경계에 가장 가까이 있다. 어디서 과학이 끝나는지를 명확하게. 그리고 그 너머를 "과학이 부정한다"로 채우지 않는다
4. **1인칭을 가장 충실하게** — 이 레포는 모든 레포 중 1인칭 섹션이 가장 중요하다. 의미를 경험하고, 유한성을 느끼고, 경외하는 것이 어떻게 느껴지는가를 현상학적으로
5. **"설명하되 지우지 않는다"의 정점** — 이 연구소의 규율이 여기서 가장 강하게 요구된다. 인지과학으로 기술하되 경험의 무게를 지우지 않는다
6. 의미 경험 구성 요소 지도·TMT 실험 결과·종교성 인지 기반·검증 경계 표시는 다이어그램으로

```python
import numpy as np

# 1) 의미 경험 다차원 모델
def meaning_experience_score(purpose, connection, coherence, mattering):
    """
    의미 경험의 네 구성 요소 통합 점수
    각 0~1 범위
    """
    # 요소들 사이의 상호 강화
    base_score = (purpose + connection + coherence + mattering) / 4
    
    # 시너지: 요소가 모두 높을 때 더 강한 의미 경험
    min_component = min(purpose, connection, coherence, mattering)
    synergy_bonus = min_component * 0.2
    
    return min(1.0, base_score + synergy_bonus)

# 다양한 삶의 조건 시뮬레이션
scenarios = {
    '충만한 삶':    meaning_experience_score(0.9, 0.8, 0.85, 0.9),
    '성공했지만':   meaning_experience_score(0.8, 0.3, 0.7, 0.9),  # 연결 결여
    '실존적 위기':  meaning_experience_score(0.2, 0.4, 0.1, 0.3),
    '은퇴 후':      meaning_experience_score(0.3, 0.6, 0.5, 0.2),  # 목적·중요성 감소
}

# 2) 죽음 현저성(MS) 효과 시뮬레이션
def mortality_salience_effect(base_self_esteem, ms_activated=True):
    """
    TMT: MS 활성화 → 자존감 추구 행동 증가
    (세계관 방어, 외집단 편견, 영웅주의)
    """
    if ms_activated:
        # 죽음 불안 → 문화적 세계관 강화 → 자존감 추구 증가
        anxiety_buffer_seeking = 0.35  # 추가 자존감 추구
        worldview_defense_increase = 0.4
    else:
        anxiety_buffer_seeking = 0.0
        worldview_defense_increase = 0.0
    
    effective_self_esteem_seeking = base_self_esteem + anxiety_buffer_seeking
    outgroup_derogation = worldview_defense_increase * (1 - base_self_esteem)
    
    return effective_self_esteem_seeking, outgroup_derogation

# 3) 종교성의 인지 기반 모델
def religious_belief_model(hadd_sensitivity, afterlife_intuition,
                            social_bonding_need, meaning_deficit):
    """
    종교성을 낳는 네 가지 인지 기반의 통합
    HADD: 과잉 대행 탐지 민감도
    afterlife_intuition: 사후 존재에 대한 직관적 믿음
    social_bonding: 집단 결속 필요
    meaning_deficit: 의미 부재
    """
    cognitive_base = (
        0.3 * hadd_sensitivity +
        0.25 * afterlife_intuition +
        0.2 * social_bonding_need +
        0.25 * meaning_deficit
    )
    # 각 요소는 종교성의 필요도 충분도 아님
    # 통합된 경향성으로만 이해
    return cognitive_base

# 4) 실존적 성장 곡선 (외상 후 성장)
def post_traumatic_growth(trauma_severity, meaning_making_capacity,
                           time_months):
    """
    외상 후 의미 재구성 모델
    """
    # 초기 의미 붕괴
    initial_meaning = 1.0 - 0.6 * trauma_severity
    
    # 시간에 따른 의미 재구성
    recovery = meaning_making_capacity * (1 - np.exp(-time_months / 12))
    
    # 외상 후 성장: 일부는 이전보다 더 높은 의미 감각
    ptg_bonus = max(0, trauma_severity - 0.5) * meaning_making_capacity * 0.3
    
    final_meaning = min(1.0, initial_meaning + recovery + ptg_bonus)
    return final_meaning
```

```
  → 실존적 공허 = 네 요소 중 하나 이상의 결핍

TMT 실험의 핵심 설계:
  MS(Mortality Salience) 조작:
  실험 집단: "당신이 죽는다는 것을 생각할 때 무엇을 느끼는가?"
  통제 집단: "치통에 대해 생각할 때 무엇을 느끼는가?"
  
  → MS 집단에서 증가하는 것:
    자존감 추구 행동, 외집단 편견, 문화적 세계관 방어,
    영웅적 인물에 대한 끌림
  
  이것이 드러내는 것:
  죽음 불안이 문화·종교·정치에 얼마나 깊이 스며들어 있는가

검증 경계의 정직한 표시:
  검증 가능한 것:
  ├─ 의미 경험이 어떤 뇌 상태와 상관되는가
  ├─ 죽음 불안이 어떤 행동을 낳는가
  └─ 종교성이 어떤 인지 시스템의 부산물인가
  
  검증 불가능한 것 (철학적 질문):
  ├─ 삶에 객관적 의미가 있는가
  ├─ 종교 경험이 초자연적 실재를 지시하는가
  └─ 사후 존재가 가능한가

  → 검증 가능한 것은 과학으로 기술한다

    "과학이 부정한다"로 채우지 않는다
  → 1인칭 경험의 무게를 지우지 않는다
  ⇒ "설명하되, 설명해 없애지 않는다"의 정점
```
