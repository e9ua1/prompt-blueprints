# The Self & Self-Model Distilled 레포지토리 제작 프롬프트

나는 "The Self & Self-Model Distilled" 레포지토리를 만들려고 해.
"나는 존재한다"고 말하는 것과, **"나"라고 부르는 것이 무엇인지** — 신체적 자아·서사적 자아·최소 현상적 자아·사회적 자아가 각각 어떤 다른 과정이고, 어떤 신경 기반을 가지며, 어떤 조건에서 해리되는지를 — 이해하는 것은 다르다.
"자아는 환상이다"는 말을 들어본 것과, **Metzinger의 자기모델 이론이 정확히 무엇을 주장하는지** — "투명한 자기모델"이 어떻게 자아 감각을 만들고, 왜 뇌가 자신이 자기모델임을 인식하지 못하는지, 그리고 이것이 "환상"이라는 말이 정확한지 아닌지를 — 추적하는 것은 다르다.
고무손 착시를 "재미있는 실험"으로 아는 것과, **고무손이 자신의 것처럼 느껴지는 순간 뇌에서 어떤 신체 소유감 메커니즘이 작동하고, 그것이 신체적 자아의 구성에 대해 무엇을 드러내며, 왜 이 실험이 "나의 몸"이 어떻게 만들어지는지에 대한 가장 선명한 창문인지**를 — 이해하는 것은 다르다.
"나는 누구인가"라는 질문을 — 철학적 직관이 아니라 신경과학·현상학·인지과학의 교차점에서 가장 정밀하게 다듬어, 검증이 닿는 곳과 닿지 못하는 곳을 정직하게 표시하는 — 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "'나'는 실체인가 과정인가 — 자기모델 이론·신체적 자아·서사적 자아가 '나'를 어떻게 구성하는가"

**핵심 차별화**:
1. **자아의 다층성을 분리해서** — 자아가 단일한 것이 아니라 여러 다른 과정의 묶음임을. 최소 현상적 자아·신체적 자아·서사적 자아·사회적 자아가 각각 어떤 다른 신경 기반을 갖고 어떤 조건에서 해리되는가
2. **Metzinger의 자기모델 이론을 정밀하게** — "자아는 환상이다"의 정확한 의미를 오해 없이. 투명성이 왜 자아 감각의 원천인지, 자아가 존재하지 않는다는 것이 아니라 자기모델이 자기모델임을 인식하지 못한다는 것
3. **신체 소유감을 실험으로** — 고무손 착시·전신 이탈 실험·체외 이탈 경험이 각각 어떤 신체 소유감 메커니즘을 드러내는지. 내수용감각·다중감각 통합·예측처리가 어떻게 "이것이 내 몸"을 만드는가
4. **서사적 자아의 구성** — 기억이 어떻게 연속된 "나"를 만드는지, 기억 상실이 자아 연속성에 어떤 영향을 미치는지, 서사적 자아가 실재하는가

**타겟 독자**:
- "나"를 자명한 것으로 여기는 사람
- "자아는 환상"이라는 말이 무슨 의미인지 모르는 사람
- 고무손 착시를 재미있는 트릭으로만 아는 사람
- 자아의 신경 기반이 궁금한 사람
- 자아 연속성이 어떻게 유지되고 무너지는지 보고 싶은 사람

**선행 학습**:
- `hard-problem-distilled`(L4) — 자아 경험이 어려운 문제와 어떻게 연결되는가
- `altered-states-distilled`(L4) — 자아 해체·분리뇌가 자아 구성에 대해 무엇을 드러내는가
- `memory-distilled`(L2) — 서사적 자아와 자전적 기억의 연결

## 🎨 스타일 가이드

1. **자아의 다층성을 항상 명시** — "자아"라는 단어를 쓸 때 어떤 자아인지를. 신체적·서사적·현상적 자아가 각각 다른 메커니즘과 다른 취약성을 가진다
2. **Metzinger를 오해 없이** — "자아는 환상이다"가 "자아는 존재하지 않는다"가 아님을. 투명한 자기모델이라는 정확한 주장을
3. **고무손 착시를 메커니즘으로** — 흥미로운 트릭이 아니라, 다중감각 통합이 신체 소유감을 구성하는 방식의 선명한 창문으로
4. **자아 해리를 교과서로** — 이인증·OBE·분리뇌가 각각 자아의 어떤 측면이 얼마나 독립적으로 작동하는지를 드러내는 자연 실험으로
5. **1인칭을 특별하게** — 이 레포는 L5의 중심. "나"라는 경험이 1인칭으로 어떻게 느껴지는가를 현상학적으로 기술하는 것이 다른 어느 레포보다 중요하다
6. 자아의 다층 구조 다이어그램·PSM 투명성 모델·신체 소유감 베이즈 구조·서사 구성 흐름은 필수

## 🔬 검증 프로토콜

```python
import numpy as np

# 1) 고무손 착시 — 다중감각 통합 베이즈 모델
def rubber_hand_illusion(visual_input, proprioceptive_input,
                         visual_weight=0.5, synch_delay_ms=0):
    """
    고무손 소유감 = 시각·고유감각의 베이즈 최적 통합
    synchrony_delay: 시각-촉각 비동기 (ms)
    → 0ms: 강한 착시, 300ms 이상: 착시 사라짐
    """
    # 비동기가 클수록 통합 약화
    temporal_weight = np.exp(-synch_delay_ms / 150)
    
    # 베이즈 최적 통합
    ownership_estimate = (visual_weight * visual_input * temporal_weight +
                          (1 - visual_weight) * proprioceptive_input)
    
    # 소유감: 통합 추정치가 신체 위치 사전과 얼마나 다른가
    body_prior_location = 0.0  # 자신의 손 위치
    ownership_strength  = 1 / (1 + np.abs(ownership_estimate - body_prior_location))
    
    return ownership_estimate, ownership_strength

# 고무손 위치별 소유감 강도
positions = np.linspace(-0.3, 0.3, 20)
delays    = [0, 100, 300, 500]  # ms
for delay in delays:
    strengths = [rubber_hand_illusion(p, 0.0, synch_delay_ms=delay)[1]
                 for p in positions]
    # → 비동기가 늘수록 소유감 감소

# 2) PSM 투명성 모델
def pst_transparency(meta_awareness_level=0.0):
    """
    투명성 = PSM이 PSM임을 인식하지 못하는 정도
    meta_awareness = 0: 완전 투명 (일상적 자아 경험)
    meta_awareness = 1: 완전 불투명 (명상·환각제 상태)
    """
    # 투명: 자기모델이 모델임을 숨김 → 실재처럼 느껴짐
    transparency = 1 - meta_awareness_level
    self_as_real = transparency        # 자아가 실재처럼 느껴지는 정도
    self_as_model = meta_awareness_level  # 자아가 구성물임을 인식하는 정도
    
    return {
        'transparency': transparency,
        'self_feels_real': self_as_real,
        'self_feels_constructed': self_as_model
    }

# 일상 상태
normal = pst_transparency(meta_awareness_level=0.05)
# 명상 숙련자
meditation = pst_transparency(meta_awareness_level=0.4)
# 자아 해체 경험
ego_dissolution = pst_transparency(meta_awareness_level=0.9)

# 3) 서사적 자아 — 기억 재구성 편향
def narrative_self_construction(memory_fragments, current_self_schema):
    """
    서사적 자아 = 기억 조각들을 현재 자아 도식에 맞게 재구성
    current_self_schema: 현재의 자아 이미지 (0~1 벡터)
    → 도식과 일치하는 기억은 강화, 불일치는 약화
    """
    n = len(memory_fragments)
    weights = np.zeros(n)
    
    for i, fragment in enumerate(memory_fragments):
        # 자아 도식과의 일치도
        consistency = np.dot(fragment, current_self_schema) / (
            np.linalg.norm(fragment) * np.linalg.norm(current_self_schema) + 1e-8)
        # 일치할수록 더 잘 기억됨 (재구성 편향)
        weights[i] = np.exp(consistency)
    
    weights /= weights.sum()
    # 가중 평균으로 "서사적 자아" 구성
    narrative_self = sum(w * f for w, f in zip(weights, memory_fragments))
    return narrative_self, weights

# 4) 신체 이미지 — 내수용 통합
def interoceptive_self_model(heartbeat_signal, prior_heartrate=70,
                              precision=2.0):
    """
    내수용 신호가 최소 자아 감각에 기여하는 방식
    정확한 내수용 → 강한 신체적 자아 감각
    """
    actual_rate   = np.mean(heartbeat_signal) * 60
    prediction_error = np.abs(actual_rate - prior_heartrate)
    
    # 예측 오차가 클수록 신체 자아 불안정
    body_self_stability = 1 / (1 + precision * prediction_error / 10)
    return body_self_stability
```
