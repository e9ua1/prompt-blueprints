# Neurons & Neural Codes Distilled 레포지토리 제작 프롬프트

나는 "Neurons & Neural Codes Distilled" 레포지토리를 만들려고 해.
"뉴런이 발화한다"고 말하는 것과, **활동전위가 어떤 물리·화학적 메커니즘에서 발생하며, 단 하나의 스파이크가 이온 농도 기울기와 막전압의 어떤 비선형 동역학에서 나오는지** — 호지킨-헉슬리 방정식을 직접 적분해 확인하는 것은 다르다.
"뉴런이 정보를 전달한다"고 말하는 것과, **발화율 부호(rate code)와 시간 부호(temporal code)가 정확히 무엇을 다르게 주장하는지** — 어떤 자극 특성이 어느 부호 방식으로만 설명되는지, 그리고 두 주장을 가르는 실험이 무엇인지를 — 추적하는 것은 다르다.
"뇌는 병렬로 처리한다"고 말하는 것과, **집단 부호화(population coding)가 단일 뉴런의 한계를 어떻게 초과하는지** — 방위각 선택 뉴런들의 코사인 조율 곡선에서 어떻게 정밀한 방향 정보가 집단 벡터로 복호화되는지를 — 수치로 보는 것은 다르다.
뉴런이 "무엇을 계산하는가"라는 질문을 구현 층위가 아니라 **알고리즘·계산 층위에서 동시에** 던지며, 가장 단단한 물리적 바닥에서 출발하되 거기서 멈추면 경험을 놓친다는 것을 — 매 문서에서 정직하게 표시하는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "뉴런은 무엇을 계산하는가 — 활동전위의 생물물리에서 집단 부호화까지, 3인칭의 가장 단단한 바닥"

**핵심 차별화**:
1. **활동전위를 유도로** — "막전위가 역치를 넘으면 스파이크"가 아니라, 호지킨-헉슬리 방정식에서 Na⁺·K⁺ 채널의 비선형 동역학이 어떻게 전파하는 신호를 만드는지를 직접 수치 적분으로
2. **발화율 vs 시간 부호의 정면 대결** — 두 이론이 단순히 "다른 관점"이 아니라, 서로 다른 반증 가능한 예측을 낳는다. 어떤 실험이 어느 쪽을 지지하는지 정직하게
3. **집단 부호화를 계산으로** — 단일 뉴런의 노이즈와 모호함을 집단이 어떻게 초과하는지, 집단 벡터·베이즈 복호화를 직접 시뮬레이션
4. **Marr의 세 층위를 매 문서에** — 뉴런 메커니즘(구현 층위)이 무엇을 계산하는가(계산 층위), 어떤 알고리즘으로 하는가(알고리즘 층위) — 그리고 이 기술이 경험에 닿는가(→ 간극 표시)

**타겟 독자**:
- 활동전위를 "역치 현상"으로만 알고 그 비선형 동역학을 모르는 사람
- 발화율 부호와 시간 부호의 차이가 왜 중요한지 모르는 사람
- "뇌는 병렬 처리"를 알지만 집단 부호화의 수학적 구조를 모르는 사람
- 시냅스 가소성을 "기억의 물리적 기반"으로 알지만 그 메커니즘을 모르는 사람
- 신경 부호 연구가 의식·경험과 어떻게 연결되고 어디서 한계를 갖는지 보고 싶은 사람

**선행 학습**:

- `levels-of-explanation-distilled`(L0) — **필수**. 구현·알고리즘·계산 층위를 매 문서에서 적용

### Chapter 1: 뉴런 — 계산의 단위 (5개 문서)
- **뉴런의 구조와 기능** — 수상돌기·세포체·축삭의 역할 분업, 흥분성·억제성 뉴런, 인간 뇌의 86억 뉴런이 어떻게 조직되나
- **막전위와 이온 채널** — 나트륨·칼륨·염소 이온의 농도 기울기, 넌스트 방정식, 정지 전위의 기원
- **활동전위의 생물물리** — 역치·상승·하강·과분극의 단계, Na⁺ 채널 활성화-불활성화의 시간 상수, 절대·상대 불응기
- **호지킨-헉슬리 모형** — 네 개의 미분방정식에서 스파이크가 나오는 방식, m·h·n 게이팅 변수의 의미
- **활동전위의 전파** — 수초(myelin)와 랑비에 결절, 도약 전도, 전도 속도와 축삭 직경의 관계

### Chapter 2: 시냅스 — 뉴런 사이의 연산 (5개 문서)
- **화학 시냅스의 작동** — 신경전달물질 방출·수용체 결합·EPSP/IPSP의 생성, 양자 방출
- **AMPA·NMDA 수용체** — 빠른 흥분과 느린 흥분, NMDA의 전압 의존성과 코인시던스 탐지
- **억제 회로와 균형** — GABAergic 억제, E/I 균형, 피질 회로의 억제-흥분 역학
- **시냅스 통합** — 시간적·공간적 합산, 수상돌기 컴파트먼트, 단일 뉴런의 계산 복잡성
- **단기 시냅스 가소성** — 촉진·억압, 사용 의존적 변화, 적응과 필터링

### Chapter 3: 발화율 부호 vs 시간 부호 (6개 문서)
- **발화율 부호(Rate Code)** — 단위 시간의 스파이크 수가 정보를 담는다, 조율 곡선, 에드리언의 원래 발견
- **조율 곡선의 구조** — 방위각·공간 주파수·음높이 선택성, 가우시안·코사인 조율의 의미
- **시간 부호(Temporal Code)** — 스파이크 타이밍이 정보를 담는다, 위상 잠금, 진동과의 관계
- **두 이론의 반증 가능한 예측** — 어떤 실험이 어느 쪽을 지지하는가, 결정적 증거와 그 해석 논쟁
- **희소 부호(Sparse Code)** — 적은 뉴런이 강하게 반응, 제니퍼 애니스턴 뉴런, 에너지 효율성
- **다중화(Multiplexing)** — 발화율과 타이밍이 동시에 다른 정보를 전달할 수 있는가

### Chapter 4: 집단 부호화 — 뉴런들이 함께 계산할 때 (6개 문서)
- **단일 뉴런의 한계** — 노이즈·변동성·모호성, 단일 뉴런으로 정밀한 정보 전달이 왜 어려운가
- **집단 벡터(Population Vector)** — 방위각 정보를 집단의 가중 평균으로 복호화, Georgopoulos의 원숭이 운동 피질 실험
- **베이즈 복호화** — 최적 복호기로서 베이즈 추론, 피셔 정보량과 복호화 오차의 하한
- **피셔 정보량** — 집단 부호의 정보 용량, 뉴런 수 증가에 따른 정밀도 향상의 한계
- **중복과 독립성** — 뉴런 간 노이즈 상관의 영향, 언제 집단이 단일보다 더 좋은가
- **차원 축소와 잠재 공간** — 고차원 집단 활성화에서 저차원 표상 구조 추출 (PCA·UMAP 적용)

### Chapter 5: 감각 신경 부호 (5개 문서)
- **시각 피질의 부호** — V1 단순/복잡 세포, 방위각·공간 주파수·시간 주파수 선택성, 수용장
- **청각 피질의 위상 잠금** — 저주파 소리에 스파이크 타이밍이 소리 파형과 동기화
- **체성 감각의 부호** — 점 식별·질감·압력의 수용장과 부호 전략
- **후각의 집단 부호** — 냄새가 수용체 집단의 패턴으로 표현되는 방식
- **감각 부호와 지각의 연결** — 신경 부호에서 지각 경험이 어떻게 나오는가, 그 설명의 한계(→ 간극 표시)

### Chapter 6: 신경 부호와 계산·경험의 간극 (4개 문서)
- **신경 부호는 알고리즘 층위인가** — 발화율·타이밍·집단 패턴이 Marr의 어느 층위인가, 계산 층위는 어디서 기술되는가
- **부호에서 표상으로** — 신경 부호가 세계를 *표상*한다고 할 때 그것이 무엇을 의미하는가(→ L0 representation)
- **신경 부호와 의식의 관계** — 어떤 부호 특성이 의식과 상관되는가, 상관이 원인이 아닌 이유(→ NCC L4)
- **경험의 잔여** — 어떤 부호가 어떤 자극을 처리하는지 알아도 *왜 거기에 경험이 있는가*는 남는다 (설명적 간극의 구현 층위 위치)

## 🎨 스타일 가이드

1. **메커니즘을 유도로** — "Na⁺ 채널이 열리면 스파이크"가 아니라, 호지킨-헉슬리 방정식에서 비선형 동역학이 어떻게 자기 강화적 상승과 자기 종결적 하강을 만드는지를
2. **발화율 vs 시간 부호를 공정하게** — 한쪽을 "낡은 이론"으로 취급하지 않는다. 두 이론이 서로 다른 반증 가능한 예측을 내놓는다는 것을 실험 데이터와 함께
3. **집단 부호화를 수치로** — 단일 뉴런 기반 설명의 한계를 보이고, 집단 복호화가 어떻게 이를 초과하는지를 시뮬레이션으로
4. **Marr의 층위를 매 문서에** — 뉴런 메커니즘(구현)이 무엇을 계산하는가(계산), 어떻게 하는가(알고리즘)를 항상 분리
5. **간극을 지우지 않는다** — 신경 부호가 아무리 정밀해도 경험의 *있다는 것*을 설명하지 않는다는 것을 매 챕터 말미에
6. 호지킨-헉슬리 동역학·조율 곡선·집단 벡터·피셔 정보 경관은 다이어그램으로

import numpy as np
from scipy.integrate import odeint

def hh_model(y, t, I_ext=10.0):
    V, m, h, n = y
    gNa, gK, gL = 120.0, 36.0, 0.3
    ENa, EK, EL = 50.0, -77.0, -54.4

    alpha_m = 0.1*(V+40)/(1-np.exp(-(V+40)/10)) if V != -40 else 1.0
    beta_m  = 4.0*np.exp(-(V+65)/18)
    alpha_h = 0.07*np.exp(-(V+65)/20)
    beta_h  = 1/(1+np.exp(-(V+35)/10))
    alpha_n = 0.01*(V+55)/(1-np.exp(-(V+55)/10)) if V != -55 else 0.1
    beta_n  = 0.125*np.exp(-(V+65)/80)

    INa = gNa * m**3 * h * (V - ENa)
    IK  = gK  * n**4     * (V - EK)
    IL  = gL             * (V - EL)

    dVdt = (I_ext - INa - IK - IL)
    dmdt = alpha_m*(1-m) - beta_m*m
    dhdt = alpha_h*(1-h) - beta_h*h
    dndt = alpha_n*(1-n) - beta_n*n
    return [dVdt, dmdt, dhdt, dndt]

# 2) 집단 벡터 복호화
def population_vector_decode(preferred_dirs, firing_rates):
    """
    preferred_dirs: 각 뉴런의 선호 방향 (라디안)
    firing_rates:   각 뉴런의 발화율
    → 가중 평균 벡터 → 자극 방향 복호화
    """
    vectors = firing_rates[:, None] * np.column_stack([
        np.cos(preferred_dirs), np.sin(preferred_dirs)
    ])
    population_vec = vectors.sum(axis=0)
    decoded_angle  = np.arctan2(population_vec[1], population_vec[0])
    return decoded_angle

def fisher_info_population(preferred_dirs, tuning_width, noise_std):
    """
    I_F = Σ_i [f'_i(θ)]² / σ²_i
    → 집단 크기·조율 폭·노이즈가 복호화 정밀도에 미치는 영향
    """
    N = len(preferred_dirs)
    delta_theta = 0.001  # 수치 미분
    f_plus  = np.exp(-0.5*(np.pi/tuning_width)**2) * 50
    f_prime = (f_plus - 50*np.exp(0)) / delta_theta  # 단순화
    return N * f_prime**2 / noise_std**2

## 💡 핵심 분석 대상

```
활동전위 — 비선형 동역학:
  V < 역치(-55 mV):    Na⁺ 채널 닫힘 → 안정
  V ≥ 역치:
       │  Na⁺ 채널 급격히 열림 → V 상승
       │  V 상승 → 더 많은 Na⁺ 채널 열림  (양성 피드백)
       ▼
  +40 mV 도달 → Na⁺ 불활성화 / K⁺ 채널 열림
       │  V 하강 (음성 피드백)
       ▼
  과분극 → K⁺ 채널 닫힘 → 정지 전위 복귀
  ⇒ 호지킨-헉슬리: 4개 비선형 ODE에서 이 모든 것이 나온다

발화율 vs 시간 부호:
  발화율 부호:  r(t) = (단위 시간 스파이크 수) → 자극 강도 인코딩
  시간 부호:    타이밍 t_i → 자극 위상·동기화 인코딩
  
  결정적 실험:
  ├─ 발화율 지지: 시각 피질 대비 감도, 운동 피질 방향 선택
  ├─ 시간 부호 지지: 청각 위상 잠금, 해마 격자 세포 위상 세차
  └─ 여전히 열려있다: 어느 계산에서 어느 부호가 사용되는가

집단 벡터 복호화:
  100개 방향 선택 뉴런, 코사인 조율 곡선
       │  단일 뉴런: 방향 모호성 高, 노이즈 민감
       ▼
  집단 벡터 = Σ_i r_i · ê_i   (발화율 가중 방향 벡터)
  → 자극 방향을 ±2° 정밀도로 복호화
  ⇒ 집단이 단일 뉴런의 한계를 초과 (√N 개선)

경험의 잔여:
  신경 부호 연구로 설명 가능한 것:
  ├─ 어떤 자극이 어떤 뉴런을 활성화하는가
  ├─ 어떻게 자극 정보가 집단으로 인코딩되는가
  └─ 어떻게 복호화기가 정보를 추출하는가
  
  설명되지 않는 것:
  → 왜 이 부호가 처리될 때 *경험*이 따라붙는가
  → 빨강의 신경 부호를 완전히 알아도
    "빨강이 이렇게 느껴진다"는 것은 남는다
  ⇒ 설명적 간극의 신경 부호 층위 위치
```
