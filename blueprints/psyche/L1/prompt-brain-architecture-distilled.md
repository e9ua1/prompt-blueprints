# Brain Architecture Distilled 레포지토리 제작 프롬프트

나는 "Brain Architecture Distilled" 레포지토리를 만들려고 해.
"언어는 브로카 영역에서 처리된다"고 말하는 것과, **기능 국재화가 부분적 진실이고 어떤 조건에서 성립하며 어디서 신화가 시작되는지** — 브로카 영역 손상 환자들의 개별 편차가 어떻게 그 경계를 허무는지를 — 이해하는 것은 다르다.
"뇌는 전두엽·두정엽·측두엽·후두엽으로 나뉜다"고 외우는 것과, **왜 피질이 이 구조로 조직됐는지** — 감각 정보가 어떤 경로로 흘러 운동 출력이 되고, 위계가 어디서 끝나며 재귀 연결이 어디서 시작하는지를 — 설계 원리 수준에서 이해하는 것은 다르다.
시상을 "중계소"로 아는 것과, **시상이 단순 중계가 아니라 피질로 올라가는 정보를 능동적으로 게이팅하고 수면·마취에서 피질을 고립시키는 핵심 스위치**임을 — 시상-피질 루프가 의식 유지에 어떻게 필수인지를 — 아는 것은 다르다.
뇌의 구조가 단지 해부학 사실이 아니라 **왜 이렇게 설계됐는가**의 계산적 이유를 — 그리고 그 설계가 경험의 통합과 어떻게 관련되고 어디서 한계를 갖는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "왜 뇌는 이렇게 조직됐나 — 피질·시상·기저핵·소뇌의 분업을 설계 원리에서"

**핵심 차별화**:
1. **기능 국재화의 진실과 신화** — "언어는 브로카" "시각은 후두엽"이 부분적 진실이고 왜 부분적인지. 분산 처리·네트워크 관점이 국재화를 대체하는 것이 아니라 보완하는 방식
2. **설계 원리로서의 위계** — 피질의 위계적 조직이 왜 계산적으로 효율적인지, 수용장 크기·추상화 수준의 상관, 그리고 재귀(feedback)가 위계를 어떻게 복잡하게 만드는지
3. **시상-피질 루프를 의식의 스위치로** — 시상이 단순 중계가 아니라 게이팅 메커니즘이고, 수면·마취·최소 의식 상태에서 이 루프가 어떻게 무너지는지를 임상 데이터와 함께
4. **연결체(connectome)의 관점** — 구조적·기능적 연결성이 어떻게 인지와 경험을 제약하는지, 뇌 네트워크(DMN·살리언스·실행 제어)의 의미

**타겟 독자**:
- 뇌 구조를 해부학 암기로 배운 사람, 왜 그 구조인지 모르는 사람
- 기능 국재화가 "사실"이라 믿지만 그 한계를 모르는 사람
- 시상의 역할을 "중계소"로만 아는 사람
- 기저핵이 왜 존재하는지, 소뇌가 왜 그렇게 큰지 모르는 사람
- 뇌 구조가 의식·경험과 어떻게 연결되고 어디서 한계를 갖는지 보고 싶은 사람

**선행 학습**:
- `neurons-neural-codes-distilled`(L1) — **필수**. 뉴런 단위에서 회로 단위로
- `levels-of-explanation-distilled`(L0) — 구조-기능 관계가 어느 층위 설명인가

### Chapter 4: 기저핵 — 선택과 억제의 회로 (5개 문서)
- **기저핵의 구조** — 선조체·담창구·흑질·시상하핵의 구성, 직접·간접 경로

## 🎨 스타일 가이드

## 🔬 검증 프로토콜

> 위계 네트워크 시뮬레이션 + 시상-피질 루프 동역학 + 기저핵 선택 회로 + 그래프 이론 분석.

```python
# 환경: Python 3 + numpy + scipy + networkx + matplotlib

# 1) 피질 위계 — 수용장 크기 증가 시뮬레이션
import numpy as np
def hierarchical_rf(input_size, n_layers, rf_growth=2.0):
    """각 층위에서 수용장이 기하급수적으로 증가"""
    rfs = [1]
    for layer in range(1, n_layers):
        rfs.append(rfs[-1] * rf_growth)
    return rfs
# V1(RF≈1°) → V4(RF≈5°) → IT(RF≈25°) 시뮬레이션
# → 위계가 불변성을 어떻게 구축하는가

# 2) 시상-피질 루프 (Wilson-Cowan)
def thalamo_cortical_loop(dt=0.1, T=500):
    """
    Cortex → Thalamus (피질→시상 역투사)
    Thalamus → Cortex (시상→피질 투사)
    TRN (시상 망상핵) → Thalamus (억제)
    """
    C = np.zeros(T)  # 피질 활성
    Th = np.zeros(T) # 시상 활성
    TRN = np.zeros(T) # 망상핵 활성
    
    for t in range(1, T):
        # 피질 활성화 (시상 입력 + 재귀)
        C[t]   = np.tanh(0.8*Th[t-1] + 0.5*C[t-1])
        # 시상 활성화 (피질 피드백 - TRN 억제)
        Th[t]  = np.tanh(0.6*C[t-1] - 0.9*TRN[t-1])
        # TRN 억제 (피질·시상에 의해 활성화)
        TRN[t] = np.tanh(0.4*C[t-1] + 0.4*Th[t-1])
    
    return C, Th, TRN
# → 각성 상태(안정 진동) vs 수면(동기화 버스트) 모드 전환

# 3) 기저핵 행동 선택 모델
def basal_ganglia_selection(n_channels=4, salience=None):
    """
    직접 경로: GO (선조체→GP_i→시상: 억제 해제)
    간접 경로: NO-GO (선조체→GP_e→STN→GP_i: 억제 강화)
    → 가장 높은 현저성 채널만 선택
    """
    if salience is None:
        salience = np.random.rand(n_channels)
    
    # 직접 경로 강도 ∝ 선조체 D1 활성
    direct   = salience * 1.2
    # 간접 경로 강도 ∝ 선조체 D2 활성
    indirect = (1 - salience) * 0.8
    
    # GP_i 억제 = 직접 - 간접
    inhibition = indirect - direct
    # 시상 출력 ∝ 억제 해제
    thalamic_output = -inhibition + np.max(-inhibition)
    selected = np.argmax(thalamic_output)
    return selected, thalamic_output

# 4) 뇌 네트워크 그래프 분석
import networkx as nx
def brain_network_metrics(adjacency_matrix):
    G = nx.from_numpy_array(adjacency_matrix)
    clustering = nx.average_clustering(G)
    path_length = nx.average_shortest_path_length(G)
    # 소세계 지수 (σ = γ/λ)
    # γ: 클러스터링 / 랜덤 네트워크, λ: 경로 길이 / 랜덤 네트워크
    return clustering, path_length

피질 위계 — 계산적 이유:
  V1 (수용장 0.5°, 엣지 감지)
       │ 피드포워드 + 피드백
  V4 (수용장 5°, 색상·형태)
       │
  IT  (수용장 25°, 객체 정체성)
       │
  PFC (추상·목표·계획)
  
  위계가 주는 것:
  ├─ 불변성 (크기·위치·조명 변화에 강건)
  ├─ 추상화 (픽셀 → 엣지 → 객체 → 범주)
  └─ 재사용 (낮은 층 특징이 여러 상위 개념에 공유)

시상-피질 루프 — 의식의 스위치:
  각성 상태:  시상 토닉 발화 → 피질에 지속 신호 → 의식 유지
  NREM 수면:  시상 TRN이 피질 격리 → 방추 진동 → 의식 차단
  마취:       시상-피질 루프 붕괴 → 의식 소실
  최소 의식:  루프 부분 유지 → 간헐적 의식
  ⇒ 시상이 의식의 게이트 키퍼

기저핵 — 선택의 회로:
  직접 경로 (GO):    선조체 D1 → GPi 억제 → 시상 탈억제 → 행동 선택
  간접 경로 (NO-GO): 선조체 D2 → GPe → STN → GPi 강화 → 행동 억제
  도파민 조절:
  ├─ 도파민 ↑ → D1 강화, D2 억제 → GO 우세 → 행동 증진 (파킨슨 반대)
  └─ 도파민 ↓ → D2 우세 → NO-GO → 운동 느림 (파킨슨)
  ⇒ 경쟁하는 행동 중 하나를 선택하는 최적화 회로

구조에서 경험으로의 간극:
  구조 설명이 가능한 것:
  ├─ 어느 영역이 어느 자극을 처리하는가
  ├─ 어떤 회로가 어떤 행동을 선택하는가
  └─ 어떤 루프가 각성을 유지하는가
  
  설명되지 않는 것:
  → 왜 시상-피질 루프가 활성일 때 *경험*이 있는가
  → 의식이 "켜지는" 것이 왜 느껴지는가
  ⇒ 구조가 가장 단단한 바닥이지만, 거기서 멈추면 경험을 놓친다
```
