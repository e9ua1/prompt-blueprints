# Neuromodulation & Arousal Distilled 레포지토리 제작 프롬프트

나는 "Neuromodulation & Arousal Distilled" 레포지토리를 만들려고 해.
"도파민은 행복 물질이다"고 말하는 것과, **도파민이 실제로 보상예측오차(reward prediction error)를 신호한다는 것** — 예상된 보상이 오면 도파민 발화가 증가하지 *않고*, 예상보다 더 나오면 증가하고 예상보다 못 나오면 *감소*한다는 것을 — 슐츠의 원숭이 실험에서 직접 추적하는 것은 다르다.
"세로토닌이 기분을 조절한다"는 것과, **세로토닌의 실제 기능이 기분 조절이 아니라 시간적 할인, 처벌 억제, 내수용 감각 신호와 더 밀접하게 연결된다는 것** — SSRIl이 왜 2-4주가 걸리는지, 그 지연이 세로토닌 단순 증가가 아닌 무엇을 시사하는지를 — 이해하는 것은 다르다.
"수면이 필요하다"고 알면서도 **뇌간의 어떤 스위치가 각성과 수면을 전환하는지** — LC(청반)·DRN·TMN·VLPO의 상호 억제 플립플롭이 어떻게 불안정한 중간 상태 없이 두 상태 사이를 전환하는지를 — 회로 수준에서 이해하는 것은 다르다.
조절 물질들이 단순히 "신호 전달 물질"이 아니라 **피질 전체의 계산 상태를 바꾸는 전역 조절자**임을 — 그리고 그 전역 상태가 의식의 온/오프와 어떻게 연결되는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "도파민은 행복이 아니다 — 신경조절 물질이 계산 상태를 어떻게 전환하고, 각성 스위치가 의식을 어떻게 켜는가"

**핵심 차별화**:
1. **도파민 = 보상예측오차를 수치로** — 슐츠 실험의 단계별 재현: 무조건 자극→조건화 자극 이동에서 도파민 신호가 어떻게 이동하는지, TD 학습과의 정확한 대응(→ AI Lab RL 교차)
2. **세로토닌의 복잡한 실제** — "기분 물질" 단순화를 교정: 세로토닌이 신호하는 것(처벌 억제·시간 할인)과 신호하지 않는 것의 구분, SSRI 지연이 시사하는 것
3. **각성 스위치를 회로로** — LC·DRN·TMN·VLPO의 플립플롭 모델: 왜 중간 상태(반쯤 각성·반쯤 수면)가 드문가, 기면증에서 이 회로가 어떻게 무너지는가
4. **전역 조절을 계산적으로** — 아세틸콜린이 피질의 신호-대-잡음비를 높이고, 노르에피네프린이 주의 자원을 재배분하고, 도파민이 예측 오차 가중치를 바꾸는 방식을 통합적으로

## 🔬 검증 프로토콜

> TD 학습 RPE 시뮬레이션 + 각성 플립플롭 동역학 + 신경조절 gain 모델.

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) TD 학습으로 도파민 RPE 시뮬레이션
import numpy as np

def td_learning(n_trials=100, alpha=0.1, gamma=0.9):
    """
    슐츠 실험: CS(조건화 자극) → (2초 후) US(보상)
    도파민 = RPE = R + γV(s') - V(s)
    """
    n_steps = 10  # CS부터 US까지 10 타임스텝
    V = np.zeros(n_steps + 1)  # 가치 함수
    da_responses = []  # 도파민 응답 기록
    
    for trial in range(n_trials):
        trial_da = np.zeros(n_steps)
        R = np.zeros(n_steps)
        R[-1] = 1.0  # US(보상)은 마지막 타임스텝
        
        for t in range(n_steps):
            rpe = R[t] + gamma * V[t+1] - V[t]  # RPE = 도파민 신호
            V[t] += alpha * rpe
            trial_da[t] = rpe
        
        da_responses.append(trial_da.copy())
    
    return np.array(da_responses), V
# → 초기 trial: US 시점에 도파민 발화
# → 후기 trial: CS 시점으로 도파민 이동 (슐츠 실험 재현)

# 2) 각성-수면 플립플롭 모델
def arousal_flipflop(dt=0.01, T=1000, w_mutual=2.5):
    """
    각성 핵 (A) ─┤─ VLPO (S)
    VLPO   (S) ─┤─ 각성 핵 (A)
    상호 억제 → 이분 안정 상태
    """
    A = np.zeros(int(T/dt))  # 각성 핵 활성
    S = np.zeros(int(T/dt))  # VLPO 활성
    
    A[0], S[0] = 1.0, 0.0  # 초기: 각성
    
    for i in range(1, len(A)):
        ext_drive_A = 0.5 + 0.1*np.random.randn()  # 외부 각성 압력
        ext_drive_S = 0.3 + 0.05*np.random.randn() # 수면 압력 (피로)
        
        # 상호 억제
        A[i] = np.clip(A[i-1] + dt*(ext_drive_A - w_mutual*S[i-1] - 0.5*A[i-1]), 0, 1)
        S[i] = np.clip(S[i-1] + dt*(ext_drive_S - w_mutual*A[i-1] - 0.5*S[i-1]), 0, 1)
    
    return A, S
# → 각성/수면 사이 안정 전환, 중간 상태 불안정 (기면증: w_mutual 감소)

# 3) 신경조절 Gain 모델
def neuromodulation_gain(stimulus, NE_level=1.0, ACh_level=1.0):
    """
    NE: 신호-잡음비 조절 (gain 증폭)
    ACh: 수용장 선명화 (억제 강화)
    """
    # 기저 반응
    baseline_noise = np.random.randn(*stimulus.shape) * 0.5
    response = stimulus + baseline_noise
    
    # NE: gain 증폭 (역U 함수)
    optimal_NE = 1.0
    ne_factor = 1 + NE_level - (NE_level - optimal_NE)**2
    response *= ne_factor
    
    # ACh: 억제 강화 → 피질 선명화
    ach_sharpening = 1 + 0.3 * ACh_level
    response = np.where(response > 0, response * ach_sharpening, response)
    
    return response
```

## 💡 핵심 분석 대상

```
도파민 = 보상예측오차:
  [초기 조건화]
  CS(빛) → 0.5초 대기 → US(주스)
  도파민 발화: CS에서 없음, US에서 큰 발화 (예상 외 보상)
  
  [완전 조건화 후]
  CS(빛) → 도파민 발화 (예측 = 기댓값 갱신)
  US(주스) → 도파민 변화 없음 (예측된 보상, RPE=0)
  
  [보상 생략]
  CS(빛) → 도파민 발화, US 시점에 → 도파민 억제 (RPE < 0)
  
  ⇒ 도파민 = R + γV(s') - V(s) (TD 오차)
  ⇒ "행복"이 아니라 "예측과 현실의 차이"

각성 플립플롭:
  각성 핵 (LC·DRN·TMN) ──억제──► VLPO
  VLPO ──────────────────억제──► 각성 핵
  
  두 안정 상태:
  각성: 각성 핵 ↑, VLPO ↓ → 피질 활성화
  수면: 각성 핵 ↓, VLPO ↑ → 피질 억제
  
  전환 트리거:
  ├─ 수면 압력(아데노신 축적) → VLPO 쪽으로
  └─ 각성 신호(오렉신·빛) → 각성 핵 쪽으로
  
  기면증: 오렉신 손실 → 플립플롭 불안정 → 갑작스러운 수면 침입

신경조절의 계산 역할:
  물질          계산 파라미터     수준 ↑이면
  ──────────────────────────────────────────
  도파민(DA)    학습률·탐색 온도  새 정보 더 무게
  노르에피네프린  gain·신호잡음비  감각 선명·주의 집중
  아세틸콜린    피질 선명도·가소성 학습 증진·지각 강화
  세로토닌      할인율·충동 억제  미래 가중·반응 억제
  히스타민      각성 유지         각성 강화
  ⇒ 조절 물질들은 "신호"가 아니라 계산 파라미터를 세팅한다

경험의 잔여:
  신경조절이 설명하는 것:
  ├─ 왜 각성 상태에서 더 선명하게 지각하는가
  ├─ 왜 도파민이 높을 때 더 적극적으로 행동하는가
  └─ 왜 수면 중 의식이 변하는가
  
  설명되지 않는 것:
  → 왜 각성 상태가 "이렇게 느껴지는가"
  → 왜 도취 상태에 특정한 질감의 경험이 있는가
  ⇒ 신경조절이 의식을 켜지만, 켜진 의식의 *내용*과 *질감*은 남는다
```
