# Perception Distilled 레포지토리 제작 프롬프트

나는 "Perception Distilled" 레포지토리를 만들려고 해.
"눈이 세계를 본다"고 말하는 것과, **시각 피질이 망막 신호를 수동적으로 수신하는 것이 아니라, 이미 가진 세계 모델로 예측을 내려보내고 예측 오차만 올려 받는다**는 것을 — 그리고 우리가 보는 것의 대부분이 눈에서 오는 것이 아니라 뇌에서 내려오는 것임을 — 이해하는 것은 다르다.
착시를 "눈의 착각"으로 아는 것과, **착시가 뇌의 오류가 아니라 평소에는 정확한 추론 규칙이 극단적 자극에서 드러나는 것**임을 — 뮬러-라이어 착시가 깊이 단서를 이용한 크기 항등성의 부산물임을 — 유도하는 것은 다르다.
"눈이 카메라다"라는 직관을 가지고 있는 것과, **수용장·횡단 억제·색 항등성·운동 지각이 각각 어떤 계산 문제를 해결하기 위해 어떻게 설계됐는지**를 — 그리고 그 설계가 경험의 "보임"을 어디까지 설명하고 어디서 멈추는지를 — 추적하는 것은 다르다.
지각이 알고리즘 층위에서 어떤 계산을 하는가를 — 그리고 그 계산이 경험으로서의 "봄"을 설명하는가, 아닌가를 — 매 문서에서 정직하게 마주하는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "본다는 것은 수신이 아니라 추론이다 — 예측처리·베이즈 지각·항등성이 지각의 알고리즘을 어떻게 드러내는가"

**핵심 차별화**:
1. **예측처리로서의 지각을 Marr 층위로** — 예측처리 이론이 계산 층위("3D 세계 재구성")·알고리즘 층위("하향 예측 + 상향 오차")·구현 층위("V1 피라미드 세포")를 어떻게 각각 기술하는지 분리해서 다룬다
2. **착시를 추론 규칙의 노출로** — 착시 목록이 아니라, 각 착시가 어떤 추론 규칙의 어떤 조건에서 나타나는지를 베이즈 추론 틀로 추적
3. **항등성(constancy)의 계산적 의미** — 색·크기·모양·명도 항등성이 왜 지각 시스템의 가장 중요한 성취이고, 그것이 어떻게 "물체 세계"를 만들어내는지
4. **지각과 행동의 연결** — 배측/복측 경로의 분리, 지각이 행동을 위해 어떻게 다르게 처리되는지, 지각 없는 행동(맹시)이 무엇을 시사하는지

**타겟 독자**:
- "눈이 세계를 보는 것"이라는 직관을 가진 사람
- 착시를 "뇌의 버그"로 아는 사람
- 예측처리 이론을 들었지만 지각에 어떻게 적용되는지 모르는 사람
- 색 항등성·크기 항등성의 계산적 의미를 모르는 사람
- 지각과 의식이 어떻게 연결되고 어디서 분리되는지 보고 싶은 사람

**선행 학습**:
- `information-prediction-distilled`(L0) — **필수**. 베이즈 추론·예측처리의 수학적 틀
- `neurons-neural-codes-distilled`(L1) — 시각 피질의 부호, 수용장·조율 곡선
- `brain-architecture-distilled`(L1) — 시각 위계(V1→IT/MT)의 구조

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 지각이란 무엇인가 — 추론으로서의 봄 (5개 문서)
- **지각의 역문제** — 망막의 2D 이미지에서 3D 세계를 복원하는 것이 왜 수학적으로 불량 설정(ill-posed)인가, 추가 가정(prior)이 왜 필요한가
- **헬름홀츠의 무의식적 추론** — 지각을 추론으로 보는 전통의 시작, 현대 예측처리와의 연결
- **예측처리로서의 지각** — 하향 예측·상향 오차, 뇌는 세계 모델을 검증하는 기계
- **지각과 행동의 목적** — 지각이 아름다운 표상을 위해서가 아니라 행동을 위해 존재한다는 관점
- **지각 연구의 방법론** — 정신물리학·신경영상·병변·착시를 지각 이론 검증에 어떻게 쓰는가

### Chapter 2: 시각 처리의 위계 (5개 문서)
- **망막에서 V1까지** — 광수용체·쌍극세포·신경절세포·외측 슬상핵, 각 단계의 계산
- **V1 — 특징 탐지기** — 방위각·공간 주파수·색·운동 선택성, 단순/복잡 세포, 수용장 구조
- **복측 경로 — "무엇"** — V4(색·형태) → IT(객체 정체성), 시각적 불변성 구축
- **배측 경로 — "어디"와 "어떻게"** — MT(운동) → LIP/VIP → 공간 처리와 행동 안내
- **피드백의 규모** — 피질 시각 연결의 70%는 피드백, 상향 신호보다 하향 신호가 많다

### Chapter 3: 베이즈 지각과 착시 (6개 문서)
- **베이즈 지각의 수식** — P(세계|감각) ∝ P(감각|세계) × P(세계), 지각 = 사후 확률 최대화
- **크기 항등성과 뮬러-라이어 착시** — 깊이 단서에서 나온 크기 보정 규칙이 평면 이미지에서 착시를 낳는 방식
- **명도 항등성과 동시 대비** — 주변 맥락에서 조명을 추론해 반사율을 분리하는 알고리즘
- **색 항등성** — 조명이 바뀌어도 색이 같아 보이는 이유, 망막 신호 비율을 이용한 계산
- **운동 착시** — 정지 이미지에서 운동이 보이는 이유, 운동 시스템의 예측 편향
- **사전확률 강도와 착시 개인차** — 왜 같은 착시를 사람마다 다르게 경험하는가, 가소성과 문화

### Chapter 4: 항등성 — 지각의 핵심 성취 (5개 문서)
- **항등성 문제** — 왜 같은 물체가 조명·거리·각도가 달라도 같아 보이는가, 이게 왜 어려운가
- **크기 항등성의 알고리즘** — 거리 단서(시차·렌즈 조절)에서 실제 크기 복원
- **색 항등성의 알고리즘** — 폰 크리스 적응·비율 코딩·Land의 망막 이론
- **모양 항등성과 시점 불변성** — 다양한 시점에서 같은 물체 인식, IT 피질의 역할
- **항등성 실패 — 착시의 반대편** — 항등성이 지나쳐 다른 것을 같게 보는 경우들

### Chapter 5: 다중 감각과 시간 지각 (4개 문서)
- **다중감각 통합** — 청각·촉각·시각의 베이즈 최적 결합, 맥거크 효과·고무손 착각
- **시간 지각의 추론** — 내부 시계가 아니라 정보 밀도로 시간을 추론, 왜 지루할 때 시간이 느린가
- **예측과 시간** — 기대된 자극은 더 빨리 처리되는 것처럼 느껴지는 이유
- **행동이 지각을 바꾼다** — 능동적 탐색, 안구 운동, 감각운동 우연성

### Chapter 6: 지각과 의식 (4개 문서)
- **맹시(Blindsight)** — 의식적 봄 없이 시각 정보로 행동할 수 있다, 지각과 의식의 분리
- **양안경쟁** — 의식 내용이 신경 신호 강도만으로 결정되지 않는 이유, 능동적 선택
- **지각과 주의의 관계** — 주의 없이 지각하는가, 지각 없이 주의를 기울이는가
- **지각의 설명적 간극** — 지각의 알고리즘이 완전히 해명돼도 "보임"의 경험은 어디서 남는가

### Chapter 7: 종합·계산 (7개 문서)
- **베이즈 지각 모델 구현** — 가우시안 사전확률 + 가능도 → 크기·깊이 추정(Python)
- **착시 시뮬레이션** — 뮬러-라이어·체스판 명도 착시를 베이즈 모델로 재현(Python)
- **색 항등성 알고리즘** — 비율 코딩으로 조명 변화에 불변한 색 복원(Python)
- **예측처리 시각 모델** — 1D 계층 예측오차 최소화 시뮬레이션(Python)
- **V1 수용장 시뮬레이션** — 가보 필터·방위각 선택성 시각화(Python)
- **맹시 패러다임 분석** — d'(민감도) 계산으로 의식/무의식 시각 처리 분리(Python)
- **종합** — "추론으로서의 지각"의 통합, 그리고 "보임"이 남기는 잔여(→ L4)

```python
# 환경: Python 3 + numpy + scipy + matplotlib

# 1) 베이즈 크기 추정
import numpy as np
def bayesian_size_estimate(retinal_size, depth_cue, prior_size_mean=1.0,
                            prior_size_std=0.5, likelihood_std=0.2):
    prior_var      = prior_size_std**2
    likelihood_var = likelihood_std**2
    # 실제 크기 = 망막 크기 × 거리 (깊이 단서로 추정)
    perceived_size = depth_cue * retinal_size
    # 베이즈 갱신
    posterior_var  = 1/(1/prior_var + 1/likelihood_var)
    posterior_mean = posterior_var*(prior_size_mean/prior_var + perceived_size/likelihood_var)
    return posterior_mean

# 2) 뮬러-라이어 착시 시뮬레이션
def muller_lyer_model(line_length, arrow_angle):
    """
    깊이 단서로서의 화살표: 안쪽 화살(모서리 안쪽) → 더 멀리
    → 같은 망막 크기 = 더 큰 실제 크기로 해석 → 길어 보임
    """
    depth_bias = np.cos(arrow_angle)  # 화살 각도가 깊이 단서
    perceived_length = line_length * (1 + 0.3 * depth_bias)
    return perceived_length

# 3) 색 항등성 — 비율 코딩
def color_constancy_ratio(surface_reflectance, illumination):
    """Land의 망막 이론: 인접 영역의 비율이 반사율을 복원"""
    sensor_response = surface_reflectance * illumination
    # 인접 영역과의 비율 → 조명 추정 후 반사율 분리
    ratio = sensor_response / np.mean(sensor_response)
    return ratio  # 조명 변화에 불변

# 4) 예측처리 지각 모델 (1D)
def predictive_perception(observations, n_levels=3, alpha=0.1):
    predictions = [np.zeros_like(observations) for _ in range(n_levels)]
    errors      = [np.zeros_like(observations) for _ in range(n_levels)]
    for t, obs in enumerate(observations):
        errors[0][t] = obs - predictions[0][t]
        for level in range(n_levels-1):
            errors[level+1][t] = errors[level][t] - predictions[level+1][t]
            predictions[level][t+1 if t+1 < len(observations) else t] += \
                alpha * errors[level][t]
    return predictions, errors

# 5) V1 가보 필터 (방위각 선택성)
def gabor_filter(size=64, wavelength=8, orientation=0, phase=0):
    x = np.linspace(-size//2, size//2, size)
    X, Y = np.meshgrid(x, x)
    Xr = X*np.cos(orientation) + Y*np.sin(orientation)
    Yr = -X*np.sin(orientation) + Y*np.cos(orientation)
    gaussian = np.exp(-(Xr**2 + Yr**2)/(2*(size/6)**2))
    sinusoid  = np.cos(2*np.pi*Xr/wavelength + phase)
    return gaussian * sinusoid
```

## 💡 핵심 분석 대상

```
지각의 역문제:
  관측: 망막 이미지 I (2D, 모호함)
       │  역문제: 무한히 많은 3D 세계가 같은 I를 낳을 수 있다
       ▼
  지각: 3D 세계 S (선택된 해석)
  
  해결: 베이즈 추론
  P(S|I) ∝ P(I|S) × P(S)
          가능도     사전확률(이전 경험·진화적 가정)
  
  ⇒ 지각 = 가장 그럴듯한 세계의 원인 추론

착시 = 올바른 규칙의 노출:
  뮬러-라이어: "화살표 모양 → 깊이 단서 → 크기 보정"
  → 평면에서: 보정이 오적용 → 같은 선이 다른 길이로
  
  체스판 착시: "주변 명도 → 조명 추론 → 반사율 분리"
  → 맥락 때문에 같은 회색이 다르게 보임
  
  ⇒ 착시 = 뇌의 버그가 아니라 평소 올바른 알고리즘의 노출

맹시가 보여주는 것:
  V1 손상 환자: 의식적 봄 없음
  그러나: 장애물 피하기·물체 방향 맞추기 가능
  
  ⇒ 지각(시각 정보 처리)과 의식적 봄은 분리 가능
  ⇒ 배측 경로(행동 안내)가 의식 없이 작동
  ⇒ 의식이 봄의 충분조건도 필요조건도 아닐 수 있다

경험의 잔여:
  알고리즘이 설명하는 것:
  ├─ 왜 착시가 일어나는가
  ├─ 어떻게 항등성이 유지되는가
  └─ 어떻게 3D 세계가 복원되는가
  
  설명되지 않는 것:
  → 왜 빨강이 "이렇게" 느껴지는가
  → 왜 봄에 주관적 질감(qualia)이 있는가
  ⇒ 지각의 설명적 간극 — 알고리즘 이후에도 남는 것
```
