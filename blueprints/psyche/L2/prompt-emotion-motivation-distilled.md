# Emotion & Motivation Distilled 레포지토리 제작 프롬프트

나는 "Emotion & Motivation Distilled" 레포지토리를 만들려고 해.
"감정은 이성의 적이다"고 말하는 것과, **다마지오의 체성표지 가설이 어떻게 감정 없는 결정이 왜 망가지는지를 보여주는지** — VMF 피질 손상 환자 엘리엇이 왜 논리적으로 완벽하지만 생활에서 결정을 못 하는지를 — 이해하는 것은 다르다.
"기본 감정 6가지"(에크만)를 외우는 것과, **기본 감정 이론과 구성된 감정 이론(Lisa Feldman Barrett)이 어떻게 정반대를 주장하고, 어떤 실험적 증거가 각각을 지지하며 어느 쪽이 더 잘 설명하는지**를 — 그리고 이 논쟁이 "감정이란 무엇인가"에 대한 더 깊은 질문임을 — 추적하는 것은 다르다.
"감정을 느낀다"고 말하는 것과, **내수용감각(interoception)이 감정 경험을 어떻게 바닥에서 구성하는지** — 심박수·혈압·내장 신호가 어떻게 뇌로 올라가고, 예측 처리 틀에서 이것이 어떻게 감정의 "원재료"가 되는지를 — 이해하는 것은 다르다.
감정이 알고리즘 층위에서 어떻게 작동하는지를 — 그리고 감정의 경험이 그 알고리즘의 어디에 해당하고 어디서 가장 날카롭게 남는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "감정은 합리의 적이 아니라 평가 시스템이다 — 체성표지·내수용감각·구성된 감정이 어떻게 결정을 가능하게 하는가"

**핵심 차별화**:
1. **체성표지 가설을 핵심으로** — 감정이 "느낌"이 아니라 신체 상태의 표지로서 결정을 안내한다는 것을, 아이오와 도박 과제·VMF 손상 사례로. 감정 없는 결정은 더 좋은 것이 아니라 더 나쁘다
2. **기본 감정 vs 구성된 감정의 정면 대결** — 에크만의 보편 기본 감정과 Barrett의 "감정은 뇌가 구성하는 것"의 논쟁을 실험 증거와 함께. 어느 쪽이 어떤 현상을 더 잘 설명하는가
3. **내수용감각을 감정의 기반으로** — 심장·내장·폐의 신호가 어떻게 감정 경험을 구성하는지를 예측처리 틀로. "심장이 두근거리니까 무섭다"(제임스-랑게) vs "무서우니까 두근거린다"(캐논-바드)의 현대적 해소
4. **동기와 감정의 통합** — 동기가 단순한 욕구가 아니라 예측된 보상(욕구)·현재 손실(회피)·목표 표상(의도)의 복합임을 계산적으로

**타겟 독자**:
- "감정은 이성의 적"이라 믿는 사람
- 에크만의 6 기본 감정이 "사실"이라고 배운 사람
- "심장이 두근거리면 무섭다"와 "무서워서 두근거린다" 중 어느 것인지 모르는 사람
- 감정 없이 더 좋은 결정을 할 수 있다고 생각하는 사람
- 감정의 알고리즘과 "감정을 느끼는 것"이 어떻게 연결되는지 보고 싶은 사람

**선행 학습**:
- `neuromodulation-arousal-distilled`(L1) — 감정 관련 신경조절물질(도파민·세로토닌)
- `learning-decision-distilled`(L2) — 가치 기반 결정에서 감정의 역할
- `information-prediction-distilled`(L0) — 예측처리 틀로서의 내수용감각

### Chapter 1: 감정이란 무엇인가 (5개 문서)
- **감정의 구성 요소** — 주관적 경험·생리적 각성·행동 경향·인지적 평가, 어느 것이 본질인가

- **감정과 느낌의 구분** — 다마지오의 구분: 감정(신체 과정)과 느낌(그것의 의식적 경험)
- **감정 범주의 문제** — "화남"이 어디서 끝나고 "짜증"이 어디서 시작하는가, 범주의 임의성
- **감정 연구의 방법론** — 자기 보고·생리 측정·신경영상·표정 부호화가 각각 무엇을 측정하는가

### Chapter 2: 기본 감정 vs 구성된 감정 (5개 문서)
- **에크만의 기본 감정** — 6(7)가지 기본 감정, 표정의 보편성 주장, 파푸아뉴기니 실험
- **기본 감정 이론의 증거** — 보편 표정·신생아 감정·맹인 선수의 자발 표정
- **Barrett의 구성된 감정 이론** — 감정은 뇌가 신체 상태에 개념을 붙여 구성한다, 핵심 정동(valence·arousal)
- **기본 감정의 신경 증거 실패** — 편도체 = 공포 공식이 왜 틀렸는가, 메타분석 결과
- **두 이론의 현황** — 어떤 현상이 어느 이론을 지지하는가, 통합 가능성

### Chapter 3: 체성표지와 결정 (5개 문서)
- **아이오와 도박 과제** — 정상인은 학습 전에 좋은 패를 "느낀다", VMF 손상자는 못 느낀다
- **체성표지 가설** — 신체 상태가 결정 옵션에 표지(marker)를 붙여 선택을 안내하는 방식
- **감정 없는 결정의 실패** — 엘리엇 사례: 완벽한 논리, 망가진 생활 결정
- **체성표지의 신경 기반** — VMF·편도체·체성 감각 피질의 역할, 피부 전도 반응
- **반감정론에 대한 반박** — "감정을 배제하면 더 좋은 결정"이 왜 틀렸는가, 고점선택 효과

### Chapter 4: 내수용감각과 감정의 구성 (5개 문서)
- **내수용감각이란** — 심장·폐·내장·피부의 신호가 어떻게 뇌에 도달하는가, 내수용 경로
- **예측처리로서의 내수용감각** — 뇌가 내장 상태를 예측하고 오차를 조정하는 방식
- **심박수와 감정 경험** — "심장이 빠른지 느린지"를 아는 정도(내수용 정확도)가 감정 강도와 상관
- **신체 피드백 이론의 부활** — 얼굴 피드백·신체 자세가 감정 경험에 미치는 효과(논쟁 포함)
- **내수용과 감정 조절** — 내수용 신호를 잘 느끼는 것이 감정 조절에 어떻게 도움이 되는가

### Chapter 5: 감정의 신경 기반 (4개 문서)

- **뇌섬엽과 내수용** — 뇌섬엽이 신체 신호를 어떻게 통합하고 감정에 기여하는가
- **보상 회로와 쾌락** — 도파민이 욕구(wanting)와 좋아함(liking)을 어떻게 분리하는가

### Chapter 6: 동기 — 감정에서 행동으로 (5개 문서)

1. **체성표지를 중심으로** — 감정이 결정을 "방해"하는 것이 아니라 "가능하게" 한다는 역전을 핵심 주장으로. 다마지오의 증거가 가장 강력한 반직관
2. **기본 감정 vs 구성된 감정을 공정하게** — 어느 쪽도 완전히 승리하지 않았다. 두 이론이 각각 어떤 현상을 더 잘 설명하는지를 정직하게
3. **내수용감각을 과소평가하지 않는다** — 피부 전도·심박·내장이 감정에 어떻게 기여하는지가 최근 연구에서 얼마나 중요해졌는지를
4. **감정 조절을 규범이 아니라 알고리즘으로** — "감정을 잘 조절해야 한다"가 아니라 재평가·억제가 어떻게 다르게 작동하는지를 신경 회로로
5. **가장 날카로운 경험 간극** — 감정이 알고리즘 중에서 경험의 *내용*과 가장 직접적으로 연결된다. 그럼에도 "감정을 느끼는 것"은 왜 설명되지 않는가
6. 핵심 정동 공간·체성표지 경로·편도체 회로·내수용-예측처리 모형은 다이어그램으로

```python
import numpy as np
import matplotlib.pyplot as plt

# 1) 핵심 정동 공간 시각화
def plot_core_affect_space(emotions_data):
    """
    x축: 유인성(valence, 부정-긍정)
    y축: 각성(arousal, 낮음-높음)
    각 감정을 2D 공간에 매핑
    """
    emotions = {
        '기쁨': (0.8, 0.7), '분노': (-0.7, 0.8),
        '슬픔': (-0.6, -0.5), '공포': (-0.8, 0.6),
        '혐오': (-0.7, 0.2), '놀람': (0.1, 0.9),
        '평온': (0.4, -0.6), '지루함': (-0.3, -0.7),
    }
    fig, ax = plt.subplots(figsize=(8, 8))
    for name, (v, a) in emotions.items():
        ax.scatter(v, a, s=100)
        ax.annotate(name, (v, a), textcoords='offset points', xytext=(5, 5))
    ax.axhline(0, c='gray', lw=0.5); ax.axvline(0, c='gray', lw=0.5)
    ax.set_xlabel('유인성 (부정 ← → 긍정)'); ax.set_ylabel('각성 (낮음 ↓ ↑ 높음)')
    return fig

# 2) 아이오와 도박 과제 — 체성표지 시뮬레이션
def iowa_gambling_task(n_trials=100, somatic_marker_strength=0.5):
    """
    4개 덱: A·B(높은 보상, 높은 손실), C·D(낮은 보상, 낮은 손실)
    체성표지: 불량 덱 선택 전 피부 전도 반응 증가
    """
    deck_expected_value = {'A': -25, 'B': -25, 'C': 25, 'D': 25}
    somatic_markers = {'A': 0.0, 'B': 0.0, 'C': 0.0, 'D': 0.0}
    choices = []
    
    for trial in range(n_trials):
        # 체성표지 기반 가중 선택
        weights = {d: max(0, 1 + somatic_marker_strength * somatic_markers[d]) 
                   for d in deck_expected_value}
        total = sum(weights.values())
        probs = {d: w/total for d, w in weights.items()}
        choice = np.random.choice(list(probs.keys()), p=list(probs.values()))
        
        # 결과: 손익 → 체성표지 갱신
        ev = deck_expected_value[choice] + np.random.randn()*20
        somatic_markers[choice] += 0.1 * np.sign(ev)
        choices.append(choice)
    
    good_choices = sum(1 for c in choices if c in ['C', 'D'])
    return good_choices / n_trials, somatic_markers

# 3) 내수용감각 예측처리 모델
def interoceptive_prediction(heartbeat_signal, prior_rate=70, precision=2.0):
    """
    뇌는 심박수를 예측하고 오차를 최소화
    예측 오차 → 각성 신호 → 감정 구성 재료
    """
    predicted = prior_rate
    emotions_constructed = []
    
    for t, actual in enumerate(heartbeat_signal):
        prediction_error = actual - predicted
        # 오차가 크면 각성↑ → 감정 구성 재료
        arousal_signal = np.abs(prediction_error) * precision
        predicted += 0.1 * prediction_error  # 예측 갱신
        emotions_constructed.append(arousal_signal)
    
    return emotions_constructed

# 4) 감정 조절 — 재평가 vs 억제
def emotion_regulation_comparison(emotion_intensity, strategy='reappraisal'):
    """
    재평가: 상황 해석을 바꿈 → 감정 자체 감소, 생리 반응 감소
    억제:   표현만 억제 → 내부 각성 유지, 인지 자원 소모
    """
    if strategy == 'reappraisal':
        felt_intensity   = emotion_intensity * 0.6  # 실제 감소
        expressed        = felt_intensity * 0.9
        cognitive_cost   = 0.2  # 낮은 인지 비용
    elif strategy == 'suppression':
        felt_intensity   = emotion_intensity * 0.95  # 내부는 유지
        expressed        = emotion_intensity * 0.4   # 표현만 억제
        cognitive_cost   = 0.6  # 높은 인지 비용
    return felt_intensity, expressed, cognitive_cost
```

```
  ⇒ 감정은 이성의 장애물이 아니라 이성의 기반

기본 감정 vs 구성된 감정:
  에크만:  공포 → 공포 회로 → 공포 표정 (하향식, 범주 선행)
  Barrett: 신체 각성 + 맥락 + 감정 개념 → "공포"로 구성 (상향식)
  
  에크만 지지:
  ├─ 보편 표정 (파푸아뉴기니 고립 집단)
  └─ 맹인 선수의 자발 표정
  
  Barrett 지지:
  ├─ 편도체 = 공포 전담이 아님 (메타분석)
  └─ 감정 개념이 없으면 감정 구분 못함
  
  현황: 두 이론 모두 부분적으로 맞다 — 통합 필요

내수용감각과 감정 구성:
  심박·혈압·내장 신호 → 뇌섬엽 → 핵심 정동(각성·유인성)
       │  + 맥락 + 감정 개념
       ▼
  "감정" 경험 구성
  
  예측처리 틀:
  뇌: "지금 심박수는 80이어야 해" (예측)

  맥락(위험한 상황): 이 각성 = "공포"로 구성
  ⇒ 감정은 신체에 붙인 뇌의 레이블

  감정 알고리즘이 설명하는 것:
  ├─ 어떻게 신체 상태가 결정을 편향시키는가
  ├─ 어떻게 감정이 맥락에 따라 달리 구성되는가
  └─ 어떻게 감정 조절이 작동하는가

  ⇒ 감정의 현상적 질감 — 설명적 간극이 가장 날카로운 곳
     (감정은 의식 연구의 핵심 사례)
```
