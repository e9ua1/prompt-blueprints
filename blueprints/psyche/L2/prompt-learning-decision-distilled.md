# Learning & Decision Distilled 레포지토리 제작 프롬프트

나는 "Learning & Decision Distilled" 레포지토리를 만들려고 해.
"사람은 이성적으로 결정한다"고 가정하는 것과, **카너먼·트버스키가 체계적으로 문서화한 인지 편향들이 왜 오류가 아니라 제한된 자원 내에서의 합리적 어림법(heuristic)인지** — 그리고 언제 이 어림법이 유용하고 언제 실패하는지를 — 이해하는 것은 다르다.
강화학습을 "AI 기술"로만 아는 것과, **도파민이 TD 오차를 신호한다는 발견이 심리학의 조건화 이론과 AI 강화학습 알고리즘을 하나의 수학으로 통합한다**는 것을 — 행동주의 시대의 조건화 실험이 실제로 TD 학습의 신경 구현을 무의식중에 탐구했음을 — 이해하는 것은 다르다.
"습관 vs 의지"를 도덕의 문제로 아는 것과, **습관(모델 프리·무의식·선조체)과 목표 지향 행동(모델 기반·의식적·PFC)이 서로 다른 신경 시스템이고, 어떤 조건에서 어느 시스템이 행동을 장악하는지**를 — 그리고 중독이 왜 모델 프리 시스템의 과도한 우세인지를 — 추적하는 것은 다르다.
마음이 가치를 어떻게 계산하는지를 — 그리고 그 계산이 "선택한다는 경험"과 어떻게 연결되고 어디서 한계를 갖는지를 — 끝까지 파헤치는 레포를 만들 거야.

```python
import numpy as np
import matplotlib.pyplot as plt

# 1) TD 학습 (Q-학습)
def q_learning(env_size=5, n_episodes=500, alpha=0.1, gamma=0.9, epsilon=0.1):
    Q = np.zeros((env_size, 2))  # 상태 × 행동
    rewards_per_episode = []
    for ep in range(n_episodes):
        state = 0
        total_reward = 0
        while state < env_size - 1:
            # ε-greedy 행동 선택
            if np.random.random() < epsilon:
                action = np.random.randint(2)
            else:
                action = np.argmax(Q[state])
            # 환경 스텝
            next_state = min(state + (1 if action == 1 else -1), env_size-1)
            reward = 1.0 if next_state == env_size-1 else 0.0
            # TD 갱신
            td_error = reward + gamma*np.max(Q[next_state]) - Q[state, action]
            Q[state, action] += alpha * td_error
            state = next_state
            total_reward += reward
        rewards_per_episode.append(total_reward)
    return Q, rewards_per_episode

# 2) 쌍곡 할인 vs 지수 할인
def hyperbolic_discount(delay, k=0.1):
    return 1 / (1 + k * delay)

def exponential_discount(delay, delta=0.95):
    return delta ** delay

delays = np.linspace(0, 50, 100)
# 시간 선호 역전: 나중에 결정하면 즉각 보상 선택
# 미리 결정하면 지연 보상 선택 (사전 확약의 논거)

# 3) 손실 회피 모형 (전망 이론)
def prospect_value(x, alpha=0.88, beta=0.88, lambda_=2.25):
    """카너먼-트버스키 가치 함수"""
    if x >= 0:
        return x ** alpha
    else:
        return -lambda_ * ((-x) ** beta)

# 4) Rescorla-Wagner 모형 (파블로프)
def rescorla_wagner(trials=100, alpha_cs=0.1, alpha_us=0.1, lambda_us=1.0):
    V = 0.0  # CS의 연상 강도
    vs = []
    for t in range(trials):
        delta_v = alpha_cs * alpha_us * (lambda_us - V)  # TD 오차와 동형
        V += delta_v
        vs.append(V)
    return vs
# → 포화 곡선: V → lambda_us (최대 예측치)
# → Rescorla-Wagner = 1-스텝 TD 학습
```

  도파민:   VTA 발화 ↑ = δ > 0, VTA 발화 ↓ = δ < 0
  
  ⇒ 같은 수학, 다른 언어:
     조건화(심리학) = TD 학습(AI) = 도파민 RPE(신경과학)
  ⇒ 3분야가 170년 걸쳐 독립적으로 발견한 것이 같은 것

모델 프리 vs 모델 기반:
  모델 프리:  직접 경험 → 가치 함수, 느리게 학습, 빠르게 실행
  모델 기반:  세계 모델 → 계획 → 행동, 빠르게 학습, 느리게 실행
  
  신경 기반:
  모델 프리: 선조체 (보상→습관)
  모델 기반: PFC + 해마 (계획·유연성)
  
  습관 형성: 반복 → 모델 프리 우세 → 선조체가 행동 장악
  중독:      보상 왜곡 → 가치 함수 왜곡 → 모델 프리 과우세
  자기통제:  PFC가 선조체를 억제 → 실패 시 충동

시간 할인의 역전:
  지수 할인: r_t = δ^t R (시간 비율 일정)
  쌍곡 할인: r_t = R/(1+kt) (현재 과중치)
  
  역전: 사전에는 "나중 큰 보상" 선호
         실제 순간에는 "지금 작은 보상" 선호
  ⇒ 자기 통제 실패의 계산적 이유
  ⇒ 사전 확약(Ulysses의 계약)이 왜 효과적인가
