# Memory Distilled 레포지토리 제작 프롬프트

나는 "Memory Distilled" 레포지토리를 만들려고 해.
"기억은 과거를 저장한다"고 말하는 것과, **기억이 인출될 때마다 재구성되고, 그 재구성 과정에서 현재 맥락·기대·감정이 개입해 원본이 조금씩 바뀐다**는 것을 — 기억이 비디오 녹화가 아니라 매번 새로 쓰이는 이야기임을 — 이해하는 것은 다르다.
거짓기억을 "드문 이상 현상"으로 아는 것과, **Loftus의 실험에서 정상인들이 얼마나 쉽게 거짓기억을 형성하는지** — "차가 충돌했을 때 속도는"이 아니라 "차가 박살났을 때 속도는"으로 질문만 바꾸면 기억이 달라진다는 것을 — 그리고 이것이 법정 증언의 신뢰성에 어떤 함의를 갖는지를 — 추적하는 것은 다르다.
"망각"을 기억의 실패로 아는 것과, **망각이 간섭 감소·일반화·개인정보 보호라는 세 가지 적응적 기능을 가지며, 망각 없이는 추론이 불가능하다**는 것을 — 보르헤스의 "퓨네스"가 왜 비극인지를 — 이해하는 것은 다르다.
기억이 어떻게 알고리즘 층위에서 작동하는지를 — 그리고 "기억한다는 것"의 경험이 그 알고리즘의 어디에 해당하고 어디서 남는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "기억은 재생이 아니라 재구성이다 — 부호화·응고화·인출·망각의 알고리즘과 거짓기억의 불가피성"

**핵심 차별화**:
1. **재구성 이론을 핵심으로** — 기억이 저장-재생이 아니라 부호화-재구성임을, Bartlett·Loftus의 실증 연구로. "기억이 달라진다"가 버그가 아니라 설계
2. **기억 종류의 지도를 정밀하게** — 선언적(일화·의미)·비선언적(절차·점화·조건화)의 분류가 왜 단순한 분류가 아니라 서로 다른 신경 시스템과 다른 인출 방식을 가지는지
3. **망각을 기능으로** — 간섭 이론·망각 곡선·유익한 망각. 망각이 없으면 추론과 일반화가 불가능한 이유를 계산적으로
4. **재응고화의 치료적 함의** — 인출 후 기억이 다시 가소적이 된다는 발견이 PTSD 치료에서 어떻게 사용되고, 그 한계는 무엇인지

**타겟 독자**:
- 기억을 "저장"으로 생각하는 사람
- 자신의 기억은 정확하다고 믿는 사람
- 거짓기억이 "특이한 사람들"에게만 일어난다고 생각하는 사람
- 망각을 "나쁜 것"으로만 아는 사람
- 기억의 알고리즘과 "기억한다는 경험"이 어떻게 연결되는지 보고 싶은 사람

**선행 학습**:
- `plasticity-learning-distilled`(L1) — **필수**. 헵 가소성·LTP·엔그램의 신경 기반
- `attention-working-memory-distilled`(L2) — 작업기억이 장기기억과 어떻게 인터페이스하는가

## 🔗 레포 연결

**⬆️ 선행**: `plasticity-learning-distilled`(L1), `attention-working-memory-distilled`(L2).
**🤝 시너지 (L2 내부)**: `perception-distilled`(지각이 기억을 어떻게 채색하는가), `emotion-motivation-distilled`(감정이 기억 부호화를 어떻게 강화하는가), `learning-decision-distilled`(기억이 가치 학습에서 어떻게 사용되는가).

### Chapter 1: 기억은 재구성이다 (5개 문서)
- **Bartlett의 "유령 이야기"** — 기억이 문화적 도식에 맞게 재구성되는 첫 번째 실험적 증거
- **재구성의 알고리즘** — 인출 시 어떤 정보가 채워지고, 어떤 규칙으로 채워지는가
- **맥락 효과** — 부호화 맥락과 인출 맥락의 일치가 기억에 미치는 영향, 상태 의존 기억
- **기억의 서사 구조** — 왜 기억은 이야기 형태인가, 이야기가 기억을 어떻게 안정시키고 왜곡하는가
- **재구성과 적응** — 재구성이 왜 진화적으로 유리한가, 완벽한 재생이 오히려 나쁜 이유

### Chapter 2: 기억 종류의 지도 (5개 문서)
- **선언적 기억 — 일화와 의미** — 일화 기억(언제·어디서)과 의미 기억(사실)의 분리, 해마 의존성

- **의미 기억의 형성** — 반복된 일화 기억에서 의미 기억이 어떻게 추출되는가
- **암묵 기억과 습관** — 습관이 명시적 기억을 어떻게 압도하는가, 기저핵의 역할

### Chapter 3: 거짓기억 — 정상 현상 (6개 문서)
- **Loftus의 유도 질문 실험** — "박살났다"는 단어 하나가 기억한 속도를 어떻게 바꾸는가
- **거짓기억의 생성 메커니즘** — 원천 모니터링 오류, 상상 팽창, 관련 연상의 과잉 활성화
- **DRM 패러다임** — 연관 단어들이 없는 단어의 거짓 기억을 어떻게 만드는가
- **아동 증언의 취약성** — 왜 아동의 기억이 더 쉽게 오염되는가, 법적 함의
- **목격자 증언의 신뢰성** — 확신과 정확도의 비상관, 라인업 절차가 기억을 어떻게 오염시키는가
- **거짓기억과 자아** — 자신에 대한 거짓 기억이 자아 이해를 어떻게 바꾸는가

### Chapter 4: 망각 — 기억의 기능 (5개 문서)
- **에빙하우스 망각 곡선** — 망각의 지수적 패턴, 반복 학습의 효과
- **간섭 이론** — 유사한 기억이 서로를 방해하는 방식, 소급적·순행적 간섭
- **망각의 세 가지 기능** — 간섭 감소·일반화 지원·개인정보 보호
- **퓨네스 — 망각하지 못한다는 것** — 보르헤스의 단편이 망각의 필요성을 어떻게 드러내는가
- **망각을 설계하는 법** — 간격 반복·테스트 효과·적절한 망각을 활용하는 학습 전략

### Chapter 5: 응고화와 재응고화 (5개 문서)

```python
import numpy as np

# 1) 기억 재구성 — Hopfield 부분 완성과 오류
class HopfieldMemory:
    def __init__(self, n):
        self.n = n
        self.W = np.zeros((n, n))
    
    def store(self, patterns):
        for p in patterns:
            self.W += np.outer(p, p) / self.n
        np.fill_diagonal(self.W, 0)
    
    def recall(self, cue, n_iter=20):
        state = cue.copy()
        for _ in range(n_iter):
            state = np.sign(self.W @ state)
        return state
    
    def recall_with_noise(self, pattern, noise_level=0.2):
        noisy = pattern.copy()
        flip_idx = np.random.choice(self.n, int(self.n*noise_level), replace=False)
        noisy[flip_idx] *= -1  # 노이즈 추가
        recalled = self.recall(noisy)
        # 오류: 다른 저장된 패턴으로 수렴 = "거짓기억"
        return recalled

# 2) 에빙하우스 망각 곡선 + 간격 반복
def forgetting_curve(t, R=1.0, k=0.5):
    """R = R_0 * e^{-k*t}"""
    return R * np.exp(-k * t)

def spaced_repetition_schedule(n_reviews=5, initial_interval=1):
    """간격을 지수적으로 늘리는 최적 반복 스케줄"""
    intervals = [initial_interval * (2**i) for i in range(n_reviews)]
    return intervals

# 3) DRM 거짓기억 — 연상 확산 모델
def drm_false_memory(target_word, associates, semantic_network, threshold=0.6):
    """
    연관 단어들의 활성화가 목표 단어로 확산
    활성화 > threshold → 거짓 기억 (없는 단어를 기억한다고 보고)
    """
    activation = sum(semantic_network.get((assoc, target_word), 0) 
                     for assoc in associates)
    return activation > threshold, activation

# 4) 간섭 모델 — 유사 기억 경쟁
def interference_model(memories, test_cue, similarity_matrix):
    """
    유사한 기억끼리 인출 시 경쟁
    → 가장 유사한 기억이 승리하지만, 경쟁이 심할수록 정확도 저하
    """
    activations = [np.dot(similarity_matrix[i], test_cue) for i in range(len(memories))]
    winner = np.argmax(activations)
    competition = np.std(activations)  # 경쟁 강도
    accuracy = 1 / (1 + competition)   # 경쟁 강도 → 정확도 저하
    return winner, accuracy
```

```
  부호화: 경험 E → 선택적 주의 → 기존 도식과 통합 → 흔적 T

  인출:   단서 C → 패턴 완성 → 재구성 R (T ≠ R, 맥락이 개입)
  
  왜 R ≠ E인가:
  ├─ 인출 맥락이 재구성에 개입
  ├─ 이후 정보가 역행적으로 편집
  └─ 인출 자체가 기억을 수정 (재응고화)

거짓기억 생성 메커니즘:
  원천 모니터링 오류: "어디서 알았는가"를 잘못 귀인
  상상 팽창: 상상한 것을 경험한 것으로 혼동
  연상 과잉 활성화: DRM — "잠"과 연관된 단어들 → "잠" 거짓 기억
  
  Loftus 실험:
  "차가 (박살났을/접촉했을) 때 속도는?" → 기억한 속도 차이
  ⇒ 질문 언어 하나가 기억을 수정한다

망각의 세 기능:
  1. 간섭 감소: 유사한 기억이 쌓이면 인출 어려워짐 → 오래된 것 지우기
  2. 일반화 지원: 개별 에피소드를 지워야 규칙 추출 가능
  3. 사생활 보호: 모든 것을 기억하면 과거가 현재를 지배
  
  퓨네스(Borges): 모든 것을 기억 → 추상화·일반화 불가 → 사고 마비
  ⇒ 망각 없이는 지능이 없다
```
