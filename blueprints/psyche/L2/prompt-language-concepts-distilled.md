# Language & Concepts Distilled 레포지토리 제작 프롬프트

나는 "Language & Concepts Distilled" 레포지토리를 만들려고 해.
"언어는 생각을 표현하는 도구다"고 말하는 것과, **언어가 생각을 표현할 뿐 아니라 생각의 구조 자체를 형성한다는 주장이 어떤 실험적 증거를 가지며 어디서 한계를 갖는지** — 사피어-워프 가설의 약한 버전이 어떻게 현대 실험으로 부분적으로 지지되고 부분적으로 반박됐는지를 — 이해하는 것은 다르다.
"개념을 안다"고 말하는 것과, **개념이 뇌에 어떻게 저장되는지** — 개념이 기호적 정의인가, 원형(prototype)인가, 시뮬레이션인가, 행동 잠재성인가 — 네 이론이 각각 어떤 현상을 설명하고 어떤 실험에 부딪히는지를 — 추적하는 것은 다르다.
LLM이 "언어를 이해한다"는 말과 "통계적으로 패턴을 생성한다"는 말의 차이가 왜 단순한 표현 차이가 아니라 **이해(understanding)의 본성에 관한 심층 질문**인지를 — 그리고 그 질문이 중국어 방 논변·의미론·인간 언어 처리와 어떻게 연결되는지를 — 아는 것은 다르다.
언어와 개념이 마음의 알고리즘 층위에서 어떻게 작동하는지를 — 그리고 언어가 경험에 어떻게 영향 미치고 경험이 언어에 어떻게 저항하는지를 — 끝까지 파헤치는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "언어는 사고를 가두는가, 해방하는가 — 개념·범주·합성성·언어 상대성의 정밀한 해부"

**핵심 차별화**:
1. **사피어-워프를 현대적으로** — "언어가 사고를 결정한다"(강한 버전, 폐기)와 "언어가 사고에 영향 미친다"(약한 버전, 증거 있음)를 분리. 구체적 실험 사례(색채 지각·공간 인지·시제)로
2. **개념 이론의 대결** — 고전적 정의론·원형 이론·이론 이론·체화 인지의 개념 시뮬레이션이 각각 어떤 현상을 설명하고 어떤 반례에 부딪히는지를
3. **합성성과 그 한계** — "빨간 사과"가 "빨간"+"사과"에서 합성되는 방식, 그리고 "죽은 은유"·"사기꾼 탐지기"처럼 합성성이 깨지는 경우
4. **LLM vs 인간 언어 처리** — AI Lab과의 가장 직접적 교차. LLM이 통계 패턴에서 의미론을 학습하는가, 아닌가의 논쟁을 구체적 실험으로

**타겟 독자**:
- 언어를 "생각의 표현"으로만 아는 사람
- 사피어-워프를 "틀린 이론"으로 아는 사람 (약한 버전은 부분적으로 맞다)
- "개념을 안다"는 것이 뇌에서 어떤 상태인지 모르는 사람
- LLM이 "언어를 이해하는지"에 대한 입장을 가지고 싶은 사람
- 언어와 경험의 관계가 철학적으로 어디서 열려있는지 보고 싶은 사람

**선행 학습**:
- `computation-representation-distilled`(L0) — **필수**. 기호 표상·분산 표상·지향성
- `memory-distilled`(L2) — 의미 기억이 어떻게 저장되는가

### Chapter 1: 언어와 사고의 관계 (5개 문서)
- **언어 없는 사고가 가능한가** — 농인(수어)·선천적 청각장애인·비언어적 문제해결의 사례
- **사피어-워프 가설의 역사** — 강한 버전(언어 결정론)의 등장과 폐기, 약한 버전의 부활
- **약한 워프 가설의 증거** — 색채 범주가 색 지각을 어떻게 바꾸는가(러시아어 파란색 실험)
- **약한 워프 가설의 한계** — 어디서 언어 효과가 사라지는가, 어림법의 공유
- **언어와 사고의 상호 의존** — 언어가 사고를 형성하고 사고가 언어를 형성하는 쌍방향

### Chapter 2: 개념이란 무엇인가 (6개 문서)
- **고전적 정의론** — 필요충분조건으로서의 개념, Wittgenstein의 비판("게임"을 정의하라)
- **원형 이론(Rosch)** — 원형과 가족 유사성, 닭 vs 독수리: 새의 원형은 무엇인가
- **이론 이론** — 개념은 암묵적 이론, 어린이가 "심장"을 왜 펌프로 이해하는가
- **체화 인지와 개념 시뮬레이션** — 개념이 감각운동 시뮬레이션, "사과"를 생각하면 운동 피질 활성화
- **신경망의 개념 표상** — 분산 표상·활성화 패턴, Word2Vec의 왕-남자+여자≈여왕
- **개념의 통합과 수정** — 새 경험이 기존 개념을 어떻게 수정하는가, 개념 학습의 알고리즘

### Chapter 3: 언어의 구조 — 합성성과 그 한계 (5개 문서)
- **합성성 원리** — 전체의 의미가 부분의 의미와 결합 방식에서 나온다, Frege
- **합성성의 작동** — 구문론이 의미론을 어떻게 조합하는가, 최소주의 통사론 입문
- **합성성의 한계** — 관용구·은유·함축, "식은 죽 먹기"는 합성적인가
- **은유와 개념** — 개념적 은유 이론(Lakoff), 추상 개념이 어떻게 구체적 은유에 기반하는가
- **화용론** — 말하는 것 이상을 전달하는 방식, Grice의 협력 원칙·함축

### Chapter 4: 언어 처리의 신경 기반 (5개 문서)
- **브로카·베르니케를 넘어서** — 언어의 분산 처리 네트워크, 이중 경로 모형
- **예측 처리와 언어** — 다음 단어를 예측하는 뇌, N400 ERP의 의미 위반 반응
- **통사론 처리** — 문장 구조 분석의 신경 기반, 정원길 문장(garden-path)
- **언어와 사고의 신경 분리** — 언어 네트워크와 다중 요구 네트워크의 해리
- **이중언어와 뇌** — 두 언어가 같은 공간을 쓰는가, 언어 전환의 신경 비용

### Chapter 5: LLM vs 인간 언어 처리 (5개 문서)
- **LLM이 하는 것** — 통계적 패턴 학습·다음 토큰 예측·컨텍스트 기반 생성
- **LLM이 이해하는가** — 의미론적 이해 vs 통계적 패턴 매칭의 실험적 구분 시도
- **벤치마크의 한계** — 언어 과제 성능이 이해의 증거인가, 오버피팅·데이터 오염
- **뇌와 LLM의 표상 비교** — RSA(표상 유사성 분석)로 두 시스템의 내부 표상 비교
- **LLM의 심리언어학** — LLM이 어린이와 같은 순서로 개념을 학습하는가, 뇌 유사성 점수

### Chapter 6: 언어, 범주, 경험 (4개 문서)
- **범주화가 경험을 만드는가** — 분노 vs 슬픔: 언어 범주가 감정 경험을 어떻게 형성하는가(→ emotion)
- **언어 없는 경험** — 명상·선선험(프리버벌) 경험, 언어로 잡히지 않는 경험이 있는가
- **언어와 기억의 공모** — 경험을 언어로 재구성할 때 무엇이 보존되고 무엇이 사라지는가
- **말할 수 없는 것** — 비트겐슈타인의 "언어의 한계가 세계의 한계", 경험의 언어 초과

### Chapter 7: 종합·계산 (3개 문서)
- **Word2Vec로 개념 공간 탐색** — 의미 산술·범주 구조·문화 비교(Python)
- **언어 상대성 실험 시뮬레이션** — 색채 범주가 변별 과제에 미치는 효과 모델(Python)
- **종합** — "언어가 사고에 어떻게 영향 미치고, 경험이 언어에 어떻게 저항하는가"

## 🎨 스타일 가이드

1. **사피어-워프를 공정하게** — 강한 버전은 폐기됐지만 약한 버전은 살아있다. 각 버전이 어떤 증거를 가지는지를 분리해서
2. **개념 이론들을 대결로** — 어느 이론이 "맞다"가 아니라 각 이론이 어떤 현상을 잘 설명하고 어떤 반례에 부딪히는지
3. **LLM 논쟁을 공정하게** — "LLM은 이해한다"와 "LLM은 패턴 매칭이다" 사이에서, 실험적 증거와 개념적 구분을 사용해 공정하게
4. **체화 언어학을 진지하게** — 추상 개념이 구체적 경험에 기반한다는 주장의 신경 증거를 소홀히 하지 않는다
5. **경험이 언어에 저항하는 곳을** — 언어로 완전히 포착되지 않는 경험의 측면을 정직하게 표시
6. 개념 공간·합성성 트리·언어-뇌 네트워크·LLM vs 뇌 RSA는 다이어그램으로

# 1) Word2Vec 개념 공간 탐색
from gensim.models import Word2Vec
import numpy as np

# 의미 산술
def semantic_arithmetic(model, word1, word2, word3):
    """word1 - word2 + word3 ≈ ?"""
    vector = model.wv[word1] - model.wv[word2] + model.wv[word3]
    return model.wv.most_similar([vector], topn=3)

# 범주 구조 시각화
from sklearn.decomposition import PCA
def visualize_concept_space(model, words):
    vectors = np.array([model.wv[w] for w in words])
    pca = PCA(n_components=2)
    coords = pca.fit_transform(vectors)
    return coords  # 범주별 군집화 확인

# 2) 언어 상대성 실험 시뮬레이션
def color_discrimination_task(target_rgb, distractor_rgb, category_boundary):
    """
    같은 범주 내 색 vs 범주 경계를 가로지르는 색
    언어 범주가 있으면: 경계 가로지르기 더 쉽게 변별
    오른 시야(좌뇌, 언어 반구)에서 효과 더 강함
    """
    same_category = abs(target_rgb - category_boundary) < 20 and \
                    abs(distractor_rgb - category_boundary) < 20
    cross_category = (target_rgb < category_boundary) != (distractor_rgb < category_boundary)
    discrimination_advantage = 0.15 if cross_category else 0.0
    return discrimination_advantage

# 3) N400 시뮬레이션 (의미 위반)
def n400_model(sentence, target_word, semantic_context):
    """
    의미적 예측성이 낮을수록 N400 진폭 증가
    "나는 피자를 먹었다" → 정상 (낮은 N400)
    "나는 피자를 읽었다" → 위반 (높은 N400)
    """
    predictability = semantic_context.get(target_word, 0.0)
    n400_amplitude = -5 * (1 - predictability)  # mV
    return n400_amplitude

# 4) 표상 유사성 분석 (LLM vs 뇌)
def rsa_comparison(brain_rdm, llm_rdm):
    """
    brain_rdm: 뇌 fMRI 활성화 패턴 간 비유사성 행렬
    llm_rdm: LLM 내부 표상 간 비유사성 행렬
    Spearman 상관 → 두 시스템의 표상 구조 유사성
    """
    from scipy.stats import spearmanr
    # 상삼각 행렬 벡터로 변환
    n = brain_rdm.shape[0]
    idx = np.triu_indices(n, k=1)
    r, p = spearmanr(brain_rdm[idx], llm_rdm[idx])
    return r, p
```

       │  반증: 농인도 시간·수·공간 개념 보유
  
  약한 워프 (부분 지지): 언어가 지각·기억·판단에 영향
       │  지지: 러시아어 파랑 2색소어 → 명도 구분 더 빠름
       │  지지: 공간 언어 차이 → 공간 기억 차이
       │  한계: 뇌 반구, 언어적 간섭 있을 때만 효과

개념 이론의 대결:
  고전론:    필요충분조건 (새 = 깃털 있고, 날개 있고, ...)
             반례: 박쥐 새인가? 타조의 날 수 없음
  원형론:    원형과 유사성 (참새 = 좋은 새, 펭귄 = 나쁜 새)
             반례: "사기꾼 탐지기" 범주는 원형 없음
  이론론:    암묵적 이론으로 묶임 (무게는 왜 중요한가)
             반례: 이론을 어떻게 표상하는가
  시뮬레이션: 감각운동으로 재활성화 (사과 생각 → 쥐는 동작)
             반례: 추상 개념 (정의·자유는 어떻게 시뮬레이션?)

LLM의 "이해" 논쟁:
  지지 증거:
  ├─ 문맥에 따른 의미 변별 가능
  ├─ 유추 과제 성능 (왕:여왕 = 남자:?)
  └─ 뇌 언어 네트워크와 표상 유사성 (RSA)
  
  반론:
  ├─ 형태 vs 의미 혼동 가능 (clever Hans)
  ├─ 분포 외 일반화 실패
  └─ 지향성 결여 (중국어 방)
  ⇒ 결론: 아직 열려있다 — 판단 보류가 정직한 입장
```
