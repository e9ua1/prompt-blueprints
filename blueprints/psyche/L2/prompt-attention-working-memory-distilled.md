# Attention & Working Memory Distilled 레포지토리 제작 프롬프트

나는 "Attention & Working Memory Distilled" 레포지토리를 만들려고 해.
"주의를 기울인다"고 말하는 것과, **주의가 단일 자원이 아니라 서로 독립적으로 작동하는 여러 시스템의 집합**이고, 공간 주의·특징 주의·객체 기반 주의가 각각 다른 신경 기반을 가지며 서로 다른 실험으로만 분리된다는 것을 — 이해하는 것은 다르다.
"작업기억 용량은 7±2이다"라고 외우는 것과, **7±2가 의미 있는 덩어리(chunk)의 수이지 원자적 항목의 수가 아니고**, 코완의 수정된 추정치가 왜 4±1에 가깝고, 작업기억이 단기 기억과 어떻게 다른 시스템인지를 — 그리고 용량 한계가 왜 계산적 이유를 가지는지를 — 이해하는 것은 다르다.
"부주의 맹시"를 "집중하면 다른 걸 못 본다"는 말로 아는 것과, **보이지 않는 고릴라 실험이 어떤 신경 메커니즘으로 설명되고, 부주의 맹시가 왜 주의 결여가 아니라 표상의 실패인지**를 — 그리고 그것이 의식과 주의의 관계에 대해 무엇을 시사하는지를 — 추적하는 것은 다르다.
주의와 작업기억이 어떻게 계산 자원의 할당 문제를 해결하는지를 — 그리고 그 해결 방식이 경험의 "현재 순간"과 어떻게 연결되고 어디서 한계를 갖는지를 — 끝까지 파헤치는 레포를 만들 거야.

**핵심 차별화**:
1. **주의의 다원성** — 주의를 단일 자원으로 보는 직관을 교정. 공간·특징·객체·시간 기반 주의가 각각 어떤 신경 시스템을 쓰고 어떤 실험으로 분리되는지
2. **작업기억 용량의 계산적 이유** — 왜 4±1인가, 정보이론적 관점에서 용량 한계가 왜 적응적인지, 청킹이 용량 한계를 어떻게 극복하는지
3. **부주의 맹시와 변화 맹시** — 두 현상이 어떻게 다르고, 각각이 주의-의식 관계에 대해 어떤 다른 시사점을 주는지
4. **주의와 의식의 해리** — 주의 없이 의식이 있을 수 있는가, 의식 없이 주의가 있을 수 있는가 — Koch & Tsuchiya의 논쟁을 중심으로

## 🔬 검증 프로토콜

```python
import numpy as np
import matplotlib.pyplot as plt

# 1) 현저성 지도
def salience_map(image, color_weight=1.0, orientation_weight=1.0, intensity_weight=1.0):
    from scipy.ndimage import sobel, gaussian_filter
    # 강도 현저성: 중심-주변 차이
    intensity = gaussian_filter(image.mean(axis=2), 2) - gaussian_filter(image.mean(axis=2), 10)
    # 방위각 현저성: 소벨 필터
    edges = np.hypot(sobel(image.mean(axis=2), axis=0), sobel(image.mean(axis=2), axis=1))
    salience = intensity_weight*np.abs(intensity) + orientation_weight*edges
    return salience / salience.max()

# 2) 작업기억 용량 — 청킹 효과
def chunking_simulation(n_items, chunk_size, wm_capacity=4):
    n_chunks = np.ceil(n_items / chunk_size)
    can_hold = wm_capacity * chunk_size  # 청킹 후 실효 용량
    return min(n_items, can_hold), n_chunks <= wm_capacity

# 3) 주의의 깜박임 (Attentional Blink)
def attentional_blink_model(lag, T1_strength=1.0, inhibition_duration=300):
    """T1 처리 후 억제 기간 동안 T2 탐지 저하"""
    if lag < inhibition_duration:
        t2_detection = 1 - np.exp(-lag / 100) * T1_strength
    else:
        t2_detection = 0.9
    return t2_detection

lags = np.arange(0, 800, 100)  # ms
detection_rates = [attentional_blink_model(l) for l in lags]
# → 100-400ms 구간에서 T2 탐지율 저하 (AB 효과)

# 4) 신호탐지이론으로 주의 효과 분리
from scipy.stats import norm
def attention_sdt(hits_attended, fa_attended, hits_unattended, fa_unattended, n=100):
    d_attended   = norm.ppf(hits_attended/n) - norm.ppf(fa_attended/n)
    d_unattended = norm.ppf(hits_unattended/n) - norm.ppf(fa_unattended/n)
    # 주의가 d'를 높이는가 (민감도), criterion을 낮추는가 (편향)
    return d_attended, d_unattended
```

```
  ├─ 갱신 속도 (항목 교체 비용)
  └─ 통합 용이성 (4항목은 한 번에 통합 가능)

주의-의식 해리:
  주의 O, 의식 X: 무의식적 주의 포획 (위협 자극)
  주의 X, 의식 O: 주변 시야의 경험, 주의 없는 풍부함
  
  함의:
  → 주의가 의식의 필요조건도 충분조건도 아닐 수 있다
  → GWT vs IIT의 예측 차이 (→ L4)
  ⇒ 의식과 주의는 겹치지만 같지 않다
```
