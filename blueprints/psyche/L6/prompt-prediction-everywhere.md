# Prediction Everywhere 레포지토리 제작 프롬프트

나는 "Prediction Everywhere" 레포지토리를 만들려고 해.
이 레포는 Psyche Lab의 L6 Synthesis 레포다 — **예측(prediction)이라는 하나의 원리가 뇌간·신경 부호·지각·보상·언어·의식·행위·자유에너지에서 어떻게 반복해서 나타나는지를 횡단적으로 회수**하는 곳이다.

도파민이 "보상예측오차"를 신호하고, 지각이 "세계에 대한 예측을 검증"하며, 언어 모델이 "다음 토큰을 예측"하고, 자유에너지 원리가 "놀라움을 최소화"할 때 — 이 네 "예측"이 같은 원리의 다른 표현인가, 아니면 단지 같은 단어를 공유하는 것인가를 끝까지 추적하는 레포다.

## 📋 프로젝트 목표

**컨셉**: "하나의 추론 원리가 마음 전체를 관통한다 — 도파민 RPE·예측 지각·자유에너지·능동 추론이 하나인가"

**횡단하는 축**:
- **L0** `information-prediction-distilled` — 베이즈 추론·자유에너지·예측처리의 수학적 기반
- **L1** `neuromodulation-arousal-distilled` — 도파민 RPE = TD 오차, 가장 구체적인 예측 오차 신호
- **L1** `neurons-neural-codes-distilled` — 예측 부호화, 하향 예측과 상향 오차의 신경 구현
- **L2** `perception-distilled` — 지각 = 예측 검증, 착시 = 강한 사전확률의 승리
- **L2** `learning-decision-distilled` — 강화학습 = TD 학습, 파블로프 조건화 = 예측 갱신
- **L4** `theories-of-consciousness-distilled` — 예측처리 의식 이론, 자유에너지와 의식 수준
- **L5** `free-will-agency-distilled` — 능동 추론 = 행동으로 예측을 실현하기
- **IQ AI Lab 직결** — LLM의 다음 토큰 예측, RL의 TD 학습, 모델 기반 계획

**핵심 차별화**:
1. **예측의 세 수준을 구분** — 신호 예측(도파민 RPE)·상태 예측(지각 모델)·정책 예측(능동 추론)이 어떻게 다르고 어떻게 연결되는가
2. **자유에너지 원리를 중심으로** — 카를 프리스턴의 통일 이론이 도파민·지각·행동·의식을 어떻게 하나의 수학으로 연결하는지, 그 야망과 한계를
3. **TD 학습의 세 분야 통합** — 파블로프 조건화(심리학)·TD 학습(AI)·도파민 RPE(신경과학)가 같은 수학임을 Synthesis 수준에서 최종 정리
4. **예측이 경험과 만나는 지점** — 예측처리가 의식의 *내용*을 설명하지만 *있다는 것*은 설명하지 못하는 지점을 Synthesis 수준에서 정직하게

## 🎯 전체 구조 설계

6개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 예측의 세 수준 (4개 문서)
- **신호 예측** — 도파민 RPE: "기대한 것이 왔는가", 가장 구체적 예측 오차 신호
- **상태 예측** — 지각 모델: "세계가 어떤 상태인가", 베이즈 갱신
- **정책 예측** — 능동 추론: "내 행동이 어떤 결과를 낳는가", 자유에너지 최소화
- **세 수준의 통합** — 자유에너지 원리가 어떻게 세 수준을 하나로 묶는가, 그 한계

### Chapter 2: 도파민 RPE — 예측 원리의 가장 구체적 형태 (4개 문서)
- **TD 학습의 세 언어** — 파블로프(심리학)·도파민(신경과학)·TD 오차(AI), 동일한 수학의 세 번역
- **RPE의 계층적 구조** — 단순 RPE에서 복잡한 모델 기반 예측까지
- **도파민이 예측 이외에 신호하는 것** — RPE가 전부가 아닌 이유, 도파민의 다른 역할
- **RPE에서 자유에너지로** — 보상 예측이 어떻게 더 일반적인 자유에너지 원리의 특수 사례인가

### Chapter 3: 지각·언어·기억의 예측 구조 (5개 문서)
- **지각 = 예측 검증** — 하향 예측과 상향 오차, 착시 = 강한 사전확률의 승리(→ perception)
- **기억 = 예측적 재구성** — 인출이 예측적 완성인 이유, 거짓기억 = 예측 편향(→ memory)
- **언어 = 예측 기계** — 다음 단어 예측이 언어 이해와 어떻게 같고 다른가
- **주의 = 정밀 가중치** — 주의가 어떤 예측에 더 높은 정밀도를 할당하는가(→ attention)
- **감정 = 내수용 예측 오차** — 내장 상태 예측이 어떻게 감정 경험을 구성하는가(→ emotion)

### Chapter 4: 능동 추론 — 예측으로서의 행동 (4개 문서)
- **능동 추론의 핵심** — 지각(세계를 예측에 맞추기) vs 행동(세계를 예측에 맞게 바꾸기)의 통일
- **자유에너지 원리의 야망** — 생명·지각·행동·학습·사회가 자유에너지 최소화의 특수 사례인가
- **능동 추론과 행위주체성** — 예측이 행동을 일으킬 때 자유의지와 어떻게 연결되는가
- **자유에너지의 한계** — 통일 이론의 과대포장과 실질적 기여 사이의 정직한 평가

### Chapter 5: 예측처리 의식 이론과 그 한계 (4개 문서)
- **예측처리가 설명하는 의식 내용** — 어떤 예측 오차가 의식적 경험에 기여하는가
- **자유에너지와 의식 수준** — 각성·수면·마취에서 자유에너지 최소화가 어떻게 달라지는가
- **예측처리가 설명하지 못하는 것** — 어려운 문제에 대한 예측처리의 응답과 그 한계
- **AI의 예측과 경험** — LLM이 다음 토큰을 예측한다는 것이 의식과 어떻게 관계하는가

### Chapter 6: 횡단 종합 — 예측 원리의 회수 (3개 문서)
- **예측 원리의 전체 지도** — L0~L5에서 예측이 어떻게 변주되는지의 최종 지도
- **예측이 경험과 만나는 지점** — 예측처리가 경험의 *내용*을 설명하고 *있다는 것*은 설명하지 못하는 간극
- **Prediction Everywhere의 종합** — 하나의 추론 원리가 마음 전체를 관통한다, 그리고 관통하지 못하는 곳

## 🔬 검증 프로토콜

```python
import numpy as np

# 1) TD 학습 = 도파민 RPE = 파블로프의 통일
def unified_prediction_error(expected, actual, learning_rate=0.1):
    """
    세 분야의 공통 수학:
    Rescorla-Wagner: ΔV = α(λ - V)
    TD 오차:         δ = r + γV(s') - V(s)
    도파민 RPE:      발화율 ∝ δ
    """
    prediction_error = actual - expected          # δ = 실제 - 예측
    updated_expectation = expected + learning_rate * prediction_error
    return prediction_error, updated_expectation

# 2) 자유에너지 계산
def free_energy(observation, prior_mean, prior_precision,
                likelihood_precision):
    """
    F = -ln P(o) ≈ 정확도 항 + 복잡성 항
    지각: F 최소화 → 베이즈 갱신
    행동: F 최소화 → 세계를 바꿔 예측에 맞춤
    """
    # 변분 추론으로 근사
    posterior_precision = prior_precision + likelihood_precision
    posterior_mean      = (prior_precision * prior_mean +
                           likelihood_precision * observation) / posterior_precision
    
    # 자유에너지 = KL 발산 - 로그 가능도
    kl_term      = 0.5 * (posterior_precision / prior_precision - 1
                          - np.log(posterior_precision / prior_precision)
                          + prior_precision * (posterior_mean - prior_mean)**2)
    accuracy_term = -0.5 * likelihood_precision * (observation - posterior_mean)**2
    
    F = kl_term - accuracy_term
    return F, posterior_mean

# 3) 능동 추론 시뮬레이션
def active_inference_step(world_state, preferred_state,
                           prior_beliefs, precision=1.0):
    """
    지각: 믿음을 갱신해 세계를 설명
    행동: 세계를 바꿔 예측(선호 상태)에 맞춤
    """
    # 예측 오차
    prediction_error = world_state - prior_beliefs
    
    # 지각: 믿음 갱신
    updated_beliefs = prior_beliefs + precision * prediction_error
    
    # 행동: 자유에너지 최소화 → 선호 상태로 이동
    action = precision * (preferred_state - world_state)
    
    return updated_beliefs, action

# 4) 예측처리 착시 모델
def illusion_as_strong_prior(sensory_signal, scene_prior, prior_strength=2.0):
    """
    착시 = 강한 사전확률이 약한 감각 신호를 압도
    → 예측처리의 지각에 대한 직접적 시연
    """
    likelihood_strength = 1.0  # 감각 신호의 강도
    posterior = (prior_strength * scene_prior + likelihood_strength * sensory_signal) / \
                (prior_strength + likelihood_strength)
    
    # 감각이 실제와 달라도 사전확률이 이기면 "착시" 발생
    illusory_percept = posterior
    actual_scene     = sensory_signal
    illusion_magnitude = abs(illusory_percept - actual_scene)
    
    return illusory_percept, illusion_magnitude
```

## 💡 핵심 분석 대상

```
예측 원리의 층위별 변주:

  L0 수학:     P(H|E) ∝ P(E|H) × P(H)
              베이즈 갱신 = 예측 오차로 믿음 갱신
       ↕ 변주
  L1 신경:     도파민 δ = R + γV(s') - V(s)
              TD 오차 = 예측 오차의 신경 신호
       ↕ 변주
  L2 지각:     지각 = argmax P(세계|감각)
              감각 → 가설 검증 → 예측 갱신
       ↕ 변주
  L2 학습:     ΔV = α(λ - V)  [파블로프 = TD]
              경험 → 가치 예측 갱신
       ↕ 변주
  L5 행동:     행동 = 자유에너지 최소화
              세계를 예측(선호)에 맞게 바꾸기

  공통 핵심: δ = 실제 - 예측
            → 믿음/가치/행동을 갱신

  AI와의 연결:
  LLM: 다음 토큰 예측 = 조건부 확률 최대화
  RL:  TD 오차 = 도파민 RPE와 동일한 수학
  
  남는 간극:
  예측 오차가 아무리 정밀해도
  "놀라움이 느껴진다"는 것은 남는다
```
