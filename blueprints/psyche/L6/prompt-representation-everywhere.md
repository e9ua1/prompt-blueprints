# Representation Everywhere 레포지토리 제작 프롬프트

나는 "Representation Everywhere" 레포지토리를 만들려고 해.
이 레포는 Psyche Lab의 L6 Synthesis 레포다 — 개별 레이어의 심화가 아니라, **표상(representation)이라는 하나의 원리가 신경·인지·의식·자아·AI에서 어떻게 반복해서 나타나는지를 횡단적으로 회수**하는 곳이다.

L1의 신경 부호가 "자극을 표상한다"고 말할 때, L2의 지각이 "세계의 가설을 표상한다"고 말할 때, L5의 자기모델이 "자아를 표상한다"고 말할 때 — 이 세 "표상"이 같은 것인가, 다른 것인가, 어떤 공통 구조를 공유하는가를 끝까지 추적하는 레포다.

## 📋 프로젝트 목표

**컨셉**: "물질이 무언가에 관한 것이 되는 동형성 — 신경 부호·지각 추론·자기모델·AI 표상을 하나의 원리로 회수한다"

**횡단하는 축**:
- **L0** `computation-representation-distilled` — 지향성·기호/분산 표상, 물질이 어떻게 무언가에 관한 것이 되는가
- **L1** `neurons-neural-codes-distilled` — 발화율·시간·집단 부호, 신경 수준의 표상
- **L2** `perception-distilled`, `memory-distilled`, `language-concepts-distilled` — 지각·기억·언어가 세계를 어떻게 표상하는가
- **L4** `theories-of-consciousness-distilled` — IIT의 통합 정보, GWT의 전역 방송이 표상을 어떻게 다루는가
- **L5** `self-model-distilled` — PSM(Phenomenal Self-Model), 자아를 표상하는 뇌
- **IQ AI Lab 직결** — 딥러닝의 분산 표상, LLM의 언어 표상, 인공망과 뇌의 표상 비교

**핵심 차별화**:
1. **표상의 네 층위를 구조적으로 비교** — 신경 부호(구현)·지각 모델(알고리즘)·개념/언어(계산)·자기모델(재귀) 사이의 공통 구조와 본질적 차이를 Marr의 층위로 정리
2. **지향성 문제의 횡단 회수** — L0에서 제기된 "물질이 어떻게 무언가에 관한 것이 되는가"가 각 층위에서 어떻게 다르게 나타나고, L5 자기모델에서 어떻게 재귀적 형태가 되는가
3. **AI 표상과의 수렴·발산** — RSA로 비교했을 때 뇌와 AI의 표상이 어디서 수렴하고 어디서 발산하는지를 통합적으로 기술
4. **표상에서 경험으로의 간극** — 표상이 완전히 해명돼도 *표상이 경험을 가지는 것*은 어디서 남는가

## 🎯 전체 구조 설계

6개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 표상의 공통 구조 (5개 문서)
- **표상이란 — 최소 조건** — X가 Y를 표상하려면 무엇이 필요한가: 인과·정보·기능·지향성의 조건
- **표상의 네 층위 지도** — 신경 부호(구현)·지각 모델(알고리즘)·개념/언어(계산)·자기모델(재귀)
- **지향성의 층위별 등장** — L0 원초적 지향성 → L1 파생적 표상 → L2 추론적 표상 → L5 자기지향적 표상
- **표상의 동형성** — 서로 다른 층위의 표상이 공유하는 추상적 구조, 무엇이 같고 무엇이 다른가
- **표상 없는 마음의 도전** — 체화 인지·포섭 아키텍처가 표상 개념에 제기하는 문제(→ embodied-mind L3)

### Chapter 2: 신경 표상 — 구현 층위 (4개 문서)
- **발화율·시간·집단 부호의 통일** — 세 부호 방식이 공통으로 해결하는 표상 문제
- **신경 표상의 지향성 문제** — 뉴런 발화가 *무언가에 관한 것*인 이유와 조건
- **표상 공간의 구조** — 신경 다양체·잠재 공간이 어떻게 의미론적 구조를 포착하는가
- **신경 표상에서 인지적 표상으로** — 층위 간 창발: 뉴런 집단이 어떻게 지각 대상을 표상하는가

### Chapter 3: 지각·기억·언어의 표상 — 알고리즘 층위 (5개 문서)
- **지각 표상 — 세계의 가설** — 지각이 세계에 대한 베이즈 추론임을, 이것이 어떤 표상인가
- **기억 표상 — 재구성적 표상** — 저장이 아닌 재구성으로서의 기억 표상, Hopfield 연결과 AI 어텐션의 동형성
- **개념 표상 — 원형·이론·시뮬레이션** — 세 이론이 각각 어떤 표상 구조를 제안하는가
- **언어 표상 — 합성성과 분산** — 기호 표상과 분산 표상이 언어에서 어떻게 공존하는가
- **감정과 내수용 표상** — 신체 상태의 표상이 어떻게 의미를 띠는가(→ emotion-motivation)

### Chapter 4: 자기모델 — 재귀적 표상의 정점 (4개 문서)
- **PSM(Phenomenal Self-Model)과 일반 표상의 차이** — 자아 표상이 일반 표상과 어떻게 다른가
- **표상이 자기 자신을 표상할 때** — 재귀성이 어떻게 표상 구조를 변형하는가
- **투명한 자기표상** — Metzinger의 투명성이 재귀적 표상에 어떤 특수한 결과를 낳는가
- **자기표상과 의식** — 자기모델이 의식 경험에 어떻게 기여하는가(→ theories-of-consciousness)

### Chapter 5: 뇌와 AI의 표상 비교 (4개 문서)
- **RSA로 본 수렴** — 시각 피질과 딥러닝 시각 모델, 언어 피질과 LLM이 어디서 같은 표상 구조를 학습하는가
- **유사성의 한계** — 어떤 표상 특성이 뇌에는 있고 AI에는 없는가, 그 반대는
- **표상에서 의미론으로** — 통계적 표상이 어떻게 의미론적 내용을 갖는가, 갖지 않는가(중국어 방 재방문)
- **표상 비교가 드러내는 것** — 뇌-AI 표상 비교가 표상의 본성에 대해 어떤 새로운 질문을 낳는가

### Chapter 6: 횡단 종합 — 표상에서 경험으로의 간극 (4개 문서)
- **표상의 횡단 동형성 지도** — L0~L5에서 "표상"이 어떻게 다르고 같은지의 전체 지도
- **표상이 완전해도 남는 것** — 표상의 모든 구조가 해명돼도 *표상이 경험을 가지는 것*은 어디서 남는가
- **표상과 어려운 문제의 최종 관계** — 표상 이론이 어려운 문제를 해결하는가, 더 정밀하게 위치시키는가
- **Representation Everywhere의 종합** — 물질이 무언가에 관한 것이 되는 동형성의 최종 지도

→ **총 26개 문서** 목표 (L6 Synthesis 규약: 각 챕터 4~5개, 총 26개 내외).

## 📐 문서 구조 — Principle → Boundary → Experience

L6 Synthesis 레포의 특수 섹션 구조:

```markdown
## 🎯 횡단 질문      — 이 문서가 회수하는 표상 원리가 어떤 층위들을 연결하는가
## 🌐 횡단 입력      — 어떤 L0~L5 레포에서 어떤 발견을 가져오는가
## 🔍 표면의 다양성  — 층위마다 표상이 다르게 보이는 이유
## ⚙️ 깊은 동형성   — 층위를 가로지르는 공통 구조를 추출
## 🧪 수렴 증거      — 동형성을 지지하는 실험·계산 증거
## 🌉 간극의 위치   — 표상 원리가 어디서 경험의 있다는 것에 닿지 못하는가
## 🧬 원리의 회수   — "물질이 무언가에 관한 것이 된다"가 각 층위에서 어떻게 변주되는가
## 🪞 1인칭          — 이 횡단 원리가 경험으로서 어떻게 실감되는가
## 📐 예측·반증      — 동형성 주장이 내놓는 반증 가능한 예측
## 🤔 열린 질문     — 동형성 이후에 남는 미해결

---
🧩 **Principle** — (이 층위의 표상이 어떻게 더 일반적인 표상 원리의 변주인가)
🌉 **Boundary**  — (표상 원리가 경험의 "있다는 것"을 설명하지 못하는 지점)
🪞 **Experience** — (표상이 1인칭 경험과 어떻게 연결되고 어떻게 남는가)
```

## 🎨 스타일 가이드

1. **횡단을 주인공으로** — 개별 층위의 복습이 아니다. "A층위에서 B층위로"의 연결을 항상 명시하고, 그 연결에서 새로 보이는 것을 부각
2. **동형성에서 차이를** — 비슷해 보이지만 다른 것을 정밀하게 구분. "신경 표상"과 "지각 표상"이 같은 단어를 쓰지만 어떻게 다른가를
3. **AI 표상을 적극적으로** — IQ AI Lab과의 연결이 이 레포의 가장 생산적인 교차. RSA·프로빙·표상 유사성 연구를 횡단의 실증 도구로
4. **간극을 마지막에 날카롭게** — 표상의 모든 층위를 탐구한 후, "그래도 남는 것"을 최종 챕터에서 집약
5. **L6 형식 준수** — 섹션 이름이 일반 레포와 다름 (`🌐 횡단 입력`, `⚙️ 깊은 동형성` 등). L6 규약을 지킨다

## 🔬 검증 프로토콜

```python
import numpy as np
from scipy.stats import spearmanr

# 1) 층위별 표상 구조 비교 (RSA)
def cross_layer_rsa(neural_rdm, perceptual_rdm, conceptual_rdm, self_rdm):
    """
    층위 간 표상 유사성 행렬(RDM) 비교
    → 어떤 층위쌍이 가장 유사한 구조를 가지는가
    """
    n = neural_rdm.shape[0]
    idx = np.triu_indices(n, k=1)
    
    comparisons = {}
    rdms = {
        'neural': neural_rdm,
        'perceptual': perceptual_rdm,
        'conceptual': conceptual_rdm,
        'self-model': self_rdm
    }
    
    for name1, rdm1 in rdms.items():
        for name2, rdm2 in rdms.items():
            if name1 < name2:
                r, p = spearmanr(rdm1[idx], rdm2[idx])
                comparisons[f'{name1}↔{name2}'] = (r, p)
    
    return comparisons

# 2) 지향성의 층위별 강도 측정
def intentionality_strength(representation_type):
    """
    각 층위에서 표상의 지향성 강도
    (측정 가능한 지표들로 근사)
    """
    metrics = {
        'neural_code': {
            'causal_specificity': 0.7,   # 자극-반응 특이성
            'semantic_content':  0.3,    # 의미론적 내용
            'intrinsic':         False   # 파생적
        },
        'perceptual': {
            'causal_specificity': 0.8,
            'semantic_content':  0.6,
            'intrinsic':         False
        },
        'conceptual': {
            'causal_specificity': 0.5,
            'semantic_content':  0.9,
            'intrinsic':         False   # 여전히 논쟁
        },
        'self_model': {
            'causal_specificity': 0.6,
            'semantic_content':  0.95,
            'intrinsic':         True    # 재귀적
        }
    }
    return metrics.get(representation_type, {})

# 3) AI 표상과의 동형성 계산 (CKA)
def cka_across_layers(brain_layers, ai_layers):
    """
    뇌의 각 영역과 AI 네트워크의 각 층 사이의 CKA
    → 어느 뇌 영역이 어느 AI 층과 가장 유사한 표상을 학습하는가
    """
    results = {}
    for brain_name, brain_act in brain_layers.items():
        for ai_name, ai_act in ai_layers.items():
            brain_act_c = brain_act - brain_act.mean(0)
            ai_act_c    = ai_act - ai_act.mean(0)
            hsic_ba = np.trace((brain_act_c @ brain_act_c.T) @ (ai_act_c @ ai_act_c.T))
            hsic_bb = np.trace((brain_act_c @ brain_act_c.T) @ (brain_act_c @ brain_act_c.T))
            hsic_aa = np.trace((ai_act_c @ ai_act_c.T) @ (ai_act_c @ ai_act_c.T))
            cka = hsic_ba / (np.sqrt(hsic_bb * hsic_aa) + 1e-8)
            results[f'{brain_name}↔{ai_name}'] = cka
    return results
```
