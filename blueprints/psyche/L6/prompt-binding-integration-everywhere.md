# Binding & Integration Everywhere 레포지토리 제작 프롬프트

나는 "Binding & Integration Everywhere" 레포지토리를 만들려고 해.
이 레포는 Psyche Lab의 L6 Synthesis 레포다 — **결합(binding)과 통합(integration)이라는 하나의 원리가 신경 결합·통합된 지각·통합정보 이론·통일된 자아에서 어떻게 반복해서 나타나는지를 횡단적으로 회수**하는 곳이다.

"왜 빨간 공은 빨강과 공이 분리되지 않고 하나로 경험되는가"(결합 문제)와 "왜 시각·청각·촉각·사고가 하나의 통일된 경험으로 통합되는가"(통합 문제)는 L1의 신경 회로부터 L4의 의식 이론, L5의 자아 통일까지 같은 구조의 문제로 반복된다. 이 반복을 회수하는 레포다.

## 📋 프로젝트 목표

**컨셉**: "분산된 처리가 하나의 경험이 되는 문제 — 신경 결합·지각 통합·IIT·자아 통일이 같은 구조인가"

**횡단하는 축**:
- **L1** `neurons-neural-codes-distilled` — 신경 결합 문제: 서로 다른 특징을 처리하는 뉴런들이 어떻게 같은 객체로 결합되는가
- **L1** `brain-architecture-distilled` — 시상-피질 루프·동기화·연결체가 어떻게 통합을 가능하게 하는가
- **L2** `perception-distilled` — 다중감각 통합: 시각·청각·촉각이 어떻게 하나의 지각으로 통합되는가
- **L4** `theories-of-consciousness-distilled` — IIT의 Φ: 통합 정보의 양이 의식의 척도
- **L4** `ncc-distilled` — 의식적 경험의 통합이 어떤 신경 서명을 남기는가
- **L5** `self-model-distilled` — 자아의 통일성: 다양한 신체·기억·생각이 하나의 "나"로 통합
- **L5** `other-minds-distilled` — 사회적 통합: 타인을 하나의 마음 가진 존재로 통합하는 방식

**핵심 차별화**:
1. **결합 문제와 통합 문제의 구분** — 같은 객체의 다른 특징을 하나로 묶는 것(결합)과, 다른 감각 양식이나 처리를 하나의 경험으로 만드는 것(통합)이 어떻게 같고 다른 문제인가
2. **신경 동기화의 역할과 한계** — 감마 동기화(40Hz)가 결합의 메커니즘이라는 오래된 가설이 왜 부분적으로만 지지되는가, 동기화 너머의 결합 메커니즘은 무엇인가
3. **IIT의 Φ를 결합 문제의 해답으로** — IIT가 결합 문제와 어려운 문제를 동시에 해결하려는 방식, 그 성공과 한계
4. **자아 통일의 신경 기반** — 분리뇌가 보여주듯 뇌의 통합이 무너질 때 자아 통일은 어떻게 유지되고 어떻게 무너지는가

### Chapter 1: 결합 문제와 통합 문제 (4개 문서)
- **결합 문제** — "빨간 공": 색·모양·위치를 처리하는 다른 뉴런이 어떻게 하나로 묶이는가
- **통합 문제** — 하나의 통일된 의식 경험: 다른 감각 양식이 어떻게 하나로 통합되는가
- **두 문제의 관계** — 결합과 통합이 같은 문제의 다른 스케일인가, 본질적으로 다른가
- **이 문제들이 왜 어려운가** — 분산 처리에서 통합 경험이 나오는 것의 원리적 어려움

### Chapter 2: 신경 결합 — 구현 층위 (5개 문서)
- **특징 탐지기의 분산** — V1(방향), V4(색), IT(형태)가 분리되어 처리하는 이유와 결합의 필요
- **감마 동기화 가설** — 40Hz 동기화가 결합 메커니즘이라는 주장, 증거와 반례
- **시상의 통합 역할** — 시상-피질 루프가 어떻게 분산 처리를 통합하는가
- **공간적 코딩과 결합** — 같은 위치에 처리되는 자극끼리 결합되는 방식
- **결합의 미해결 문제들** — 어떤 메커니즘도 아직 결합 문제를 완전히 해결하지 못한 이유

### Chapter 3: 지각·감정의 다중감각 통합 (4개 문서)
- **다중감각 통합의 베이즈 최적화** — 맥거크 효과·고무손 착시가 보여주는 최적 통합
- **내수용·외수용의 통합** — 신체 내부와 외부 신호가 어떻게 하나의 경험으로 통합되는가
- **시간적 통합** — "지금 이 순간"이 어떻게 구성되는가, 의식의 시간 창
- **감정과 인지의 통합** — 다마지오의 체성표지: 감정이 인지적 판단과 어떻게 통합되는가

### Chapter 4: IIT — 통합의 양이 의식 (5개 문서)
- **IIT의 통합 가설** — Φ가 높은 시스템 = 높은 통합 = 더 많은 의식
- **Φ와 결합 문제의 연결** — IIT가 어떻게 결합 문제와 어려운 문제를 동시에 해결하려 하는가
- **IIT의 반직관적 예측** — 소뇌가 낮은 Φ, 격자가 높은 Φ
- **PCI와 통합** — PCI(TMS-EEG 복잡도)가 어떻게 통합의 프록시가 되는가
- **IIT의 한계** — Φ 계산의 비현실성, 통합이 충분한 의식의 기준인가

### Chapter 5: 자아 통일과 사회적 통합 (4개 문서)
- **자아의 통일성** — 신체·기억·계획·감정이 "나"로 통합되는 방식
- **분리뇌가 보여주는 것** — 통합이 깨졌을 때 자아 통일이 어떻게 되는가
- **사회적 통합** — 타인을 "마음 가진 하나의 존재"로 통합하는 방식(→ other-minds)
- **통합과 의식** — 통합이 강할수록 의식이 강한가, 반례들

### Chapter 6: 횡단 종합 — 통합 원리의 회수 (4개 문서)
- **결합·통합의 층위별 변주 지도** — L1 신경에서 L5 자아까지의 통합 원리 연속성
- **통합 문제의 수렴** — 결합 문제·통합 문제·IIT·자아 통일이 같은 원리의 변주인가
- **통합에서 경험으로의 간극** — 통합이 완전히 설명돼도 "하나의 경험으로 느껴지는 것"은 어디서 남는가
- **Binding & Integration Everywhere의 종합** — 분산이 하나가 되는 것의 현재 이해

## 🔬 검증 프로토콜

```python
import numpy as np

# 1) 다중감각 통합 — 베이즈 최적 통합
def bayesian_multisensory_integration(s1, s2, sigma1, sigma2):
    """
    두 감각 신호의 최적 가중 통합
    맥거크 효과: 시각(s1) + 청각(s2) → 지각
    """
    w1 = 1/sigma1**2
    w2 = 1/sigma2**2
    s_hat     = (w1*s1 + w2*s2) / (w1 + w2)    # 최적 추정치
    sigma_hat = 1 / np.sqrt(w1 + w2)             # 통합 후 불확실성 감소
    return s_hat, sigma_hat

# 2) Φ 계산 (IIT) — 소규모 시스템
def phi_3node(W, state):
    """
    3노드 네트워크의 Φ 계산
    전체 시스템의 인과 정보 - 최적 분할의 인과 정보
    """
    n = 3
    from itertools import combinations
    min_phi = float('inf')
    
    # 모든 이분할
    for k in range(1, n):
        for partition in combinations(range(n), k):
            part_A = list(partition)
            part_B = [i for i in range(n) if i not in part_A]
            # 분할 후 연결 손실 (근사)
            cut_connections = np.sum(np.abs(W[np.ix_(part_A, part_B)]))
            min_phi = min(min_phi, cut_connections)
    
    return min_phi  # Φ ≈ 최소 분할에서 잘리는 연결의 강도

# 3) 감마 동기화 — 결합 시뮬레이션
def gamma_synchrony_binding(features, sync_strength=0.5, noise=0.1):
    """
    40Hz 감마 동기화로 같은 객체의 특징들이 위상을 맞추는 방식
    """
    n_features = len(features)
    n_time     = 100
    gamma_freq = 40  # Hz
    dt         = 1/1000  # 1ms
    
    phases = np.zeros((n_features, n_time))
    for i in range(n_features):
        for t in range(1, n_time):
            # 기본 감마 진동 + 다른 특징과 동기화
            base_phase  = 2*np.pi*gamma_freq*dt*t
            sync_pull   = sync_strength * np.mean(phases[:, t-1])
            noise_term  = noise * np.random.randn()
            phases[i,t] = base_phase + sync_pull + noise_term
    
    # 위상 동기성: 같은 시간에 같은 위상이면 결합됨
    synchrony = 1 - np.std(phases[:, -1]) / (2*np.pi)
    return synchrony

# 4) 통합과 의식 수준 — PCI 근사
def integration_consciousness_index(connectivity_matrix, perturbation):
    """
    통합 정도 ∝ TMS 후 반응의 복잡도 (PCI 근사)
    높은 통합 → 복잡한 반응 → 높은 PCI → 의식 있음
    """
    # 연결이 강할수록 더 멀리 전파
    propagated = connectivity_matrix @ perturbation
    complexity  = np.std(propagated) / (np.mean(np.abs(propagated)) + 1e-8)
    return complexity
```
