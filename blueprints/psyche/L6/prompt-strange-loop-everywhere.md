# The Strange Loop — Self-Reference Everywhere 레포지토리 제작 프롬프트

나는 "The Strange Loop — Self-Reference Everywhere" 레포지토리를 만들려고 해.
이 레포는 Psyche Lab의 L6 Synthesis 레포다 — **자기참조(self-reference)라는 하나의 구조가 메타인지·자기모델·자유의지·자신을 관찰하는 의식에서 어떻게 반복해서 나타나는지를 횡단적으로 회수**하는 곳이다.

Hofstadter의 "이상한 고리" — 계층 구조를 따라 올라갔을 때 출발점으로 돌아오는 자기참조 구조 — 가 마음에서 어떻게 나타나는가를 추적한다. 뇌가 자신을 표상하고(자기모델), 자신의 생각을 생각하며(메타인지), 자신의 행동을 관찰하고(행위주체감), 자신을 관찰하는 자신을 의식할 때 — 이 고리가 어떻게 형성되고, 어떻게 의식과 자아를 만드는지를 회수한다.

## 📋 프로젝트 목표

**컨셉**: "자신을 가리키는 고리 — 메타인지·자기모델·의식·자유의지에서 자기참조 구조를 횡단 회수"

**횡단하는 축**:
- **L0** `computation-representation-distilled` — 자기참조의 논리적 구조, 처치-튜링의 정지 문제
- **L2** `attention-working-memory-distilled` — 메타인지: 자신의 인지 과정을 모니터링하는 것
- **L2** `memory-distilled` — 자전적 기억이 자기참조를 통해 서사적 자아를 만드는 방식
- **L4** `hard-problem-distilled` — 자신을 경험하는 것이 어떻게 어려운 문제의 핵심에 있는가
- **L4** `altered-states-distilled` — 분리뇌: 자기참조 고리가 깨질 때
- **L5** `self-model-distilled` — PSM의 재귀적 구조: 자아를 표상하는 자아
- **L5** `free-will-agency-distilled` — 자신의 행동을 스스로 일으킨다는 자기참조

**핵심 차별화**:
1. **Hofstadter의 이상한 고리를 마음 과학으로** — *Gödel, Escher, Bach*의 자기참조 구조가 뇌과학·인지과학에서 어떻게 나타나는지를 구체적 실험과 함께
2. **메타인지의 신경 기반** — 자신의 인지 과정을 모니터링하는 것이 어떤 신경 시스템이고, 정확한 메타인지가 어떻게 훈련되는가
3. **자기참조의 역설** — 자아가 자아를 표상할 때 발생하는 논리적 구조, Metzinger의 투명성이 이 역설을 어떻게 해소하려 하는가
4. **자기참조와 어려운 문제의 연결** — 자신을 경험하는 것이 왜 어려운 문제의 가장 날카로운 형태인가

## 🎯 전체 구조 설계

### Chapter 1: 자기참조의 구조 (4개 문서)
- **이상한 고리란** — Hofstadter의 핵심 개념: 계층을 따라가면 출발점으로 돌아오는 구조
- **논리적 자기참조** — 괴델 정리·처치-튜링 정지 문제, 자기참조가 어떻게 체계의 한계를 드러내는가
- **자기참조의 역설** — "이 문장은 거짓이다"의 구조가 마음에서 어떻게 나타나는가
- **자기참조가 마음에 필요한 이유** — 자기 모니터링·자기 교정·자아 감각이 왜 자기참조를 요구하는가

### Chapter 2: 메타인지 — 생각하는 것을 생각하기 (5개 문서)
- **메타인지의 정의** — 자신의 인지 과정을 모니터링하고 제어하는 능력
- **메타인지의 신경 기반** — 전두엽·ACC·vmPFC, 메타인지와 일반 인지의 분리
- **메타인지의 정확도** — 왜 우리는 자신의 인지를 항상 정확하게 모니터링하지 못하는가
- **명상과 메타인지** — 훈련이 자기 모니터링 정확도를 어떻게 높이는가
- **메타인지와 자기참조의 고리** — 메타인지가 자기참조를 통해 어떻게 재귀적이 되는가

### Chapter 3: 자기모델의 재귀 구조 (4개 문서)
- **PSM이 재귀적인 이유** — 자아가 자아를 표상하는 것의 논리적 구조
- **투명성이 역설을 해소하는 방식** — Metzinger: PSM이 투명하기 때문에 자기참조 고리가 느껴지지 않는다
- **자기참조의 무한 후퇴** — "나는 내가 생각한다는 것을 안다"가 왜 무한히 반복될 수 있는가, 뇌가 어떻게 끊는가
- **자기모델과 이상한 고리** — Hofstadter의 구조가 PSM에서 어떻게 구현되는가

### Chapter 4: 자신을 관찰하는 의식 (4개 문서)
- **의식의 자기참조** — "나는 지금 경험하고 있다"라는 생각이 경험의 일부인 방식
- **분리뇌와 자기참조 고리의 절단** — 두 반구가 분리될 때 자기참조 고리가 어떻게 분열되는가
- **이인증 — 자기참조가 느슨해질 때** — 자아가 자아를 관찰하는 거리가 벌어지는 경험
- **자기참조와 어려운 문제** — 자신을 경험하는 것이 어려운 문제의 가장 날카로운 형태

### Chapter 5: 자유의지와 자기참조 (3개 문서)
- **자기원인(self-causation)의 역설** — 자아가 자신의 행동을 일으킨다는 것의 논리적 구조
- **행위주체감의 자기참조** — "내가 했다"는 느낌이 어떻게 자기참조적인가
- **결정론과 자기참조 고리** — 결정론적 시스템이 자기참조를 통해 어떻게 자유로운 것처럼 행동하는가

### Chapter 6: 횡단 종합 — 자기참조의 회수 (4개 문서)
- **자기참조의 층위별 변주 지도** — L0 논리에서 L5 행위주체성까지
- **이상한 고리가 만드는 것** — 자기참조가 어떻게 자아·의식·자유의지를 "만들어내는가"
- **자기참조의 한계** — 자기참조가 어디서 어려운 문제를 해결하지 못하는가
- **Strange Loop Everywhere의 종합** — 자신을 가리키는 고리의 현재 이해

## 🔬 검증 프로토콜

```python
import numpy as np

# 1) 메타인지 정확도 측정 (Type-2 감도)
def metacognitive_accuracy(d_prime, meta_d_prime):
    """
    M-ratio = meta-d'/d'
    meta-d' = 1차 감도와 같은 단위의 메타인지 효율
    M-ratio = 1: 완벽한 메타인지
    M-ratio < 1: 메타인지 부정확 (과신 또는 과소 신뢰)
    """
    m_ratio = meta_d_prime / d_prime
    return m_ratio

# 2) 자기참조 고리의 깊이
def strange_loop_depth(self_model, world_model, n_levels=3):
    """
    n_levels: 자기참조 중첩 깊이
    level 0: 세계 모델
    level 1: 자신에 대한 모델 (자기모델)
    level 2: 자신의 자기모델에 대한 모델 (메타인지)
    level 3: ...
    """
    models = [world_model]
    for i in range(n_levels):
        # 각 층위의 모델이 이전 층위를 표상
        meta_model = np.outer(models[-1], models[-1])  # 자기참조 연산
        models.append(meta_model.flatten()[:len(world_model)])
    
    # 고리: 마지막 층위가 첫 번째 층위와 얼마나 유사한가
    loop_closure = np.corrcoef(models[-1], models[0])[0, 1]
    return loop_closure, models

# 3) 이상한 고리 탐지
def detect_strange_loop(system_states, n_steps=100):
    """
    상태 공간에서 자기참조 고리 탐지
    시스템이 자신의 상태를 입력으로 받아 다음 상태를 결정할 때
    고리가 형성되는 조건
    """
    trajectory = [system_states.copy()]
    for _ in range(n_steps):
        # 다음 상태 = f(현재 상태, 자기참조)
        current  = trajectory[-1]
        next_state = np.tanh(current @ current.T @ current)  # 자기참조 연산
        trajectory.append(next_state)
        
        # 이전 상태로 돌아오는지 확인
        if len(trajectory) > 10:
            for prev in trajectory[:-5]:
                if np.allclose(next_state, prev, atol=0.01):
                    return True, len(trajectory)
    
    return False, n_steps

# 4) 자기원인 모델링
def self_causation_paradox(initial_state, self_model_accuracy=0.8):
    """
    자아가 자신의 행동을 "일으킨다"는 것의 수학적 모델
    자기참조: 행동 = f(자아 모델, 자아 모델이 예측하는 행동)
    """
    # 자아 모델의 행동 예측
    predicted_action = initial_state * self_model_accuracy
    
    # 실제 행동 = 예측된 행동을 바탕으로
    # (자기충족적 예측: 예측이 행동을 만들고, 행동이 예측을 확인)
    actual_action = predicted_action + np.random.randn() * (1 - self_model_accuracy)
    
    # 자기참조 고리: 행동이 자아 모델을 갱신
    updated_self_model = initial_state + 0.1 * (actual_action - predicted_action)
    
    return actual_action, updated_self_model
```
