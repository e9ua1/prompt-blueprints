# Altered & Edge States Distilled 레포지토리 제작 프롬프트

나는 "Altered & Edge States Distilled" 레포지토리를 만들려고 해.
"수면 중에는 의식이 없다"고 말하는 것과, **REM 수면 중 꿈은 의식의 한 형태이고, NREM 수면 중에도 수면 중 의식 보고(SDC)가 가능하며, 수면 단계별로 의식 내용과 수준이 어떻게 달라지는지** — 그리고 꿈이 의식의 구조에 대해 어떤 자연 실험을 제공하는지를 — 이해하는 것은 다르다.
환각제를 "환각을 일으키는 약물"로 아는 것과, **실로시빈·LSD·DMT가 각각 어떤 신경 수용체에 작용하고, 기본 모드 네트워크의 어떤 변화가 자아 해체(ego dissolution) 경험과 연결되며, 왜 이 상태가 의식의 구조를 이해하는 데 독특한 창문이 되는지** — 그리고 치료 효과의 신경 메커니즘이 무엇인지를 — 추적하는 것은 다르다.
분리뇌(split-brain)를 "두 반구가 분리된 것"으로 아는 것과, **Sperry-Gazzaniga 실험에서 각 반구가 서로 다른 믿음·선호·행동을 보이는데도 환자가 "나는 하나의 의식"이라고 경험하는 것이 자아 통일의 신경 기반에 대해 무엇을 시사하는지** — 그리고 이것이 "단일한 자아"가 어떻게 뇌에서 구성되는 것인지를 — 이해하는 것은 다르다.
의식이 흐트러질 때 드러나는 구조를 — 변성 상태들이 의식의 정상 상태에서 보이지 않던 것을 어떻게 드러내는지를 — 과대포장 없이 기록하는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "의식이 흐트러질 때 그 구조가 드러난다 — 수면·꿈·마취·환각제·명상·분리뇌가 의식의 경계를 어떻게 측량하는가"

**핵심 차별화**:
1. **각 변성 상태를 자연 실험으로** — 각 상태가 어떤 변수를 독립적으로 조작하는지를 명시. 수면은 자각 없이 처리가 지속됨을, 환각제는 자아 경계가 유지된 채 내용이 변함을, 분리뇌는 통합이 깨질 때 일어나는 것을 보여줌
2. **자아 해체(ego dissolution)를 현상학과 신경과학으로** — 환각제 경험의 1인칭 기술(자아와 세계의 경계 소실)이 신경과학적으로 어떻게 기술되는가(DMN 연결성 변화, 엔트로피 증가)를 연결
3. **분리뇌의 함의를 끝까지** — 두 반구가 독립적 의도와 믿음을 가질 때 "나는 누구인가"의 질문이 어떻게 날카로워지는가를. 이것이 자아 통일에 관한 어떤 이론을 지지하고 반박하는가
4. **명상을 신경과학으로** — 명상 상태가 무엇을 변화시키는가를. 기본 모드 네트워크 억제, 디폴트 자아 서사의 완화, 메타인지 능력의 향상

**타겟 독자**:
- 수면 중 의식이 없다고 단순하게 믿는 사람
- 환각제를 단순한 "환각제"로 아는 사람
- 분리뇌 실험이 함의하는 것을 모르는 사람
- 명상을 신경과학과 연결하고 싶은 사람
- 변성 상태가 의식 이론에 어떤 증거를 제공하는지 보고 싶은 사람

**선행 학습**:
- `hard-problem-distilled`(L4) — 변성 상태가 어려운 문제에 어떤 증거를 제공하는가
- `ncc-distilled`(L4) — 각 상태에서 NCC가 어떻게 변하는가
- `neuromodulation-arousal-distilled`(L1) — 각성 조절 시스템과 변성 상태의 연결

- **변성 상태와 의식 이론** — 각 상태가 GWT·IIT·HOT·PP의 예측을 어떻게 검증하는가
- **방법론** — 변성 상태 연구의 특수한 어려움(1인칭 보고의 신뢰성, 병행 신경 측정)

### Chapter 2: 수면과 꿈 (6개 문서)
- **수면 단계와 의식** — NREM N1·N2·N3와 REM에서 의식이 어떻게 다른가
- **꿈 — REM 의식** — 꿈이 왜 의식의 한 형태인가, 자각몽의 특수한 위상
- **NREM 꿈과 수면 중 의식 보고** — NREM에서도 경험이 있다는 증거
- **꿈이 의식에 대해 드러내는 것** — 외부 입력 없이 의식이 구성되는 방식
- **자각몽 — 꿈에서 의식적 통제** — 자각몽의 신경 기반, 어떻게 연구 도구가 되는가
- **수면과 기억 응고화** — 수면 중 처리가 의식 없이 일어나는 것의 의미(→ memory L2)

### Chapter 3: 마취 — 의식의 정확한 소실 (5개 문서)
- **마취 작용의 신경 메커니즘** — 어떤 경로가 어떤 순서로 억제되는가
- **의식 소실의 순간** — 마취 중 의식이 정확히 언제 꺼지는가, 측정의 어려움
- **마취 중 각성(anesthesia awareness)** — 마취됐지만 의식이 있는 상태, 그 신경 기반
- **마취와 PCI** — PCI가 마취 깊이보다 더 좋은 의식 지표인 이유(→ NCC)
- **마취 연구가 의식 이론에 제공하는 것** — 어떤 이론의 어떤 예측이 검증되는가

### Chapter 4: 환각제 — 의식 구조의 극단적 변형 (6개 문서)
- **환각제의 약리학** — 5-HT2A 수용체 작용, 어떤 신경 회로가 어떻게 변하는가
- **기본 모드 네트워크(DMN)의 변화** — 실로시빈·LSD에서 DMN 연결성 감소와 자아 해체
- **신경 엔트로피 증가** — 환각제 상태에서 뇌 활성화의 복잡도가 높아지는 현상
- **자아 해체(Ego Dissolution)** — 1인칭 현상학과 신경과학적 기술의 연결
- **환각제의 치료적 응용** — 우울증·PTSD·중독에서의 임상 연구, 왜 효과적인가
- **환각제가 의식 이론에 제공하는 것** — 자아 구성·경험 구성에 대한 증거

### Chapter 5: 명상 — 훈련된 주의와 메타인지 (5개 문서)
- **명상의 종류** — 집중 명상·마음챙김·열린 모니터링·비이원 명상의 차이
- **명상의 신경 상관물** — DMN 억제, 살리언스 네트워크 활성화, 장기 수련자의 뇌 변화
- **메타인지 능력** — 명상이 내성의 정확도를 어떻게 높이는가(→ first-person-methods L0)
- **비이원 경험** — 자아-세계 경계가 사라지는 명상 경험, 환각제 자아 해체와의 비교

```python
import numpy as np
import matplotlib.pyplot as plt

# 1) 수면 단계별 PCI 비교
def simulate_sleep_pci():
    """
    각 수면 단계에서 TMS-EEG 복잡도 (PCI 근사)
    """
    stages = {
        'Waking':      np.random.randn(100) * 0.3 + 0.65,  # 높은 복잡도
        'REM Sleep':   np.random.randn(100) * 0.3 + 0.55,  # 중간-높음
        'N2 Sleep':    np.random.randn(100) * 0.2 + 0.35,  # 낮음
        'N3 Sleep':    np.random.randn(100) * 0.15 + 0.25, # 가장 낮음
        'Anesthesia':  np.random.randn(100) * 0.1 + 0.20,  # 마취와 유사
    }
    return stages

# 2) DMN 연결성 변화 (환각제)
def dmn_connectivity_model(psilocybin_dose=0):
    """
    실로시빈 용량에 따른 DMN 연결성 변화
    용량 증가 → DMN 내부 연결 감소
            → 다른 네트워크와의 연결 증가
            → 자아 해체 경험
    """
    baseline_connectivity = np.eye(5) * 0.8  # 5개 DMN 노드
    # 실로시빈: DMN 내부 연결 감소
    dose_effect = psilocybin_dose * 0.4
    connectivity = baseline_connectivity * (1 - dose_effect)
    # 다른 네트워크로의 교차 연결 증가
    cross_network = psilocybin_dose * 0.3
    return connectivity, cross_network

# 3) 뇌 엔트로피 측정
def brain_entropy(eeg_signal, m=2, r=0.2):
    """
    샘플 엔트로피: 환각제 상태에서 높음, 마취에서 낮음
    의식 수준의 지표로 제안됨
    """
    N = len(eeg_signal)
    templates_m   = np.array([eeg_signal[i:i+m]   for i in range(N-m)])
    templates_m1  = np.array([eeg_signal[i:i+m+1] for i in range(N-m)])
    
    def count_matches(templates, r):
        n = len(templates)
        matches = 0
        for i in range(n):
            for j in range(i+1, n):
                if np.max(np.abs(templates[i] - templates[j])) < r * np.std(eeg_signal):
                    matches += 1
        return matches
    
    B = count_matches(templates_m, r)
    A = count_matches(templates_m1, r)
    
    if B == 0 or A == 0:
        return 0
    return -np.log(A / B)

# 4) 분리뇌 — 반구 독립 시뮬레이션
def split_brain_conflict():
    """
    같은 상황에서 두 반구가 다른 응답을 하는 상황 시뮬레이션
    좌반구: 언어·분석 → 합리화
    우반구: 공간·직관 → 다른 행동 선택
    """
    situations = {
        'visual_left': '공의 색이 파란색이다',  # 우반구가 처리
        'visual_right': '공의 색이 빨간색이다', # 좌반구가 처리
        'left_hand_action': '파란 공을 집는다',
        'verbal_report':    '빨간 공을 집으려고 했다',  # 좌반구의 해석기
        'interpreter_story': '파란 공이 더 예뻐서 집었다'  # 사후 합리화
    }
    return situations
    # → 같은 행동에 대해 다른 이야기를 만드는 좌반구
    # → "해석기"가 의식적 통일성을 구성하는 방식
```

```
  명상           주의 방향 훈련            메타인지·자아 감소
  분리뇌          반구 통합 제거            통합과 자아 통일의 관계

자아 해체 — 1인칭 + 신경과학:
  1인칭 경험:
  "나와 세계의 경계가 사라진다"
  "모든 것이 하나다"
  "시간이 멈추거나 무한히 늘어난다"
  
  신경과학:
  ├─ DMN 내부 연결 감소 (자아 서사 네트워크 약화)
  ├─ 네트워크 간 연결 증가 (보통 분리된 것들이 통합)
  └─ 뇌 엔트로피 증가 (더 복잡하고 다양한 상태)
  
  함의:
  → 자아 = DMN이 만드는 서사
  → 자아 해체 = 이 서사가 약화될 때
  ⇒ 자아 모델 이론(Metzinger)의 직접적 증거

분리뇌의 가장 날카로운 함의:
  실험:
  좌 시야 → 우반구: "닭발"
  우 시야 → 좌반구: "눈"
  
  행동:
  왼손(우반구 제어): 닭 삽 선택
  언어 보고(좌반구): "눈을 치우려고 삽을 선택했다"
  
  → 좌반구는 우반구의 행동을 보고 사후 이야기를 만든다
  → "해석기" = 의식적 통일성의 구성자
  
  함의:
  → 우리의 의식적 이야기가 행동의 원인이 아닐 수 있다
  → 통일된 자아는 분열된 뇌가 만들어내는 구성물
  ⇒ 자유의지·자아·통일성에 대한 가장 날카로운 자연 실험
```
