# The Hard Problem Distilled 레포지토리 제작 프롬프트

나는 "The Hard Problem Distilled" 레포지토리를 만들려고 해.
"뇌가 의식을 만든다"고 말하는 것과, **왜 뇌의 어떤 과정이 경험을 만들고, 왜 그 경험에 주관적 느낌이 따라붙는지** — 기능·정보 처리·신경 활성화를 완전히 설명한 후에도 여전히 묻게 되는 "왜 거기에 *느낌*이 있는가"라는 질문이 왜 다른 과학적 질문과 근본적으로 다른지를 — 이해하는 것은 다르다.
"좀비가 가능한가"를 SF 설정으로 아는 것과, **철학적 좀비 논변이 어떤 전제에서 어떤 결론을 이끌어내고, 그 논변이 물리주의에 어떤 정확한 압박을 가하며, 물리주의의 최선 응답이 무엇인지** — 그리고 왜 그 응답이 대부분의 철학자를 완전히 설득하지 못하는지를 — 단계별로 추적하는 것은 다르다.
"설명적 간극"을 아는 것과, **Levine이 왜 "C섬유 발화 = 고통"이 설명이 아니라 단순한 동일화인지를 — 물리적 기술과 경험적 기술 사이에 왜 설명 관계가 아니라 단순한 상관 관계만 있는지를** — 그리고 이것이 수천 년 철학의 가장 끈질긴 문제와 어떻게 연결되는지를 — 이해하는 것은 다르다.
이 연구소가 왜 존재하는지의 이유 그 자체를 — L0부터 L3까지 쌓아온 모든 메커니즘이 도달하는 가장 깊은 질문을 — 과대포장 없이, 그러나 지우지도 않고 정직하게 마주하는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "왜 정보 처리에 느낌이 따라붙는가 — 어려운 문제의 정확한 위치, 좀비 논변의 해부, 설명적 간극의 구조"

**핵심 차별화**:
1. **쉬운 문제와 어려운 문제를 칼같이 분리** — Chalmers의 구분이 단순한 용어가 아니라 어떤 설명 전략이 어떤 문제에 작동하고 어떤 문제에 작동하지 않는지를 가르는 정밀한 칼임을. 의식의 쉬운 문제들(주의·통합·보고)은 원칙적으로 메커니즘으로 설명 가능하지만, 어려운 문제는 왜 그 메커니즘이 있는 동안 *경험*이 있는가이다
2. **좀비 논변을 논문 수준으로 추적** — 전제 1(좀비는 개념적으로 가능)·전제 2(개념적 가능 → 형이상학적 가능)·결론(물리주의 거짓)의 각 단계, 각 단계에 대한 최선 반론, 그 반론에 대한 재반론
3. **설명적 간극의 구조를 해부** — 왜 "C섬유 발화 = 고통"이 "H₂O = 물"과 다른가. 후자는 설명적이지만 전자는 왜 단순한 동일화인가. 이 차이가 어디서 오는가
4. **전략들의 정직한 비용 분석** — 제거주의·환원주의·이원론·신비주의·범심론이 각각 어떤 비용을 지불하면서 어려운 문제에 응답하는지를 표로 제시

**타겟 독자**:
- "뇌가 의식을 만든다"를 완전한 설명으로 받아들이는 사람
- 좀비 논변을 "이미 논파됐다"고 아는 사람
- 설명적 간극이 무엇인지 이름만 아는 사람
- 이 연구소가 왜 7개 층위로 쌓였는지, 그 최종 이유를 알고 싶은 사람
- 의식 문제에 "과학이 발전하면 풀린다"고 믿는 사람

**선행 학습**:
- `mind-body-map-distilled`(L0) — **필수**. 지형도 전체가 이 레포로 수렴한다
- `computation-representation-distilled`·`levels-of-explanation-distilled`(L0) — 설명 층위와 지향성
- L1~L3 전체 — 각 층위의 메커니즘이 어려운 문제를 해결하지 *못한다*는 것을 직접 확인한 상태에서

## 🎯 1단계: 전체 구조 설계

다음 7개 챕터로 레포지토리를 설계해줘:

### Chapter 1: 의식이라는 문제 (5개 문서)
- **의식이 왜 문제인가** — 다른 자연 현상과 달리 의식이 제기하는 특수한 설명 요구
- **쉬운 문제들** — 주의·통합·보고·각성·수면이 왜 "쉬운" 문제인가(원칙적 해결 가능성)
- **어려운 문제** — Chalmers의 명명, 경험의 주관성이 왜 다른 설명 전략을 요구하는가
- **쉬운과 어려운의 경계** — 어디서 쉬운 문제의 설명이 끝나고 어려운 문제가 시작되는가
- **이 문제의 역사** — 데카르트·라이프니츠·칸트·제임스로 이어지는 의식 문제의 계보

### Chapter 2: 설명적 간극의 구조 (6개 문서)
- **Levine의 원래 논문** — "Materialism and Qualia: The Explanatory Gap"(1983)의 핵심 주장
- **"H₂O = 물"과 "C섬유 = 고통"의 차이** — 전자는 왜 설명적이고 후자는 왜 단순한 동일화인가
- **현상 개념의 특수성** — 우리가 경험을 기술할 때 쓰는 개념이 왜 물리 개념과 다른 종류인가
- **상상 가능성과 설명 가능성** — 물리 기질 없이 경험만 있는 상황이 왜 상상 가능한가
- **간극의 인식론적 vs 존재론적 해석** — 간극이 우리의 인식 한계인가, 실재의 구조인가
- **간극의 현재 위상** — 어떤 철학자가 어떤 입장에서 간극을 어떻게 다루는가

### Chapter 3: 좀비 논변 — 단계별 해부 (6개 문서)
- **철학적 좀비란** — 물리적으로 나와 동일하지만 경험이 없는 존재, 정확한 설정
- **논변의 형식적 구조** — P1·P2·C의 정확한 형식화, 각 전제의 의미
- **P1 공격: 좀비는 개념적으로 불가능** — 물리주의 내에서 좀비 개념이 왜 정합적이지 않은가
- **P2 공격: 개념 가능 ≠ 형이상학 가능** — 2차원 의미론과 필연성의 종류
- **결론의 범위 제한** — 논변이 물리주의의 어떤 버전을 거부하는가
- **논변의 현재 위상** — 어떤 반론이 가장 강력하고, 왜 논쟁이 닫히지 않는가

### Chapter 4: 물리주의의 전략들 (6개 문서)
- **동일론의 가장 단순한 버전** — 경험 = 물리 상태, 왜 직관적이지만 불완전한가
- **유형 동일론 vs 사례 동일론** — 두 버전의 차이와 각각의 문제
- **비환원적 물리주의** — 경험은 물리에 수반되지만 물리로 환원되지 않는다
- **수반론의 문제** — 수반이 설명 관계가 아니라는 것, 수반론이 어떻게 간극을 봉합하지 못하는가
- **현상 개념 전략** — 간극은 개념의 문제이지 실재의 문제가 아니다(Papineau·Loar)
- **현상 개념 전략의 한계** — 왜 이 전략이 대부분의 비물리주의자를 설득하지 못하는가

### Chapter 5: 물리주의를 넘어서 (5개 문서)
- **속성 이원론** — 물리 기질은 하나, 속성은 둘(물리·현상), 간극을 실재의 구조로 인정
- **범심론** — 경험이 물리 세계의 근본 속성, Philip Goff의 현대 버전
- **신비주의(Mysterianism)** — 인간 인지 능력의 한계로 어려운 문제는 원리적으로 풀 수 없다(McGinn)
- **제거주의** — 경험의 주관성은 착각이다, 간극은 잘못된 틀에서 생긴다(Dennett)
- **전략들의 비용 비교** — 어떤 전략이 어떤 비용을 지불하는가, 어느 것이 덜 나쁜가

### Chapter 6: 어려운 문제와 과학 (5개 문서)
- **"과학이 발전하면 풀린다"는 낙관론** — 이 낙관론의 근거와 구체적 한계
- **어려운 문제의 불용해성 주장** — 왜 물리주의 내에서 어려운 문제가 원리적으로 불용해일 수 있는가
- **신경과학이 줄 수 있는 것** — NCC·의식 이론·측정이 어려운 문제에 어떤 압박을 가하는가
- **어려운 문제와 AI** — 인공 시스템의 의식 가능성에서 어려운 문제가 어떤 역할인가
- **이 연구소가 존재하는 이유** — L0~L6의 구조가 왜 어려운 문제의 지형을 반영하는가

### Chapter 7: 종합·탐구 (5개 문서)
- **논변 지도 시각화** — 어려운 문제를 둘러싼 주요 입장·논변·반론의 관계도(Python/Mermaid)
- **입장별 예측 비교표** — 각 입장이 어떤 경험적·사고실험적 결과를 예측하는가
- **개념 분석 도구** — 주요 개념(수반·환원·설명·동일성)의 정밀한 정의와 관계 시각화
- **간극 측정 시뮬레이션** — 설명 거리를 정보이론적으로 근사화하는 시도(Python)
- **종합** — "왜 거기에 느낌이 있는가"를 둘러싼 현재 상태의 정직한 지도

```markdown
## 🎯 핵심 질문      — 어떤 의식/경험 현상을, 어떤 철학적 분석 틀에서 다루나
## 🌍 어디서 마주치나  — 어려운 문제가 살아있는 장면 (임상·AI·일상의 경이감)
## 🔍 직관의 함정     — "뇌가 의식을 만든다 = 완전한 설명"·"간극은 착각" 같은 단순화
## ⚙️ 논증 해부      — 좀비·메리·간극의 전제-결론 구조를 단계별로
## 🧪 사고실험·사례   — 철학적 논변이 어떤 직관을 끌어내는가, 어떤 실험이 연관되는가
## 🌉 설명적 간극     — 이 문서의 핵심: 간극이 정확히 어디에 있고 어떤 구조인가
## 🧬 횡단 원리       — 표상·예측·자기참조가 어려운 문제와 어떻게 연결되는가
## 🪞 1인칭           — 어려운 문제가 실감되는 방식: 경험이 있다는 것이 어떻게 느껴지는가
## 📐 예측·반증       — 각 입장이 내놓는 반증 가능한 예측 비교
## 🤔 다음 질문       — 다음 문서/레이어로의 연결

---
🧩 **Principle** — (이 논변·입장이 어려운 문제에 어떻게 응답하는가)
🌉 **Boundary**  — (어려운 문제의 정확한 위치: 어떤 설명 전략이 여기서 멈추는가)
🪞 **Experience** — (어려운 문제가 1인칭으로 실감되는 방식)
```

이 레포에서 **🌉 설명적 간극**은 단순히 "어디서 설명이 멈추나"가 아니라 **이 레포의 가장 중요한 섹션**이다. 매 문서에서 간극의 정확한 위치를 다른 언어로 기술한다.

## 🎨 스타일 가이드

1. **어려운 문제를 지우지 않는다** — Dennett식 제거주의를 "해결책"으로 제시하지 않는다. 간극을 실재하는 것으로 다루되, 그것이 무엇을 의미하는지에 대해 열린 자세를
2. **좀비 논변을 형식적으로** — "좀비가 가능한가"를 직관에 맡기지 않는다. 논변의 각 전제를 명시하고, 각 반론이 어느 전제를 공격하는지를 정확하게
3. **입장들에 공정한 최선** — 물리주의·이원론·범심론·신비주의 모두에게 그 입장의 가장 강한 버전을 제시. "이미 논파됐다"는 표현 금지
4. **경이감을 유지한다** — 어려운 문제는 해소될 수 없는 좌절감이 아니라, 실재에 대한 가장 깊은 경이감의 원천임을. "Explain it, don't explain it away"의 의미
5. **1인칭으로 반드시 닫는다** — 모든 논변이 추상적 논의가 아니라 "지금 이것을 읽는 나에게 경험이 있다"는 실감으로 닫힌다
6. 설명 전략 비용 표·논변 구조도·간극의 위치 다이어그램은 필수

import numpy as np
def explanatory_gap_measure(physical_description, phenomenal_description,
                             shared_vocabulary_ratio=0.1):
    """
    물리 기술과 현상 기술 사이의 어휘 공유율이 낮을수록 간극이 크다
    (완전한 측정은 불가능하지만, 구조적 유비로서)
    """
    # 두 기술이 같은 어휘를 얼마나 공유하는가
    gap_metric = 1 - shared_vocabulary_ratio
    # 간극이 크면 설명 관계 확립 어려움
    explanatory_distance = -np.log(shared_vocabulary_ratio + 1e-10)
    return gap_metric, explanatory_distance
