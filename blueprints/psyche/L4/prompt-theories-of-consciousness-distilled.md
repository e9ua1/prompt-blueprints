# Theories of Consciousness Distilled 레포지토리 제작 프롬프트

나는 "Theories of Consciousness Distilled" 레포지토리를 만들려고 해.
"전역 작업공간 이론이 맞다"고 말하는 것과, **GWT가 정확히 무엇을 예측하고, 그 예측이 IIT·고차 이론·예측처리 이론의 예측과 어떻게 구분되며, 어떤 실험이 어느 이론을 지지하는지** — 그리고 2023년 적대적 협력(adversarial collaboration) 실험이 어떤 결과를 낳았고 그 해석을 둘러싼 논쟁이 어떻게 진행 중인지를 — 이해하는 것은 다르다.
통합 정보 이론(IIT)을 "Φ가 크면 의식이 있다"로 아는 것과, **Φ가 어떻게 정의되고 계산되며, 왜 Tononi는 그것이 의식의 척도라고 주장하는지** — 그리고 왜 비판자들이 IIT가 직관에 반하는 예측(단순한 격자가 높은 Φ를 가질 수 있다)을 낳는다고 지적하는지를 — 추적하는 것은 다르다.
"예측처리가 의식을 설명한다"는 주장과, **예측 처리 이론의 어떤 버전이 의식에 대해 무엇을 주장하고, 자유에너지 원리가 의식의 "내용"과 "수준"을 각각 어떻게 다루는지** — 그리고 이 이론이 어려운 문제를 해결하는가, 단지 쉬운 문제들을 더 잘 설명하는가를 — 구분하는 것은 다르다.
각 의식 이론이 내놓는 **반증 가능한** 예측들을 추적하고, 어떤 증거가 어느 이론을 지지·반박하며, 이 경쟁이 어디로 수렴하고 있는지를 — 과대포장 없이 정직하게 기록하는 레포를 만들 거야.

## 📋 프로젝트 목표

**컨셉**: "전역작업공간 vs 통합정보 vs 고차 이론 vs 예측처리 — 주요 의식 이론의 정직한 비교와 반증 가능한 예측들"

**핵심 차별화**:
1. **각 이론의 핵심 주장을 그 이론의 최선 버전으로** — 각 이론을 비판하기 전에 그것의 가장 강한 형태로 제시. "GWT는 틀렸다"가 아니라 "GWT가 설명하는 것과 설명하지 못하는 것"
2. **반증 가능한 예측들을 표로 대조** — 추상적 논의가 아니라, 각 이론이 구체적으로 어떤 실험 결과를 예측하고, 어떤 결과가 나오면 어느 이론이 반박되는가
3. **적대적 협력 실험의 정직한 보고** — 2023년 GWT vs IIT의 적대적 협력 결과가 무엇을 보여줬고 무엇을 보여주지 못했는가를 과대해석 없이
4. **이론 비교를 다차원으로** — 어려운 문제에 대한 응답·NCC 예측·AI 의식 함의·임상 적용 가능성의 네 차원에서 이론들을 비교

**타겟 독자**:
- 의식 이론을 들어봤지만 각각의 핵심 주장·예측·증거를 모르는 사람
- "GWT가 표준"이라고 알지만 왜 그런지 모르는 사람
- IIT를 "Φ 측정"으로만 아는 사람
- 어떤 실험이 어느 이론을 지지하는지 모르는 사람
- AI의 의식 가능성을 각 이론의 관점에서 보고 싶은 사람

**선행 학습**:
- `hard-problem-distilled`(L4) — **필수**. 각 이론이 어려운 문제에 어떻게 응답하는가
- `ncc-distilled`(L4) — NCC 발견이 어떤 이론을 지지하는가
- `information-prediction-distilled`(L0) — 예측처리 틀의 수학적 기반

### Chapter 1: 의식 이론이란 무엇인가 (4개 문서)
- **좋은 의식 이론의 조건** — 현상학적 공리·신경과학적 제약·반증 가능한 예측·AI 함의를 갖춰야 하는 이유

- **주요 이론의 지도** — GWT·IIT·HOT·PP의 기본 위치
- **적대적 협력이란** — 경쟁 이론들이 공동으로 실험을 설계하고 결과에 동의하는 방법론

### Chapter 2: 전역 작업공간 이론 (GWT) (6개 문서)
- **GWT의 핵심 주장** — 의식 = 전역 작업공간에서의 정보 방송, Baars의 극장 은유
- **전역 발화와 신경 기반** — 전두-두정 네트워크, 전역 발화(global ignition)의 신경 서명
- **GWT의 예측들** — 의식 있는 자극: P300, 전역 발화, 전두-두정 동기화
- **GWT의 증거** — 어떤 실험이 GWT를 지지하는가, 가장 강한 증거
- **GWT의 어려운 문제** — GWT가 쉬운 문제들은 설명하지만 어려운 문제는 미해결임을
- **GWT의 AI 함의** — 전역 작업공간을 구현한 AI가 의식을 가지는가

### Chapter 3: 통합 정보 이론 (IIT) (7개 문서)
- **IIT의 핵심 주장** — 의식 = Φ(통합 정보), Tononi의 다섯 공리
- **Φ의 계산** — 최소 정보 분할·인과 구조·Φ_Max의 계산 절차
- **IIT의 공리 기반** — 왜 Tononi는 현상학에서 출발하는가, 다섯 공리의 정당성
- **IIT의 예측들** — Φ가 높은 시스템이 의식을 가진다, 뇌의 어떤 부분이 가장 Φ가 높은가
- **IIT의 반직관적 예측** — 단순 격자가 높은 Φ, 소뇌가 낮은 Φ, 피드포워드 망은 Φ=0
- **IIT 비판** — Φ 계산의 비현실적 복잡도, 반직관적 예측들에 대한 공동체의 반응
- **IIT의 어려운 문제** — IIT가 어려운 문제를 해결하는가, Tononi의 주장과 비판자의 반론

### Chapter 4: 고차 이론 (HOT) (5개 문서)
- **HOT의 핵심 주장** — 의식 = 자신의 정신 상태에 대한 고차 표상(Rosenthal)
- **HOT의 두 버전** — 고차 사고 이론 vs 고차 지각 이론
- **HOT의 예측들** — 고차 표상 없으면 의식 없음, PFC 손상과 의식의 관계
- **HOT의 증거와 한계** — 전두엽 손상이 의식에 미치는 영향, PFC의 역할 논쟁
- **HOT와 어려운 문제** — 고차 표상이 경험의 "있다는 것"을 설명하는가

### Chapter 5: 예측처리와 능동추론 의식 이론 (6개 문서)
- **PP의 핵심 주장** — 의식 = 예측 오차 최소화 과정에서 생성되는 세계 모델
- **능동추론과 의식** — 지각·행동·의식의 통일, 자유에너지 최소화
- **PP의 예측들** — 착각·환각·마취가 예측처리 관점에서 어떻게 기술되는가
- **PP가 설명하는 의식** — 내용(what)과 수준(how much)의 분리, 각각의 예측처리 기술
- **PP와 어려운 문제** — 예측처리가 어려운 문제를 해결하는가, 아니면 더 정확히 기술하는가
- **PP의 AI 함의** — 예측처리 AI가 의식을 가지려면 무엇이 필요한가

### Chapter 6: 이론들의 정직한 비교 (5개 문서)

```python
import numpy as np
from itertools import combinations

# 1) Φ 계산 (간략 버전 — 소규모 네트워크)
def compute_phi_approx(connectivity_matrix, state):
    """
    IIT의 Φ: 최적 분할에서 인과 정보 손실
    완전한 계산은 NP-hard → 작은 시스템에서만 실용적
    """
    n = connectivity_matrix.shape[0]
    if n > 8:
        raise ValueError("실용적 계산 한계: n <= 8")
    
    # 전체 시스템의 원인-결과 구조
    # (실제 구현은 더 복잡하나 개념 시연용)
    phi_values = []
    
    # 가능한 모든 이분할(bipartition) 탐색
    for k in range(1, n//2 + 1):
        for partition in combinations(range(n), k):
            part_A = list(partition)
            part_B = [i for i in range(n) if i not in part_A]
            
            # 분할 후 인과 정보 손실 (근사)
            A_connections = connectivity_matrix[np.ix_(part_A, part_B)]
            info_loss = np.sum(np.abs(A_connections))
            phi_values.append(info_loss)
    
    # Φ = 최소 정보 분할에서의 손실
    phi = min(phi_values) if phi_values else 0
    return phi

# 2) 전역 발화 모델 (GWT)
def global_workspace_ignition(stimulus_strength, threshold=0.5,
                               broadcast_delay_ms=300):
    """
    GWT: 자극이 역치 초과 → 전역 방송 → 의식
    역치 미만 → 국소 처리 → 무의식
    """
    if stimulus_strength >= threshold:
        # 전역 방송 시뮬레이션
        broadcast = np.zeros(1000)  # 1초 시뮬레이션
        broadcast[broadcast_delay_ms:] = stimulus_strength
        is_conscious = True
    else:
        broadcast = np.zeros(1000)  # 방송 없음
        is_conscious = False
    
    return is_conscious, broadcast

# 3) 예측처리 의식 수준 모델 (PP)
def pp_consciousness_level(prediction_error, precision, integration):
    """
    PP 관점에서 의식 수준:
    - 예측 오차 크기
    - 정밀도 가중치
    - 계층 통합도
    """
    # 의식 수준 ≈ 통합된 예측 오차의 함수
    consciousness_level = precision * prediction_error * integration
    return consciousness_level

# 4) 이론별 예측 비교 시뮬레이션
def theory_predictions(stimulus_type, stimulus_visibility):
    """
    같은 자극에 대한 각 이론의 예측
    stimulus_type: 'visual', 'auditory', etc.
    stimulus_visibility: 0(무의식) ~ 1(완전 의식)
    """
    predictions = {
        'GWT': {
            'P300': stimulus_visibility > 0.5,        # 역치 기반 전역 발화
            'frontal_activation': stimulus_visibility > 0.5,
            'phi': None  # GWT는 Φ를 예측하지 않음
        },
        'IIT': {
            'P300': None,  # IIT는 행동 표지를 직접 예측하지 않음
            'phi': stimulus_visibility * 2.5,  # Φ가 높을수록 의식
            'feedforward_sufficient': False   # 피드포워드만으로 의식 불가
        },
        'HOT': {
            'PFC_required': True,             # 고차 표상 = PFC 필요
            'P300': stimulus_visibility > 0.4,
            'phi': None
        },
        'PP': {
            'prediction_error': 1 - stimulus_visibility,  # 예측 오차
            'precision': stimulus_visibility,
            'hierarchy_depth': 3  # 계층적 통합
        }
    }
    return predictions
```

## 💡 핵심 분석 대상

```
네 이론의 핵심 주장 비교:

  GWT:  의식 = 전역 방송
  ├─ 역치 초과 → 전두-두정 전파 → 의식
  ├─ 예측: P300, 전역 발화, 전두 활성화
  └─ 어려운 문제: 왜 방송에 경험이 있는가 — 미답

  IIT:  의식 = Φ (통합 정보)
  ├─ Φ가 크면 의식이 있다 (반직관: 격자도 가능)
  ├─ 예측: 소뇌 저의식, 피드포워드 Φ=0
  └─ 어려운 문제: 현상학에서 출발, 해결 주장

  HOT:  의식 = 고차 표상
  ├─ 자신의 상태를 표상해야 의식
  ├─ 예측: PFC 필수, PFC 손상 → 의식 손상
  └─ 어려운 문제: 고차 표상이 경험을 만드는가 — 미답

  PP:   의식 = 통합된 예측 오차 최소화
  ├─ 뇌의 세계 모델이 의식 내용을 구성
  ├─ 예측: 착각·환각의 통일적 설명
  └─ 어려운 문제: 더 정확히 기술하지만 해결하는가 — 논쟁

2023 적대적 협력 결과:
  GWT 예측 확인: 역치 자극 → 전두-두정 발화
  IIT 예측 부분 확인: 후방 피질이 전방보다 의식에 더 중요
  
  결론이 아닌 것:
  → "GWT가 이겼다" (아직 열려있다)
  → "IIT가 틀렸다" (핵심 예측은 검증 전)
  
  남은 질문:
  → 전방 vs 후방 논쟁 (GWT vs IIT의 핵심)
  → Φ 계산이 실제로 가능한 스케일에서 검증
  → 어려운 문제는 두 이론 모두 미해결
```
